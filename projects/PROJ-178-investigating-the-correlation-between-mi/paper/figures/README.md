# Final Figures

This directory contains the final figures generated by task T046.

## Generated Artifacts

- `linear_fit_age_burden.png`: Scatter plot of Age vs. Heteroplasmy Burden with a linear regression line.
- `threshold_sensitivity.png`: Line plot showing the Spearman correlation coefficient across different VAF thresholds (0.5%, 1.0%, 2.0%).

## Generation

These figures are generated by running:
```bash
python code/analysis/plot_final_figures.py
```

Prerequisites:
- `code/data/processed/mito_aging_dataset.csv` (from T018/T020)
- `code/data/processed/sensitivity_results.csv` (from T032)
