# Implementation Plan: llmXive follow-up: extending "Achieving Gold-Medal-Level Olympiad Reasoning via Simple and Unified S"

**Branch**: `001-llmxive-followup` | **Date**: 2026-07-14 | **Spec**: `spec.md`

## Summary

This project investigates whether the "reverse-perplexity" curriculum used to train Olympiad-level models (SU-01) induces rigid heuristics that degrade performance on open-ended, ill-structured scientific problems. The technical approach involves: (1) downloading verified Olympiad datasets (IMO/IPhO) and constructing a synthetic "OpenSci-Reason" dataset from open scientific abstracts; (2) running CPU-only inference for SU-01 and a baseline model; (3) scoring open-ended responses using a frozen, INT4-quantized Llama-3-8B proxy model; and (4) performing statistical correlation and t-tests to quantify the trade-off between Olympiad accuracy and scientific creativity.

## Technical Context

**Language/Version**: Python 3.11  
**Primary Dependencies**: `transformers`, `datasets`, `torch` (CPU-only), `scikit-learn`, `pandas`, `pyyaml`, `pytest`  
**Storage**: Local JSONL files (`data/raw/`, `data/processed/`), HuggingFace cache  
**Testing**: `pytest` (unit tests for parsing/scoring logic, integration tests for pipeline)  
**Target Platform**: GitHub Actions Free Tier (Linux, 2 CPU, 7GB RAM, no GPU)  
**Project Type**: Research Pipeline / CLI  
**Performance Goals**: Complete full pipeline (500 prompts, 2 models, 3 samples each) within 6 hours; memory peak < 7GB.  
**Constraints**: CPU-only inference; INT4 quantization required for Llama-3-8B scoring model; no proprietary data access.  
**Scale/Scope**: 500 OpenSci prompts; 2 models; 3 candidate responses per prompt.

> Note: Dataset sizes and empirical values are deferred to `research.md`.
