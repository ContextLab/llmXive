# Specification Amendment Draft

This document records proposed amendments to the original specification for the
*Quantifying the Impact of Data Cleaning on Statistical Inference* project.
It aggregates earlier amendment proposals (SC‑006, FR‑007, SC‑008, etc.) and
introduces the new functional requirement FR‑008 concerning stratification.

## Proposed Functional Requirement FR-008: Stratification

**Statement**
The analysis pipeline shall support systematic stratification of datasets based on
(a) **Missingness rate** and (b) **Dataset size**. For each stratum the pipeline must
compute baseline and cleaned statistical metrics (p‑values, confidence‑interval
widths, effect‑size deltas) and report per‑stratum summaries.

**Missingness‑rate bins** (applied to each dataset before cleaning):
- `0%`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          ――

### Functional Requirement Details

**FR‑008: Stratification**
*The pipeline shall stratify datasets based on missingness rate and dataset size to enable sensitivity analysis.*

- **Missingness Rate Bins**:
 1. `0%` – No missing values.
 2. `≤5%` – Low missingness.
 3. `≤10%` – Moderate missingness.
 4. `>10%` – High missingness.
 Datasets are assigned to the first bin that their proportion of missing outcome values satisfies.

- **Dataset Size Bins**:
 1. `n < 50` – Small dataset.
 2. `50 ≤ n ≤ 200` – Medium dataset.
 3. `n > 200` – Large dataset.
 `n` is the number of rows after cleaning.

- **Implementation Notes**:
 * The functions in `code/reporting.py` and `code/sensitivity.py` will compute metrics for each stratum.
 * If a bin contains no datasets, a warning `"Missingness bin empty: bin <X> has no datasets"` or `"Dataset size bin empty: bin <Y> has no datasets"` will be logged, and processing will continue.
 * Stratification results are stored in `data/processed/stratified_metrics.json` and used for downstream visualizations (forest plot, heatmap).

- **Rationale**:
 Stratification allows the research to assess how the impact of cleaning strategies varies with data quality and sample size, addressing reviewer concerns about robustness and generalizability.
