# Phenomenological AI: First-Person Experience Modeling - Quick Start

This guide provides the essential setup and usage instructions for the Phenomenological AI pipeline.
The pipeline generates phenomenological reports, computes validity metrics, and performs statistical analysis
on CPU-tractable models.

## Prerequisites

- Python 3.10+
- 16GB+ RAM (for local model execution)
- Internet connection (for dataset/model downloads)

## Environment Setup

1. **Clone and Install**
 ```bash
 git clone <repository-url>
 cd PROJ-592-phenomenological-ai-first-person-experie
 python -m venv.venv
 source.venv/bin/activate # On Windows:.venv\Scripts\activate
 pip install -r requirements.txt
 ```

2. **Download Models (Optional for CI, Required for Local)**
 The primary CI path uses `TheBloke/TinyLlama-1.1B-Chat-v1.0-GGUF`.
 For local reproduction, download `phi-2.Q4_K_M.gguf` from Hugging Face.
 Ensure models are placed in `data/models/` or configured in `code/config.py`.

3. **Initialize Project Structure**
 ```bash
 python scripts/init_project.py
 ```

## CLI Usage Examples

The main entry point is `code/main.py`. It supports three primary modes:

### 1. Generation Mode
Generates the corpus of phenomenological reports using the TinyLlama model.
This runs the four prompting strategies (Direct, Hypothetical, Comparative, Role-play).

```bash
python code/main.py --mode generation --config code/config.py --limit 100
```

- `--mode generation`: Triggers the generation pipeline.
- `--config`: Path to the configuration file.
- `--limit`: Number of samples to generate per strategy (default: 80).

Output: `data/raw/generation_batch_*.json` files.

### 2. Analysis Mode
Computes validity metrics (Internal Consistency, Semantic Stability, Marker Presence)
and performs statistical analysis (ANOVA/Kruskal-Wallis, FDR correction).

```bash
python code/main.py --mode analysis --config code/config.py
```

- `--mode analysis`: Triggers the metric computation and statistical orchestration.
- Requires `data/processed/merged_dataset.csv` to exist (generated by `generation` + `control` phases).

Output: `data/processed/validity_scores.csv`, `data/processed/stats_report.json`.

### 3. Validation Mode
Facilitates human evaluation by selecting a stratified sample and preparing rating sheets.

```bash
python code/main.py --mode validate --config code/config.py
```

- `--mode validate`: Runs stratified sampling and prepares data for human raters.
- Requires generated reports to exist.

Output: `data/qualitative/sampling_list.csv`, `data/qualitative/ratings.csv` (after human input).

## Full Pipeline Execution

To run the entire pipeline end-to-end (Generation → Control → Analysis → Validation):

```bash
python code/main.py --mode full --config code/config.py
```

This command orchestrates all phases sequentially. Ensure sufficient disk space and time
(typically 4-6 hours on CPU for the full dataset).

## Verification

After running the pipeline, verify the outputs:

```bash
# Check generation counts
python -c "import json, glob; data=[json.load(open(f)) for f in glob.glob('data/raw/generation_batch_*.json')]; counts={s:sum(1 for d in data if d['strategy']==s) for s in set(d['strategy'] for d in data)}; print(counts); assert all(c>=80 for c in counts.values())"

# Check stats report
python -c "import json; r=json.load(open('data/processed/stats_report.json')); print('ANOVA p-value:', r.get('anova', {}).get('p_value')); print('Kruskal p-value:', r.get('kruskal', {}).get('p_value'))"
```

## Troubleshooting

- **Model Not Found**: Ensure `data/models/` contains the required GGUF files or update `code/config.py` with the correct path.
- **Dataset Not Found**: The control corpus uses `arxiv_nlp` (or similar). If this dataset is unavailable, update `code/generation/control_corpus.py` to use a verified alternative (e.g., `tech_reports` or a direct CSV).
- **CUDA Errors**: This pipeline is designed for CPU. If you see CUDA errors, ensure `llama-cpp-python` was installed with CPU-only flags or check your `config.py` model path.

## Reproducibility

To archive all artifacts for public reproducibility:

```bash
python code/utils/archiver.py --output archive.zip
```

This packages prompts, seeds, scripts, and anonymized ratings.
