# Quickstart: Autocorrelation of the Möbius Function in Short Intervals

## Prerequisites
- **Git** (≥ 2.30)  
- **Python** 3.11 (default on GitHub Actions runners)  
- **Disk space**: at least 1 GB free (the full pipeline uses < 500 MB)  
- Internet access for installing packages from PyPI.

## Installation
```bash
# Clone the repository (replace <repo-url> with the actual URL)
git clone <repo-url>
cd autocorr-mobius
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Running the Full Pipeline
```bash
python code/main.py
```
`main.py` orchestrates all stages with fault isolation:

1. **Sieve & Packing** – creates `data/raw/mobius_array.npy` & `data/raw/mobius_2bit.npy`.  
2. **Window Sampling** – writes `data/processed/window_index.csv`.  
3. **Demo Autocorrelation** – produces a single‑row CSV `data/processed/demo_autocorr.csv` (expected **≈ −0.047047** with ≥ 6 decimal places).  
4. **Raw Autocorrelation** – computes autocorrelation for all windows and lags, writing `data/processed/autocorrelation_raw.csv` (≈ 5.5 M rows).  
5. **Cross‑validation** – verifies cross‑validation status is recorded in `data/processed/pipeline_status.json`.  
6. **Permutation Null** – builds a per‑length null from the **first 20 windows** per length using **500 permutations** each, then computes p‑values and confidence intervals for **all 300 windows**, producing `data/processed/autocorrelation_stats.csv`.  
7. **FDR Correction** – adds the `adjusted_p_value` column to the stats CSV.  
8. **Calibration** – runs the null‑calibration checks and writes `data/processed/calibration_test.json`.  
9. **Sensitivity Analysis** – creates `data/processed/sensitivity_summary.csv` with flags for zero‑density adjustments.  
10. **Visualization** – generates heatmap PNGs `outputs/figures/heatmap_L1000.png`, `heatmap_L10000.png`, `heatmap_L100000.png` (≥ 1200 × 1200 px).  
11. **Checksum Manifest** – writes `data/checksums/manifest.sha256` containing SHA‑256 hashes of all output files.  
12. **Orchestration** – the pipeline exits with a successful status and a concise JSON summary in `data/processed/pipeline_status.json`.

### Expected Results
- `demo_autocorr.csv` contains one row with `autocorrelation` ≈ −0.047047047047 (six‑decimal precision).  
- `autocorrelation_raw.csv` contains ≈ 5.55 million rows (all windows, all lags).  
- `autocorrelation_stats.csv` includes columns `p_value`, `ci_lower`, `ci_upper`, **`adjusted_p_value`**.  
- Heatmaps show a zero contour line and 95 % confidence bands; significant cells are marked in red.  
- All SHA‑256 checksums match the recorded values in `manifest.sha256`.

If any stage **fails** (e.g., due to insufficient memory, missing files), the pipeline logs the error **as a JSON entry** in `pipeline_status.json` and continues with independent stages where possible.
