## Unresolved concerns

- Only 20 non‑overlapping windows per interval length (total 60 windows) are sampled. Given the high variability of autocorrelation statistics, this sample size provides limited power to detect small deviations from zero, especially after Benjamini‑Hochberg correction across ~3 600 lag‑tests.
- The null distribution is generated by permuting blocks of size b = 100 while preserving intra‑block order. This block‑permutation does not fully randomize the sign pattern and may retain residual autocorrelation structure, biasing the null distribution and inflating type‑I error rates.
- Using only 1 000 permutations yields a minimum p‑value resolution of 0.001. Combined with Benjamini‑Hochberg correction over thousands of lag‑tests, the procedure may be overly conservative, further reducing the ability to identify genuine signals.
- The plan proposes 1,000 block‑permutations per window and computes autocorrelations for all lags h ≤ L/2 within each permutation (e.g., up to 50,000 lags for L=10⁵). This results in on the order of 1 billion autocorrelation calculations across all windows, which is unlikely to complete within the 6 h GitHub Actions free‑tier limit using CPU‑only NumPy vectorisation. The runtime estimate of ~2.5 h appears overly optimistic and does not account for the massive per‑permutation, per‑lag computation. This makes the approach infeasible under the free‑compute constraints.
- Data model states 'Row count: ≈ 3 600 (20 windows × 3 lengths × average ≈ 60 lags)', but the implementation plan computes autocorrelations for all lags h ≤ L/2, which yields far more rows (e.g., for L=10⁵, 20 × 50 000 = 1 000 000 rows). This discrepancy means the data‑model’s row‑count estimate and “average ≈ 60 lags” are inconsistent with the plan’s detailed lag range.
- The null distribution is generated by **block‑permutations** of size b = 100 that preserve intra‑block order. Because autocorrelation depends on the relative ordering of adjacent values, preserving block structure leaves residual dependence that is not independent of the observed autocorrelation. Consequently, the p‑values derived from this null model are not truly independent of the predictor (the observed sequence), creating a circular/tautological validation of the random‑sign hypothesis.
