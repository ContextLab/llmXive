# PROJ-177: Investigating the Validity of the Equipartition Theorem in Driven Granular Systems

## Project Structure
- `code/`: Python modules for ingestion, analysis, and reporting.
- `data/`: Raw and derived data files.
- `artifacts/`: Logs, hashes, and statistical reports.
- `tests/`: Test suites.

## Quickstart
Run the pipeline:
```bash
python code/main.py --stage all --sample-ratio 0.1
```
