# Data Lineage: Equipartition Theorem Investigation

This document explicitly traces the flow of data from the raw source through the
intermediate processing steps to the final statistical results. It documents the
specific sampling rules, exclusion criteria, and transformation logic applied in
this run.

## 1. Raw Data Source

The analysis originates from a real, external dataset hosted on **Zenodo** (or UCI).
The specific source is configured in `data/config.yaml` under the `data_source` section.

- **Source Type**: `zenodo` (or `uciml`)
- **Source ID**: *(Resolved from `DATA_SOURCE_ID` environment variable or curated default)*
- **Raw File Path**: `data/raw/<dataset_name>.csv`
- **Checksum**: SHA-256 hash recorded in `state/checksums.yaml` (generated by `code/checksum_raw_data.py`).

## 2. Ingestion and Preprocessing

### 2.1 Loading and Sampling
- **Script**: `code/ingestion.py` (Function: `load_and_sample`)
- **Logic**:
 1. Reads the raw CSV.
 2. Applies sampling if the dataset exceeds 1M rows or 14GB.
 3. **Sampling Rule**: If sampling is triggered, the first $N$ rows are selected using `itertools.islice` (or a fixed-seed random sample).
 4. The specific seed and sample count are recorded in `artifacts/sampling_metadata.json`.
- **Output**: A synchronized DataFrame containing particle tracking data and driving signals.

### 2.2 Synchronization and Interpolation
- **Script**: `code/ingestion.py` (Functions: `sync_timestamps`, `handle_missing_frames`)
- **Logic**:
 - Aligns particle positions with driving signal timestamps.
 - **Missing Frames**: Linear interpolation is applied for gaps $\le$ threshold. Gaps $>$ threshold are flagged in a `gap_flag` column.
 - **Missing Z-Axis**: If z-axis data is absent, a `pot_incomplete` boolean is set to `True`.

### 2.3 Energy Calculation
- **Script**: `code/ingestion.py` (Function: `calculate_energy_components`)
- **Formulas**:
 - **Translational**: $E_{trans} = 0.5 \cdot m \cdot v^2$
 - **Rotational**: $E_{rot} = 0.5 \cdot I \cdot \omega^2$
 - **Potential**: $E_{pot} = m \cdot g \cdot z$
 - **Vibrational**: $E_{vib} = m \cdot \text{var}(a)$ (Variance of acceleration over a sliding window $N=5$, scaled by mass).
- **Output**: `data/derived/energy_samples.csv`
 - **Columns**: `particle_id`, `timestamp`, `E_trans`, `E_rot`, `E_pot`, `E_vib`, `pot_incomplete`.
 - **Hash**: SHA-256 of this file is stored in `artifacts/energy_samples.hash`.

## 3. Non-Stationary Signal Handling (Chirp)

### 3.1 Detection and Masking
- **Script**: `code/ingestion.py` / `code/stats.py`
- **Logic**:
 - Computes instantaneous frequency via Hilbert transform.
 - Flags segments where frequency variance $> 5\%$ of the mean.
- **Output**: `artifacts/chirp_mask.csv`
 - **Usage**: Rows flagged in this mask are **excluded** from statistical analysis unless `--chirp-handling=bin` is specified.

### 3.2 Alternative Binning (Optional)
- If `--chirp-handling=bin` is used, data is binned into dynamic frequency intervals.
- **Output**: `artifacts/instantaneous_freq_bins.csv`.

## 4. Statistical Analysis

### 4.1 Binning and Testing
- **Script**: `code/stats.py`
- **Input**: `data/derived/energy_samples.csv` (filtered by `chirp_mask.csv` or binned).
- **Logic**:
 - Bins data by driving frequency and material type.
 - Performs Kolmogorov-Smirnov (KS) and Chi-squared tests against the Maxwell-Boltzmann distribution.
 - Applies Benjamini-Hochberg FDR correction.
- **Output**: `artifacts/statistical_results.json`
 - **Contents**: Test statistics, raw/corrected p-values, rejection flags, and effective sample size ($n_{samples}$) per bin.

## 5. Sensitivity and Regression

### 5.1 Sensitivity Analysis
- **Script**: `code/sensitivity.py`
- **Input**: `artifacts/statistical_results.json`
- **Logic**: Sweeps $\alpha \in \{0.01, 0.05, 0.10\}$ and quasi-thermal boundaries.
- **Output**: `artifacts/sensitivity_analysis_report.json`, `artifacts/stability_check.json`.

### 5.2 Regression Analysis
- **Script**: `code/regression.py`
- **Input**: `artifacts/statistical_results.json`
- **Logic**: Fits linear model (Deviation vs. Frequency/Roughness).
- **Output**: `artifacts/regression_results.json`, `artifacts/regression_validity_check.json`.

## 6. Summary of Exclusion Criteria

The following criteria were applied to exclude data from the final statistical inference:

1. **Chirp Segments**: Frames where instantaneous frequency variance $> 5\%$ of the mean (see `artifacts/chirp_mask.csv`).
2. **Missing Z-Axis**: If `pot_incomplete` is `True`, potential energy is marked as incomplete (handled via flag, not necessarily exclusion, but noted).
3. **Sampling**: If the dataset was too large, a subset was taken. The excluded rows are not represented in the analysis (see `artifacts/sampling_metadata.json`).
4. **Empty Bins**: Frequency/Material bins with $n_{samples} < 5$ (after Chi-squared adjustment) are excluded from the final rejection count.

## 7. Reproducibility

To reproduce this exact lineage:
1. Set `DATA_SOURCE_ID` to the value recorded in `data/config.yaml`.
2. Run `python code/main.py --stage all` (or specific stages).
3. Verify `artifacts/sampling_metadata.json` matches the recorded seed and rule.
4. Verify `state/checksums.yaml` matches the raw data hash.
