### Restated research question (v4)

> **Do cheap structural summary features of text, distilled into a compact model, add predictive value beyond dense text features for the dataset’s overlap/CPU‑score label?**

### Hypothesis structure (v4)

* Primary hypothesis: the augmented representation (text embedding ⊕ **orthogonalized** predicted structural latent) yields a statistically significant improvement over a per‑seed re‑trained text‑only baseline (paired t‑test, Bonferroni‑corrected α = 0.025).  
* Sanity check: MSE convergence of the distilled student vs. a frozen‑random‑head student (downgraded to feasibility only).  
* Ablation: incremental predictive value of the latent alone (FR‑008 reframed).  
* **Control**: a random‑latent model (predicts random vectors) to isolate any gain due to latent redundancy.

**Statistical rigor**: primary hypothesis + ablation + random‑latent control = 3 tests; Bonferroni α = 0.025. Normality checked (Shapiro‑Wilk); Wilcoxon fallback. Power limitation acknowledged (seed count = 10). All claims associational (FR‑006). Collinearity addressed via orthogonalization; residual correlation reported.  

**Compute feasibility**: all steps are classical ML / small Torch CPU models over a single parquet; comfortably within 2 CPU cores, ≤7 GB RAM, ≤6 h. No GPU escape hatch needed.

## Complexity Tracking

| Violation | Why Needed | Simpler Alternative Rejected |
|---|---|---|
| FR‑001 visual‑encoder component dropped | No verified dataset provides images + layout; fabricating would violate the fabrication gate. | Synthesizing images/latents would be fabrication. |
| Collinearity between text embedding & latent | Latent is deterministic function of text; without orthogonalization gains could be spurious. | Ignoring collinearity would threaten construct validity. |
| Seed count unspecified | Paired tests need enough replication; fixed to 10 seeds for modest power. | Leaving it undefined would make the test under‑powered. |
| FR‑008 independence ablation reframed | True independence impossible; we instead test incremental predictive value. | Claiming independence would be unsupported. |
| SC‑001 downgraded to sanity check | Deterministic target makes MSE convergence trivial; not hypothesis evidence. | Using it as primary evidence would be circular validation. |
