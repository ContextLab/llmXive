# llmXive Research Pipeline Code

This directory contains the implementation code for the llmXive automated science pipeline.

## Structure

- `data/`: Data loading, processing, and validation utilities.
- `models/`: Model runners, wrappers, and inference logic.
- `experiments/`: Experiment orchestration, batching, and execution scripts.
- `analysis/`: Statistical analysis, GLM modeling, and result interpretation.
- `tests/`: Unit and integration tests.

## Setup

1. Install dependencies: `pip install -r requirements.txt`
2. Configure environment variables (see `config.py` for details).
3. Run experiments via scripts in `experiments/`.
