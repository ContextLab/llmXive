# Data Model Specification

This document defines the data structures, schemas, and file formats used in the `llmXive` project.

## Core Entities

### TaskInstance
Represents a single software engineering task from the Claw-SWE-Bench dataset.

| Field | Type | Description |
|:--- |:--- |:--- |
| `issue_id` | str | Unique identifier for the issue. |
| `repo_state` | dict | Snapshot of the repository state (files, imports). |
| `tests` | list | List of test cases associated with the issue. |
| `issue_text` | str | Raw description of the issue. |
| `relevant_files` | list[str] | List of file paths relevant to the issue. |

**Source**: `code/config.py` (Class `TaskInstance`)
**Schema**: `specs/001-context-fidelity-scaling-tradeoff/contracts/task_instance.schema.yaml`

### ContextConfiguration
Defines the parameters for context construction.

| Field | Type | Description |
|:--- |:--- |:--- |
| `model_size` | str | Size of the model (e.g., "1B", "7B"). |
| `strategy` | str | Context compression strategy (e.g., "naive", "tfidf", "diff_aware", "semantic"). |
| `token_budget` | int | Maximum number of tokens allowed in the context. |

**Source**: `code/config.py` (Class `ContextConfiguration`)
**Enum**: `StrategyType` (naive, tfidf, diff_aware, semantic)

### ExecutionResult
The output of running a task instance with a specific model and context.

| Field | Type | Description |
|:--- |:--- |:--- |
| `issue_id` | str | Reference to the TaskInstance. |
| `pass_status` | bool | Whether the task passed (True/False). |
| `token_count` | int | Actual number of tokens used in the context. |
| `failure_mode` | str | Classification of failure (e.g., "missing_context", "reasoning_error", "resource_constraint"). |
| `strategy` | str | The context strategy used. |
| `model_size` | str | The model size used. |
| `latency_seconds` | float | Execution time. |

**Source**: `code/config.py` (Class `ExecutionResult`)
**Schema**: `specs/001-context-fidelity-scaling-tradeoff/contracts/execution_result.schema.yaml`

## Data Artifacts

### Raw/Intermediate JSONL Files
Generated by experiment scripts. One JSON object per line.

- `data/intermediate/baseline_run.jsonl`: Results from T019 (1B model, naive strategy).
- `data/intermediate/hf_run_1b.jsonl`: Results from T028 (1B model, high-fidelity strategies).
- `data/intermediate/hf_run_7b.jsonl`: Results from T031 (7B model, high-fidelity strategies).

**Format**:
```json
{"issue_id": "123", "pass_status": true, "token_count": 4096, "failure_mode": null, "strategy": "tfidf", "model_size": "1B", "latency_seconds": 12.5}
```

### Aggregated Results (CSV)
Generated by `analysis/merge_results.py`.

- `data/results.csv`: Consolidated view of all experiments.

**Columns**: `issue_id`, `pass_status`, `token_count`, `failure_mode`, `strategy`, `model_size`, `latency_seconds`, `validation_score` (optional).

### Analysis Outputs (JSON)
- `data/analysis/post_hoc_results.json`: Pairwise comparison results from GLM analysis.
- `data/validation_report.json`: Validation metrics for issue text sufficiency.

## Schemas

All entity schemas are defined in YAML format under `specs/001-context-fidelity-scaling-tradeoff/contracts/`.

### task_instance.schema.yaml
Defines the structure of input task instances.

### context_configuration.schema.yaml
Defines the structure of configuration parameters.

### execution_result.schema.yaml
Defines the structure of experiment outputs.

## Dependencies

- **Hugging Face Datasets**: Used for streaming `ClawSweBench` data.
- **NetworkX**: Used for dependency graph traversal in `loader.py`.
- **Scikit-Learn**: Used for TF-IDF vectorization in `context_processors.py`.
- **Statsmodels**: Used for GLM analysis in `glm_analyzer.py`.
