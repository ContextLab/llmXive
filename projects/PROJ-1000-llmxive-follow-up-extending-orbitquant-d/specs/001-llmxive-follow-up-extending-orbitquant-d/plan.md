## Summary

This feature implements a dynamic rotation router for Diffusion Transformers (DiT) to improve W2A4 quantization fidelity. The approach empirically validates a correlation between **prompt semantic entropy** (derived from MS-COCO image captions) and **intermediate activation variance** (measured during the **generative trajectory** of a DiT conditioned on those captions). 

**Critical Methodological Correction**: The DiT is run in **text-to-image generation mode** using the caption as the sole conditioning input. The "Activation Variance" is measured from the intermediate latents generated by the DiT in response to the prompt. The ground-truth MS-COCO images are used **only** for the final FID/CLIP evaluation, not as conditioning inputs during the activation measurement phase. This ensures the (x, y) data point is a valid pair: (Prompt Entropy, Activation Variance of the generation driven by that prompt).

If a correlation exists, the system clusters prompts by entropy into $K=16$ bins (using an [deferred] training split), derives pre-optimized rotation matrices for each bin from the activation histograms of the corresponding generated trajectories, and at inference, a lightweight proxy computes the prompt's entropy to select the optimal matrix. This reduces quantization error for high-entropy prompts while maintaining the static baseline's efficiency.

## Complexity Tracking

| Violation | Why Needed | Simpler Alternative Rejected Because |
|-----------|------------|-------------------------------------|
| **GPU Escape Hatch** | Float generation passes on DiT (FLUX/Wan) exceed available CPU RAM capacity. | A synthetic CPU approximation of the DiT generation pass would be fabrication; the real computation must be offloaded to Kaggle. |
| **Semantic Entropy Proxy** | Full LLM inference for every prompt is too slow for large batches of prompts on CPU. | Using a fixed heuristic for entropy (e.g., string length) fails to capture *semantic* complexity, invalidating the core hypothesis. |
| **Clustering (K=16)** | Requires analyzing activation histograms across the dataset. | A static rotation (K=1) is the baseline; K=16 is necessary to test the dynamic hypothesis. |
| **Train/Test Split** | Required to avoid circular validation (concern scientific_soundness-e46de492). | Using the full dataset to both derive bins and validate the router would result in tautological performance claims. |
