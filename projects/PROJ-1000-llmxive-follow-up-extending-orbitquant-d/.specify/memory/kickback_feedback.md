## Unresolved concerns

- The plan claims that 200 stratified prompts provide >80 % power to detect |r| ≥ 0.2 at α = 0.05. A power analysis for Pearson correlation shows that detecting r = 0.2 with 80 % power requires roughly 750–800 samples, not 200. The stated power is therefore inaccurate, risking a false‑negative conclusion about the entropy‑variance relationship.
- Phase 0 only tests the correlation between semantic entropy and activation variance. The core hypothesis that higher variance predicts greater quantization error (MSE) – the justification for a dynamic router – is never empirically evaluated. Without a validated link between variance and quantization sensitivity, the correlation study does not substantiate the router design.
- The plan cites the MS‑COCO 2017 parquet dataset (https://huggingface.co/datasets/ChristophSchuhmann/MS_COCO_2017_URL_TEXT/resolve/main/mscoco.parquet) as the sole data source, but this dataset provides only caption text (and possibly image metadata) without the actual image pixel data required for activation‑variance measurement and FID/CLIP evaluation. Since the research requires both captions *and* the corresponding images, the cited dataset is inappropriate for the intended experiments.
- The Data Model lists an entity *Semantic Entropy Scores* with schema `contracts/entropy_schema.schema.yaml`, but this schema file does not exist in the `contracts/` directory. This breaks the contract‑validation pipeline and violates the requirement that every entity have a defined schema.
- The Data Model lists an entity *Prompt Metadata* with schema `contracts/prompt_schema.schema.yaml`, which is also missing from the `contracts/` directory. Without this schema the prompt metadata cannot be validated against the project’s SSoT.
- The plan proposes using Pearson correlation (two‑tailed) between semantic entropy and activation variance, controlling for prompt length. Pearson assumes linearity and approximate normality of both variables. Semantic entropy, as constructed (Shannon entropy of a 3‑cluster distribution), is bounded and highly non‑Gaussian, and activation variance is often right‑skewed. A rank‑based correlation (Spearman or Kendall) or a suitable transformation should be considered to avoid violating the test’s assumptions.
- Paired t‑tests are planned for each metric (FID, CLIP, MSE, inference time). These tests assume the paired differences are normally distributed. Metrics such as FID and CLIP scores are typically skewed and may contain outliers, making the normality assumption questionable. A non‑parametric alternative (e.g., Wilcoxon signed‑rank test) or a bootstrap confidence‑interval approach would be more robust.
