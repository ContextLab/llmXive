# Quickstart: llmXive Pipeline

## Prerequisites
- Python 3.9+
- `pip install -r requirements.txt`

## Execution Steps

1. **Download Weights**
 ```bash
 python src/ingestion/download_weights.py
 ```

2. **Flatten Weights**
 ```bash
 python src/ingestion/flatten_lora.py --input data/raw/lora_weights --output data/processed/weights_flattened.npz
 ```

3. **Build Index**
 ```bash
 python src/retrieval/vector_db.py --input data/processed/weights_flattened.npz --output data/processed/skill_index.npz --k 5
 ```

4. **Run Evaluation (Example Task)**
 ```bash
 # Ensure you have a synthesized adapter in artifacts/synthesized_adapters/
 # For this demo, we assume a mock adapter exists or is generated by previous steps
 # In a real run, this would be the path to a real adapter
 python src/evaluation/runner.py --adapter artifacts/synthesized_adapters/mean_test_task.npz --task test_task --output data/results/eval_log.json --runs 5
 ```

5. **Generate Stats Report**
 ```bash
 python src/evaluation/report_generator.py
 ```

6. **Generate Final Report**
 ```bash
 python src/evaluation/final_report.py --output reports/final_report.md
 ```

## Output Artifacts
- `data/processed/skill_index.npz`
- `data/results/stats_report.json`
- `reports/final_report.md`
