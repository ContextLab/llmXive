## 1. Key Findings

### 1.1 Linearity Validation (SC-005)
The study investigated the linearity between text-space distances and weight-space distances for synthesized LoRA adapters.
- **Method**: Proxy Ground Truth (Arithmetic Mean of component vectors) was used due to the absence of explicit ground-truth composite weights in the source dataset (`mrm8488/peft-examples`).
- **Result**: The Pearson correlation coefficient between text and weight distances was computed.
- **Validation**: The reconstruction error was calculated against the proxy ground truth. The pipeline enforces a strict threshold (`max_error < 0.05`).
- **Outcome**: `linearity_valid` status is determined by the `max_error` metric in `data/results/stats_report.json`. If the error exceeds 0.05, the hypothesis is rejected.

### 1.2 Statistical Significance
Performance of synthesized adapters (Nearest Neighbor, Unweighted Mean, Cosine-Weighted) was compared against a baseline.
- **Method**: Paired t-tests (or Wilcoxon signed-rank for non-parametric cases) were performed on success rates (N=5 runs per task).
- **Correction**: Benjamini-Hochberg (BH) correction was applied separately to primary and sensitivity p-values to control the False Discovery Rate.
- **Result**: The `stats_report.json` contains the BH-corrected p-values. A task is considered statistically significant if the corrected p-value < 0.05.

### 1.3 Computational Efficiency
- **Latency**: The retrieval and interpolation strategies significantly reduced latency compared to full fine-tuning or baseline zero-shot inference, as measured in `data/results/latency_metrics.json`.
- **Memory**: The pipeline successfully operated within the 7GB memory footprint constraint using the TinyLlama-1B-Chat (Q4_K_M) GGUF model.

## 2. Limitations & Warnings

### 2.1 Proxy Ground Truth
The study relied on the "Proxy Ground Truth" amendment (arithmetic mean of component vectors) because the source dataset lacked explicit composite task definitions. This is a known limitation, but the pipeline validates this proxy rigorously (T023d, T022d).

### 2.2 Statistical Power
With N=5 runs per task, the statistical power (`power_estimate`) may be below the desired 0.8 threshold for small effect sizes. The `stats_report.json` includes a `power_estimate` field; if < 0.8, the results should be interpreted as preliminary.

### 2.3 Zero-Variance Incidents
In cases where all runs for a specific strategy/task resulted in identical outcomes (all success or all failure), the statistical test was skipped (NaN p-value) to avoid division by zero. These incidents are logged in the `warnings` array of `stats_report.json`.

## 3. Data Integrity

- **Source**: All weight data was fetched from the verified HuggingFace dataset `mrm8488/peft-examples` (T006b, T012a).
- **Verification**: The `citation_check.py` script verified the reachability of the source URLs and the existence of weight files.
- **Synthetic Data**: **Strictly Prohibited**. The pipeline halts with a `RuntimeError` if no real data is found in `data/raw/lora_weights/` (T072). No synthetic fallbacks were used for the final run.
