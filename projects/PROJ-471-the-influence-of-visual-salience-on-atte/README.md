# The Influence of Visual Salience on Attentional Bias in Moral Judgements

## Project Structure

This repository implements the automated science pipeline for the specified study.

- `code/`: Source code for ingestion, processing, analysis, and utilities.
- `data/`:
 - `raw/`: Original downloaded datasets.
 - `interim/`: Intermediate processing artifacts.
 - `processed/`: Final aligned metrics and results.
 - `figures/`: Generated plots.
- `tests/`: Unit and integration tests.
- `docs/`: Governance documents (SCRs) and specifications.
- `specs/`: Feature specifications and data models.

## Setup

1. Install dependencies: `pip install -r requirements.txt`
2. Run tests: `pytest`
