# Quickstart: Social Rejection Analysis Pipeline

## Overview
This project investigates the effect of simulated social rejection on behavioral proxies (reaction time and mood).

## Installation
1. Clone the repository.
2. Create a virtual environment: `python -m venv venv && source venv/bin/activate`
3. Install dependencies: `pip install -r requirements.txt`

## Running the Pipeline
The entire research pipeline—from data ingestion to report generation—can be executed with a single command:

```bash
python -m code.pipeline
```

## Testing
Run the test suite to verify the results:
```bash
pytest tests/
```
