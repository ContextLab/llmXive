# Quickstart: Social Rejection Analysis Pipeline

## Overview

This project provides a reproducible, end‑to‑end pipeline for analysing the effect of simulated social rejection on behavioural proxies (reaction time and mood).
All steps – data ingestion, preprocessing, statistical analysis, and report generation – are orchestrated by a single command.

## Prerequisites

* Python 3.11 or newer
* Git
* Access to the internet (to download the OpenNeuro dataset)
* ≤ 7 GB RAM available (the pipeline enforces this limit)

## Installation

```bash
# Clone the repository
git clone <repo_url>
cd projects/PROJ-258-the-effect-of-simulated-social-rejection

# Create a virtual environment
python -m venv venv
source venv/bin/activate # Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

## Running the full pipeline

```bash
python -m code.pipeline
```

The command performs the following actions in sequence:

1. **Ingest** the OpenNeuro Cyberball dataset (`ds000208`).
2. **Preprocess** the raw data (outlier detection, Z‑score normalisation, feature aggregation).
3. **Statistical analysis** (One‑Way ANOVA, FDR correction, α‑sensitivity sweep).
4. **Generate the final markdown report** (`paper/report.md`).

All artefacts are written under the `data/`, `results/`, and `paper/` directories as described in the project specification.

## Testing

After the pipeline finishes, run the test suite to confirm that all components behave as expected:


The suite checks:

* Schema compliance for generated JSON/CSV files
* Correct outlier flagging and normalisation
* Proper Benjamini‑Hochberg correction (`p_fdr ≥ p_raw`)
* Presence of required phrasing constraints in the final report
* End‑to‑end execution producing all expected artefacts

## Troubleshooting

* **ImportError for pandas** – ensure the virtual environment is activated and `pip install -r requirements.txt` completed successfully.
* **Memory‑limit error** – the pipeline aborts if the dataset size exceeds 7 GB; verify you have sufficient RAM or use a smaller dataset.
* **Missing columns** – the ingestion step validates that `participant_id`, `condition`, `reaction_time`, and `mood_rating` are present; otherwise the pipeline exits with code 1.
* **Report phrasing failures** – if the generated `paper/report.md` does not contain the word “associational” in the Limitations section or contains “causal” in the Results section, the pipeline will abort; re‑run after fixing any manual edits.
