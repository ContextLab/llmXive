# Data Model: The Effect of Simulated Social Rejection on Neural Responses to Positive Feedback

## Overview
The pipeline manipulates five logical data layers, each validated against a JSON/YAML schema in `contracts/`.

| Layer | Description | File Location | Schema |
|-------|-------------|---------------|--------|
| **Raw Dataset** | Unmodified download from OpenNeuro (Parquet) | `data/raw/ds000208.parquet` | `contracts/dataset.schema.yaml` |
| **Preprocessed Dataset** | Cleaned, outlier‑flagged, Z‑score normalized, and aggregated per participant/condition | `data/processed/analysis_ready_ds000208.csv` | `contracts/dataset.schema.yaml` (extended) |
| **Outlier Log** | Per‑condition IQR thresholds and counts of flagged rows | `data/interim/outlier_log.json` | *see description* |
| **Design Branch** | Stores the chosen design type (`Between-Subjects`) | `data/interim/design_branch.json` | *see description* |
| **Analysis Output** | Statistical results, FDR‑corrected p‑values, effect sizes, and sensitivity flags | `results/analysis_output.json` | `contracts/analysis_output.schema.yaml` |
| **Full Results Package** | Combines `analysis_output.json` with design metadata, phrasing checks, and outlier‑sensitivity summary | `results/analysis_results.json` | `contracts/analysis_results.schema.yaml` |
| **Metadata** | Checksum, download timestamp, and citation for the raw dataset | `data/raw/metadata.json` | *see description* |
| **Citation File** | Human‑readable citation for the dataset | `data/raw/CITATION.md` | – |

## Entity Definitions

### 1. Raw Dataset Record
| Field | Type | Description |
|-------|------|-------------|
| `participant_id` | string | Anonymized participant identifier. |
| `condition` | string | `"rejection"` or `"control"` (must both be present). |
| `reaction_time` | number (≥ 0) | RT in milliseconds. |
| `mood_rating` | number (1 – 7) | Self‑reported mood. |
| `age` | number (optional) | Age in years, if provided. |
| `gender` | string (optional) | `"male"`, `"female"` or `"other"`, if provided. |

### 2. Preprocessed Record
| Field | Type | Description |
|-------|------|-------------|
| `participant_id` | string | Same as raw. |
| `condition` | string | Same as raw. |
| `rt_normalized` | number | Z‑score of `reaction_time` within the condition. |
| `is_outlier` | boolean | `true` if flagged by IQR rule. |
| `rt_mean` | number | Mean of `rt_normalized` for the participant‑condition pair. |
| `mood_mean` | number | Mean of `mood_rating` for the participant‑condition pair. |
| `age` | number (optional) | Propagated from raw. |
| `gender` | string (optional) | Propagated from raw. |

### 3. Outlier Log (JSON)
```json
{
  "condition": "rejection",
  "iqr_lower": <number>,
  "iqr_upper": <number>,
  "flagged_count": <int>
}
```
One object per condition; stored in `data/interim/outlier_log.json`.

### 4. Design Branch (JSON)
```json
{
  "design_type": "Between-Subjects"
}
```
Reflects the automatic selection when only one dataset is available (see FR‑007).

### 5. Analysis Output (per outcome) – conforms to `contracts/analysis_output.schema.yaml`
| Field | Type | Description |
|-------|------|-------------|
| `test_type` | string | `"One_Way_ANOVA"` |
| `design_type` | string | `"Between-Subjects"` |
| `f_value` | number | F‑statistic for the outcome. |
| `p_raw` | number (0‑1) | Unadjusted p‑value. |
| `p_fdr` | number (0‑1) | Benjamini‑Hochberg corrected p‑value (≥ `p_raw`). |
| `effect_size` | number | Eta‑squared. |
| `alpha_sensitivity` | object | Keys `"0.01"`, `"0.05"`, `"0.1"` → booleans indicating significance at each α. |

### 6. Full Results Package (conforms to `contracts/analysis_results.schema.yaml`)
| Field | Type | Description |
|-------|------|-------------|
| `design_type` | string | `"Between-Subjects"` (the only feasible design given data). |
| `main_test` | object | Mirrors `analysis_output.json` (F, raw & FDR p‑values, effect size). |
| `sensitivity_analysis` | array | Results of α sweep (α = 0.01, 0.05, 0.1). |
| `outlier_sensitivity` | object | Differences in statistics with vs. without outliers (generated by T017). |
| `limitations` | object | Flags for required phrasing (`contains_associational` = true). |

### 7. Metadata (JSON)
| Field | Type | Description |
|-------|------|-------------|
| `dataset_id` | string | `"ds000208"` |
| `checksum_sha256` | string | SHA‑256 hash of the downloaded parquet file. |
| `download_timestamp` | string (ISO‑8601) | When the file was fetched. |
| `citation` | string | Full citation text (also written to `CITATION.md`). |

## Data Flow
1. **Ingestion** (`code/ingest.py`) → `data/raw/ds000208.parquet` + `metadata.json` + `CITATION.md`.  
2. **Validation** (`T003`‑`T005`) → schema checks, `design_branch.json`.  
3. **Preprocessing** (`code/preprocess.py`) → `data/processed/analysis_ready_ds000208.csv` + `outlier_log.json`.  
4. **Analysis** (`code/analyze.py`) → `results/analysis_output.json`.  
5. **Packaging** (`code/report.py`) → `results/analysis_results.json` & `paper/report.md`.  

All intermediate files are immutable; any transformation writes a new file with documented provenance.

## Constraints
- **Memory**: Files must fit within 7 GB RAM; raw parquet is streamed/memory‑mapped.  
- **PII**: `participant_id` is anonymized; no personal data stored.  
- **Immutability**: Raw files never overwritten; checksums guarantee integrity.
