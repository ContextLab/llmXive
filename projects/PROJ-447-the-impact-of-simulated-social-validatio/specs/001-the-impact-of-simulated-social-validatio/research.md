# Research: The Impact of Simulated Social Validation on Self-Perception in Adolescents

## Executive Summary

This research investigates the associational link between simulated social validation (quantified via engagement metrics and sentiment) and adolescent self-perception (Rosenberg Self-Esteem Scale, Body Image Scale). Due to the scarcity of public datasets linking specific social media logs with validated psychometric scores for the same individuals (a privacy constraint under COPPA/GDPR), the primary strategy relies on a **Synthetic Data Generator** with known ground truth parameters to validate the pipeline. The analysis is strictly framed as **associational**, controlling for offline relationships and intrinsic traits.

**Methodological Correction**: The synthetic data generation protocol has been revised to use a **Structural Equation Model (SEM)** that explicitly includes:
1.  **Measurement Error**: The "Perceived Social Validation" observed score is a noisy proxy of a latent variable.
2.  **Reverse Causality**: Self-esteem influences engagement (feedback loop).
3.  **Third-Variable Confounding**: Unmeasured traits influence both.

The "ground truth" for pipeline validation is defined as the *observed association parameters* generated by this SEM (which include attenuation and bias), ensuring that the OLS recovery test is mathematically consistent. The pipeline validates that the code correctly recovers these *observed* parameters, not the latent causal beta.

## Dataset Strategy

### Verified Datasets

Based on the "# Verified datasets" block provided, **no dataset exists that contains both social media engagement metrics and validated psychometric self-report scales (RSES) for the same adolescents.**

- **GDPR Datasets**: The verified sources (`AndreaSimeri/GDPR`, `lislia/gdpr_train`, `Johny201/gdpr-articles`) contain legal text (articles, recitals) and are **not** suitable for this study. They lack engagement metrics, psychometric scores, or demographic data for adolescents.
- **COPPA, AND, ONLY**: No verified sources found.

**Decision**: Since no real dataset meets the specific variable requirements (engagement + self-esteem + longitudinal match), the project **MUST** proceed with the **Synthetic Data Generator** as the primary data source, as mandated by **FR-001** and **US-1**. The generator will simulate:
1.  **Engagement Metrics**: Likes, comments, and sentiment scores derived from a latent "validation" variable.
2.  **Psychometric Scores**: Rosenberg Self-Esteem Scale (RSES) and Body Image Scale scores, correlated with the validation variable and confounders.
3.  **Confounders**: Offline relationship count and intrinsic trait scores (e.g., neuroticism).
4.  **Longitudinal Structure**: Timestamps ensuring engagement precedes self-report.

### Synthetic Data Generation Protocol (SEM-Based)

To ensure **Reproducibility (Constitution I)** and **Instrument Validity (Constitution VI)**, and to address methodological concerns regarding measurement error and reverse causality:

1.  **Latent Structure**: The generator defines a latent variable $L_{val}$ (True Social Validation) and a latent outcome $L_{self}$ (True Self-Esteem).
2.  **Measurement Model**: The observed `perceived_validation_score` is generated as $L_{val} + \epsilon_{meas}$, where $\epsilon_{meas}$ is random noise with a known variance (measurement error). This creates the attenuation bias expected in OLS.
3.  **Structural Model**:
    -   $L_{self} = \beta_{lat} \cdot L_{val} + \beta_{conf} \cdot Confounders + \epsilon_{out}$
    -   **Reverse Causality**: $L_{val} = \gamma \cdot L_{self} + \epsilon_{rev}$ (simulating the feedback loop where self-esteem drives engagement).
    -   **Confounders**: $Confounders$ are generated with specified correlations to both $L_{val}$ and $L_{self}$.
4.  **Ground Truth Definition**: The "ground truth" for the pipeline validation is the set of *observed* regression coefficients that result from this SEM. The pipeline is validated if the OLS model recovers these *observed* coefficients (within statistical tolerance), not the latent $\beta_{lat}$. This avoids the tautology of recovering a parameter that is mathematically impossible to observe directly without measurement error correction.
5.  **Sample Size**: Generated to ensure $N \ge 1000$ (well above the $N \ge 100$ minimum for power) to allow for robust sensitivity analysis.
6.  **Collinearity Tuning**: The generator's correlation parameters are tuned to ensure VIF values remain below the threshold (<5) for the baseline case, while allowing for sensitivity testing where VIF is intentionally increased.

### Data Availability & Feasibility

- **Real Data**: Attempted load of verified GDPR datasets will be performed but expected to fail the column check (missing RSES/engagement).
- **Synthetic Data**: Guaranteed to succeed. The pipeline will automatically switch to synthetic generation if the real data validation check fails (per **US-1**).
- **Compute**: Synthetic data generation is CPU-tractable and fits within the available RAM limit.

## Statistical Methodology

### Model Specification

The core analysis uses **Multiple Linear Regression (OLS)** on the *observed* variables:
$$ Y_{self\_esteem} = \beta_0 + \beta_1(X_{validation}) + \beta_2(X_{offline}) + \beta_3(X_{intrinsic}) + \beta_4(X_{age}) + \beta_5(X_{gender}) + \epsilon $$

Where:
- $Y$: Standardized Rosenberg Self-Esteem Scale score.
- $X_{validation}$: Observed "Perceived Social Validation" score (noisy proxy).
- $X_{offline}$: Count of offline relationships.
- $X_{intrinsic}$: Intrinsic trait score (e.g., baseline neuroticism).
- $X_{age}, X_{gender}$: Demographic controls.

### Rigor & Assumptions

1.  **Associational Framing**: Per **FR-006** and **US-2**, all results will be explicitly labeled as "associational". No causal claims (e.g., "causes", "leads to") will be made. The output will be scanned for causal trigger words and rejected if found.
2.  **Multicollinearity**: **FR-003** requires calculating Variance Inflation Factors (VIF) for all predictors. If $VIF > 5$ (or a pre-registered threshold), the variable will be flagged. The synthetic generator is tuned to avoid artificial high VIF in the baseline.
3.  **Multiple Comparisons**: If multiple models are run (e.g., different outcomes), a correction (e.g., Bonferroni) will be applied to the alpha level.
4.  **Power Analysis**: With $N \ge$ a sufficiently large synthetic sample size, the study has high power to detect small-to-moderate effects ($\beta \approx 0.1$). For any real data subset, power will be calculated and reported.
5.  **Non-Linearity**: **FR-007** mandates a quadratic term check ($X_{validation}^2$). Significance of the quadratic coefficient will be tested.

### Robustness & Sensitivity (FR-004, US-3)

The pipeline will execute the following sensitivity checks:
- **Outlier Strategies**:
  1.  No removal (baseline).
  2.  IQR-based removal (values outside $1.5 \times IQR$).
  3.  Winsorization (capping at 1st/99th percentile).
- **Confounder Toggle**:
  1.  Full model (with confounders).
  2.  Reduced model (without confounders).
- **Reverse Causality Check**: A specific test where the generator's reverse path ($\gamma$) is toggled to assess the stability of the primary coefficient under different feedback loop strengths.
- **Collinearity Tuning**: The generator's correlation parameters are varied to intentionally induce high VIF, verifying that the system correctly flags the instability.
- **Stability Metric**: The variation in $\beta_1$ across these strategies will be reported. If the variation exceeds a pre-registered threshold, the result is flagged as unstable.

## Ethical Considerations

- **Privacy**: Synthetic data contains no real PII.
- **Adolescent Focus**: While data is synthetic, the measurement instruments (RSES) are validated for adolescents.
- **Causal Misinterpretation**: Strict safeguards (causal word scanning) are in place to prevent misinterpretation of associational results as causal.

## Limitations

- **Synthetic Nature**: Real-world complexity (unmeasured confounders, non-linear dynamics) may not be fully captured by the simulation.
- **Lack of Real Data**: No verified public dataset currently exists to validate the synthetic model against real adolescent behavior.
- **Cross-Sectional Proxy**: While timestamps are simulated, the lack of true longitudinal tracking in real data limits the ability to infer temporal precedence in a real-world context.
- **Pipeline vs. Science**: The synthetic analysis validates the *pipeline's code* (ability to recover generated parameters), not the *scientific hypothesis* (existence of the phenomenon). A null result in real data would be scientifically meaningful, whereas the synthetic result only confirms the code's correctness.
