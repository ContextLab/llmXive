# Implementation Plan: The Impact of Simulated Social Validation on Self-Perception in Adolescents

## Summary

This project implements a statistical analysis pipeline to investigate the associational relationship between simulated social validation (likes/comments) and adolescent self-perception (self-esteem/body image). Given the extreme rarity of public datasets linking specific social media logs with validated psychometric scales for the same individuals (due to privacy constraints like COPPA/GDPR), the primary technical approach involves a **Synthetic Data Generator** with known ground truth parameters to validate the pipeline, alongside a fallback strategy to attempt loading verified open datasets. The core analysis employs multiple linear regression with rigorous confounding control, multicollinearity diagnostics (VIF), and sensitivity analysis against outliers and model specifications.

**Key Methodological Correction**: The synthetic data generation now explicitly models **measurement error** and **reverse causality** via a Structural Equation Model (SEM). The "ground truth" for pipeline validation is defined as the *observed association parameters* generated by the SEM (accounting for attenuation and bias), not the latent causal beta. This ensures the OLS recovery test is mathematically consistent and avoids circularity.
