# PROJ-163: Exploring the Role of Network Structure in Superconducting Qubit Coupling

## Prerequisites
- Python 3.11+

## Setup
1. Create a virtual environment:
 ```bash
 python3.11 -m venv venv
 source venv/bin/activate # On Windows: venv\Scripts\activate
 ```
2. Install dependencies:
 ```bash
 pip install -r requirements.txt
 ```
3. Configure IBM Quantum credentials (see `code/config.py` for details).

## Project Structure
- `code/`: Source code modules
- `data/raw/`: Raw data from IBM Quantum API
- `data/processed/`: Processed data and analysis results
- `tests/`: Unit and integration tests
- `specs/`: Feature specifications and design documents
