# Scope Boundary Document: Visual Detail and False Memory

## 1. Primary Scope Definition

This study measures **behavioral** false memory rates in response to variations in visual detail within stimulus images. The project explicitly **does not** measure, infer, or hypothesize about specific molecular or cellular mechanisms (e.g., CREB activation, synaptic weight changes, PKA pathways) in the human brain.

## 2. Theoretical Framework: Constructive Memory vs. Biological Mechanism

The theoretical foundation of this work rests on the Constructive Memory framework (Loftus et al., 1974; Schacter et al., 1998), which posits that memory is a reconstructive process susceptible to distortion. This study investigates how a psychophysical variable ("visual detail") modulates the *susceptibility* of this reconstructive process.

While biological models of memory (e.g., Kandel et al., 2000) describe the molecular underpinnings of memory storage in model organisms (e.g., *Aplysia*), this project operates strictly at the behavioral rung of the "Ladder of Explanation."

## 3. Response to Mechanistic Critique

In response to the critique regarding the "ladder of explanation" (behavior → cells → synapses → molecules):

While the "ladder of explanation" is a valid framework for mechanistic discovery, this study is strictly confined to the behavioral rung. We do not measure, infer, or hypothesize about specific synaptic changes (e.g., CREB activation, PKA pathways) in the visual cortex or hippocampus. The "visual detail" variable is a psychophysical stimulus parameter, not a proxy for synaptic weight. Any correlation between detail and false memory is an associational finding, not evidence of a molecular mechanism.

## 4. Biological Context and Limitations

While the project is strictly behavioral, it acknowledges the biological hypothesis: that increased visual detail may enhance synaptic encoding strength (potentially via CREB-dependent protein synthesis) or alter reconsolidation dynamics. However, this project does not measure these variables. The "visual detail" parameter is a psychophysical proxy, not a direct measure of synaptic weight.

## 5. Hypothesis Gap: No Cellular Correlate Claimed

This study does not claim to have identified a cellular correlate for the effect of visual detail on false memory. The "visual detail" parameter is a stimulus property, not a measure of synaptic strength. Any speculation about molecular pathways (e.g., CREB activation) is purely theoretical and not supported by data in this study. The project explicitly states that the "ladder of explanation" has not been walked down to the synaptic rung.

## 6. Ethical Compliance

This research protocol adheres to the guidelines set forth in the Declaration of Helsinki and has been designed to minimize risk to participants. All data will be anonymized and stored securely in accordance with GDPR regulations.
