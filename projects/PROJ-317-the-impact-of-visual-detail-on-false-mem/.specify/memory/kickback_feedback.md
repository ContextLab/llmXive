## Unresolved concerns

- The plan does not specify how many true and lure recognition items will be presented per condition. Without a sufficient number of trials, the per‑condition false‑memory rate will be noisy, undermining construct validity and reducing the effective statistical power of the repeated‑measures ANOVA.
- Condition order is described as “randomized,” but no explicit counterbalancing or inclusion of order as a covariate is mentioned. Randomization alone may not fully control for fatigue or learning effects in a within‑subjects design, which could confound the estimated effect of visual detail.
- The power analysis assumes an effect size f = 0.25 (medium) based on unrelated visual‑memory work. The justification for applying that effect size to the specific manipulation of visual detail is missing, and no sensitivity analysis is provided to show how required N changes with smaller effects.
- Functional Requirement FR-007 (visualization with confidence intervals) is not explicitly linked in the plan. The mapping table lists "FR‑07" (missing a leading zero) for Phase 3, which does not match the spec identifier FR-007, leaving FR-007 unbacked.
- Success Criterion SC-002 (Power analysis ≥ 50 complete sessions) is not listed in any phase. The plan’s phase table only references SC-001, SC-003, SC-005 for Phase 3, leaving SC-002 uncovered.
- FR identifier typo: the table lists "FR-07" while the specification defines this requirement as "FR-007". This inconsistency may cause traceability errors.
- The plan mentions capturing timestamped responses but does not explicitly reference the response contract (`contracts/response.schema.yaml`). To satisfy the contract‑coverage rule, the plan should state that responses will be validated against this schema (e.g., via Task T006 – Response Validator).
- The plan states a *Repeated‑Measures (Within‑Subjects) design* where each participant views all three stimulus conditions (enhanced, reduced, baseline) in a randomized order, but the stimulus generation pipeline creates distinct images for each condition (Phase 0 loads baseline images, Phase 1 creates enhanced/reduced versions). If participants see different base images in each condition rather than the same image presented in all three versions, the condition factor is confounded with image identity, violating the independence assumption required for a valid within‑subjects ANOVA.
- The analysis proposes a repeated‑measures ANOVA on *false‑memory rates* (proportions of “Yes” responses to lure items). Proportion data are bounded [0,1] and often non‑normally distributed, especially with small numbers of lure trials per condition. Using `statsmodels.stats.anova.AnovaRM` assumes normally distributed residuals; even with Shapiro‑Wilk checks, the transformation may be insufficient. A generalized linear mixed‑effects model with a binomial (logit) link would be more appropriate and would also allow random effects for items as well as participants.
