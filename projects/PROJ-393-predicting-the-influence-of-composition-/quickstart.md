# Quickstart Guide: Heusler Alloy Hysteresis Prediction Pipeline

This guide provides instructions to run the full pipeline end-to-end.

## Prerequisites

- Python 3.11+
- Virtual environment (recommended)

## Setup

1. Clone the repository.
2. Create a virtual environment:
 ```bash
 python -m venv.venv
 source.venv/bin/activate # On Windows:.venv\Scripts\activate
 ```
3. Install dependencies:
 ```bash
 pip install -r code/requirements.txt
 ```

## Running the Pipeline

The full pipeline can be executed via the main entry point:

```bash
cd code
python main.py
```

Alternatively, run individual stages:

```bash
# 1. Ingestion (Fetch and merge raw data)
python scripts/run_ingestion.py

# 2. Manual Curation (Ensure template exists)
python scripts/run_manual_curator.py

# 3. Preprocessing (Standardize, filter, impute)
python scripts/run_preprocessing.py

# 4. Scarcity Check
python scripts/run_scarcity_check.py

# 5. Feature Engineering
python scripts/run_feature_engineering.py

# 6. Model Training
python scripts/run_model_training.py

# 7. Final Report Generation
python scripts/run_final_report.py
```

## Output Artifacts

After successful execution, the following files will be generated:

- `data/raw/manual_curated.csv`
- `data/processed/alloys_raw.csv`
- `data/processed/alloys_features.csv`
- `data/processed/model_metrics.json`
- `docs/reports/final_report.md`
- `docs/reports/statistical_limitations.md`
- `docs/reports/microstructure_note.md`
- `docs/reports/data_scarcity_warning.md`

## Troubleshooting

- If `data/raw/manual_curated.csv` is missing, run `python scripts/run_manual_curator.py`.
- Ensure `data/raw/elemental_properties.csv` exists (generated by T006).
- Check logs in `logs/` for detailed error messages.
