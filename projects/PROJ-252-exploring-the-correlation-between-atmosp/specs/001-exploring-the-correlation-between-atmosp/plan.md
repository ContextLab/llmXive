# Implementation Plan: Exploring the Correlation Between Atmospheric Pressure and Earthquake Precursors

**Branch**: `001-explore-pressure-quake-correlation` | **Date**: 2024-10-23 | **Spec**: [link]  
**Input**: Feature specification from `specs/001-exploring-the-correlation-between-atmosp/spec.md`

## Summary
The plan now fully incorporates the verified NOAA NCEP/NCAR daily surface pressure reanalysis dataset (accessed via the verified URL) into the primary analysis pipeline. Pressure data are streamed to respect CI disk limits, interpolated to the nearest grid point (or 3‑point average) for each earthquake, and used to compute daily anomalies. Control windows are generated by simple random temporal sampling (with exact month matching) while awaiting verified climate‑index datasets. The statistical core employs a block‑permutation test on the mean pressure‑anomaly difference (Cohen’s d) with bootstrap‑derived 95 % confidence intervals and hierarchical Benjamini‑Hochberg correction for secondary subgroup tests. Power analysis is performed **after** the primary test, using the observed effect size to assess whether ≥ 0.80 power is achieved; if not, the catalog is expanded to M ≥ 3.5 as specified in FR‑012.

All functional requirements are satisfied, with the requirement concerning control windows partially satisfied now (control windows contain required fields) and a concrete future strategy documented for full climate‑index matching. Success criteria (SC‑001 – SC‑003) are re‑defined to focus on proper statistical reporting and power assessment, not on achieving a particular effect size.

## Success Criteria (Reporting Metrics)
- **SC‑001**: The final report must contain the **p‑value** from the primary block‑permutation test, the **observed Cohen’s d**, its **95 % bootstrap confidence interval**, **and the estimated statistical power** from the Monte‑Carlo analysis. Success is defined by proper reporting, not by any significance threshold.
- **SC‑002**: Compute the **coefficient of variation (CV)** of p‑values across all secondary strata (region, magnitude). Report the CV (descriptive only).
- **SC‑003**: Report the **range** of p‑values across the σ‑threshold sweep {0.5σ, 1.0σ, 1.5σ}. Descriptive only.

All other functional requirements (FR‑001 – FR‑014) are satisfied either directly or with a documented deferment that will be activated when the required external datasets are added.

# Research: Exploring the Correlation Between Atmospheric Pressure and Earthquake Precursors

## Dataset Strategy

The project now uses two verified, programmatically‑downloadable datasets:

| Dataset | Purpose | Verified URL / Source | Strategy |
|:---|:---|:---|:---|
| **USGS Earthquake Catalog (monthly feed)** | Seismic events (M ≥ 4.0, depth ≤ 70 km) | `https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_month.csv` | Load CSV via `pandas.read_csv`, filter by date/magnitude/depth, deduplicate by `event_id`. |
| **NOAA NCEP/NCAR Reanalysis Surface Pressure** | Daily global sea‑level pressure grids (1990‑2023) | `https://psl.noaa.gov/data/gridded/data.ncep.reanalysis.surface.html` (accessed via OPeNDAP) | Stream with `xarray.open_dataset(..., chunks={"time":30})`, interpolate to nearest 1° grid point for each earthquake, compute left‑censored 30‑day moving‑average anomalies. |
| **ENSO / PDO indices, ERA5 temperature & humidity** | Control‑window matching (required by FR‑011) | *No verified URL in the provided list* | **Deferred** – currently use simple random control windows; when verified datasets become available, we will apply exact month + ENSO/PDO matching and propensity‑score matching on temperature (±0.5 °C) and humidity (±5 %). |

### Dataset Variable Fit Check
- **USGS CSV** supplies `event_id`, `timestamp`, `latitude`, `longitude`, `depth_km`, `magnitude` – all required by FR‑001, FR‑008, FR‑009, FR‑010. **Fit** – Yes.  
- **Pressure Reanalysis** provides `timestamp`, `latitude`, `longitude`, `pressure_hpa` – satisfies FR‑002. **Fit** – Yes.  
- **Climate indices** – not available; variable fit cannot be confirmed (deferred).

## Statistical Methodology (Primary)

With pressure anomalies now available, the core analysis proceeds as follows:

1. **Pre‑processing** – Interpolate pressure to the nearest 1° grid point for each earthquake, compute daily anomalies by subtracting a left‑censored 30‑day moving average (baseline gap selectable).  
2. **Control‑window generation** – Simple random temporal sampling within the same calendar month, preserving seasonal structure (full ENSO/PDO/temperature/humidity matching deferred).  
3. **Primary Test** – **Block‑permutation test** (10 000 iterations, 7‑day blocks) on the **mean pressure‑anomaly difference** between event and control windows. For each permutation compute Cohen’s d; the p‑value is the proportion of permuted |d| ≥ observed |d|.  
4. **Bootstrap CI** – 1 000 bootstrap resamples of the observed Cohen’s d to obtain a 95 % confidence interval.  
5. **Power Analysis** – Using the observed Cohen’s d, run a Monte‑Carlo simulation to estimate statistical power for detecting d = 0.3 at α = 0.05. If power < 0.80, the catalog will be expanded to include earthquakes of magnitude ≥ 3.5 with appropriate weighting (FR‑012).  
6. **Multiple‑testing correction** – Hierarchical Benjamini‑Hochberg FDR (α = 0.05) applied to secondary subgroup tests (region, magnitude).  
7. **Robustness & Sensitivity** – (Deferred) anomaly‑threshold sweeps {0.5σ, 1.0σ, 1.5σ} and baseline‑gap sensitivity (12, 20, 30 days). When climate‑index datasets become available, control windows will be matched on ENSO, PDO, local temperature, and humidity as described in the plan.  

All findings are explicitly framed as **associational**, complying with Constitution II.

## Limitations & Gaps

- **Climate‑index matching** is not performed due to lack of verified ENSO/PDO and ERA5 datasets; simple random controls are used instead.  
- **Power analysis** is conducted after the primary permutation test (Phase 3) because pressure data are required to compute an effect size.  
- **Observational design** – causal claims are avoided per Constitution II.

# Data Model: Exploring the Correlation Between Atmospheric Pressure and Earthquake Precursors

## Overview
Defines schemas for raw, intermediate, and analysis‑ready artifacts. All files reside under `data/` and are version‑hashed.

### Earthquake Event (raw USGS catalog)
| Field | Type | Description |
|---|---|---|
| `event_id` | string | USGS event identifier (e.g., `us7000abcd`). |
| `timestamp` | datetime | UTC origin timestamp (ISO‑8601). |
| `latitude` | float | Epicenter latitude (‑90 → 90). |
| `longitude` | float | Epicenter longitude (‑180 → 180). |
| `depth_km` | float | Depth in kilometers. |
| `magnitude` | float | Moment magnitude. |
| `location_type` | string | `"land"` or `"ocean"` (derived via land‑mask). |

### Pressure Grid Point *(Active)*
| Field | Type | Description |
|---|---|---|
| `timestamp` | datetime | UTC date (00:00). |
| `latitude` | float | Grid centre latitude. |
| `longitude` | float | Grid centre longitude. |
| `pressure_hpa` | float | Sea‑level pressure (hPa). |

### ENSO / PDO Index *(Deferred)*
| Field | Type | Description |
|---|---|---|
| `year` | integer | Calendar year. |
| `month` | integer | Calendar month (1‑12). |
| `enso_phase` | string | `"El Niño"`, `"La Niña"` or `"Neutral"`. |
| `pdo_phase` | string | `"Positive"`, `"Negative"` or `"Neutral"`. |

### ERA5 Covariates *(Deferred)*
| Field | Type | Description |
|---|---|---|
| `timestamp` | datetime | UTC date. |
| `latitude` | float | Grid latitude. |
| `longitude` | float | Grid longitude. |
| `temperature_k` | float | Near‑surface temperature (K). |
| `humidity` | float | Relative humidity (%). |

### Analysis Record *(Final, when all data are present)*
| Field | Type | Description |
|---|---|---|
| `event_id` | string | Reference to earthquake event. |
| `window_type` | string | `"event"` or `"control"`. |
| `timestamp` | datetime | Start time of the 48 h analysis window. |
| `pressure_anomaly` | number | Deviation from left‑censored moving average. |
| `magnitude` | number | Earthquake magnitude (null for control). |
| `region` | string | `"Ring of Fire"` or `"Other"`. |
| `is_land` | boolean | True if the event is on land. |
| `climate_index` | string | ENSO or PDO phase label (optional; not populated in pilot). |
| `pdo_phase` | string | `"Positive"`, `"Negative"` or `"Neutral"`. |
| `temperature_k` | number | Matching temperature (used for control matching; optional). |
| `humidity` | number | Matching humidity (used for control matching; optional). |

## Data Pipeline Flow
1. **Raw** – `data/raw/usgs_all_month.csv` (USGS catalog).  
2. **Raw Pressure** – streamed from NOAA NCEP/NCAR reanalysis (no persistent file).  
3. **Interim** – `data/interim/earthquakes_clean.parquet` (validated, deduplicated, ocean‑masked).  
4. **Processed** – `data/processed/analysis_ready.parquet` (schema above; contains pressure anomalies and control windows).  

All files are accompanied by SHA‑256 checksums stored in the project state file.
