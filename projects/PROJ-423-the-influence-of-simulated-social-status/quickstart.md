# Quickstart Guide: The Influence of Simulated Social Status on Risk-Taking Behavior

## Prerequisites
- Python 3.11+
- Virtual environment (`.venv`) created and activated

## Setup
1. Clone the repository and navigate to the project directory.
2. Create a virtual environment:
 ```bash
 python3.11 -m venv.venv
 source.venv/bin/activate
 ```
3. Install dependencies:
 ```bash
 pip install -r code/requirements.txt
 ```

## Execution Pipeline

### Step 1: Generate Simulation Parameters (Pre-requisite)
Ensure `code/simulation_parameters.json` exists with verified effect sizes and N.
(This is generated by Phase 0 tasks T000f-T000h).

### Step 2: Generate Data
Run the simulation script to generate raw synthetic data.
```bash
python code/simulate.py --output data/raw/simulation_output.csv
```

### Step 3: Preprocess Data
Run the preprocessing pipeline to clean data, detect structure, and update checksums.
```bash
python code/preprocess.py \
 --input data/raw/simulation_output.csv \
 --output data/processed/cleaned_data.csv \
 --structure-output data/processed/model_config.json
```
*Note: This also generates `data/processed/outcome_type.json` and updates `data/checksums.json`.*

### Step 4: Run Analysis
Fit the adaptive model and generate model output.
```bash
python code/analysis.py \
 --input data/processed/cleaned_data.csv \
 --output data/processed/model_output.json \
 --config data/processed/model_config.json
```

### Step 5: Generate Report
Generate the final HTML/PDF report.
```bash
python code/report.py \
 --input data/processed/cleaned_data.csv \
 --model-output data/processed/model_output.json \
 --output reports/analysis_report.html
```

## Validation
Run the test suite to verify data integrity and model correctness.
```bash
pytest tests/
```

## Troubleshooting
- If `data/processed/cleaned_data.csv` is missing, ensure Step 3 ran successfully.
- If `data/checksums.json` is empty, ensure `code/utils.py` `append_checksum_to_file` was called.
- Check `logs/` directory for detailed error logs if a script fails.
