# Research: Predicting Chemical Reaction Yields from Spectroscopic Data with Attention Mechanisms

## Executive Summary

This research investigates a **Simulation-to-Simulation Benchmark**: whether a multi-head self-attention neural network can learn to map simulated spectroscopic data (IR, NMR) to a synthetic yield target derived from molecular descriptors (MW, LogP, TPSA). The study explicitly reframes the research question from "Do spectra predict real yields?" to "Can a model learn to map simulated DFT spectra to a synthetic yield target derived from molecular descriptors?" This acknowledges that the primary verified dataset (DFT) lacks experimental yield data, and the study focuses on validating the architecture's ability to learn a complex mapping within a controlled, reproducible simulation environment. The methodology prioritizes CPU feasibility, strict data hygiene, and rigorous statistical validation (paired t-tests with Bonferroni correction, **Partial Correlation Analysis** to control for structure, and **Simulated Data Integrity Checks**).

## Dataset Strategy

### Verified Datasets

The following datasets are verified for availability and format. Only these sources will be used.

| Dataset | Source | Format | Variables Available | Suitability |
|---------|--------|--------|---------------------|-------------|
| **DFT (Spectra)** | ` | Parquet | `smiles`, `spectrum` (simulated DFT IR/NMR) | **High** for spectral data. **Does NOT contain yield**. Yield is generated synthetically. |
| **USPTO (Templates)** | ` | Parquet | `reaction_smiles`, `template` | **High** for reaction template extraction and splitting logic. |
| **NIST (Functional Groups)** | `data/verified/nist_functional_groups.yaml` | YAML | Functional group frequencies (verified static list) | **High** for validating attention peaks (SC-003). Source: NIST Chemistry WebBook (pre-verified via script). |

**Decision**: The primary dataset for spectra is the **DFT** dataset (`sdmattpotter/dftest61523`). The target variable (`yield_percent`) is **NOT** from the dataset. It is generated by a **Synthetic Yield Generator** (`src/data/synthetic_yield_generator.py`) which computes a value based on molecular descriptors (MW, LogP, TPSA) derived from the `smiles`. This ensures the target is structurally correlated but not directly dependent upon the spectra in this benchmark. **USPTO** will be used for template extraction to enforce splitting. **NIST** data is a pre-verified static list generated from the NIST WebBook and stored locally.

**Data Availability Check**:
- **DFT**: Contains reaction SMILES and simulated spectra. **No yield data**.
- **USPTO**: Contains reaction templates.
- **Gap**: No single verified dataset contains *experimental* spectra, *experimental* yields, and *reaction templates* simultaneously.
- **Strategy**: 1. Use DFT dataset for spectral + structural data. 2. Generate synthetic yield from descriptors (not spectra) to test the model's ability to learn a mapping within simulated parameters. 3. Use USPTO for template extraction to enforce splitting. 4. Validate attention peaks against the **Verified Static List** of NIST functional groups.

**Dataset Variable Fit**:
- **Predictors**: `ir_spectrum`, `nmr_spectrum`, `ecfp4_fingerprint`, `solvent`, `catalyst`, `temperature`.
- **Outcome**: `synthetic_yield` (generated from MW, LogP, TPSA).
- **Check**: The DFT dataset contains `spectrum` and `smiles`. The synthetic yield is generated from `smiles` via descriptors. The **Integrity Check** (FR-015) will verify that the synthetic yield is not a deterministic function of the spectra.

**DFT Simulation Parameters:**

The spectra in the `sdmattpotter/dftest61523` dataset were generated using Density Functional Theory (DFT) calculations with the following parameters:

* **Functional**: B3LYP
* **Basis Set**: 6-31G(d)
* **Solvent Model**: PCM (Polarizable Continuum Model) – implicit solvation
* **Frequency Scaling Factor**: 0.96
* **Software**: Gaussian 16

These parameters are documented to ensure reproducibility of the simulated spectral data and are treated as a core part of the 'Single Source of Truth' for this project.

**NIST Functional Group Verification:**

The NIST functional group frequencies used for attention peak validation are not hardcoded. They are generated by a script (`src/data/generate_nist_list.py`) that parses the NIST Chemistry WebBook (documented in `data/verified/nist_functional_groups.yaml` generation notes) and stored as a versioned, checksummed file (`data/verified/nist_functional_groups.yaml`). This ensures the values are real measurements from the primary source, not fabricated or hardcoded in the code.
