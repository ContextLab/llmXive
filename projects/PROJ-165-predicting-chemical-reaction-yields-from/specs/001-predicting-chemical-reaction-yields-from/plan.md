# Implementation Plan: Predicting Chemical Reaction Yields from Spectroscopic Data with Attention Mechanisms

**Input**: Feature specification from `/specs/001-predict-reaction-yields-from-spectra/spec.md`

## Summary

This project implements a **Simulation-to-Simulation Benchmark** to investigate whether a model can learn the mapping between simulated spectra and a synthetic yield target derived from molecular descriptors (MW, LogP, TPSA). The core hypothesis is that a multi-head self-attention network can effectively map these features. The study explicitly reframes the research question: "Can a model learn to map simulated DFT spectra to a synthetic yield target derived from molecular descriptors?" rather than "Do spectra predict real yields?" (which requires experimental data not available in the verified dataset list). The implementation prioritizes CPU feasibility on GitHub Actions, utilizing a sampled subset of verified open datasets (DFT for spectra), strictly enforcing reaction-template-based splitting to prevent data leakage, and performing rigorous statistical validation (including Simulated Data Integrity Checks and Partial Correlation Analysis).

### Causal Inference
- **Observational**: The study is observational (no randomization of reactions).
- **Claims**: Claims will be framed as **associational** within the simulation. No causal claims about "spectra causing yield" will be made. The goal is to assess the model's ability to *learn* a mapping between features, not to establish causality in the real world.
- **Confounding**: Reaction conditions (solvent, catalyst) are explicitly encoded as features to reduce confounding. **Partial Correlation** is used to control for structural descriptors.
