# Project Structure

This directory contains the implementation for the llmXive project.

## Directory Structure

- `src/`: Source code for the application
 - `utils/`: Utility functions (seeds, state management, validators)
 - `data/`: Data ingestion, preprocessing, and loading
 - `models/`: Model architectures and training logic
 - `eval/`: Evaluation metrics and interpretability
 - `cli/`: Command line interface
 - `config/`: Configuration files
- `tests/`: Test suites
 - `unit/`: Unit tests
 - `integration/`: Integration tests
- `data/`: Data storage
 - `raw/`: Raw input data
 - `processed/`: Processed data splits
 - `artifacts/`: Generated reports and manifests
 - `references/`: Reference data (literature values)
- `state/`: Project state tracking and checksums
- `specs/`: Feature specifications and design documents
- `scripts/`: Standalone scripts for setup and validation
