# PROJ-037: Investigating the Correlation Between Gut Microbiome Composition and Circadian Rhythm Disruption

## Overview
This project investigates the associational relationship between gut microbiome composition (specifically alpha and beta diversity metrics) and circadian rhythm disruption indicators (sleep duration, quality, and chronotype). Using data from the American Gut Project (AGP) and Open Humans, we perform statistical analyses to identify potential links while rigorously controlling for confounders.

## ⚠️ Scientific Disclaimer
**All findings in this project are strictly associational.** This analysis does not establish causality. Correlation does not imply causation; observed relationships may be driven by unmeasured confounders or reverse causality. This project adheres to FR-008 by explicitly avoiding causal language in all reports and visualizations.

## Prerequisites
- Python 3.9+
- `pip`
- System dependencies: `libhdf5` (for `biom-format`), `scipy` build tools

## Installation

1. **Clone and navigate to the project root:**
 ```bash
 cd projects/PROJ-037-investigating-the-correlation-between-gu
 ```

2. **Create and activate a virtual environment:**
 ```bash
 python -m venv venv
 source venv/bin/activate # On Windows: venv\Scripts\activate
 ```

3. **Install dependencies:**
 ```bash
 pip install -r requirements.txt
 ```

## Data Sources
This project uses **real data** from:
- **American Gut Project (AGP)**: 16S rRNA sequencing data and metadata (downloaded manually via `code/ingestion.py` from canonical URLs).
- **Open Humans**: Sleep and circadian rhythm metadata (downloaded via `code/ingestion.py`).

**No synthetic data is used.** If real data sources are unreachable, the pipeline fails loudly to prevent fabrication.

## Usage

### 1. Data Ingestion (US1)
Download, merge, and clean data:
```bash
python code/ingestion.py
```
**Outputs:**
- `data/processed/cohort_merged.csv`: Final analysis-ready cohort.
- `logs/ingestion.log`: Execution log with participant counts and data quality metrics.

### 2. Diversity Analysis (US2)
Calculate alpha/beta diversity:
```bash
python code/diversity.py
```

### 3. Associational Analysis (US2)
Perform correlations, dbRDA, GLM, PERMANOVA:
```bash
python code/analysis.py
```
**Outputs:**
- `data/outputs/correlation_results.csv`: Correlation coefficients, p-values, FDR-corrected p-values.
- `data/outputs/heatmap.png`: Heatmap of taxa-sleep associations.
- `data/outputs/pcoa_sleep_quality.png`: PCoA ordination colored by sleep quality.

### 4. Visualization (US2)
Generate plots (if not auto-generated by `analysis.py`):
```bash
python code/viz.py
```

### 5. Validation & Sensitivity (US3)
Bootstrap resampling and sensitivity analysis:
```bash
python code/validation.py
```
**Outputs:**
- `data/outputs/validation_status.json`: Bootstrap stability status.
- `data/outputs/sensitivity_report.csv`: Sensitivity analysis results.

### 6. Report Generation (US3)
Generate the final associational report:
```bash
python code/report.py
```
**Outputs:**
- `data/outputs/final_report.md`: Comprehensive report framing all findings as associational.

## Key Constraints & Compliance
- **No Causal Claims**: All outputs explicitly state findings are "associational" (FR-008).
- **Real Data Only**: No synthetic data fabrication. Pipeline fails if real sources are unreachable.
- **CPU-Only**: All analyses run on CPU; no GPU dependencies.
- **Reproducibility**: Random seeds managed via `code/utils/seeding.py`.
- **FDR Correction**: All p-values corrected using Benjamini-Hochberg (US2).
- **Confounder Adjustment**: GLM adjusts for age, BMI, diet type, medication, antibiotic history (US2).

## Limitations
- **Diet Timing**: Required by FR-004 but unavailable in AGP; "diet type" used as a substitute (documented in reports).
- **Sample Size**: Bootstrap resampling skipped if N < 40 (US3).
- **Data Availability**: AGP metadata may have missing values; imputation applied per spec (median/mode).
