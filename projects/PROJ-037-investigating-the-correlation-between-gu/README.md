# PROJ-037: Investigating the Correlation Between Gut Microbiome Composition and Circadian Rhythm Disruption

## Overview
This project investigates the associational links between gut microbiome diversity (alpha and beta diversity) and circadian rhythm disruption metrics (sleep duration, quality, chronotype) using data from the American Gut Project and Open Humans.

## Scientific Rigor
All findings are framed as **associational**. No causal claims are made. Correlation is a necessary but insufficient condition for understanding; this pipeline focuses on robust statistical association, FDR correction, and sensitivity analysis to establish reliable hypotheses for future mechanistic study.
