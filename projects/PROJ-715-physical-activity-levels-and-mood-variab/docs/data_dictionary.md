# Data Dictionary: Daily Aggregates

This document describes the schema, data types, and business logic for the `data/processed/daily_aggregates.csv` file, generated by the `code/preprocess.py` module (Task T016).

## File Overview

- **Source**: `data/raw/bronze.parquet` (StudentLife Dataset)
- **Granularity**: One row per participant per day.
- **Purpose**: To provide a normalized dataset for statistical modeling of physical activity and mood variability.

## Schema

| Column Name | Data Type | Description | Logic / Derivation |
|:--- |:--- |:--- |:--- |
| `participant_id` | `int` | Unique identifier for the participant. | Extracted from raw logs. |
| `date` | `datetime` | The date of the observation (YYYY-MM-DD). | Truncated timestamp of activity. |
| `total_steps` | `float` | Total number of steps recorded for the day. | Sum of step counts. **Note**: Days with 0 steps are recorded as `0.0`, not `NaN`. |
| `mean_mood` | `float` | Average mood rating for the day. | Mean of EMA mood ratings (1-5 scale). Days with < 2 ratings are excluded. |
| `mood_std` | `float` | Log-transformed standard deviation of mood. | Calculated as `np.log(mood_std_raw + 0.01)`. The `+0.01` offset prevents `log(0)` errors for days with zero variability. |
| `sleep_duration` | `float` | Estimated sleep duration in hours. | Derived from accelerometer data if missing. If missingness > `MISSINGNESS_THRESHOLD`, the value may be `NaN` (depending on spec assumptions). |
| `baseline_affect` | `float` | Participant's baseline affect score. | Derived from the first week's average or imputed if missing. |
| `day_of_week` | `int` | Day of the week (0=Monday, 6=Sunday). | Derived from the `date` column. |

## Data Quality & Constraints

- **Missingness**:
 - Rows with missing `total_steps` or `mean_mood` (due to insufficient ratings) are **excluded** from the dataset.
 - `sleep_duration` and `baseline_affect` may contain `NaN` if derivation is not possible and the missingness threshold is not met.
- **Transformations**:
 - The `mood_std` column is **already log-transformed**. Do not apply further log transformations before modeling.
- **Zero Handling**:
 - `total_steps` of 0 is a valid value representing a sedentary day.
 - `mood_std` of 0 (raw) is transformed to `log(0.01) ≈ -4.6`.

## Usage in Analysis

This file is the primary input for:
1. **Linear Mixed-Effects Models** (`code/analysis.py`): Predicting `mood_std` and `mean_mood` from `total_steps`.
2. **Validation**: Leave-One-Participant-Out (LOPO) cross-validation.
3. **Sensitivity Analysis**: Testing robustness against single-rating days and alternative metrics.
