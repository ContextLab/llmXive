# PROJ-849: Semantic Divergence Diagnostic for Agentic Reasoning

This project implements an automated diagnostic pipeline to compute semantic divergence scores
between agent thinking traces and tool descriptions, correlating them with simulated RL failure rates.

## Structure

- `src/`: Source code
- `tests/`: Test suites
- `data/`: Data artifacts and downloads
- `specs/`: Design documents

## Setup

1. Install dependencies: `pip install -r requirements.txt`
2. Run diagnostic: `python -m src.cli.run_diagnostic`
