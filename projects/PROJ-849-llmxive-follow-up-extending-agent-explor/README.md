# PROJ-849-llmxive-follow-up-extending-agent-explor
Automated Science Pipeline: Semantic Divergence Diagnostic for Agentic Reasoning

## Project Structure
- `code/`: Source code (cli, lib, models, services, tests)
- `data/`: Input datasets and intermediate files
- `results/`: Final outputs and reports
- `specs/`: Design documents and requirements

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Run diagnostic: `python -m code.cli.run_diagnostic`
