# Data Model: Exploring the Distribution of Smooth Numbers in Short Intervals

## Overview

This document defines the data structures, schemas, and storage formats for the project. All data is stored in `data/` and is immutable once written.

## Key Entities

### 1. PrimeList
A sorted, immutable collection of prime numbers up to $10^9$.
-   **Source**: Generated by `code/sieve.py`.
-   **Format**: CSV (`primes_1e9.csv`).
-   **Structure**: Single column `prime` (integer).

### 2. IntervalConfig
Defines the parameters for a single measurement run.
-   **Fields**: `x` (int), `y` (int), `h` (int), `start_offset` (int).
-   **Derived**: `interval_start` = `x + start_offset`, `interval_end` = `min(x + start_offset + h, 10^9)`.

### 3. DensityMeasurement
The raw output of the enumeration process, extended with theoretical baselines.
-   **Fields**:
    -   `config_id`: Unique identifier for the parameter set.
    -   `x`: Base start of the interval.
    -   `y`: Smoothness bound.
    -   `h`: Interval length.
    -   `start_offset`: Random offset applied.
    -   `u_value`: Calculated parameter $u = \ln x / \ln y$.
    -   `rho_theory`: Theoretical Dickman density $\rho(u)$.
    -   `count`: Number of $y$-smooth integers found.
    -   `rho_observed`: Calculated density `count / h`.
    -   `deviation_ratio`: Ratio `rho_observed / rho_theory`.
    -   `weight`: Statistical weight for WLS (approx `sqrt(count)` or `1/variance`).
    -   `timestamp`: ISO 8601 timestamp.

### 4. ModelFit
The result of the statistical analysis.
-   **Fields**:
    -   `y_bound`: The $y$ value for this group.
    -   `exponent_beta`: The fitted power-law exponent for the deviation ratio.
    -   `coefficient_c`: The fitted coefficient.
    -   `r_squared`: Goodness of fit (WLS).
    -   `p_value_ks`: Result of the Kolmogorov-Smirnov test.
    -   `p_value_adjusted`: Bonferroni-adjusted p-value.

## Storage Strategy

| Artifact | File Path | Format | Checksum |
| :--- | :--- | :--- | :--- |
| Prime List | `data/primes_1e9.csv` | CSV | SHA-256 |
| Raw Measurements | `data/density_measurements.csv` | CSV | SHA-256 |
| Model Fits | `data/model_fits.json` | JSON | SHA-256 |
| Visualizations | `data/figures/` | PNG | SHA-256 |

## Data Generation Pipeline

1.  **Sieve Phase**: Generates `primes_1e9.csv`.
2.  **Enumeration Phase**: Reads `primes_1e9.csv`, iterates through the parameter grid, computes `u_value` and `rho_theory` (via `code/dickman.py`), and appends rows to `density_measurements.csv`.
3.  **Analysis Phase**: Reads `density_measurements.csv`, performs WLS regression and KS tests, and writes `model_fits.json` and PNGs.

## Integrity Constraints

-   **Uniqueness**: Each `config_id` + `start_offset` combination must be unique.
-   **Validity**: `density` must be $\ge 0.0$ and $\le 1.0$.
-   **Completeness**: The `count` must be $\le h$.
-   **Theoretical Consistency**: `deviation_ratio` must be calculated using the `rho_theory` derived from the specific `u_value` of the interval.
