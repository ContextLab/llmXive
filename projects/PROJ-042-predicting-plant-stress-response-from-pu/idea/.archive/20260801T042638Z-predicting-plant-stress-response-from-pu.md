# Predicting Plant Stress Response from Publicly Available Transcriptomic Data

**Field**: biology

## Research question

Do distinct abiotic stress types (drought, salinity, heat, cold) induce biologically separable transcriptional signatures in plant RNA-seq data that generalize across independent public datasets without batch-effect correction, or are observed "generalization" signals primarily driven by dataset-specific technical artifacts?

## Motivation

Current crop resilience breeding relies on stress-specific biomarkers that often fail to transfer across conditions or species. While machine learning models frequently report high accuracy on within-dataset validation, these results are often inflated by batch effects that correlate stress labels with dataset identity. This research addresses a critical gap: distinguishing true biological generalization from technical artifacts by explicitly evaluating model performance on uncorrected data across independent repositories. The outcome will determine whether a unified, portable stress-screening pipeline is scientifically viable or if current biomarker discovery is fundamentally confounded by experimental noise.

### What is known

- [Investigation of temperature stress tolerance in Arabidopsis STTM165/166 using electrophysiology and RNA-Seq (2023)](https://arxiv.org/abs/2309.04107) — Establishes specific transcriptional responses to temperature stress in *Arabidopsis*, but focuses on a single stressor and genotype without addressing cross-dataset generalization or the impact of batch effects on multi-stress classification.
- [Identifying Stress Responsive Genes using Overlapping Communities in Co-expression Networks (2020)](https://arxiv.org/abs/2011.03526) — Proposes a workflow to identify stress-responsive genes using co-expression networks, but validates findings within a single experimental context and does not test the stability of these signatures across independent datasets or the necessity of batch correction for cross-study prediction.

### What is NOT known

No published work has systematically quantified the degree of transcriptional separability between multiple abiotic stress types using RNA-seq data from independent public repositories while explicitly **avoiding** batch-effect correction. Specifically, there is no benchmark establishing whether a classifier trained on one dataset can predict stress types in another dataset (from a different lab, species, or platform) significantly better than random chance when technical variation is left intact. The extent to which "generalization" in prior literature was driven by biological signal versus dataset-specific artifacts remains unquantified.

### Why this gap matters

Filling this gap is critical for the feasibility of universal stress biomarkers. If signatures generalize without correction, it enables robust, portable screening pipelines for crop improvement. If signatures only generalize after batch correction, it implies that current biomarker discovery is confounded by experimental artifacts, necessitating a shift toward dataset-specific models or rigorous meta-analytic frameworks that account for batch structure as a primary variable.

### How this project addresses the gap

The methodology will download and integrate RNA-seq data from multiple public GEO datasets, perform strict quality control to ensure dataset diversity, and quantify separability via a "Leave-One-Dataset-Out" (LODO) validation strategy on **uncorrected** data. This directly measures whether stress signatures possess biological independence from dataset-specific technical noise, providing the first empirical benchmark for true cross-dataset generalization in plant stress transcriptomics.

## Expected results

We expect to observe distinct transcriptional signatures for each stress type with high within-dataset accuracy (>75%), but a significant drop in cross-dataset performance on uncorrected data (accuracy near the dynamic random baseline of 1/N, where N is the number of classes in the held-out set). Evidence will be confirmed if the observed cross-dataset accuracy is not statistically distinguishable from a null distribution generated by permuting stress labels within the held-out dataset, demonstrating that apparent generalization in prior studies was likely driven by batch effects.

## Methodology sketch

- **Dataset Verification & Selection**: Download raw count matrices and metadata for 5–8 public RNA-seq datasets from NCBI GEO covering drought, salinity, heat, and cold stress. **Strictly verify** that each selected dataset contains plant samples and samples for *at least two* of the target stress classes to avoid complete confounding. Exclude any dataset that is human-derived, lacks sufficient class representation, or has a 100% confounded batch/condition (e.g., one dataset containing only drought samples).
- **Preprocessing & Harmonization**: Normalize counts using **TMM (Trimmed Mean of M-values)** via `edgeR` (or `scran` in R/Python equivalents) to account for library size and composition bias, as TPM is insufficient for cross-dataset comparison. Filter low-expression genes (<1 CPM across >80% of samples within each dataset). **Retain only genes present in 100% of the selected datasets** (Constitution Principle VII) to ensure a consistent feature space; if the intersection is biologically impoverished (e.g., <500 genes), the project will be flagged as out-of-scope.
- **Confounding Diagnostics**: Perform a **Chi-squared test of independence** (or Fisher's Exact Test if cell counts are low) on a contingency table of Dataset ID vs. Stress Type for each dataset to detect partial or complete confounding. Datasets with significant confounding (p < 0.05) will be excluded from the cross-dataset analysis to prevent batch-driven artifacts, but the exclusion will be logged rather than halting the entire pipeline.
- **Feature Selection**: Identify the top 1,500 most variable genes across the *combined* dataset using variance stabilization. **Crucially**, do not apply batch correction (ComBat/Harmony). Perform feature selection strictly within the training fold of each cross-validation split to prevent data leakage.
- **Cross-Dataset Validation Strategy**: Implement a "Leave-One-Dataset-Out" (LODO) strategy. For each iteration:
    - Train a Random Forest classifier on 4 datasets.
    - Test on the 1 held-out dataset.
    - **Do not apply batch correction** to the test set or training set prior to evaluation. The primary metric will be accuracy on uncorrected data.
- **Statistical Significance Testing**: Perform a **label-permutation test** (1,000 iterations) where stress labels are shuffled **strictly within the held-out test set** (preserving the dataset structure but breaking the biological signal). Compare the observed cross-dataset accuracy against this null distribution to determine if generalization is significantly better than chance (p < 0.05).
- **Biomarker Stability Analysis**: Perform **bootstrap resampling** (100 iterations) of the training data to calculate the variance of feature importance scores. Report only genes with low importance variance (selection frequency > 0.7) as robust candidates.
- **Evaluation Metrics**: Report stratified accuracy, F1-score, and macro-averaged precision/recall. Define the "random chance" baseline dynamically as $1/N$ where $N$ is the number of stress classes present in the held-out dataset. Define "Ambiguous" results as accuracy strictly between the random baseline and a Minimum Detectable Effect Size (MDES) calculated via post-hoc power analysis.
- **Visualization**: Generate UMAP plots of the held-out test data colored by stress type and by dataset ID. Calculate a **conditional Silhouette Score** (stress-type clustering conditioned on dataset ID) to ensure observed clusters are not driven by batch effects.
