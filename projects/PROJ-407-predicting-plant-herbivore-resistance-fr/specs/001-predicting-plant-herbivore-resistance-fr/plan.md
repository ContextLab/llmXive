# Implementation Plan: Predicting Plant Herbivore Resistance from Publicly Available Metabolomic Data

**Branch**: `001-predict-herbivore-resistance` | **Date**: 2026-07-11 | **Spec**: `specs/001-predict-herbivore-resistance/spec.md`
**Input**: Feature specification from `/specs/001-predict-herbivore-resistance/spec.md`

## Summary

This project implements a CPU-tractable machine learning pipeline to predict plant herbivore resistance scores from metabolomic data sourced from public repositories (HuggingFace/NCBI GEO). The system ingests raw metabolomic profiles and metadata, extracts and harmonizes quantifiable resistance metrics, performs rigorous preprocessing (imputation, normalization, SVA for batch effects), trains a Random Forest model to identify predictive metabolites, and validates findings via genotype-stratified permutation testing and Benjamini-Hochberg correction. The pipeline is designed to execute entirely within GitHub Actions free-tier constraints (CPU-only, ≤7 GB RAM, ≤6h).

## Implementation Phases

### Phase 0: Data Ingestion & Variable Fit (Addresses SC-004, FR-001)
1.  **Download**: Fetch the verified dataset `plant-metabolomics/herbivore-resistance-v1` via HuggingFace `datasets` library.
2.  **Variable Fit Check**: Verify presence of `sample_id`, `genotype_id`, `metabolite_*` columns, and a `resistance` column.
    *   *Abort Condition*: If required columns are missing or `resistance` is non-numeric/non-ordinal, log error "No quantifiable resistance metric found" and abort.
3.  **Harmonization**:
    *   Convert categorical resistance (Low/Med/High) to ordinal (1/2/3).
    *   Normalize continuous resistance (e.g., % leaf area) to [0, 1] if needed.
    *   **FR-008**: Check for `herbivore_density`. If present, normalize resistance score. If absent, flag limitation in metadata.

### Phase 1: Contract Validation (Addresses Plan Consistency)
1.  **Schema Check**: Run `pytest` with `jsonschema` to validate the processed data against `contracts/dataset.schema.yaml`.
2.  **Abort Condition**: If validation fails, halt pipeline and report schema mismatch.

### Phase 2: Preprocessing & Modeling (Addresses FR-002, FR-003, FR-004)
1.  **Preprocessing**:
    *   Filter low-variance metabolites (var < 0.001).
    *   Impute missing values using k-NN (k=5).
    *   **p >> n Handling**: If metabolites > samples, apply PCA to top variance components.
2.  **Split**: Stratified split by `genotype_id` (Train/Test). Ensure no genotype leakage.
3.  **Training**: Train Random Forest (n_estimators=100, max_depth=10).
4.  **Feasibility Monitoring**: Log runtime and peak memory usage.

### Phase 3: Statistical Validation (Addresses FR-005, FR-006, SC-001, SC-002)
1.  **Global Significance**: Run a sufficient number of permutations (stratified by genotype) to generate a null R² distribution.
    *   *Conditional Logic*: If global p ≥ 0.05, report "Null Result" and **skip** biomarker listing.
2.  **Biomarker Analysis**: If global p < 0.05:
    *   Calculate univariate correlations (Pearson/Spearman) for each metabolite.
    *   Apply Benjamini-Hochberg correction.
    *   Filter for q < 0.10.
3.  **Batch Effect Control**: If batch metadata is missing, run Surrogate Variable Analysis (SVA) before permutation.

### Phase 4: Reporting & Versioning (Addresses SC-005, Principle V)
1.  **Report Generation**: Compile results into `results/summary_report.md`.
2.  **Feasibility Check**: Compare logged runtime/memory against 6h/7GB limits.
3.  **Versioning**: Run `versioning.py` to hash artifacts and update `state/...yaml`.
4.  **Task Generation**: Run `tasks-generator` to produce `tasks.md`.

## Risk Assessment

| Risk | Impact | Mitigation |
| :--- | :--- | :--- |
| **No Real Metabolomic Data Available** | **Fatal**: Pipeline cannot run. | Use verified HuggingFace dataset `plant-metabolomics/herbivore-resistance-v1`. If unavailable, abort. |
| **Resistance Metric Missing/Non-numeric** | High | Graceful failure with specific error message (US-1 Edge Case). |
| **p >> n Overfitting** | Medium | Automatic PCA dimensionality reduction if features > samples. |
| **Permutation Test Timeout** | Medium | Limit iterations to a predetermined maximum number (as specified). Monitor runtime. |
| **Batch Effects** | Medium | Stratified permutation or SVA if metadata missing. |
