# Processed Data Directory

This directory contains all intermediate and final processed datasets generated by the analysis pipeline.

## Contents

- `global_subset_{band}.nc`: Sliced geopotential height and IVT data for specific latitudinal bands.
- `ar_freq_{band}.nc`: Monthly Atmospheric River (AR) frequency counts and event metadata.
- `corr_fdr_{band}_{season}.nc`: Pearson correlation coefficients, raw p-values, and Benjamini-Hochberg FDR adjusted p-values.
- `validation_{band}_{season}.json`: Validation metrics comparing results against teleconnection indices (PNA/NAO).
- `sensitivity_summary.csv`: Summary of threshold sensitivity analysis results.

## Generation

These files are generated by running the analysis pipeline phases:
- Phase 2: Data Preprocessing and Slicing
- Phase 3: AR Detection and Frequency Aggregation
- Phase 4: Correlation and FDR Analysis
- Phase 5: Validation
- Phase 6: Sensitivity Analysis

## File Naming Convention

- `{band}`: Latitudinal band identifier (e.g., `30N-40N`)
- `{season}`: Season identifier (e.g., `DJF`, `MAM`, `JJA`, `SON`)

## Data Integrity

All data in this directory is derived from real ERA5 reanalysis data fetched from the Copernicus Climate Data Store (CDS). No synthetic or placeholder data is stored here.
