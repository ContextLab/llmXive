# Processed Data Directory

This directory contains processed NetCDF files generated during the analysis pipeline.

## Contents

- `ar_freq_{band}.nc`: Monthly Atmospheric River frequency counts per latitudinal band.
- `corr_fdr_{band}_{season}.nc`: Correlation results with FDR correction.
- `sensitivity_summary.csv`: Threshold sensitivity analysis results.

## Generation

These files are generated by the `src/data/preprocess.py` and `src/data/analysis.py` modules.
Do not manually edit these files; regenerate them using the pipeline.
