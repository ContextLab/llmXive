# Figures Directory

This directory contains all visualizations and maps generated by the analysis pipeline.

## Contents

- `corr_map_{band}_{season}_{hash}.png`: Global spatial maps of significant AR-Z500 correlation coefficients.
 - Non-significant cells (adjusted p > 0.05) are masked/transparent.
 - Files include a SHA-256 content hash in the filename for reproducibility.

## Generation

These figures are generated by the visualization module (`src/viz/maps.py`) during Phase 7 of the pipeline.

## Requirements

To regenerate these figures, ensure the following dependencies are installed:
- `cartopy`
- `matplotlib`
- `xarray`

## Usage

View the correlation maps to identify regions where AR frequency significantly covaries with 500mb geopotential height anomalies. The color scale indicates the strength and direction of the correlation, while transparency indicates statistical non-significance.
