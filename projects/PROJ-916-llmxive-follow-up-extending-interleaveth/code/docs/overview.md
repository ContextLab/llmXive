# Overview

## Project: llmXive

llmXive is an automated science pipeline designed to evaluate and compare agentic interleaved generation against single-pass baselines in the context of visual scene understanding.

## Goals

- Implement a deterministic text-based simulator to model the "grounding gap"
- Execute a CPU-tractable agentic loop (Planner → Generator → Critic)
- Perform statistical comparison and ablation studies

## Scope

This project focuses on:
- Text-based scene simulation
- Agentic loop execution on CPU
- Statistical analysis of reasoning scores
