# Golden Set Acquisition Instructions (Task T007e)

## Purpose
This document provides instructions for domain experts to manually label interactions
from the generated template to create the `data/processed/golden_set.csv` required
for the Cognitive Load Estimation Model training.

**CRITICAL**: This is a **manual human task**. The pipeline cannot proceed without
these expert labels. Do **NOT** use synthetic data, random values, or automated
heuristics to populate this file.

## Prerequisites
1. You must have completed **Task T007**: Generate Golden Set Template.
2. Verify the file `data/processed/golden_set_template.csv` exists in the project directory.
3. Ensure you have a text editor or spreadsheet tool (e.g., VS Code, Excel, Google Sheets) open.

## Step-by-Step Instructions

### 1. Open the Template
Locate and open `data/processed/golden_set_template.csv`. It contains columns:
- `interaction_id`: Unique identifier for the student interaction.
- `expert_load_score`: **Empty** (this is what you must fill).

### 2. Review the Interaction Data
For each `interaction_id`, you will need to review the underlying interaction data
(e.g., response latency, error patterns, hint requests) to determine the cognitive load.
The raw data is available in `data/processed/raw_assistments.csv` (or the dataset
generated by `code/load_data.py`).

### 3. Assign Expert Load Scores
Using your domain expertise, assign a **cognitive load score** between **0 and 100**
for each interaction based on the behavioral proxies:
- **Low Load (0-30)**: Fast response, no errors, minimal hints.
- **Moderate Load (31-70)**: Moderate latency, occasional errors, some hints.
- **High Load (71-100)**: Very slow response, frequent errors, many hints, or long pauses.

**Guidance**:
- Be consistent in your rubric.
- Aim for a distribution that reflects the difficulty of the tasks.
- **Minimum Requirement**: You must label at least **50 interactions**.
- **Target**: Label as many as possible for better model validation.

### 4. Save the File
1. Save the file as `data/processed/golden_set.csv`.
2. Ensure the `expert_load_score` column is populated with numeric values (0-100).
3. Do **NOT** change the `interaction_id` column.
4. Do **NOT** add or remove columns.

## Verification
Once saved, the pipeline (Task T007c) will automatically verify:
- The file exists at `data/processed/golden_set.csv`.
- It contains at least 50 rows.
- The `expert_load_score` values are valid numbers between 0 and 100.

If validation fails, the pipeline will halt with the error:
> "WAITING_FOR_HUMAN: Golden Set file (data/processed/golden_set.csv) is missing.
> Please complete the manual labeling process described in
> `docs/golden_set_creation.md` to acquire the Golden Set."

## Important Notes
- **NO Synthetic Data**: Do not generate fake scores using scripts or random values.
- **NO Automation**: This step requires human judgment to avoid the "illusion of competence".
- **Quality Over Quantity**: Accurate labels are more valuable than a large number of random labels.

## Next Steps
After saving `data/processed/golden_set.csv`, the pipeline will proceed to:
1. **T007c**: Validate and Load Golden Set.
2. **T008**: Validate Golden Set (check row count and score validity).
3. **T015**: Train the Cognitive Load Estimation Model using these labels.

**Contact**: If you have questions about the labeling rubric, refer to the
project's `docs/research.md` or contact the project lead.
