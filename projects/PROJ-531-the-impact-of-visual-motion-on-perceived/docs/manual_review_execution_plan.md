# Manual Review Execution Plan (T033b)

**Project**: The Impact of Visual Motion on Perceived Agency in Virtual Interactions
**Task ID**: T033b
**User Story**: US3 (Visualization and Interpretation)
**Objective**: Document the step-by-step procedure for recruiting independent reviewers, distributing the survey, collecting ratings, and verifying Success Criterion 005 (SC-005).

---

## 1. Context and Ethics Declaration

This project is a **synthetic data stress-test**. No human participants are involved in the primary data collection. The "Human Review" described in this plan is strictly a **code artifact review** to validate the quality, clarity, and reproducibility of the generated reports and visualizations.

**Ethics Declaration**:
> "This review process involves human assessors evaluating software artifacts (code, plots, documentation) generated by the pipeline. No personal data, behavioral data, or sensitive information from human subjects is being collected or analyzed. The 'ratings' collected are quality assurance scores for the project deliverables, not scientific data about human perception. Therefore, IRB approval is not required for this specific review step."

---

## 2. Prerequisites

Before executing this plan, ensure the following artifacts exist (produced by T033 and T032):
1. `docs/human_review_protocol.md` (Survey template and recruitment script).
2. `docs/human_review_aggregation.py` (Python script to calculate pass rates).
3. `data/results/interpretation.md` and `data/results/plots/` (The artifacts to be reviewed).
4. A shared folder or repository link containing the artifacts for reviewers.

---

## 3. Step-by-Step Procedure

### Step 1: Recruit Independent Reviewers
*Target*: Minimum 3 independent reviewers (developers, researchers, or domain experts).

**Action**:
1. Identify potential reviewers who are **not** the primary authors of this codebase.
2. Send the **Recruitment Script** (defined in `docs/human_review_protocol.md`) via email or internal messaging.
3. Confirm availability and agreement to complete the survey within 48 hours.

### Step 2: Distribute Survey and Artifacts
*Action*:
1. Create a shared read-only link (e.g., GitHub Pages, Google Drive, or internal wiki) containing:
 - The `data/results/interpretation.md` file.
 - The `data/results/plots/` directory (scatter plots, importance charts, partial dependence).
 - A brief README explaining the context (synthetic data stress-test).
2. Send the **Survey Link** (Google Forms, Typeform, or a simple HTML form) to the recruited reviewers.
3. Ensure the survey includes the question: *"On a scale of 1-5, how clearly do the visualizations and interpretation support the conclusion that this is a synthetic data stress-test?"* (and other questions from the T033 survey template).

### Step 3: Collect Ratings
*Action*:
1. Wait for responses.
2. Export the raw survey data to a CSV file named `data/raw/reviewer_ratings.csv`.
3. **Required Columns**: `reviewer_id`, `rating_1`, `rating_2`,..., `rating_n` (matching the survey questions).
4. Ensure at least 3 valid responses are collected. If fewer than 3 are received, recruit additional reviewers.

### Step 4: Run Aggregation Script
*Action*:
1. Open a terminal in the project root.
2. Run the aggregation script provided in T033:
 ```bash
 python code/human_review/aggregate_ratings.py
 ```
3. **Input**: The script expects `data/raw/reviewer_ratings.csv`.
4. **Output**: The script will print the pass rate and save a summary to `data/results/human_review_summary.json`.

### Step 5: Verify Success Criterion 005 (SC-005)
*Logic*:
- The script calculates the percentage of reviewers who rated **≥ 4** on the primary quality questions.
- **Pass Condition**: `pass_rate >= 0.80` (80%).

**Verification**:
- If the output shows `Pass: True`, the project meets SC-005.
- If `Pass: False`, document the specific feedback from reviewers, update the `interpretation.md` or plots, and repeat Steps 2-4 with the revised artifacts.

## 5. Troubleshooting

- **Issue**: Reviewers cannot access the artifacts.
 - **Fix**: Verify the shared folder permissions (read-only for external users).
- **Issue**: Aggregation script fails to find `reviewer_ratings.csv`.
 - **Fix**: Ensure the CSV is placed exactly at `data/raw/reviewer_ratings.csv`.
- **Issue**: Pass rate is below 80%.
 - **Fix**: Do not fabricate ratings. Re-examine the `interpretation.md` and plots for clarity. Revise the content and re-run the review with the same or new reviewers.
