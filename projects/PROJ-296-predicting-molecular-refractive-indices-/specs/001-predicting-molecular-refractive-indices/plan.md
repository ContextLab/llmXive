# Implementation Plan: Predicting Molecular Refractive Indices from Graph-Based Molecular Representations

**Branch**: `001-predict-molecular-refractive-indices` | **Date**: 2026-10-08 | **Spec**: `specs/001-predict-molecular-refractive-indices/spec.md`

## Summary

This project implements a CPU-feasible Message Passing Neural Network (MPNN) to predict molecular refractive indices from SMILES strings, comparing performance against a traditional atomic contribution baseline. The pipeline enforces strict memory (7GB) and time (6h) constraints, utilizes scaffold-based splitting to prevent data leakage, and applies Integrated Gradients for structural interpretability.

## Technical Context

**Language/Version**: Python 3.11  
**Primary Dependencies**: PyTorch (CPU-only), PyTorch Geometric, RDKit, scikit-learn, pandas, numpy  
**Storage**: Local CSV/Parquet files (streamed), GitHub Actions cache  
**Testing**: pytest (unit tests for parsers, integration tests for pipeline), paired t-tests for metrics  
**Target Platform**: Linux (GitHub Actions Free Tier: 2 vCPU, 7GB RAM)  
**Project Type**: Data Science Pipeline / Research Code  
**Performance Goals**: < 6h total runtime, < 7GB peak RAM  
**Constraints**: No CUDA, no external API calls during training, strict memory limits  
**Scale/Scope**: Dataset ~10k-50k molecules (filtered for MW < 500 Da)

## Complexity Tracking

| Violation | Why Needed | Simpler Alternative Rejected Because |
| :--- | :--- | :--- |
| **Scaffold Split** | Prevents data leakage where similar molecules appear in train/test. | Random split rejected because it inflates performance metrics by allowing near-duplicates in test. |
| **Integrated Gradients** | Required by Spec US-2 to identify structural drivers. | SHAP/Permutation importance rejected as they are computationally heavier and less granular for graph nodes. |
| **Streaming Data** | Ensures 7GB RAM limit is not exceeded with large datasets. | Loading full dataset into pandas DataFrame rejected due to OOM risk on 2-core runners. |
