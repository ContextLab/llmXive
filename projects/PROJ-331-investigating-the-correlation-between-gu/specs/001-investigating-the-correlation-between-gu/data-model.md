# Data Model: Investigating the Correlation Between Gut Microbiome Composition and Parkinson’s Disease Progression

## Raw Data Files
| Path | Format | Content |
|------|--------|---------|
| `data/raw/ppmi_asv.zip` | ZIP of CSV/TSV | Raw ASV count matrix (samples × taxa) |
| `data/raw/ppmi_clinical.parquet` | Parquet | Clinical metadata (patient_id, visit_date, age, sex, levodopa_eq_dose, optional UPDRS_partIII) |

## Processed Files
| Path | Format | Description |
|------|--------|-------------|
| `data/processed/filtered_samples.parquet` | Parquet | Samples that meet ≥ 2 visits filter, with merged clinical fields |
| `data/processed/clr_abundances.parquet` | Parquet | CLR‑transformed taxa abundances (zero‑taxa removed) |
| `data/processed/patient_taxon_slopes.parquet` | Parquet | Per‑patient slope of CLR abundance for each retained taxon |
| `data/processed/patient_updrs_slopes.parquet` | Parquet | **Optional**: Per‑patient slope of the longitudinal motor outcome (UPDRS III or alternative). Generated only if a motor‑score column is present; otherwise this file is not created and downstream phases are skipped. |

## Result Files
| Path | Format | Schema Reference |
|------|--------|------------------|
| `results/taxa_correlations.csv` | CSV | `contracts/taxa_results.schema.yaml` (section *correlation*) |
| `results/mixed_effects_summary.csv` | CSV | `contracts/taxa_results.schema.yaml` (section *mixed_effects*) |
| `results/permutation_pvalues.csv` | CSV | `contracts/taxa_results.schema.yaml` (section *permutation*) |
| `results/PD_microbiome_progression_report.pdf` | PDF | N/A (binary artifact) |

* `creation_timestamp`  
* `origin_task` (e.g., `preprocess`, `correlation`)
