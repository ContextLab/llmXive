### Implementation for User Story 3

- [ ] T028 [US3] Implement sensitivity analysis script sweeping **absolute** MAE thresholds {0.01, 0.05, 0.1} Å² (as mandated by FR-006) in `code/eval/sensitivity.py`. **Dependency**: Must run after T022 (GCN Predictions) and T024 (Oracle SASA). **Action**: Load per-molecule predictions from `results/predictions/gcn_predictions.parquet` and `results/baseline/oracle_sasa.parquet`. Calculate success rates for each threshold. **Output**: `data/processed/sensitivity_absolute.csv` with columns `[threshold, success_rate, sample_size]`. **Format**: `threshold` (float), `success_rate` (float, 0.0-1.0), `sample_size` (int). **Primary Verification**: This is the mandatory verification path per Spec FR-006.
