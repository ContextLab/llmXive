**Independent Test**: The training script runs to completion within the CI limit, producing two model artifacts and a results report showing MAE, RMSE, R² for both, along with a statistical significance test.

### Implementation for User Story 2

### Implementation for User Story 3

- [ ] T040 [US3] Calculate model performance metrics (MAE, R²) for the GCN and the **Geometry-Based Baseline** on the test set. **Dependency**: Must run after T021b (Baseline Training) and T022 (GCN Training). **Action**: Load predictions from T021b and T022. This task fulfills SC-001 and SC-002 by measuring model performance against the baseline.
- [ ] T028 [US3] Implement sensitivity analysis script sweeping **absolute** MAE thresholds {, 0.05, 0.1} Å² (as mandated by FR-006) in `code/eval/sensitivity.py`. Specify the chosen method and the condition in the output report.
