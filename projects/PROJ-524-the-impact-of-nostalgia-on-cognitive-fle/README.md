# The Impact of Nostalgia on Cognitive Flexibility in Aging Adults

## Overview
This project investigates the relationship between nostalgia induction and cognitive flexibility in adults aged 65 and older.
It implements a data pipeline for ingesting, cleaning, and analyzing cognitive task data (WCST) alongside nostalgia stimuli.

## Project Structure
- `code/`: Python modules for ingestion, analysis, and utilities.
- `data/`: Raw, processed, and results data directories.
- `tests/`: Unit and integration tests.
- `specs/`: Design documents and requirements.

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Configure environment variables (see `code/config.py`).
3. Run data ingestion: `python code/ingestion.py`
4. Run analysis: `python code/analysis.py`
