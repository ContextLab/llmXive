# Quickstart Guide: Impact of Nostalgia on Cognitive Flexibility

This guide provides instructions to set up the environment, install dependencies, and run the initial data ingestion pipeline on a real sample dataset.

## Prerequisites

- Python 3.9 or higher
- `pip` package manager
- Access to the internet (to fetch real data from OpenML/HuggingFace)

## Installation

1. **Clone the repository** (if not already done) and navigate to the project root.

2. **Create a virtual environment** (recommended):
 ```bash
 python -m venv venv
 source venv/bin/activate # On Windows: venv\Scripts\activate
 ```

3. **Install dependencies**:
 Ensure you have the `requirements.txt` file generated by task T002.
 ```bash
 pip install -r requirements.txt
 ```
 This will install `pandas`, `scipy`, `statsmodels`, `numpy`, `pyyaml`, `openml`, `datasets`, `requests`, `pytest`, `black`, and `ruff`.

4. **Verify Linting Configuration**:
 Ensure `pyproject.toml` exists with Black and Ruff configurations (created in T003a/T003b).
 ```bash
 ruff check code/
 black --check code/
 ```

## Running the Ingestion Pipeline (Hello World)

The following steps demonstrate how to fetch real data, validate the schema, and produce a cleaned dataset.

### 1. Set Environment Variables (Optional)
By default, the pipeline attempts to fetch real data. To force simulation mode (only for testing if real data is unreachable), set:
```bash
export SIMULATION_MODE=true
```
*Note: The default behavior is to fetch real data. If the real source is unreachable, the script will fail loudly as per design requirements.*

### 2. Run the Ingestion Script
Execute the main ingestion pipeline. This script (T010a/T010b) will:
- Fetch the dataset from the canonical source (OpenML/HuggingFace).
- Save the raw data to `data/raw/raw_dataset.csv`.
- Validate the schema (age, stimulus_type, metrics).
- Filter for participants aged 65+.
- Save the cleaned dataset to `data/processed/cleaned_dataset.csv`.

```bash
python -m code.ingestion
```

### 3. Verify Outputs
After successful execution, verify the following artifacts exist:

- **Raw Data**: `data/raw/raw_dataset.csv`
- **Cleaned Data**: `data/processed/cleaned_dataset.csv`
- **Exclusion Log**: `data/processed/exclusion_log.json`
- **Metadata**: `data/raw/metadata.json`

You can inspect the cleaned dataset using pandas:
```python
import pandas as pd
df = pd.read_csv("data/processed/cleaned_dataset.csv")
print(df.head())
print(f"Total valid records: {len(df)}")
```

## Troubleshooting

- **Data Fetch Failed**: If you see `DataFetchError`, the canonical source (OpenML/HuggingFace) is unreachable or the dataset ID is invalid. Ensure your internet connection is active. Do not modify the code to bypass this check unless explicitly switching to `SIMULATION_MODE=true` for offline testing.
- **Schema Validation Error**: If the fetched data does not match `contracts/dataset.schema.yaml`, the source data has changed. Check the `exclusion_log.json` for specific field errors.
- **Missing Directories**: Ensure `T001` has been run to create `data/`, `code/`, `contracts/`, etc.
