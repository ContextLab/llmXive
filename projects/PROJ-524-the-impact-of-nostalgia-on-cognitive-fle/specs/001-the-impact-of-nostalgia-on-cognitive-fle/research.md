# Research: The Impact of Nostalgia on Cognitive Flexibility in Aging Adults

## Overview

**Framing (methodological demonstration)**: The goal of this project is to **demonstrate** the full analysis pipeline (ingestion → validation → Welch's t-tests → correction → effect sizes → sensitivity analysis) on a deterministic, seeded simulation. Because no open dataset containing WCST performance plus a nostalgia-vs-control stimulus label for older adults is publicly available, the real-world research question cannot be answered with obtainable data. All results are labeled `"validity_status": "simulation"`; **no causal or real-world claims are made**. If real data are later obtained, the identical pipeline can be re-run unchanged.

### Strategy
1. **No real dataset is available**; the pipeline uses a **deterministic simulation generator** (`code/ingestion.py`, seed = 42, no network access) creating 256 participants (128 per condition) with realistic parameter values drawn from published WCST literature distributions, ages 65–85, MMSE scores, and covariates (`education_years`, `gender`).
2. **Stimulus files**: placeholder tone clips stored under `data/stimuli/` with SHA-256 checksums, clearly marked "simulation only".
3. All outputs carry `"validity_status": "simulation"`.

## Statistical Methodology

### Primary Analysis
- **Design**: Between-subjects (nostalgia vs. control), simulated.
- **Test**: Welch's independent-samples t-test for each outcome (`perseverative_errors`, `categories_completed`).
- **Multiple-Comparison Correction**: Bonferroni correction for the two outcomes (α = 0.05 / 2 = 0.025).
- **Effect Size**: **Hedges' g** with 95 % confidence interval, using the non-pooled variance convention consistent with Welch's test (supersedes the spec's "Cohen's d"; flagged for kickback).
- **MDES**: Computed post-hoc from observed sample size and variance; reported as a limitation.
- **Covariate Adjustment**: The simulation includes `education_years` and `gender`; an OLS model (`outcome ~ stimulus_type + education_years + gender`) is **always** fitted alongside the unadjusted Welch test, and `adjustment_status` is recorded. (On real observational data this would control confounding; on simulated data it demonstrates the adjusted workflow.)

### Sensitivity Analyses (FR-005)
- **Alpha Sweep**: Re-run the Welch tests at α = 0.01, 0.025 (Bonferroni-corrected), 0.05.
- **MMSE Exclusion Sensitivity**: Compare results with and without excluding `MMSE < 24`.
- **Borderline Flagging**: Any Bonferroni-corrected p-value in **[0.020, 0.030]** (±0.005 around corrected α = 0.025) is labeled `"sensitive"`. This supersedes the spec's 0.04–0.06 range, which is inconsistent with the corrected threshold (flagged for kickback).

### Assumptions & Limitations
- **Simulation-only**: All primary results are simulation results and must not be interpreted as evidence of any real effect.
- **Collinearity**: `perseverative_errors` and `categories_completed` are definitionally related; each outcome is reported separately with no claim of independent effects.
- **Sample Size**: A priori power analysis (d = 0.5, α = 0.05, power = 0.80) indicates ≈128 participants per group; the simulation meets this target (256 total).
- **Measurement Validity**: WCST is a validated measure of cognitive flexibility; citations are checked by `reference_validator.py` (title overlap ≥ 0.7).
