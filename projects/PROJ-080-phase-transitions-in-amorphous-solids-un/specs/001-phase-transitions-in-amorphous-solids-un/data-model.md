# Data Model: Phase Transitions in Amorphous Solids Under Shear Stress

## Overview

This document defines the data structures used in the project, focusing on the transformation from raw trajectory data to processed metrics and final analysis outputs.

## Data Flow

1.  **Raw Input**: Synthetic MD Trajectory (Coordinates, Box, Stress) generated by `data_generator.py`.
2.  **Preprocessing**: Calculation of $D^2_{min}$ and Stress Drop detection.
3.  **Aggregation**: Clustering into shear bands and computing mean $D^2_{min}$.
4.  **Analysis**: Permutation Test statistics, Sensitivity Table.
5.  **Output**: Validation Report (Confusion Matrix, FPR/FNR), Memory Profile.

## Entities

### 1. Trajectory (Raw)
*Source*: `data/raw/` (Synthetic MD files)
*Description*: Sequence of particle states.
*Key Fields*:
*   `timestep`: Integer, simulation time step.
*   `particle_id`: Integer, unique ID per particle.
*   `x, y, z`: Float, particle coordinates.
*   `box_x, box_y, box_z`: Float, simulation box dimensions.
*   `stress_tensor`: 6-element array or separate columns (optional, for yielding detection).
*   `label`: String, "brittle" or "ductile" (derived from simulation parameters).

### 2. Precursor Metric (Processed)
*Source*: `data/processed/d2_min_trajectory.csv`
*Description*: Non-affine displacement per particle per timestep.
*Key Fields*:
*   `timestep`: Integer.
*   `particle_id`: Integer.
*   `D2_min`: Float, Falk-Langer non-affine displacement.
*   `local_shear_strain`: Float, local shear strain.

### 3. Shear Band Aggregation (Processed)
*Source*: `data/processed/shear_band_stats.csv`
*Description*: Aggregated metrics per shear band cluster.
*Key Fields*:
*   `shear_band_id`: Integer, cluster ID from k-means.
*   `mean_D2_min`: Float, average $D^2_{min}$ in the band.
*   `particle_count`: Integer, number of particles in the band.
*   `label`: String, "brittle" or "ductile" (assigned based on global trajectory label).

### 4. Statistical Output
*Source*: `data/processed/permutation_results.json`
*Description*: Results of the Permutation Test.
*Key Fields*:
*   `statistic`: Float, test statistic.
*   `pvalue`: Float, p-value.
*   `method`: String, "Permutation Test".
*   `correction`: String, "Bonferroni" or "None".

### 5. Sensitivity Table
*Source*: `data/processed/sensitivity_table.csv`
*Description*: Threshold sweep results.
*Key Fields*:
*   `threshold`: Float, $D^2_{min}$ threshold value.
*   `fpr`: Float, False Positive Rate.
*   `fnr`: Float, False Negative Rate.
*   `f1_score`: Float, F1-score.

### 6. Memory Profile
*Source*: `data/processed/memory_profile.json`
*Description*: Memory usage statistics.
*Key Fields*:
*   `peak_ram_mb`: Float, peak RAM usage in MB.
*   `limit_mb`: Float, RAM limit (specified maximum).
*   `status`: String, "PASS" or "FAIL".

## Data Constraints

* **Particle Count**: Max [deferred] per trajectory (FR-006).
*   **Precision**: Double precision (float64) for all calculations.
*   **Determinism**: All random seeds (k-means, splits) fixed to a deterministic value.
*   **Integrity**: Raw data checksums recorded in `state/`.
