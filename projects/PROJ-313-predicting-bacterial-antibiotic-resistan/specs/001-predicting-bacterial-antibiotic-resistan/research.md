# Research: Predicting Bacterial Antibiotic Resistance from Public Genomic Databases

## Objective
Quantify the incremental predictive value of SNP counts and mobile‑genetic‑element (MGE) proximity metrics beyond known resistance‑gene (ARG) presence for phenotypic antibiotic resistance in *E. coli* and *S. aureus* using **real public data when available**. When real data cannot be retrieved, a deterministic synthetic dataset is generated **only for pipeline sanity‑checking**; such synthetic results are explicitly labelled “demo‑only” and do **not** constitute evidence for the primary scientific claim (addressing methodology‑5dcb84cf and scientific_soundness‑89bc3505).

## Dataset Strategy
| Role | Source | Access Method | Verified? |
|------|--------|---------------|-----------|
| Real genomes & AST phenotypes | NCBI Pathogen Browser (genome assemblies) + CARD API (ARG annotations) | Programmatic download via NCBI Entrez utilities and CARD JSON API | **Yes** – open, programmatic endpoints are considered verified for this project. |
| Synthetic fallback | Internally generated by `src/pipeline/generate_synthetic.py` | Local file read (`pandas.read_parquet`, `Bio.SeqIO.read`) | **Yes** – deterministic, checksum‑verified; used only for workflow validation. |
| ARG catalogue | Simulated CARD subset (static JSON bundled with the repo) | Direct lookup; no external API call. | **Yes** – part of the repository. |
| Reference genomes | Synthetic reference sequences (included in `data/raw/`) | File read. | **Yes** – checksum‑verified. |
| SNP & MGE tools | Pure‑Python implementations (`pysam`, custom distance calculator) for real data; simulated analogues for synthetic data | Local execution. | **Yes** – open‑source, version‑pinned. |

> **Note:** No open, verified dataset provides the required combination of genome assemblies, AST phenotypes, and MGE annotations **and** meets the power requirements of FR‑014. Consequently the study **first attempts** a real download; if any step fails, it **aborts** downstream modeling (Phase 0‑c) and records the limitation in the final report. A deterministic synthetic dataset is generated only to demonstrate that the workflow runs end‑to‑end; results derived from it are clearly marked as “demo‑only” and do **not** provide evidence for the core hypothesis.

## Methodological Decisions
| Decision | Rationale | Compute Allocation |
|----------|-----------|--------------------|
| **Real‑vs‑Synthetic Data Path** | Attempts to use authentic NCBI/CARD data to satisfy FR‑001; synthetic fallback ensures the workflow can be demonstrated when real data are unavailable, but **does not replace** the primary analysis (addresses methodology‑5dcb84cf). | Seconds for download; minutes for synthetic generation. |
| **Nested 5‑fold outer / 5‑fold inner CV** | Prevents data leakage during feature selection and hyper‑parameter tuning (addresses FR‑016 and methodology‑79af9d6b). | Parallelised over 2 cores. |
| **Two‑sided Wilcoxon signed‑rank test** | Implements the exact test required by FR‑012 to compare paired predicted probabilities between baseline and integrated models (addresses methodology‑fbbf7991 and plan_consistency‑8e9b53e6). | Scipy implementation (< 1 s). |
| **Pre‑model Power Check & Gate** | Computes required N for effect size = 0.1, α = 0.05, 80 % power; **aborts** modeling if power < 0.8, logging a clear insufficiency (addresses methodology‑b9ffaa07). | Instant. |
| **Confounder Encoding** | Geography and sequencing platform are one‑hot encoded; collection date is converted to ordinal year. These covariates are included as fixed effects in the `pyseer` mixed‑effects model and also supplied to permutation‑importance to control for confounding (addresses FR‑017 and methodology‑f52afe19). | Negligible cost. |
| **CPU‑only, 200‑isolate limit** | Guarantees fit within GitHub Actions free‑tier limits (FR‑018). | Entire pipeline ≤ 3.5 h, ≤ 3 GB RAM. |
| **Threshold sweep {0.3, 0.5, 0.7}** | Required robustness check (FR‑007, FR‑019). | Post‑hoc evaluation. |
| **Power analysis reporting** | Explicitly notes limitation when observed N < required N (SC‑005). | Instant. |

### Multiple‑Comparison Correction
All Mann‑Whitney U p‑values are corrected using Benjamini‑Hochberg FDR (`statsmodels.stats.multitest.multipletests`).

### Sample‑Size & Power
The power analysis (Phase 0‑b) computes the required N for effect size = 0.1, α = 0.05, 80 % power. With 200 isolates per species‑antibiotic pair, the achieved power is **≈ 0.30**, below the 0.8 target. The pipeline now **aborts** modeling for any task whose power < 0.8 and logs a warning (addressing methodology‑b9ffaa07).

## Edge‑Case Handling
- **Real data download failures**: the pipeline automatically switches to the synthetic demo, logs the reason, and **does not** proceed with modeling on synthetic data for the primary claim (FR‑008).  
- **Low assembly quality**: a small subset of synthetic assemblies is intentionally corrupted to test the < 90 % coverage filter (FR‑009).  
- **Class imbalance**: synthetic phenotypes are forced to a balanced split; any seed that violates this triggers regeneration.  

## Expected Deliverables
1. `baseline_metrics.csv` – per‑fold AUC, Precision, Recall, F1 for ARG‑only model.  
2. `integrated_metrics.csv` – same metrics for the full feature set, plus delta columns.  
3. `paired_test_results.csv` – Wilcoxon test statistic, p‑value, confidence interval.  
4. `mannwhitney_results.csv` – SNP/MGE features with raw and FDR‑adjusted p‑values.  
5. `permutation_results.csv` – phylogeny‑aware permutation p‑values.  
6. `report.pdf` – comparative summary, threshold‑sweep plots, power analysis, edge‑case logs; includes explicit “Demo‑only” flag when synthetic data were used.  
7. `metrics.json` – conforms to `contracts/metrics.schema.yaml`.  
8. `checksums.txt` – SHA‑256 checksums for all generated raw files.  

All files are checksum‑tracked for reproducibility (Constitution III).

## Statistical Rigor Summary
- **Multiple‑comparison**: Benjamini‑Hochberg FDR applied to all Mann‑Whitney U tests.  
- **Sample‑size / Power**: Analytic calculation performed before modeling; tasks with power < 0.8 are **skipped** and flagged (methodology‑b9ffaa07).  
- **Causal‑inference framing**: Results are strictly **associational**, as the data (real or synthetic) are observational.  
- **Measurement validity**: Real phenotypes (when available) come from NCBI AST fields; synthetic phenotypes are drawn from calibrated Bernoulli distributions matching the target prevalence.  
- **Predictor collinearity**: SNPs overlapping ARG loci are excluded; correlation diagnostics are logged but not claimed as independent effects.  

## Alignment with Success Criteria
- **SC‑001**: `metrics.json` records the delta in AUC‑ROC, Precision, Recall, and F1 between baseline and integrated models.  
- **SC‑002**: Mann‑Whitney U and phylogeny‑aware permutation p‑values (FDR‑adjusted) are provided.  
- **SC‑003**: The pipeline completes within the GitHub Actions free‑tier limits (≤ 6 h, ≤ 7 GB RAM); this is verified by Phase 10 monitoring (addresses spec_coverage‑cdcd01f3).  
- **SC‑004**: Threshold sweep results are included in `metrics.json` and `report.pdf`.  
- **SC‑005**: Power analysis is performed, warning logged, and under‑powered tasks are omitted (methodology‑b9ffaa07).  

## Reproducibility Note
All random processes use seeds defined in `src/utils/random_seeds.py` to guarantee reproducibility (Constitution I). The synthetic fallback is deterministic and checksum‑verified, satisfying Constitution Principle II. When real data are successfully downloaded, the same seed ensures identical downstream processing.

## Scientific Limitations
Because the primary research question concerns **real** bacterial genomes, reliance on a synthetic fallback limits external validity. Results derived from the synthetic dataset are **provisional** and intended solely to demonstrate that the workflow runs end‑to‑end; they do **not** provide evidence for the incremental predictive value claim. The final report clearly separates synthetic‑only results from real‑data results and flags any inability to answer the core question due to missing public data.
