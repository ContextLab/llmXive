# Data Model: MobileForge Logic Distillation

## 1. Overview
All artifacts in the pipeline conform to JSON‑Schema definitions stored under `contracts/`. These schemas are validated by the contract test suite.

## 2. Core Schemas

### ExtractionDataset (raw & processed)
- **File**: `data/processed/train_splits.parquet` (and `test_splits.parquet`)  
- **Schema**: `contracts/dataset.schema.yaml`  
- Fields: `ui_state`, `corrective_hint`, `action`, `trajectory_status`, plus `metadata` (source log, filter criteria).

### TrainingInput
- **File**: `data/processed/train_splits.parquet` (used by training)  
- **Schema**: `contracts/training_input.schema.yaml` (ensures required columns and status enum).

### EvaluationResult
- **File**: `state/evaluation_results.json`  
- **Schema**: `contracts/evaluation.schema.yaml`  
- Captures success rates, McNemar’s test details, power‑analysis parameters, and sensitivity report.

### PowerAnalysisOutput
- **File**: `state/validated_n.json`  
- **Schema**: `contracts/power_analysis.schema.yaml`  
- Contains `n_required` and the full parameter set used for the calculation.

### StateArtifacts
- **File**: `state/artifact_hashes.json`  
- **Schema**: `contracts/state_artifacts.schema.yaml`  
- Maps every persisted file to its SHA256 checksum for reproducibility (Principle III).

### FunctionalSuccess
- **File**: `state/functional_success.json` (generated by `pipeline/evaluate.py`)  
- **Schema**: *None yet* – this file records per‑task boolean success flags derived from the Android emulator; it is used only internally for McNemar’s test.

## 3. Data Integrity Rules
- **Checksum Verification**: On each run, loaders compute SHA‑256 of raw files and compare to `data/checksums.json`. Mismatch → hard failure.  
- **Immutability**: Raw files under `data/raw/` are never overwritten; derived files carry version suffixes if source changes.  
- **No Synthetic Fallbacks**: Loaders raise `FileNotFoundError` if a required artifact is missing.  
- **PII Prohibition**: Schemas forbid fields that could contain personal identifiers.
