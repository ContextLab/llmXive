# PROJ-930: llmXive Follow-up - Extending MobileForge

## Project Structure
This project implements CPU-tractable logic distillation for mobile automation tasks.

### Directory Layout
- `code/data/raw/`: Raw log data from MobileForge
- `code/data/processed/`: Extracted triples and processed datasets
- `code/data/evaluation/`: Evaluation datasets and results
- `code/models/`: Trained distilled models and training scripts
- `code/utils/`: Utility modules (emulator, metrics, power analysis)
- `code/tests/`: Unit and integration tests

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Run setup scripts to initialize project structure and state management.

## Usage
Refer to individual module documentation for specific CLI usage.
