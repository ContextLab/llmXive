# PROJ-677: Impact of Cache Line Padding on False Sharing in Concurrent Counters

## Project Structure

This project investigates the performance impact of cache line padding on false sharing in multi-threaded counter increments.

- `code/`: Source code for benchmarks (C++) and analysis (Python).
- `data/`: Raw and processed data files generated by experiments.
- `state/`: Runtime state, checkpoints, and artifact checksums.
- `.github/`: GitHub Actions workflows and CI/CD configurations.

## Prerequisites

- C++17 compatible compiler (g++ or clang++)
- Python 3.11+
- CMake (optional, for build system)
- Required Python packages (see `code/analysis/requirements.txt` or root `requirements.txt`)

## Quick Start

1. **Setup Environment**:
 ```bash
 python -m venv venv
 source venv/bin/activate
 pip install -r requirements.txt
 ```

2. **Build Benchmark**:
 ```bash
 cd code/scripts
 bash build.sh
 ```

3. **Run Experiments**:
 ```bash
 cd code/scripts
 bash run_benchmarks.sh
 ```

4. **Analyze Results**:
 ```bash
 cd code/analysis
 python run_analysis.py
 ```
