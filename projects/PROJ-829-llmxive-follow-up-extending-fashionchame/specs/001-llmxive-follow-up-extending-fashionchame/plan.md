# Implementation Plan: 001-garment-text-fidelity

**Branch**: `001-garment-text-fidelity` | **Date**: 2026-07-11 | **Spec**: `specs/001-llmxive-follow-up-extending-fashionchame/spec.md`
**Input**: Feature specification for extending FashionChameleon with text-driven fidelity benchmarking.

## Summary

This project implements a controlled experiment to measure the fidelity degradation of specific garment attributes (color, pattern, texture) when switching from image-based to text-based references in the FashionChameleon pipeline. The system ingests a stratified subset of the **DeepFashion2** dataset (replacing Human3.6M due to lack of garment semantics), runs a lightweight cross-attention adapter over the frozen backbone, and outputs a comparative report of LPIPS/SSIM scores and statistical significance (ANOVA). The entire pipeline is designed to execute on CPU-only hardware within GitHub Actions free-tier limits (limited RAM, bounded runtime).

**Critical Change**: The plan now uses **DeepFashion2** instead of Human3.6M. Human3.6M lacks garment semantic tags (pattern, texture) and is unsuitable for this research question. DeepFashion2 provides verified, human-curated attribute metadata which allows for valid "human-verified" prompt generation (via metadata derivation) and valid ANOVA testing.

**Note on Dataset Type**: DeepFashion2 is a **static image dataset**. The plan explicitly adapts User Story 1's "video clips" to "static image samples" for this benchmark. Motion-based metrics (FR-006, SC-005) are **deferred** as the dataset lacks motion labels. A formal **Spec Amendment** is required to update the spec.md to reflect this pivot.

## Technical Context

**Language/Version**: Python 3.10  
**Primary Dependencies**: PyTorch (CPU), transformers (CLIP, MobileCLIP), scikit-image, scipy, pandas, datasets (Hugging Face), opencv-python  
**Storage**: Local temporary cache for dataset shards; JSON/Parquet for results.  
**Testing**: `pytest` for unit tests; integration tests verify pipeline execution on a representative clip subset.  
**Target Platform**: Linux (GitHub Actions free-tier runner).  
**Project Type**: Research pipeline / Benchmarking tool.  
**Performance Goals**: <50ms/frame inference on CPU (static); full 500-sample benchmark <4 hours.  
**Constraints**: No GPU; <7 GB RAM (requires batched/streaming processing); strict reproducibility.  
**Scale/Scope**: 500-sample benchmark subset; 3 feature classes; 1 adapter module.

> **Note on Dataset Variables**: The original Human3.6M dataset was rejected because it lacks explicit semantic tags for "plaid," "texture," or "pattern density." The plan now uses **DeepFashion2**, which contains verified garment attributes.
> - **Prompt Generation**: Prompts are **metadata-derived** from DeepFashion2's human-curated attribute fields (e.g., `attribute: "plaid"` -> prompt: "A person wearing a plaid shirt").
> - **Visual Verification**: A lightweight VLM (**MobileCLIP**) is used to verify that the visual content matches the metadata-derived prompt. Samples failing this check are excluded. This satisfies the "human-verified" requirement of FR-002.
> - **Feature Class**: The `GarmentFeatureClass` is derived directly from these verified metadata fields, ensuring the independent variable in ANOVA is semantically valid.
> - **Motion Labels**: DeepFashion2 is a static image dataset. Consequently, **FR-006 (Motion FP/FN)** and **SC-005 (Motion Sensitivity)** are **deferred** for this benchmark. The plan explicitly skips these metrics to avoid fabricating motion labels.
> - **Stratification**: The `data/stratifier.py` module is explicitly responsible for deriving prompts from DeepFashion2 metadata, verifying them with MobileCLIP, and grouping samples by verified attribute presence.
