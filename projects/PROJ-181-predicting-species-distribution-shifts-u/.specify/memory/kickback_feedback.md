## Unresolved concerns

- The plan uses `statsmodels.stats.power.NormalIndPower` to compute power for detecting a ΔAUC = 0.05 (effect size = 0.50). AUC differences are not normally distributed and the NormalIndPower approximation is inappropriate for ROC‑based metrics; this undermines the claimed ≥0.8 power (FR‑011/FR‑015). A more suitable approach would be a simulation‑based power analysis using bootstrapped AUC distributions or the DeLong variance estimator.
- The evaluation compares historic model performance (spatial‑block CV) to recent records without explicitly accounting for differing sampling biases between the historic and recent datasets. Although a bias‑layer is created during preprocessing, the plan does not state that the same bias correction is applied to the recent test set, risking confounding bias with true niche change.
- Using calibrated AUC decline (ΔAUC) as the primary indicator of niche non‑stationarity conflates model transferability issues (e.g., covariate shift, extrapolation) with genuine ecological niche shifts. Without a formal test separating these sources (e.g., MESS/MOP‑only analysis, or explicit modeling of climate novelty), the conclusion about niche instability may be overstated.
- Success Criterion SC-004 (data acquisition completeness: ≥95 % species with ≥100 records after thinning and ≥99 % non‑null climate values) is absent from the plan; no task or metric is defined to measure or enforce this criterion.
- The plan schedules a hierarchical bootstrap with **≥ 2000 iterations** (see “hierarchical bootstrap (≥1000 iterations)” and “2 000 iterations” in the Implementation Phases). Combined with 10 species, 3 algorithms, 5‑fold spatial block CV, and full‑resolution WorldClim rasters, this workload is unlikely to complete within the **6‑hour, 2‑CPU‑core GitHub Actions free‑tier limit (SC‑002)**. Reduce the number of bootstrap iterations, limit the species count, or employ a more aggressive sampling strategy to ensure the pipeline stays within the allotted compute budget.
- Principle II (Verified Accuracy) is marked FAIL because the plan relies on open GBIF/eBird APIs and WorldClim download pages that are not pre‑verified static URLs. The constitution requires every external citation to be verified before use, so proceeding with unverified sources violates a non‑negotiable principle.
- The validation strategy uses recent occurrence records (2005‑2020) both to evaluate historic‑trained models and as the ground‑truth for assessing future (2050) projections (see Research §2). This creates a circular/tautological validation: the same dataset serves as the dependent variable for both the historic performance baseline and the future‑projection performance assessment, yet the hypothesis being tested is precisely whether niche suitability changes over time. Using recent records to judge future projections assumes niche stability, which is the null hypothesis, making the test unable to independently confirm or refute niche shift.
