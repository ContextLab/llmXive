# Implementation Plan: Residue Distribution of Euler's Totient Function Modulo Small Primes

**Branch**: `001-residue-distribution-totient` | **Date**: 2026-10-24 | **Spec**: `specs/001-residue-distribution-totient/spec.md`  
**Input**: Feature specification from `/specs/001-residue-distribution-totient/spec.md`

## Summary
The project will empirically assess the **uniformity** of Euler’s totient residues $\phi(n)\bmod p$ for the primes $p\in\{3,5,7,11\}$ over the integer range $[1,N]$.  The pipeline consists of:

1. **Linear‑sieve generation** of $\phi(n)$ using Python’s arbitrary‑precision `int`.  
2. **Residue aggregation** for each supported prime, producing a `ResidueDataset` JSON file.  
3. **Goodness‑of‑fit testing** with a chi‑squared statistic against the **uniform** null hypothesis $E_i = N/p$. If any expected count $<5$, the pipeline automatically switches to an **exact multinomial test**; otherwise it uses a Monte‑Carlo simulation ($M=10{,}000$) to obtain a p‑value.  
4. **Multiple‑testing correction** (Bonferroni) across the four primes.  
5. **Visualization** (bar plot + QQ‑plot) that overlays observed frequencies with the uniform baseline $N/p$ and confidence intervals.  
6. **Structured reporting** (JSON artefacts, Markdown summary, binary pass/fail flag at $\alpha=0.05$ after Bonferroni adjustment).  
7. **Resource guarding** (MemoryGuard) to keep peak RAM < 90 % of the 7 GB runner limit.  
8. **Benchmark dummy** (`benchmark_dummy.json`) generated by a dedicated script to satisfy verification of wall‑time / memory record.  
9. **Full test suite** (unit, integration, contract validation, mypy check) guaranteeing deterministic reproducibility.

All functional requirements (FR‑001 – FR‑007) and success criteria (SC‑001 – SC‑005) are explicitly addressed by the phases below.

## Technical Context
- **Language/Version**: Python 3.11  
- **Primary Dependencies**: `numpy`, `scipy`, `matplotlib`, `psutil`, `pytest`, `jsonschema`, `mypy` (all pinned in `requirements.txt`)  
- **Storage**: Local filesystem under `data/` (raw & processed) and `results/` (plots & reports)  
- **Testing**: `pytest` for unit & integration, `jsonschema` for contract validation, `mypy` for static typing  
- **Target Platform**: GitHub Actions free‑tier runner (2 CPU cores, ~7 GB RAM, ≤6 h) – **CPU‑first**; no GPU required.  
- **Constraints**: MemoryGuard aborts if usage exceeds 90 % of 7 GB limit. Arbitrary‑precision arithmetic satisfies Constitution Principle VI. Fixed random seed (`seed = 12345`) satisfies reproducibility (Principle I).
