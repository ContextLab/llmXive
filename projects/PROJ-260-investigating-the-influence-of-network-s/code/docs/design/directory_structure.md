# Data Directory Structure

This document defines the directory hierarchy for the `llmXive` project investigating the influence of network structure on heat conduction in amorphous solids.

## Root Data Directory: `data/`

The `data/` directory serves as the root for all project data artifacts, organized by lifecycle stage and derivation type.

### 1. `data/raw/`
**Purpose**: Storage for original, unmodified data fetched from external sources (e.g., Materials Cloud, Zenodo).
- Contains: Original trajectory files (`.xyz`, `.dump`, `.cfg`), metadata files, and checksum manifests.
- **Constraint**: Files in this directory must never be modified.

### 2. `data/derived/`
**Purpose**: Storage for data processed, transformed, or calculated from the raw data.
- **Constraint**: All files here are reproducible artifacts generated by the pipeline.

#### 2.1 `data/derived/topology/`
**Purpose**: Stores network topology extraction results.
- **Content**: CSV files containing atomic IDs, coordination numbers, bond angle variances, and anomaly flags.
- **Pattern**: `*_N{size}*.csv` (e.g., `topology_N1000_run1.csv`).

#### 2.2 `data/derived/vdos/`
**Purpose**: Stores vibrational density of states (VDOS) and participation ratio calculations.
- **Content**: CSV files with frequency bins, VDOS values, and participation ratios.
- **Content**: Tolerance reports (`tolerance_report.txt`).

#### 2.3 `data/derived/reference/`
**Purpose**: Stores researcher-provided independent thermal conductivity (κ) values.
- **Content**: `kappa_values.csv` containing system size, κ, source ID, and trajectory ID.

#### 2.4 `data/derived/correlation/`
**Purpose**: Stores aggregated datasets and statistical correlation results.
- **Content**: `aggregated_dataset.csv`, correlation summary tables, and bootstrap results.

### 3. `data/metadata/`
**Purpose**: Stores project-level metadata, registries, and validation logs.
- **Content**:
 - `dataset_registry.json`: Mapping of system sizes to dataset IDs.
 - `valid_sources.json`: List of validated source IDs.
 - `trajectory_ids.json`: Extracted trajectory IDs for independence checking.
 - `registry_validation.log`: Logs from the registry validation step.
 - `topology_log.log`: Logs from topology extraction.
 - `sampling_log.txt`: Logs regarding data sampling limits (if applicable).
 - `manual_reference.json`: Manually calculated reference values for verification.

## Directory Tree Summary

```text
data/
├── raw/
│ └── [Original trajectory files from external sources]
├── derived/
│ ├── topology/
│ │ └── [Topology CSVs: atom_id, coord_num, angle_var, is_valid]
│ ├── vdos/
│ │ └── [VDOS CSVs and tolerance reports]
│ ├── reference/
│ │ └── [kappa_values.csv]
│ └── correlation/
│ └── [aggregated_dataset.csv, correlation results]
└── metadata/
 ├── dataset_registry.json
 ├── valid_sources.json
 ├── trajectory_ids.json
 ├── registry_validation.log
 ├── topology_log.log
 └── sampling_log.txt
```
