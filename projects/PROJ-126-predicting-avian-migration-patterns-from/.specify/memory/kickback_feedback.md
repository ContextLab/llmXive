## Unresolved concerns

- The target variable is defined as an effort‑adjusted cumulative‑count threshold (scaled by the per‑cell effort covariate) and then the same effort covariate is also used as a predictor in the secondary model. Even though the primary model omits the covariate, the target itself still embeds effort information, which can re‑introduce circularity and bias environmental effect estimates (construct‑validity issue).
- The Diebold‑Mariano test is applied to compare model prediction errors, but DM is designed for time‑series forecast evaluation, not for spatially structured predictions. Even with HAC correction, the test may not adequately account for spatial autocorrelation, potentially inflating type‑I error rates.
- FR-010 requires fitting a Gaussian Process (scikit‑learn GaussianProcessRegressor) to residuals. The implementation plan instead uses a mixed‑effects linear model (statsmodels.MixedLM) with a random intercept, which does not satisfy the specified GP requirement.
- The plan references validation of MODIS covariates against NOAA GHCN stations (FR‑011) but provides no verified citation or automated download procedure for the GHCN dataset. In research.md the GHCN data are described as a manual download outside CI, which breaks the reproducibility and automation guarantees required by the constitution and FR‑011. A proper, reachable URL and inclusion in the “Verified Datasets” block (or an alternative fully automated source) are needed.
- The plan never validates the raw eBird CSV (`ebd_subset.csv`) against the `contracts/dataset.schema.yaml` contract, even though that contract exists and is intended for the raw checklist schema. This leaves the `dataset.schema.yaml` contract unexercised, violating the plan‑consistency requirement that every contract be exercised by at least one plan element.
- The `grid_cell_observation.schema.yaml` contract requires a `threshold_used` field, but the plan’s description of T015 does not mention writing this column to `first_arrival_sweep.csv`. Without explicitly recording which cumulative‑count threshold (3, 5, 10) produced the `first_arrival_week`, the output will fail schema validation.
- The secondary bias‑adjusted model includes the effort covariate as a predictor, but the same effort covariate is used as an offset when constructing the target variable (effort‑scaled cumulative‑count thresholds). Evaluating this model’s performance (e.g., via RMSE, Diebold‑Mariano test) therefore tests a predictor that is definitionally embedded in the outcome, creating a circular validation. This violates the independence requirement between predictors and validation targets and can artificially inflate the secondary model’s apparent skill.
