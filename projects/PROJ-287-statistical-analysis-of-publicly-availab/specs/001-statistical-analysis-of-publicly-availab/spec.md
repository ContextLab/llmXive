# Specification: Statistical Analysis of Topic Drift in Academic Abstracts
# Version: 1.1.0 (Updated per T008a)
# Date: 2024-05-20

## 1. Introduction

This document defines the requirements for analyzing topic drift in academic abstracts
across defined time windows using Latent Dirichlet Allocation (LDA) and statistical
divergence measures.

## 2. Functional Requirements

### FR-001: Data Acquisition
The system shall download abstracts from arXiv and PubMed APIs, filtering by publication
year and field.

### FR-002: Preprocessing
The system shall tokenize, lemmatize, and remove stopwords using window-specific
stopword lists to prevent language drift artifacts.

### FR-003: Topic Modeling
The system shall fit LDA models with k=10 topics per time window.

### FR-004: Topic Alignment
The system shall align topic indices across windows using cosine similarity of
topic-word distributions to resolve label switching.

### FR-005: Divergence Calculation
The system shall compute Jensen-Shannon divergence between aligned topic distributions
for consecutive time windows.

### FR-006: Permutation Testing
The system shall perform stratified permutation tests (n=1000) to establish null
distributions for divergence metrics.

### FR-007: Confidence Intervals
The system shall compute bootstrapped 95% confidence intervals for divergence estimates.

### FR-008: Multiple Testing Correction
The system shall apply **MaxT procedure** for Family-Wise Error Rate (FWER) control
across dependent window pairs.

> **AMENDMENT (T008a):** The original requirement for Benjamini-Hochberg (FDR) control
> is hereby superseded. Due to the high dependency structure between adjacent time
> windows, the **MaxT procedure** (Westfall & Young, 1993) shall be used instead.
> This ensures strict FWER control at alpha=0.05 [UNRESOLVED-CLAIM: c_d483f501 — status=not_enough_info], preventing false positives in
> drift detection. The implementation must utilize the permutation max-statistic
> approach, accounting for the correlation structure of the null distributions.
> This change addresses constraint preservation and ensures robust statistical
> inference under temporal dependency.

### FR-009: Visualization
The system shall generate PNG figures showing divergence trends and significance
markers.

### FR-010: Reproducibility
The system shall generate a manifest.json containing all parameters, seeds, and
checksums.

### FR-011: Sensitivity Analysis
The system shall sweep coherence thresholds {0.35, 0.40, 0.45} and report inconsistency rates.

### FR-012: Sampling Strategy
The system shall use stratified sampling for permutation tests to ensure
representativeness while respecting computational limits.

### FR-014: Stopword Application
The system shall explicitly load and apply versioned, window-specific stopword lists
generated by TF-IDF analysis.

## 3. Non-Functional Requirements

### SC-001: Performance
The pipeline must complete within 6 hours on 2 CPU cores.

### SC-002: Data Integrity
All data fetching must use real APIs; no synthetic data generation.

### SC-003: Error Handling
The system shall fail loudly on API failures or data corruption.

### SC-004: Significance Logic
The correction module must explicitly flag significant results based on adjusted p-values.

### SC-005: Manifest Completeness
The manifest must include at least 10 distinct parameter categories.

## 4. Time Windows

The analysis is partitioned into five non-overlapping 5-year windows:
- Window 1: 2000–2004
- Window 2: 2005–2009
- Window 3: 2010–2014
- Window 4: 2015–2019
- Window 5: 2020–2024

## 5. Data Models

- **AbstractRecord**: id, title, abstract, year, source, tokens
- **TopicVector**: window_id, topic_id, proportions (k=10)
- **DivergenceMeasurement**: window_pair, js_divergence, p_value, is_significant

## 6. Dependencies

- Python 3.11
- scikit-learn, scipy, nltk, spacy, pandas, matplotlib, requests, pyyaml
