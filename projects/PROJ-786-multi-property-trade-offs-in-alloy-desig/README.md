# PROJ-786: Multi-Property Trade-Offs in Alloy Design

This project implements an automated science pipeline to analyze trade-offs between bulk and shear moduli in alloy designs using public compositional data (OQMD).

## Structure
- `code/`: Python modules for data ingestion, encoding, modeling, and optimization.
- `data/`: Raw and processed datasets.
- `tests/`: Unit, integration, and contract tests.
- `docs/`: Documentation and specifications.

## Prerequisites
- Python 3.11+
- See `requirements.txt` for dependencies.

## Usage
Run the main pipeline:
```bash
python code/main.py
```
