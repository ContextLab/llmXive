# Data Dictionary

This document defines all data fields, file formats, and data structures used in the research pipeline.

## Raw Data Sources

### GitHub PR Metadata
Source: GitHub API v3
Format: JSON

| Field | Type | Description |
|-------|------|-------------|
| `pr_id` | int | Unique PR identifier |
| `repo_id` | str | Repository identifier |
| `author_type` | str | "human" or "llm-like" |
| `created_at` | datetime | PR creation timestamp |
| `updated_at` | datetime | Last update timestamp |
| `merged_at` | datetime | Merge timestamp (if merged) |
| `comments_count` | int | Number of review comments |
| `review_duration` | float | Time in seconds from open to first comment/merge |
| `file_size` | int | Total lines of code changed |
| `complexity_score` | float | Cyclomatic complexity |

## Processed Data Files

### `data/processed/generated_snippets.parquet`
Synthetic LLM code snippets generated by the pipeline.

| Field | Type | Description |
|-------|------|-------------|
| `snippet_id` | str | Unique snippet identifier |
| `source_commit` | str | Source commit hash |
| `generation_source` | str | "synthetic" or "classified" |
| `code_content` | str | Actual code content |
| `language` | str | Programming language |
| `complexity_metrics` | dict | LOC, cyclomatic complexity |
| `is_valid_syntax` | bool | Syntax validation result |

### `data/processed/diagnostic_scores.parquet`
Semantic similarity scores (diagnostic only, excluded from matching).

| Field | Type | Description |
|-------|------|-------------|
| `snippet_id` | str | Unique snippet identifier |
| `semantic_similarity_score` | float | Cosine similarity to human baseline |
| `embedding_model` | str | Model used for embeddings |

### `data/processed/matching_results.parquet`
Matched pairs from propensity score matching.

| Field | Type | Description |
|-------|------|-------------|
| `treatment_id` | str | LLM-like snippet ID |
| `control_id` | str | Human snippet ID |
| `propensity_score` | float | Estimated propensity score |
| `smd_file_size` | float | Standardized mean difference for file size |
| `smd_complexity` | float | Standardized mean difference for complexity |
| `smd_activity` | float | Standardized mean difference for activity |

### `data/processed/sensitivity_summary.json`
Sensitivity analysis results by star-count quartile.

```json
{

 "quartile": "Q1",

 "p_value": 0.03,
 "is_significant": true
 },
 {
 "quartile": "Q2",
 "star_range": "5000-15000",
 "p_value": 0.04,
 "is_significant": true
 }

 "consistent": true,

}
```

### `data/processed/deviation_report.md`
Documentation of methodological deviations from initial requirements.

### `data/processed/matching_failure_report.json`
Failure diagnostics when matching balance cannot be achieved.

```json
{
 "retry_count": 3,
 "final_smd": {
 "file_size": 0.15,
 "complexity": 0.12,
 "activity": 0.18
 },
 "failure_reason": "SMD > 0.1 after 3 retries",
 "timestamp": "2024-01-15T10:30:00Z"
}
```

### `data/processed/prompt_based_cohort.parquet`
Prompt-generated code cohort for validation.

| Field | Type | Description |
|-------|------|-------------|
| `snippet_id` | str | Unique snippet identifier |
| `prompt` | str | Natural language prompt from commit message |
| `generated_code` | str | Generated code content |
| `is_valid_syntax` | bool | Syntax validation result |
| `semantic_similarity` | float | Similarity to original human code |

## Configuration Files

### `data/checksums.yaml`
Checksums for data integrity verification.

```yaml
files:
 - path: data/processed/generated_snippets.parquet
 md5: abc123...
 - path: data/processed/matching_results.parquet
 md5: def456...
```

## Data Quality Metrics

- **Syntax Validation Rate**: ≥95% of generated snippets must be syntactically valid
- **Matching Balance**: SMD < 0.1 for all covariates
- **Sensitivity Consistency**: p < 0.05 in ≥80% of strata
- **PII Scan**: No PII detected in any dataset

## Data Retention

- Raw data: Retained for 6 months
- Processed data: Retained indefinitely for reproducibility
- Logs: Retained for 3 months
