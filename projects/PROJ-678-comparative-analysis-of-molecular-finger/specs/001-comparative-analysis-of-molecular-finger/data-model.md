# Data Model: Comparative Analysis of Molecular Fingerprints for Pesticide Toxicity Prediction

This document defines the core data entities, their schemas, and relationships used throughout the `PROJ-678` pipeline. These definitions serve as the contract between the data acquisition, processing, modeling, and evaluation stages.

## 1. Compound

Represents a unique chemical entity derived from the Tox21 dataset. This entity is the fundamental unit of analysis.

### Schema

| Field | Type | Description | Constraints |
|:--- |:--- |:--- |:--- |
| `compound_id` | `str` | Unique identifier for the compound (e.g., DSSTox ID). | Primary Key, Non-null |
| `smiles` | `str` | Canonical SMILES string representing the molecular structure. | Valid RDKit parseable string |
| `molecular_weight` | `float` | Calculated molecular weight. | > 0 |
| `is_organophosphate` | `bool` | Flag indicating if the compound matches the SMARTS pattern `[P](=O)([O,SC])[O,SC]`. | True/False |
| `toxicity_labels` | `dict` | Dictionary mapping endpoint names to binary toxicity labels (0/1) or NaN. | Keys: `NR-AR`, `NR-AR-LBD`, `NR-ER`, `NR-ER-LBD`, `NR-PR`, `NR-PR-LBD`, `NR-TR`, `NR-TR-LBD`, `NR-ER-LBD`, `NR-ER-LBD` (subset of Tox21 endpoints) |

### Relationships
- **1-to-Many** with `Fingerprint`: A single compound can have multiple fingerprint representations (Morgan, MACCS).
- **1-to-Many** with `PerformanceMetric`: Used to generate multiple metrics across folds or test sets.

---

## 2. Fingerprint

Represents a bit-vector or count-vector representation of a `Compound` generated by a specific algorithm.

### Schema

| Field | Type | Description | Constraints |
|:--- |:--- |:--- |:--- |
| `fingerprint_id` | `str` | Unique identifier (e.g., `{compound_id}_{algorithm}_{params}`). | Primary Key |
| `compound_id` | `str` | Foreign key referencing `Compound.compound_id`. | Non-null |
| `algorithm` | `str` | Type of fingerprint: `Morgan` or `MACCS`. | Enum: `['Morgan', 'MACCS']` |
| `radius` | `int` | Radius parameter (only for Morgan). | Default: 2 |
| `n_bits` | `int` | Number of bits in the vector. | Morgan: 2048, MACCS: 166 |
| `bit_vector` | `ndarray` | The raw binary fingerprint array (dtype: uint8 or bool). | Shape: (n_bits,) |
| `bit_info` | `dict` | Mapping of bit index to substructure indices (from RDKit `GetBitInfo`). | Optional, used for feature importance |

### Relationships
- **Many-to-1** with `Compound`.
- **1-to-Many** with `Model`: Used as input for training multiple models.

---

## 3. Model

Represents a trained machine learning model (Random Forest) associated with a specific fingerprint type and training configuration.

### Schema

| Field | Type | Description | Constraints |
|:--- |:--- |:--- |:--- |
| `model_id` | `str` | Unique identifier (e.g., `{algorithm}_{split_type}_{fold}`). | Primary Key |
| `algorithm` | `str` | Underlying ML algorithm. | Enum: `['RandomForest']` |
| `fingerprint_type` | `str` | Type of input fingerprint. | `Morgan` or `MACCS` |
| `hyperparameters` | `dict` | Configuration used for training. | Keys: `n_estimators` (100), `max_depth` (15), `random_state` (42) |
| `training_indices` | `list[int]` | List of row indices used for training. | Non-empty |
| `model_artifact` | `binary` | Pickled sklearn model object. | Serialized |
| `feature_importance` | `ndarray` | Gini importance scores for each bit. | Shape: (n_bits,) |

### Relationships
- **Many-to-1** with `Fingerprint` (conceptually, via training data).
- **1-to-Many** with `PerformanceMetric`.

---

## 4. PerformanceMetric

Represents a quantitative evaluation result of a `Model` on a specific dataset split.

### Schema

| Field | Type | Description | Constraints |
|:--- |:--- |:--- |:--- |
| `metric_id` | `str` | Unique identifier. | Primary Key |
| `model_id` | `str` | Foreign key referencing `Model.model_id`. | Non-null |
| `dataset_split` | `str` | Type of evaluation set. | Enum: `['train', 'test', 'kfold']` |
| `fold_index` | `int` | Fold index (0 to N-1) if cross-validation. | -1 if not CV |
| `roc_auc` | `float` | Area Under the Receiver Operating Characteristic Curve. | [0.0, 1.0] |
| `pr_auc` | `float` | Area Under the Precision-Recall Curve. | [0.0, 1.0] |
| `accuracy` | `float` | Classification accuracy. | [0.0, 1.0] |
| `f1_score` | `float` | F1 Harmonic Mean. | [0.0, 1.0] |

### Relationships
- **Many-to-1** with `Model`.

---

## 5. Derived Artifacts (Intermediate Files)

These are not database entities but critical file-based artifacts generated during the pipeline.

### `organophosphates_filtered.csv`
- **Source**: `code/filter.py`
- **Content**: Subset of `Compound` table where `is_organophosphate` is True.
- **Schema**: Matches `Compound` table (excluding `is_organophosphate` flag if redundant).

### `split_indices.json`
- **Source**: `code/split.py`
- **Content**: Indices for Train/Test split based on Maximal Dissimilarity.
- **Schema**:
 ```json
 {
 "status": "VALID" | "INVALID",
 "test_indices": [int,...],
 "train_indices": [int,...],
 "tanimoto_min": float,
 "tanimoto_max": float
 }
 ```

### `kfold_scores.json`
- **Source**: `code/train.py`
- **Content**: Aggregated ROC-AUC scores for the Corrected Resampled t-test.
- **Schema**:
 ```json
 {
 "morgan": { "roc_auc": [float,...] },
 "maccs": { "roc_auc": [float,...] }
 }
 ```

### `sample_size_status.json`
- **Source**: `code/filter.py` (T013b)
- **Content**: Trigger for downstream statistical tasks.
- **Schema**:
 ```json
 { "status": "OK" | "SKIP_STATS" }
 ```
