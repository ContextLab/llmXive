# T000a — Spec Amendment Definition

This document defines the EXACT text block to be inserted into
`specs/001-llmxive-follow-up-extending-colleague-sk/spec.md` by task T000b.

The amendment makes two changes:
1. **FR-006 (Statistical Method)**: Replaces "Linear Mixed-Effects Model (LMM)"
 with "Generalized Linear Mixed Model (GLMM)" to support binary/continuous
 mixed outcomes.
2. **Assumptions (Scale)**: Replaces the "50 profiles × 200 tasks" assumption
 with "10 profiles × 50 tasks" (500 combinations × 3 conditions = 1,500 runs)
 to ensure GLMM convergence within free-tier CI (CPU-only) limits.

**Rationale**: The full matrix (a comprehensive set of runs) exceeds the runtime
and RAM constraints of the free-tier runner; the reduced scale is statistically
powered for a moderate effect size (Cohen's d) with sufficient random-effect
levels (10 profiles, 50 tasks).

## Exact Amendment Text to Insert

Insert the following block into `spec.md`, replacing the existing FR-006 entry

```
## Functional Requirements
- **FR-006**: The system must perform statistical analysis using a Generalized Linear Mixed Model (GLMM) to handle mixed outcomes (binary/continuous).
 - *Amendment from T000a*: The statistical method is explicitly defined as a Generalized Linear Mixed Model (GLMM) to accommodate binary outcomes (Heuristic Adherence, Hallucination Rate) and continuous outcomes (Style Consistency) simultaneously within a unified framework. This replaces the previously specified Linear Mixed-Effects Model (LMM) to ensure statistical validity for the mixed data types generated by the evaluation pipeline.

## Assumptions and Constraints
- **Scale Assumption**: The study is conducted on a reduced scale of **10 profiles × 50 tasks × 3 conditions = 1,500 runs**.
 - *Amendment from T000a*: The original assumption of "50 profiles × 200 tasks" is replaced with "10 profiles × 50 tasks". This reduction is necessary to ensure GLMM convergence within the computational limits (RAM and runtime) of the free-tier CI runner (CPU-only). The reduced scale (a set of combinations × 3 conditions) is statistically powered to detect a moderate effect size (Cohen's d) with sufficient random-effect levels (10 profiles, 50 tasks) for the intended analysis.
```
