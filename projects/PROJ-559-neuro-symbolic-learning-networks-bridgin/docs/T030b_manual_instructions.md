# Manual Task Instructions: T030b - Human Pilot Data Ingestion

## Overview
This task (T030b) is a manual procedure to replace the synthetic pilot data generated by T030a with actual human pilot data for production validation. The pipeline currently proceeds with the synthetic artifact from T030a if this manual step is not performed.

## Prerequisites
- Completion of Task T030a (Synthetic Pilot Data Generation)
- Access to actual human pilot study data (minimum 50 records)
- Data must conform to the schema defined in `contracts/pilot_data.schema.yaml`

## Required Data Schema
The human pilot data CSV file must contain the following columns:
- `problem_id`: Unique identifier for the problem
- `condition`: Experimental condition (neural, symbolic, or neuro_symbolic)
- `correct`: Binary correctness (0 or 1)
- `rt_seconds`: Response time in seconds
- `comprehension_rating`: Self-reported comprehension rating (1-5 scale)

## Procedure

### Step 1: Prepare Human Pilot Data
1. Collect human pilot data from your study
2. Ensure the data meets the minimum requirement of 50 records
3. Verify the data conforms to the schema in `contracts/pilot_data.schema.yaml`
4. Save the data as a CSV file with the exact filename: `data/pilot/real_pilot_data.csv`

### Step 2: Replace Synthetic Data
1. Navigate to the project root directory
2. Locate the existing synthetic data file: `data/pilot/real_pilot_data.csv` (generated by T030a)
3. Backup the synthetic file if needed for reference
4. Replace it with your human pilot data file

### Step 3: Validate Data
1. Run the validation script to ensure data integrity:
 ```bash
 python code/download/check_pilot_data.py
 ```
2. Verify the script exits with code 0 and reports `has_human_data=true`
3. If validation fails, review the error messages and correct the data file

### Step 4: Proceed with Calibration
1. Once validation passes, the pipeline can proceed with Task T031 (Calibration)
2. The calibration process will now use real human data instead of the synthetic proxy

## Notes
- If human pilot data is not available, the pipeline will continue using the synthetic data from T030a
- The synthetic data is deterministic and suitable for CI reproducibility
- Human data is required for final production validation and publication-quality results

## Success Criteria
- `data/pilot/real_pilot_data.csv` contains actual human pilot data (≥50 records)
- Data passes schema validation against `contracts/pilot_data.schema.yaml`
- `code/download/check_pilot_data.py` reports `has_human_data=true`
- Calibration task (T031) can proceed using real human data
