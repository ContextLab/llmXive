## Unresolved concerns

- The plan states: 'Replace the visual embedding layer with a fixed, untrained discrete projection layer.' This creates a construct validity failure. The research question asks how the *architecture* (Kairos) handles sparse data. By freezing the projection layer, the model cannot learn the necessary discrete-to-latent mapping. Any failure to predict is indistinguishable between 'insufficient information density' and 'malformed input projection,' invalidating the causal claim about modality scaling.
- The baseline comparison is flawed. The plan compares 'discrete modality error' against a 'continuous baseline' using the *same* model architecture but with a 'fixed, untrained' projection for the discrete case. A valid causal test requires the continuous baseline to use the *trained* visual encoder. Comparing a trained continuous model against an untrained discrete adapter conflates 'modality shift' with 'training deficit,' making the stability threshold measurement scientifically invalid.
- The statistical power is insufficient. The plan proposes 'multiple independent runs with different noise seeds' but does not specify the number of seeds or episodes per seed. Given the high variance in long-horizon forecasting (500 steps) and the CPU-only constraint limiting data throughput, an undefined sample size risks a Type II error (failing to detect a real degradation effect), rendering the 'stability threshold' identification unreliable.

Without this definition in the plan, the implementer has no task to satisfy the specific measurement logic required by SC-001, and the success criterion cannot be measured.

- The plan validates the 'stability threshold' by comparing discrete MSE against a 'continuous baseline error' derived from the *same* model architecture. However, the continuous baseline is computed on the *original* continuous data, while the discrete input is a quantized version of that same data. The 'error' in the discrete case is conflated with the quantization error (information loss) inherent in the input transformation, not just the model's predictive failure. The plan fails to distinguish between 'model error' and 'input quantization error'. If the model is perfect, the discrete MSE will still be non-zero due to quantization noise. The 'stability threshold' identified will be a function of the quantization formula (Phase 1) rather than the model's architectural capacity, making the result tautological to the quantization step.
- The plan states: 'Replace the visual embedding layer with a fixed, untrained discrete projection layer'. If the projection layer is 'untrained' and 'fixed', the model cannot learn the mapping from the new discrete input space to the latent space. The model will effectively be running with random or pre-trained weights that do not match the discrete input distribution. The resulting high MSE will be a guaranteed failure of the initialization, not an empirical measurement of the 'minimum information density required for stable forecasting'. The analysis will only confirm that an untrained layer fails, which is a trivial result, not a scaling law.
- The plan proposes using a 'paired t-test' between 'discrete modality error' and 'continuous baseline error'. These are not paired in the statistical sense required for a t-test unless the 'error' is defined as the *difference* in prediction for the *same* time step. However, the inputs are different (continuous vs. discrete). A paired test assumes the two measurements are dependent on the same underlying variable. Here, the 'ground truth' for the discrete prediction is the quantized version of the continuous state. The test compares Model(Discrete) vs. GroundTruth(Discrete) against Model(Continuous) vs. GroundTruth(Continuous). This is a valid comparison of two independent error distributions, but a 'paired' test is only appropriate if the errors are correlated (e.g., same episode, same time step). The plan must clarify if the pairing is by (episode, timestep) and if the statistical test accounts for the fact that the 'ground truth' itself changes between the two conditions.
- SC-001 defines the threshold as the point where MSE exceeds a '[deferred] increase over the baseline visual-modality error'. This baseline is the error of the model on continuous data. However, the 'discrete' data is a lossy compression of the continuous data. The 'increase' in error is mathematically guaranteed to be non-zero due to the quantization step (Phase 1). The 'threshold' is therefore not a property of the model's stability, but a property of the quantization noise floor. The plan conflates 'model stability' with 'quantization fidelity'. A valid scientific question would be: 'At what bit-depth does the *model's* error exceed the *quantization* error?' The current plan measures total error, which is dominated by quantization at low bit-depths, rendering the 'stability' claim circular.
