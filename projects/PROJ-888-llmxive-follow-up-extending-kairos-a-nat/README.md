# llmXive follow-up: extending "Kairos: A Native World Model Stack for Physical AI"

This project implements a follow-up study to the "Kairos: A Native World Model Stack for Physical AI" paper, focusing on discrete state vector quantization, CPU-only training, and stability analysis.

## Quickstart

1. Install dependencies: `pip install -r requirements.txt`
2. Run the pipeline: `python code/main.py`
3. View results in `results/`

## Project Structure

- `code/`: Source code for the pipeline
- `data/`: Raw and processed data
- `tests/`: Unit and integration tests
- `results/`: Generated reports and metrics
- `logs/`: Execution logs
