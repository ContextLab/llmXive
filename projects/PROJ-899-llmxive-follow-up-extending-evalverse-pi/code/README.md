# llmXive Project Structure

This directory contains the source code, tests, and specifications for the llmXive automated science pipeline.

## Directory Structure

- `src/`: Core application logic
 - `data/`: Data loading, preprocessing, and models
 - `models/`: Model training and evaluation
 - `reports/`: Report generation
- `tests/`: Test suite
 - `unit/`: Unit tests
 - `contract/`: Contract tests
 - `integration/`: Integration tests
- `specs/`: Feature specifications and design documents
- `data/`: Data storage
 - `raw/`: Raw downloaded data
 - `processed/`: Processed data
- `state/`: State tracking and gate artifacts
- `reports/`: Generated reports
- `figures/`: Generated figures
- `scripts/`: Executable scripts

## Setup

Run `python scripts/setup_environment.py` to initialize the project environment.
