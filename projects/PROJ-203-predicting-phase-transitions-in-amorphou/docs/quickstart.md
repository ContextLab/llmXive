# Quickstart Guide: Predicting Phase Transitions in Amorphous Solids

This guide provides instructions for running the complete machine learning pipeline
to predict glass transition temperatures and crystallization propensity in amorphous
solids.

## Prerequisites

- Python 3.9 or higher
- pip package manager
- 8GB+ RAM (16GB recommended for full dataset)
- 20GB+ free disk space

## Installation

1. **Clone the repository** (if applicable):
```bash
git clone <repository-url>
cd llmXive-predicting-phase-transitions
```

2. **Create and activate a virtual environment**:
```bash
python -m venv venv
source venv/bin/activate # On Windows: venv\Scripts\activate
```

3. **Install dependencies**:
```bash
cd code
pip install -r requirements.txt
```

4. **Install optional dependencies for SHAP visualization**:
```bash
pip install matplotlib seaborn
```

## Data Preparation

The pipeline expects the following data structure:

```
data/
├── raw/
│ └── literature_subset.csv # Experimental thermal properties
├── processed/
│ ├── final_dataset.parquet # Combined dataset (generated by pipeline)
│ └── metadata.json # Simulation metadata
└── logs/
 └── simulation_times.json # Simulation timing logs
```

### Verifying Literature Data

Before running the pipeline, ensure the literature subset exists:

```bash
python code/data/validate_literature_subset.py
```

This will fail loudly if `data/raw/literature_subset.csv` is missing or corrupted.

## Running the Pipeline

### Full Pipeline Execution

To run the complete pipeline from data loading through model training and analysis:

```bash
cd code
python main.py
```

This will:
1. Validate input data
2. Run MD simulations (if needed)
3. Extract structural descriptors
4. Merge with experimental data
5. Train Random Forest models
6. Perform SHAP analysis
7. Generate reports and visualizations

**Expected runtime**: 2-4 hours on a standard CPU (depends on simulation count)

## Troubleshooting

### Common Issues

**1. Missing literature_subset.csv**
```
FileNotFoundError: FATAL: literature_subset.csv missing
```
Ensure the file exists at `data/raw/literature_subset.csv`. The pipeline will not
proceed without this file.

**2. Simulation timeout**
```
TimeoutError: Simulation exceeded 6-hour limit
```
The pipeline has a built-in timeout. Check `data/logs/simulation_times.json` for
truncated simulations.

**3. Low model performance**
If ROC-AUC ≤ 0.7, the pipeline will still complete but will generate a warning
in `docs/reports/metrics.json` noting the power limitation due to small sample size (N=24).

**4. Memory errors**
If you encounter memory errors, try:
- Running the performance optimization demo first
- Reducing the sample size in SHAP calculations
- Using a machine with more RAM

## Performance Notes

- **Small Sample Size**: This pilot study uses N=24 compositions. Statistical
 validity is ensured through Null Model and Permutation Tests (T034).
- **Timescale Matching**: MD simulation times are aligned with experimental
 cooling rates using the scaling factor protocol (T012.2).
- **Family Stratification**: SHAP analysis is performed separately for Oxide,
 Sulfide, and Organic families.
- **Multiple Comparison Correction**: Bonferroni correction is applied to
 family-wise error control (T027).
