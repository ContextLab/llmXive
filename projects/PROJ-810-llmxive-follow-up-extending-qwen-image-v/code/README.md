# llmXive: Extending Qwen-Image-VAE-2.0 Technical Report

Automated science pipeline for analyzing latent space disentanglement in document image VAEs.

## Project Structure

- `src/`: Source code
- `tests/`: Test suite
- `data/`: Data storage (raw, interim, results, manual)
- `specs/`: Design documents and specifications
- `code/`: Project root for this implementation

## Setup

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Running Tests

```bash
pytest tests/
```
