# Contributing to PROJ-198

## Code Style

- **Formatting**: Black
- **Linting**: Ruff
- **Type Hints**: Required for all function signatures.

## Development Workflow

1. **Fork & Branch**: Create a feature branch from `main`.
2. **Implement**: Write code, ensuring it runs on real data.
3. **Test**: Add unit tests for new logic.
4. **Document**: Update README or docs if behavior changes.
5. **Commit**: Use descriptive commit messages.

## Pull Request Process

1. Link to relevant issue or task ID (e.g., "Fixes T035").
2. Ensure all tests pass (`pytest`).
3. Ensure linting passes (`ruff check.`).
4. Provide a summary of changes in the PR description.

## Reporting Issues

- Use the GitHub Issues template.
- Include error tracebacks and environment details.
- Specify if the issue is reproducible with real data.
