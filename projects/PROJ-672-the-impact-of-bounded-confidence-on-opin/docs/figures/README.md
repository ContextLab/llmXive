# Figures and Visualizations

This directory contains generated figures and visualizations for the project.

## Generated Plots

The following plots are generated by `code/utils/plotting.py` and `code/analyze_scaling.py`:

1. **Convergence Log-Log Plot**: Shows the convergence time $T$ vs. $(\epsilon - \epsilon_c)$ on a log-log scale. A linear fit indicates power-law behavior.
2. **Regression Scatter Plot**: Shows the relationship between the scaling exponent $\gamma$ and structural metrics (e.g., assortativity).
3. **Critical Threshold Detection**: Visualizes the RSS minimization process used to find $\epsilon_c$.
4. **Opinion Trajectories**: Time-series plots of opinion evolution for representative network instances.

## Usage

- To regenerate all figures, run the analysis pipeline:
 ```bash
 python code/analyze_scaling.py
 ```
- Figures are saved to `data/processed/figures/`.

## File Naming Convention

- `convergence_{topology}_{seed}.png`: Convergence time plots.
- `regression_{metric}.png`: Regression scatter plots.
- `epsilon_c_detection_{topology}.png`: Critical threshold detection plots.

## Interpretation

- **Log-Log Linearity**: A straight line in the convergence plot confirms the power-law hypothesis. The slope corresponds to $-\gamma$.
- **R-squared Value**: The $R^2$ value from the linear fit indicates the goodness of fit. Values $> 0.8$ are considered strong evidence for power-law scaling.
- **Residuals**: Large residuals in the regression plot may indicate outliers or a non-linear relationship that requires further investigation.
