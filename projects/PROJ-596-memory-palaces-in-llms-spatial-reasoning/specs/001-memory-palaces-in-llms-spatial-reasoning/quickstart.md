# Quickstart: Memory Palaces in LLMs

## Prerequisites

-   Python 3.11+
-   pip
-   Git

## Installation

1.  Clone the repository and navigate to the project directory:
    ```bash
    git clone <repo-url>
    cd projects/PROJ-596-memory-palaces-in-llms-spatial-reasoning/code
    ```

2.  Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

## Running the Experiment

To run the full experiment (multiple random seeds, 3 datasets, both variants):

```bash
bash scripts/run_experiment.sh
```

This script will:
1.  Download and checksum datasets.
2.  Fine-tune spatial and non-spatial models.
3.  Evaluate on all datasets.
4.  Compute structural metrics and statistical tests.
5.  Save results to `artifacts/results/run_summary.json`.

## Running a Single Seed

To run a single seed on bAbI task 3:

```bash
python src/trainer.py --seed 0 --dataset babi_task3 --variant spatial
```

## Validation

To validate the quickstart output:

```bash
bash scripts/validate_quickstart.sh
```

This script checks:
-   `artifacts/results/run_summary.json` exists.
-   All required fields are present and conform to `contracts/results.schema.yaml`.
-   Statistical tests are valid (p-values within [0, 1], effect sizes are numeric).
