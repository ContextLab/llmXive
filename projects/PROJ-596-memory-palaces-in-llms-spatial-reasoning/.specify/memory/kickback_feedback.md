## Unresolved concerns

- The plan proposes a correlational design (comparing two fixed architectures) but the research question asks 'How does explicit spatial organization... affect recall accuracy?' implying a causal claim. Without randomization of the spatial mechanism itself (e.g., randomizing slot assignments or using a within-subject design where the same model toggles spatial modes), the analysis cannot support causal conclusions about the *effect* of spatial organization. The plan must reframe the question to 'Is spatial organization associated with...' or add a causal identification strategy.
- The 'Interference Distance' metric is defined as 'Drop in recall when unrelated items are assigned to adjacent grid coordinates.' However, the plan does not specify how 'unrelated items' are identified or how the 'adjacent' condition is experimentally manipulated in the test set. Without a controlled injection of interference (e.g., a specific adversarial test set construction), this metric cannot be computed, rendering the structural validity of the spatial claim untestable.
- The plan relies on 5 random seeds for statistical power. For a paired t-test with N=5, the power to detect a medium effect size (Cohen's d=0.5) is approximately 0.18 (assuming alpha=0.05). This is critically underpowered to detect the effect the project intends to measure. The plan must either increase the number of seeds (if computationally feasible) or explicitly acknowledge that the study is underpowered and results will be treated as exploratory only.
- The plan uses bAbI Task 3, LAMBADA, and Story Cloze. bAbI Task 3 is synthetic and highly structured, while LAMBADA and Story Cloze are natural language. The 'construct validity' of 'episodic recall' differs significantly between these datasets. A spatial mechanism might work on synthetic positional data (bAbI) but fail on semantic coherence (LAMBADA). The plan does not address this construct mismatch or propose a unified metric that is valid across such disparate data types.
- The spatial variant uses a 'deterministic hash of its content' to assign coordinates. This means the spatial organization is a fixed function of the input, not a learned representation. This design choice conflates 'spatial indexing' with 'input hashing.' If the hash function is deterministic, the model cannot learn to *optimize* spatial placement for recall; it merely retrieves based on a pre-computed index. This undermines the claim that the *model* is using spatial reasoning, as the spatial structure is external to the learning process.
- FR-010 mandates capping the dataset to '[deferred] of the original size' if memory constraints persist. The plan.md (Section 'Methodology') resolves this to '10% subsample cap', but the spec itself retains the literal placeholder '[deferred]'. While the plan provides the logic, the spec's FR-010 text remains unbacked by a concrete value in the source requirement, creating a disconnect between the requirement text and the implementable plan logic. The spec must be updated to reflect the resolved '10%' value or explicitly reference the plan's resolution to ensure the FR is fully testable against the spec text alone.
- FR-011 requires computing 'interference distance' by measuring recall drop when unrelated items are assigned to adjacent coordinates. The plan.md (Section 'Evaluation Metrics') defines this metric, but the spec's Edge Cases section mentions 'FIFO eviction' for slot capacity overflow without explicitly linking this eviction policy to the interference distance calculation. The spec does not clearly state how the interference metric is computed if the slot capacity is exceeded and eviction occurs, leaving the measurement protocol for FR-011 ambiguous in the spec text.

However, the spec does not explicitly define the 'interference distance' calculation method (e.g., 'drop in recall when unrelated items are assigned to adjacent slots') in the US-3 acceptance scenarios or the FR-011 text is the only definition. The US-3 acceptance scenario 1 mentions 'injecting semantically unrelated items' but does not specify the mechanism for 'adjacent grid coordinates' or how 'unrelated' is determined, leaving the testability of US-3 dependent on external interpretation.
