# Quickstart: Statistical Analysis of Code Complexity Metrics and Bug Prediction

## Prerequisites
- Python 3.11 or newer
- Git
- At least 14 GB of free disk space
- Internet access (to download GHTorrent or the GitHub Archive fallback)

## Installation

```bash
# 1. Clone the repository
git clone <repo-url>
cd projects/PROJ-148-statistical-analysis-of-code-complexity-

# 2. Create a clean virtual environment (optional but recommended)
python -m venv .venv
source .venv/bin/activate

# 3. Install pinned dependencies
pip install -r requirements.txt
```

> **Note**: `lizard` may need a C compiler on some platforms; the pinned version works on the Linux runner used by GitHub Actions.

## Execution Order

All scripts are idempotent; re‑running a step will skip already‑produced artifacts.

1. **Download source data** (primary GHTorrent; fallback to GitHub Archive):
   ```bash
   python code/data/download_gh.py
   ```
2. **Extract static‑analysis metrics**:
   ```bash
   python code/data/extract_metrics.py
   ```
3. **Label bug‑fix functions**:
   ```bash
   python code/data/label_bugs.py
   ```
4. **Preprocess & split** (imputation, log‑transform, VIF > 10, train/test split):
   ```bash
   python code/data/preprocess.py
   ```
5. **Train models** (L1 Logistic Regression and Random Forest):
   ```bash
   python code/modeling/train.py
   ```
6. **Evaluate and generate reports** (ROC/PR curves, calibration, PDPs, thresholds):
   ```bash
   python code/modeling/evaluate.py
   ```
7. **Run contract tests** (ensure schema compliance):
   ```bash
   pytest tests/contract/
   ```

## Expected Outputs
- `data/processed/bug_complexity_dataset.csv` – cleaned, split dataset.  
- `data/model/primary.pkl` – fitted L1 logistic regression.  
- `data/model/alternative.pkl` – fitted Random Forest.  
- `data/model/corrected_pvalues.csv` – Benjamini‑Hochberg corrected p‑values.  
- `data/model/thresholds.csv` – practical metric thresholds for ≥ 0.5 bug probability.  
- `figures/pdp_top3.png` – partial dependence plots for the three most influential metrics.  
- `reports/final_report.pdf` – compiled PDF containing all tables, figures, and statistical conclusions.

## Reproducibility Checklist
- [ ] Random seeds are fixed in `code/utils/config.py`.  
- [ ] All external downloads are verified via SHA‑256 checksums recorded in `state/`.  
- [ ] No manual edits of CSV/figure files; everything is generated by the pipeline.  

If any step fails due to memory limits, consider reducing the `MAX_PROJECTS` environment variable in `download_gh.py` (the script respects this flag).
