# PROJ-003 Design Documents

This directory contains the design specifications for the Single-Cell Trajectories of T-Cell Exhaustion project.

## Documents
- `user_stories.md`: Detailed user stories and acceptance criteria
- `data_model.md`: Data structures and entity definitions
- `research_plan.md`: Research methodology and experimental design
- `implementation_plan.md`: Technical implementation roadmap
- `contracts.md`: API and data contracts
- `constitution.md`: Project principles and constraints
