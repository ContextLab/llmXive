# Data Directory

This directory stores all data artifacts for the project.

## Subdirectories
- `raw/`: Raw data downloaded from SRA/GEO (e.g., `.h5`, `.mtx`, `.tsv`)
- `processed/`: Normalized and QC-filtered data (e.g., `.h5ad`)
- `results/`: Final analysis outputs (velocity graphs, fork-point genes, reports)

## Data Integrity
All files in `raw/` must be downloaded from verified public sources.
Do not manually edit raw data files.
