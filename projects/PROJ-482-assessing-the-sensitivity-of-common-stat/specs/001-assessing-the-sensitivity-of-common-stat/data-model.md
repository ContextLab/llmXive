# Data Model: Assessing the Sensitivity of Common Statistical Tests to Dataset Size

## Overview

This document defines the data structures used for generating, simulating, and analyzing statistical test sensitivity. All data is derived from synthetic generation with known ground truth.

## Entities

### 1. Configuration (Input)
Defines a single simulation scenario.
- `sample_size`: int (10 to 1000)
- `distribution_type`: enum {`normal`, `uniform`, `log-normal`}
- `test_type`: enum {`t-test`, `anova`, `chi-squared`}
- `effect_size`: float (0.0 for Null, 0.5 for Alternative)
- `seed`: int (for reproducibility)

### 2. SimulationRun (Intermediate)
Represents a single iteration of data generation and testing.
- `run_id`: string (unique identifier)
- `config_hash`: string (hash of Configuration)
- `generated_data`: array of floats (raw data points)
- `test_statistic`: float
- `p_value`: float
- `decision`: enum {`reject_null`, `fail_to_reject`}
- `error_type`: enum {`type_1`, `type_2`, `none`} (based on ground truth vs decision)
- `ground_truth`: dict {`true_effect_size`, `true_distribution`}

### 3. ErrorMetric (Aggregated)
Aggregated results for a specific Configuration.
- `sample_size`: int
- `distribution_type`: string
- `test_type`: string
- `effect_size`: float
- `total_replicates`: int
- `type_1_count`: int (if effect_size=0)
- `type_2_count`: int (if effect_size=0.5)
- `type_1_rate`: float
- `type_2_rate`: float
- `power`: float
- `ci_lower`: float
- `ci_upper`: float
- `ci_width`: float

### 4. RegressionResult (Output)
Results of the regression analysis.
- `predictor`: string
- `coefficient`: float
- `std_error`: float
- `p_value`: float
- `pseudo_r_squared`: float (McFadden)

## File Formats

### CSV: `data/raw/sample_validation.csv`
Generated by `data_generator.py` to verify ground truth.
- `sample_size`: int
- `distribution_type`: string
- `mean`: float
- `variance`: float
- `skewness`: float
- `expected_mean_diff`: float
- `observed_mean_diff`: float
- `checksum`: string (MD5)

### CSV: `data/processed/aggregated_results.csv`
Final output for visualization and analysis.
- `sample_size`: int
- `distribution_type`: string
- `test_type`: string
- `effect_size`: float
- `error_type`: string (`type_1` or `type_2`)
- `rate`: float
- `ci_lower`: float
- `ci_upper`: float
- `replicates`: int

## Constraints

- **Immutability**: Once written to `data/processed/`, files are never modified. New runs overwrite the file with a new checksum.
- **Checksums**: All raw and processed files must include an MD5 checksum in the project state manifest.
- **Precision**: All floating point numbers stored with 6 decimal places.
