# Implementation Plan: Investigating the Predictive Power of Plant Phylogeny on Secondary Metabolite Profiles

**Branch**: `001-phylogeny-metabolite-prediction` | **Date**: 2026-08-12 | **Spec**: [link]
**Input**: Feature specification from `specs/001-phylogeny-metabolite-prediction/spec.md`

## Summary

This feature implements a computational pipeline to test the hypothesis that plant phylogenetic distance predicts secondary metabolite profile dissimilarity. The approach involves retrieving multi-locus genomic sequences (S rRNA, rbcL, matK) and KEGG metabolite profiles for a curated list of diverse plant species., constructing a maximum-likelihood phylogeny, computing distance matrices, and performing Mantel and Partial Mantel tests to isolate phylogenetic signal from environmental (climate) convergence. The pipeline is designed to run on CPU-first infrastructure with a GPU escape hatch for any heavy alignment tasks (though MAFFT/FastTree are CPU-optimized).

## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

1.  **I. Reproducibility**: The plan mandates pinned versions in `requirements.txt`, explicit random seeds (a sufficient number of permutations), and checksumming of all downloaded data files before processing.
2.  **II. Verified Accuracy**: All dataset URLs (KEGG, NCBI, USDA) will be validated against the `# Verified datasets` block. If a required dataset (e.g., specific KEGG organism codes) lacks a verified source in the block, the plan will explicitly flag the gap rather than fabricate a URL.
3.  **III. Data Hygiene**: Raw downloads (FASTA, JSON, Parquet) will be stored in `data/raw/` with checksums. Derived artifacts (aligned FASTA, Newick trees, distance matrices) will be stored in `data/processed/` with derivation logs. No in-place modification.
4.  **IV. Single Source of Truth**: All figures (`phylo_metabolite_heatmap.png`, `mantel_results.png`) and statistics will be generated by code from `data/processed/` artifacts. No hand-typed numbers in reports.
5.  **V. Versioning Discipline**: Content hashes for all `data/` files and `code/` scripts will be recorded in `state/projects/PROJ-408...yaml`.
6.  **VI. Phylogenetic Distance and Profile Correlation Integrity**: The plan strictly adheres to the Mantel test protocol using a sufficient number of permutations for significance estimation, using FastTree for tree construction and Jaccard distance for metabolites.
    *   **Justification for Multi-Locus**: While Principle VI mentions "18S rRNA or chloroplast", the Spec (US-1) and biological necessity require multi-locus (18S, rbcL, matK) to resolve deep phylogenetic relationships. This deviation is explicitly justified as a methodological enhancement required for robust resolution.
    *   **Justification for Jaccard**: Jaccard was selected over Bray-Curtis because the KEGG BRITE data is strictly binary (presence/absence). Bray-Curtis requires abundance data which is not available.
7.  **VII. Environmental Stratification and Signal Isolation**: The Partial Mantel test implementation will explicitly use the USDA PLANTS climate data (verified source) to construct the control matrix. Additionally, the analysis will include a comparison of Mantel r-values between the full dataset and stratified subsets (per climate zone) to satisfy the specific verification requirement of Principle VII.

## Complexity Tracking

| Violation | Why Needed | Simpler Alternative Rejected Because |
|-----------|------------|-------------------------------------|
| Multi-locus alignment | Required for robust phylogeny (US-1) | Single gene (e.g., rbcL only) lacks resolution for deep metabolic divergence. |
| Partial Mantel Test | Required to isolate climate effects (US-2) | Simple stratification (US-2) is methodologically insufficient for continuous climate variables and confounding. |
| Streaming Data | 500 species + large genomes may exceed RAM | Loading full datasets into memory risks OOM on constrained RAM; streaming ensures feasibility. |
