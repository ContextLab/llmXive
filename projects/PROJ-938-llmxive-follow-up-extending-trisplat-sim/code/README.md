# Code Directory

This directory contains the source code for the TriSplat extension pipeline.

## Modules
- `cli.py`: Command-line interface
- `data/`: Data loading and metrics
- `models/`: TriSplat backbone and geometry-only layer
- `utils/`: Mesh utilities and statistical analysis
- `experiments/`: Batch orchestration and benchmarking

## Entry Points
- `python code/cli.py`: Main CLI
- `python code/experiments/run_batch.py`: Batch runner
