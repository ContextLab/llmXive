# Data Model: Investigating the Impact of Telomere Length on Lifespan Variation in Wild Bird Populations

## Overview
Four artifact classes are produced:

1. **Raw ingestion files** – immutable copies of the downloaded Dryad telomere CSVs, lifespan CSVs, and ecological covariate files from AnAge/BirdLife.  
2. **Processed analysis dataset** – `data/processed/analysis_ready.csv` conforming to `contracts/dataset.schema.yaml`. This file is generated by `03_clean_merge.py`, which now **explicitly creates** the provenance columns required by the schema (`n_obs`, `source_file`, `checksum`).  
3. **Model output artifacts** – `results/model_base.csv` and `results/model_interaction.csv` conforming to `contracts/model_output.schema.yaml`.  
4. **External validation artifact** – `results/permutation_pvalue.yaml` containing the empirical p‑value from the permutation test (supports the relevant study criteria).

All artifacts are version‑hashed; no synthetic records are introduced.

## Entity Definitions

### SpeciesRecord (analysis dataset)
| Field | Type | Description | Constraints |
|-------|------|-------------|-------------|
| `species_id` | string | Canonical species identifier (renamed from source). | Unique, non‑empty |
| `telomere_length_kb` | number | Telomere length (kilobases). | > 0 |
| `lifespan_days` | number | Lifespan (days). | > 0 |
| `migration_status` | string | `"Migratory"`, `"Resident"` or `"Unknown"` (from AnAge). | Enum |
| `breeding_latitude` | number | Mean breeding latitude (degrees). | -90 ≤ value ≤ 90 |
| `body_mass_g` | number | Body mass (grams). | > 0 |
| `n_obs` | integer | Number of raw rows aggregated into this species proxy. | ≥ 1 |
| `source_file` | string | Path(s) to the raw CSV file(s) that contributed to this record. | Non‑empty |
| `checksum` | string | SHA‑256 of the raw row block used to create this record. | Hex string |

### ModelResult
| Field | Type | Description |
|------|------|-------------|
| `model_type` | string | `"LMM_Base"` or `"LMM_Interaction"` |
| `fixed_effect_telomere` | number | null | Coefficient for telomere length; null when low‑power flag is true. |
| `se_telomere` | number | null | Standard error. |
| `ci_lower_telomere` | number | null | 95 % CI lower bound. |
| `ci_upper_telomere` | number | null | 95 % CI upper bound. |
| `fixed_effect_body_mass` | number | null | Coefficient for body mass. |
| `se_body_mass` | number | null | Standard error. |
| `ci_lower_body_mass` | number | null | 95 % CI lower bound. |
| `ci_upper_body_mass` | number | null | 95 % CI upper bound. |
| `fixed_effect_migration` | number | null | Coefficient for migration (interaction model only). |
| `se_migration` | number | null | Standard error. |
| `ci_lower_migration` | number | null | 95 % CI lower bound. |
| `ci_upper_migration` | number | null | 95 % CI upper bound. |
| `interaction_effect_migration` | number | null | Telomere × migration interaction coefficient. |
| `se_interaction_migration` | number | null | Standard error. |
| `ci_lower_interaction_migration` | number | null | 95 % CI lower bound. |
| `ci_upper_interaction_migration` | number | null | 95 % CI upper bound. |
| `interaction_effect_latitude` | number | null | Telomere × latitude interaction coefficient. |
| `se_interaction_latitude` | number | null | Standard error. |
| `ci_lower_interaction_latitude` | number | null | 95 % CI lower bound. |
| `ci_upper_interaction_latitude` | number | null | 95 % CI upper bound. |
| `p_value_telomere` | number | null | Two‑sided p‑value; null when low‑power. |
| `p_value_interaction_migration` | number | null | p‑value for telomere × migration interaction; null for base model or low‑power. |
| `p_value_interaction_latitude` | number | null | p‑value for telomere × latitude interaction; null for base model or low‑power. |
| `significance_flag` | boolean | True when **both** the model‑based p‑value **and** the permutation p‑value are `< 0.05`. |
| `aic_score` | number | null | Akaike Information Criterion; null when low‑power. |
| `delta_aic` | number | null | ΔAIC vs. base model (interaction model only). |
| `n_species` | integer | Number of unique `species_id` used in the fit. |
| `low_power_flag` | boolean | True when `n_species < 15`. |
| `low_power_message` | string | null | `"Low Power: species‑level inference unreliable"` when applicable. |
| `power_estimate` | number | Simulated power to detect a range of telomere slopes (0.05‑0.30) at α = 0.05 for the observed species count; omitted when low‑power flag is true. |
| `permutation_pvalue` | number | Empirical p‑value from the permutation test (Phase 8). |

### SensitivityLog (log‑only artifact)
| Field | Type | Description |
|-------|------|-------------|
| `iteration_id` | integer | Index of the LOOCV or jackknife iteration. |
| `excluded_unit` | string | Species ID (LOOCV) or data‑source identifier (jackknife). |
| `method` | string | `"LOOCV"` or `"Jackknife"` with justification. |
| `coefficient_telomere` | number | Refitted telomere coefficient for this iteration. |
| `p_value_telomere` | number | Corresponding p‑value. |

## Data Flow
1. `01_discover_data.py` → `config.yaml.dataset_urls` & `config.yaml.lifespan_urls`.  
2. `02_ingest_data.py` → `data/raw/` (raw CSVs) + checksum files.  
3. `03_clean_merge.py` → `data/processed/analysis_ready.csv` (validated against `contracts/dataset.schema.yaml`). Generates provenance columns.  
4. `04_fetch_ecology.py` → `data/raw/ecology.csv`.  
5. `05_fit_lmm_base.py` → `results/model_base.csv` (validated against `contracts/model_output.schema.yaml`).  
6. `06_fit_lmm_interaction.py` → `results/model_interaction.csv` (same schema).  
7. `07_sensitivity_power.py` → `results/sensitivity_log.csv`, `results/power_report.yaml` (only if `n_species ≥ 15`).  
8. `08_permutation_test.py` → `results/permutation_pvalue.yaml`.  
9. `09_visualise.py` → PNGs in `results/`.  
10. `10_validate_report.py` → `results/report.yaml` (summary of all SCs).

Every step writes a checksum file and updates `state/projects/PROJ-<project-id>.yaml`, guaranteeing reproducibility (Constitution I).
