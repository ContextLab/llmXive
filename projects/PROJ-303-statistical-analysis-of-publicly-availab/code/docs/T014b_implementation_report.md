# Task T014b Implementation Report: ExtremeEvent Entity Mapping

## Objective
Implement the logic to map raw NOAA GHCN-Daily records to the `ExtremeEvent` entity schema defined in the project specifications.

## Implementation Details

### Location
- **File**: `code/src/data/preprocessing.py`
- **Function**: `map_to_extreme_event_entity`

### Schema Definition
The `ExtremeEvent` entity is defined as a Python `dataclass` with the following fields:
- `station_id` (str): Unique identifier for the weather station.
- `date` (str): ISO format date (YYYY-MM-DD) of the event.
- `magnitude` (float): The observed value (e.g., precipitation in mm) that exceeded the threshold.
- `threshold_value` (float): The specific threshold used to identify this event.

### Logic Flow
1. **Input Validation**: Checks if the input DataFrame contains the required `is_extreme` column (generated by `flag_extreme_events`).
2. **Filtering**: Selects only rows where `is_extreme` is `True`.
3. **Mapping**: Iterates over the filtered rows and constructs `ExtremeEvent` dataclass instances.
4. **Formatting**: Converts the date to a string and ensures numeric fields are floats.

### Dependencies
- `src.data.preprocessing.flag_extreme_events`: Must be executed prior to mapping to generate the `is_extreme` flag.
- `src.data.preprocessing.calculate_thresholds`: Used to determine the `threshold_value` passed to the mapper.

## Testing
Unit tests are located in `code/tests/unit/test_extreme_event_mapping.py`.
- `test_mapping_basic_functionality`: Verifies correct creation of events for known thresholds.
- `test_mapping_no_extremes`: Ensures empty list is returned when no events occur.
- `test_mapping_with_missing_values`: Validates handling of NaN values.
- `test_mapping_missing_is_extreme_column`: Ensures proper error handling.
- `test_schema_fields_presence`: Confirms all schema fields are present.

## Integration
This function is designed to be called after `flag_extreme_events` and before generating the final Parquet output (Task T015). It bridges the gap between raw time-series data and the structured entity representation required for downstream modeling.
