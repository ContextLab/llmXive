# Implementation Plan: Predicting Plant Disease Susceptibility from Publicly Available Genomic and Environmental Data

**Branch**: `001-plant-disease-susceptibility` | **Date**: 2026-07-30 | **Spec**: `specs/001-plant-disease-susceptibility/spec.md`
**Input**: Feature specification from `/specs/001-plant-disease-susceptibility/spec.md`

## Summary

This project implements a computational pipeline to predict plant disease susceptibility by integrating genomic sequencing data (NCBI SRA) and environmental metadata (ERA5-Land/NOAA). The system ingests raw reads, aligns them to reference genomes, calls SNPs, merges them with environmental variables, imputes missing values using k-NN (per Constitution Principle VI), and trains Random Forest and SVM models. The plan strictly adheres to the /15/15 stratified split, performs permutation tests for statistical validation, and ensures all results are reproducible on a CPU-only GitHub Actions runner.

**Critical Feasibility Note**: This project is contingent on the existence of real, open data with linked genomic, environmental, and independent phenotypic disease labels. If such data cannot be identified and fetched, the project will halt at the **Feasibility Gate** (Phase 0.5) and reframe its output as a "Pipeline Validation" report only, with no scientific claims regarding disease prediction.

## Complexity Tracking

| Violation | Why Needed | Simpler Alternative Rejected Because |
|-----------|------------|-------------------------------------|
| **Genomic Alignment (minimap2/bcftools)** | Required by FR-002 to derive variant frequencies from raw SRA reads. | Pre-processed VCFs are not available for the specific crop/environment combinations needed; raw reads are the only verified source. |
| **Dual Data Sources (SRA + ERA5)** | Required by FR-003 and FR-004 to capture the joint genomic-environmental signal. | Using only genomic data ignores the environmental context central to the research question; using only environmental data ignores the genetic susceptibility component. |
| **Permutation Testing** | Required by FR-007 to validate statistical significance (SC-002). | Standard cross-validation alone cannot distinguish model performance from random chance in small-sample regimes; permutation tests provide the necessary p-value. |
| **Dimensionality Reduction (PCA)** | Required to handle p >> n (curse of dimensionality) when SNP count exceeds sample size. | LD pruning alone may not reduce features sufficiently for small sample sizes; PCA ensures statistical viability. |

## Implementation Phases

### Phase 0: Data Discovery & Feasibility Gate
*   **Goal**: Identify a specific SRA study with linked phenotypic disease labels.
*   **Action**: Search NCBI BioProject/BioSample for "Wheat disease", "Rice disease", etc., with explicit phenotype metadata.
*   **Gate**: If no such study is found, the project halts. Output: `feasibility_report.md` stating "No verified open dataset found; project reframed as Pipeline Validation."
*   **Output**: `feasibility_gate_status: PASS/FAIL`.

### Phase 0.5: Label Source Verification (FR-010)
*   **Goal**: Validate that 'disease susceptibility' labels are derived from an independent phenotypic source.
*   **Action**: Extract `phenotype_source` field from metadata. Log the linkage method (e.g., "Linked via BioSample Accession to Field Trial ID X").
*   **Gate**: If label source is ambiguous or derived from genomic data, exclude sample.
*   **Output**: `label_validation.log`.

### Phase 1: Data Ingestion & Preprocessing
*   **Goal**: Download, align, and merge data.
*   **Action**: Download SRA reads, align to reference, call SNPs. Retrieve environmental data.
*   **Imputation**: Use **k-NN** (Constitution Principle VI) to fill missing values. Log `missing_values_before_imputation` and `missing_values_after_imputation` (SC-005).
*   **Output**: `feature_matrix.csv` (zero missing values).

### Phase 1.5: Dimensionality Reduction
*   **Goal**: Prevent overfitting (p >> n).
*   **Action**: Perform LD pruning (r² > 0.8). If features exceed a moderate fraction of samples, apply PCA to reduce to a corresponding subset of components.
*   **Output**: `reduced_feature_matrix.csv`.

### Phase 2: Model Training & Evaluation
*   **Goal**: Train RF and SVM models.
*   **Action**: 70/15/15 split. Grid search (≤50 combos). Calculate AUC-ROC with confidence intervals (bootstrapped).
*   **Output**: `model_performance.json`, `pr_curve.png`.

### Phase 3: Statistical Validation
*   **Goal**: Validate significance.
*   **Action**: Permutation test (sufficient number of permutations). Sensitivity analysis (thresholds around a midpoint).
*   **Output**: `validation_report.json` (p-value, FPR/FNR variation).

### Phase 4: Variance Decomposition (SC-003)
*   **Goal**: Quantify genomic vs. environmental contribution.
*   **Action**: Calculate variance explained by each feature group.
*   **Output**: `variance_decomposition.json`.

## Success Criteria (Revised)

- **SC-001**: Model performance (AUC-ROC) is measured against the random baseline (AUC = 0.5) with **% Confidence Intervals** reported. Statistical significance is determined if the lower bound of the CI > 0.5 AND p-value < 0.05.
- **SC-002**: Statistical significance (p-value) measured against a predetermined alpha level.
- **SC-003**: Feature importance rankings measured against **total variance explained** (reported as percentage).
- **SC-004**: Sensitivity analysis results measured across thresholds.
- **SC-005**: Data completeness measured as **percentage of missing values before and after imputation** (must be [deferred] after).

## Risks & Mitigations

| Risk | Impact | Mitigation |
| :--- | :--- | :--- |
| **No open SRA data with disease labels** | High (Fatal) | **Feasibility Gate** halts project. Reframe as "Pipeline Validation". Synthetic data used ONLY for schema testing. |
| **NCBI Rate Limits** | Medium | Exponential backoff (max a bounded number of retries). |
| **ERA5 Data Unavailable** | Medium | Fall back to NOAA; if both fail, exclude sample (log action). |
| **RAM Overflow** | High | Stream data; process one sample at a time. |
| **p >> n (Overfitting)** | High | LD pruning + PCA to reduce features to a reduced subset. |
| **Label Independence Violation** | High | **Label Validation Protocol** excludes ambiguous samples. |
