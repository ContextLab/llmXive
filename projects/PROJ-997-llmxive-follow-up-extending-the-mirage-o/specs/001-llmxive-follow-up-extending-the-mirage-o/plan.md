# Implementation Plan: llmXive follow-up: extending "The Mirage of Optimizing Training Policies: Monotonic Inference Polici"

## Summary

This project implements a hardware-grounded validation framework to bound the "policy gap" (KL divergence) between full-precision and quantized LLM inference using only training-side signals (gradient norms, local curvature). The core objective is to train a lightweight regression model (Kernel Ridge Regression) that predicts this gap, thereby enabling a "Monotonic Inference Policy" (MIPU) loop that uses a fast analytical bound instead of expensive synchronous hardware checks. The plan addresses the critical need for ground-truth data generated by actual CPU-based quantized engines (`llama.cpp`) rather than simulated noise, and rigorously validates the predictor against multiple quantization levels (INT4, INT8, FP8) to ensure statistical robustness and theoretical soundness.

## Complexity Tracking

| Violation | Why Needed | Simpler Alternative Rejected Because |
|-----------|------------|-------------------------------------|
| **Hardware-Engine Wrapper** | Required by Constitution Principle VI for ground-truth validation. | Simulated noise models (e.g., Gaussian perturbation) are invalid per Principle VI and would fail the "Hardware-Grounded Validation" gate. |
| **Stratified Data Splitting** | Required by FR-004 to ensure representation of all quantization levels. | Random splitting risks omitting a quantization level, violating the "joint" requirement and invalidating the bound consistency claim (SC-004). |
| **Bonferroni Correction** | Required by Assumptions for multiple comparisons (3 quantization levels). | Uncorrected p-values would inflate Type I error rates, failing the statistical rigor requirement for SC-003. |
