# llmXive Follow-up: Extending TransitLM

This project implements an automated science pipeline to evaluate lightweight models against LLM baselines for map-free transit routing.

## Project Structure
- `code/`: Source code modules
- `data/`: Raw, processed, and analysis data
- `models/`: Model definitions and artifacts
- `analysis/`: Analysis scripts
- `tests/`: Test suite
- `docs/`: Documentation

## Quick Start
1. Initialize project structure: `python code/setup_project.py`
2. Install dependencies: `pip install -r requirements.txt`
3. Download data: `python code/data/download.py`
4. Run pipeline: See `docs/quickstart.md`
