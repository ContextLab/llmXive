# Research: Predicting the Impact of Impurity Clustering on Grain Boundary Segregation

## Executive Summary

We evaluate whether impurity‑clustering descriptors computed **on bulk configurations before impurity insertion** predict segregation energies **as generated by validated EAM potentials**. Bulk alloy records are sourced from the open OQMD dataset (Materials Project data are omitted due to lack of an unauthenticated open source on the free runner). Grain‑boundary supercells are built, impurities are inserted at the interface, and three bulk‑pre‑insertion descriptors (RDF peak, pair‑correlation, Voronoi count) are computed. Linear Regression (with robust SE p‑values) and RandomForest are trained under 5‑fold cross‑validation (or LOOCV if N < 5). Model selection follows a linearity assessment (scatter + residual diagnostics). VIF diagnostics (threshold 10) are performed before any dimensionality reduction. A **Bonferroni** multiple‑comparison correction is applied to all coefficient tests. Power analysis (f² = 0.15, α = 0.05, target ≥ 0.80) confirms that the sample size yields ≥ 0.80 power. Validation of EAM energies against a DFT benchmark is attempted; no verified benchmark exists, so the harness records `[DATA_UNAVAILABLE]` and the limitation is formally **waived** (see FR‑011 waiver). All findings are **associational within the EAM‑potential physics**; no causal claims about real materials are made.

## Methodology & Statistical Rigor

- **Model choice (FR‑004a/b, FR‑010)**: Exploratory scatter plots and residual analysis (via `plots.py`) decide whether the relationship appears linear. If `appears_linear` is `True`, Linear Regression is the primary model; otherwise RandomForest is reported alongside.  
- **Multiple comparisons (FR‑005/SC‑003)**: **Bonferroni** correction is applied whenever >1 coefficient is tested. Adjusted p‑values and the count of predictors whose significance (α = 0.05) changes are saved in `results/hypothesis_report.json`.  
- **Power analysis (FR‑008)**: `statsmodels.stats.power.FTestPower` with effect size f² = 0.15, α = 0.05, **7 predictors** (3 descriptors + 4 covariates). Required N and achieved N are reported; any shortfall is logged honestly.  
- **Significance of R² (SC‑001)**: Permutation testing for the held‑out test set (≥1000 permutations, seeded) – per‑system R² for ≥3 alloy systems.  
- **Collinearity (FR‑007/FR‑012/SC‑004)**: VIF computed on the three raw descriptors before any PCA; VIF ≥ 10 triggers the JSON collinearity report (see `contracts/output.schema.yaml`). No predictors are removed; relationships are described qualitatively.  
- **Causal framing**: The study is observational/computational; all statements are explicitly associational.  
- **Measurement validity (FR‑011)**: Attempted EAM‑vs‑DFT validation; no verified benchmark exists → script writes a JSON record with `status: DATA_UNAVAILABLE` and exits with code 0 (so integration tests pass). The requirement is formally **waived** pending future benchmark availability.  
- **Uncertainty (SC‑002)**: Linear model prediction intervals are obtained from `statsmodels` (95 % CI); RandomForest intervals are derived via bootstrap quantiles (deferred to implementation).  

## Computational Feasibility

- **CPU‑only**: EAM relaxation of modest GB supercells (≤ 200 atoms) runs in seconds‑minutes; a substantial number of configurations complete well within the 6 h runner limit.  
- **Memory/Disk**: OQMD dataset is streamed via `datasets` (arrow format) and only a sampled subset is held in memory. All intermediate files are < 7 GB total.  
- **Libraries**: All dependencies have CPU wheels; no GPU needed.
