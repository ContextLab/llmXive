## Unresolved concerns

- "CMB input – use the verified FIRAS HEALPix map as a stand‑in for a low‑resolution CMB temperature map (nside = 64 after downsampling)." The FIRAS map has markedly different angular resolution and systematic noise properties than the Planck 2018 maps required to detect the ISW signal. This substitution compromises construct validity: the temperature fluctuations being measured are not the same construct the hypothesis targets.
- "Galaxy density – generate synthetic, photometric‑redshift‑binned galaxy density maps that mimic the statistical properties of SDSS/DES..." Synthetic maps lack real large‑scale structure, void geometry, bias evolution, and survey mask complexities. Using them as a proxy for actual galaxy catalogs undermines construct validity and means the cross‑correlation will not reflect the true relationship between CMB cold spots and real supervoids.
- "Generate 1000 Gaussian CMB realizations with CLASS (ℓ_max = 1024). Run steps 3‑4 on each realization (galaxy mask fixed)." Holding the synthetic galaxy density field constant while varying only the CMB realizations fails to account for variance in the galaxy field. This confound can bias the null distribution and inflate significance, violating proper confound control.
- "Generate 1000 Gaussian CMB realizations..." With only 1000 Monte‑Carlo draws the smallest attainable p‑value is ≈0.001. Given the low‑resolution FIRAS map and synthetic galaxies, the expected ISW signal is weak; the study may be under‑powered to detect it, risking a false‑negative conclusion.
- "Sensitivity Sweep... loop over thresholds … and radii …; output a heat‑map table (pvalue_table.csv)." The plan does not describe any correction for the multiple hypothesis tests generated by the grid of thresholds and radii. Reporting raw p‑values from many correlated tests can lead to inflated Type I error rates.
- Phase 10 ‘Contract Validation’ is listed without any associated FR(s) or SC(s); the specification does not require a contract‑validation step, so this element appears to be over‑reach.
- Phase 11 ‘CI Integration’ is also listed without any linked FR(s) or SC(s); the spec does not mandate CI workflow integration, making this an unnecessary plan element.

- "CMB input – use the verified FIRAS HEALPix map as a stand‑in for a low‑resolution CMB temperature map (nside = 64 after downsampling)"
