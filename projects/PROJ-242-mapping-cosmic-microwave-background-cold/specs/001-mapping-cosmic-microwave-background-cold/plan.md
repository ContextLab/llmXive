# Implementation Plan: Mapping Cosmic Microwave Background Cold Spots to Large‑Scale Structure

**Branch**: `001-mapping-cosmic-microwave-background-cold` | **Date**: 2026-10-20 | **Spec**: [spec.md](../specs/001-mapping-cosmic-microwave-background-cold/spec.md)

## Summary
The project must (1) ingest the **Planck 2018 SMICA CMB temperature map** and **SDSS‑DR16 photometric galaxy catalog**, (2) identify CMB cold‑spot candidates with a top‑hat filter, (3) compute the angular cross‑correlation ξ(θ) between cold spots and under‑dense regions in three redshift shells, (4) establish a null distribution from **2 000** ΛCDM Gaussian realizations (each with a fresh random galaxy density field), (5) run a sensitivity sweep over detection thresholds and filter radii, (6) produce reproducible figures, tables, and a notebook, and (7) validate the memory‑pressure abort path (FR‑016). All steps run on the GitHub Actions free‑tier CPU runner (2 cores, ≤ 7 GB RAM, ≤ 6 h).

## Data Proxy Justification
* **CMB map** – The **Planck 2018 SMICA** full‑sky temperature map is publicly downloadable from the Planck Legacy Archive (verified URL: `https://pla.esac.esa.int/pla/aio/product-action?MAP.MAP=COM_CMB_IQU-smica_2048_R3.00_full.fits`). This map provides the required angular resolution and noise characteristics for ISW studies.
* **Galaxy density** – The **SDSS‑DR16 photometric galaxy catalog** is openly available (`https://data.sdss.org/sas/dr16/eboss/photoObj/`) and contains reliable photometric redshifts. We will ingest the catalog, apply the survey mask, and bin galaxies into three redshift shells (0.2–0.4, 0.4–0.6, 0.6–1.0) to create HEALPix density maps at **nside = 64**.

Both datasets are checksum‑verified and stored under `data/`. No synthetic stand‑ins are used, preserving construct validity.

## Phase‑to‑FR/SC Mapping (core implementation tasks)

| Phase | Description | FR(s) addressed | SC(s) addressed |
|-------|-------------|-----------------|-----------------|
| **0. Project Setup** | Virtualenv, install `requirements.txt`. | — | SC‑003 |
| **1. Data Ingestion** | Download Planck SMICA map; download SDSS‑DR16 catalog; convert CMB to HEALPix `nside=64`; bin galaxies into three redshift shells, applying the SDSS mask. | FR‑001, FR‑007, FR‑009 | SC‑003 |

| **4. Cross‑Correlation** | For each redshift bin compute ξ(θ) (θ ∈ [0°, 10°], Δθ = 0.5°) via spherical harmonic transforms; store `xi_theta.npy` **and** `correlation_results.yaml` conforming to `correlation_results.schema.yaml`; overlay Granett et al. 2008 ISW curve. | FR‑003, FR‑012 | SC‑004 |
| **5. ΛCDM Simulations** | Generate **2 000** Gaussian CMB realizations with CLASS (ℓ_max = 1024). For each realization also generate a fresh random galaxy density map (Gaussian with observed angular power spectrum) respecting the same mask. Run Phases 3‑4 on each, collect correlation amplitudes. | FR‑004, VI (Constitution) | SC‑001 |
| **6. Monte‑Carlo Rank Test** | Build null distribution of integrated ξ(θ) amplitude; compute p‑value `p = (rank + 1) / (N + 1)`. Record in `pvalue_table.csv`. | FR‑004, FR‑010 | SC‑001, SC‑005 |

For each combo repeat Phases 3‑6; output spot count, amplitude, raw p‑value. **Apply Bonferroni correction** (factor = 35) and store corrected p‑values in `pvalue_table.csv`. | FR‑005 | SC‑002 |
| **8. Plotting & Reporting** | Generate (a) ξ(θ) per redshift bin with simulation error bands, (b) Bonferroni‑corrected p‑value heat‑map, (c) memory‑usage log. Save PNGs. | FR‑011 | SC‑006 |

## Multiple‑Testing Correction
The sensitivity sweep evaluates **35** parameter combinations. Raw p‑values are adjusted using a **Bonferroni correction** (α / 35). Corrected p‑values appear in `pvalue_table.csv` and are used for significance statements.

## Power Considerations
With **2 000** Monte‑Carlo draws, the smallest attainable p‑value is ≈ 0.0005. This limit is reported and discussed in the results section.

## Decision / Rationale Summary
| Decision | Rationale |
|----------|-----------|
| **CPU‑only execution** | All required libraries (`healpy`, `classy`, `numpy`) run efficiently on the free‑tier runner; no GPU needed. |
| **Real SDSS‑DR16 galaxy catalog** | Provides authentic large‑scale structure, masks, and redshift information, satisfying construct validity. |
| **Planck SMICA CMB map** | Publicly verified source matching the hypothesis construct. |
| **Randomized galaxy field in simulations** | Prevents confounding and fulfills Constitution Principle VI. |
| **2000 Monte‑Carlo draws** | Improves p‑value resolution while staying within compute budget. |
| **Bonferroni correction** | Controls family‑wise error across the sensitivity‑sweep grid. |
| **Memory‑pressure test exception** | Generates a temporary `nside = 256` map solely to test resource handling; documented as a controlled deviation from Principle VII (which applies to scientific maps only). |
