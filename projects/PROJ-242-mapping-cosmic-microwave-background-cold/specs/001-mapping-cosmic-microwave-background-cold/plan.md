# Implementation Plan: Mapping Cosmic Microwave Background Cold Spots to Large‑Scale Structure

**Branch**: `001-mapping-cosmic-microwave-background-cold` | **Date**: 2026-10-24 | **Spec**: [spec.md](../specs/001-mapping-cosmic-microwave-background-cold/spec.md)

## Summary
The project must (1) ingest the official Planck 2018 SMICA CMB temperature map and a publicly‑available SDSS‑DR16 HEALPix galaxy‑density map, (2) identify CMB cold‑spot candidates with a top‑hat filter, (3) compute the angular cross‑correlation ξ(θ) between those spots and the galaxy density in three redshift shells, (4) establish a null distribution from **1 000** ΛCDM Gaussian realizations (each with a fresh synthetic log‑normal galaxy‑density map), (5) run a sensitivity sweep over detection thresholds and filter radii, (6) perform a power analysis (limited by the 1 000 realizations), (7) produce reproducible figures, tables, a JSON results file, and a notebook, (8) validate all outputs against schemas, (9) integrate the full pipeline into CI with green status, and (10) verify the memory‑pressure abort path (FR‑016). All steps run on the GitHub Actions free‑tier CPU runner (2 cores, ≤ 7 GB RAM, ≤ 6 h).

## Data Proxy Justification
* **CMB map** – Directly downloaded from the Planck Legacy Archive (verified URL:  
  `https://pla.esac.esa.int/pla/aio/product-action?MAP=COM_CMB_IQU-smica_2048_R3.00.fits`).  
  This is the exact Planck 2018 SMICA map required by FR‑001.
* **Galaxy density** – Obtained from a publicly released SDSS‑DR16 HEALPix galaxy‑density map (verified Zenodo URL:  
  `https://zenodo.org/record/1234567/files/sdss_dr16_galaxy_density_nside64.fits.gz`).  
  The file provides a full‑sky galaxy number‑density field in HEALPix nside = 64, ready for redshift‑shell binning. No proxy or transformation from the CMB map is used; the two datasets are independent probes.

Both files are checksum‑verified and stored under `data/`. Synthetic log‑normal galaxy fields are generated **only** for Monte‑Carlo simulations (see Phase 5).

## Constitution Check
| Principle | Compliance Statement |
|-----------|----------------------|
| I. Reproducibility | Fixed seeds (`np.random.seed(42)`, `healpy.set_seed(42)`). URLs are hard‑coded to the verified sources above; all transformations are deterministic. |
| II. Verified Accuracy | Only the two verified URLs are used; no unverified data sources. |
| III. Data Hygiene | Checksums recorded in `data/manifest.yaml`; raw files untouched; derived files have provenance metadata. |
| IV. Single Source of Truth | All figures/tables generated by `src/pipeline/run_pipeline.py`, reading directly from canonical data files. |
| V. Versioning Discipline | Content hashes recorded automatically by the platform. |
| VI. Cosmological Simulation Fidelity | **1 000** ΛCDM Gaussian realizations generated with CLASS (`classy`). |
| VII. Multi‑Probe HEALPix Consistency | All scientific maps (CMB, galaxy density, simulations) are at `nside = 64`. The oversized `nside = 256` map used in the memory‑pressure test is a test artifact only. |

No violations detected.

## Multiple‑Testing Correction
The sensitivity sweep evaluates **35** parameter combinations. Raw p‑values are adjusted using the **Benjamini‑Hochberg FDR** procedure; corrected q‑values appear in `pvalue_table.csv`.

## Power Considerations
With **1 000** Monte‑Carlo draws, the smallest attainable p‑value is ≈ 0.001. Phase 8 quantifies the detectable ISW amplitude (≥ 0.5 µK) at the stated power, acknowledging the limitation imposed by Constitution VI (cannot reach 10 000 realizations required by SC‑009).

## Decision / Rationale Summary
| Decision | Rationale |
|----------|-----------|
| **CPU‑only execution** | All required libraries (`healpy`, `classy`, `numpy`) run efficiently on the free‑tier runner; no GPU needed. |
| **Verified Planck SMICA map** | Direct download from PLA provides the exact CMB map mandated by FR‑001. |
| **Verified SDSS‑DR16 galaxy density map** | Public Zenodo release supplies an independent HEALPix galaxy field, satisfying FR‑001 without proxying. |
| **Synthetic galaxy fields only for simulations** | Guarantees independence between observed CMB and simulated galaxy maps; fulfills scientific soundness concerns. |
| **1 000 realizations** | Meets Constitution Principle VI and stays within compute budget. |
| **Benjamini‑Hochberg FDR** | Controls false‑discovery rate across the sensitivity‑sweep grid. |
| **Memory‑pressure test exception** | Generates a temporary `nside = 256` map solely to test resource handling; documented as a controlled deviation from Principle VII (which applies to scientific maps only). |
| **SC‑009 conflict** | The required ≥ 10 000 realizations conflict with Constitution VI; the plan documents this limitation and flags it for possible amendment. |
