# DreamX-Lite: Geometric Priors for 3D Consistency

## Overview
This project implements DreamX-Lite, a lightweight variant of DreamX-World with fixed geometric priors for 3D consistency verification.

## Data Fallback Protocol
If DreamX-World data is missing, pipeline aborts primary claim and switches to ScanNet.
