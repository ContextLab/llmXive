# DreamX-Lite: Geometric Priors for 3D Consistency

## Overview
This project implements the DreamX-Lite pipeline for evaluating 3D consistency using geometric priors.

## Setup
1. Create a virtual environment: `python -m venv venv`
2. Activate: `source venv/bin/activate`
3. Install dependencies: `pip install -r requirements.txt`

## Linting & Formatting
The project uses `ruff` for linting and `black` for formatting.
- Check linting: `ruff check.`
- Check formatting: `black --check.`
- Fix formatting: `black.`
- Fix linting: `ruff check. --fix`
