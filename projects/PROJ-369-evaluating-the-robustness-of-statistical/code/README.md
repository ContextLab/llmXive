# PROJ-369: Evaluating the Robustness of Statistical Methods to Non-Independence

## Overview
This project investigates how non-independence in time series data (autocorrelation, long memory) affects the Type I error rates of standard statistical tests (t-tests, F-tests).

## Structure
- `code/`: Source code
- `data/`: Raw and processed data
- `tests/`: Unit and integration tests
- `specs/`: Design documents

## Setup
1. Install dependencies: `pip install -r code/requirements.txt`
2. Run tests: `pytest code/tests/`
