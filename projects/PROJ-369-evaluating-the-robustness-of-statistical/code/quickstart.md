# Quickstart Guide for Statistical Robustness Pipeline

## Prerequisites

- Python 3.9+
- pip and virtual environment support

## Setup

1. **Clone and setup environment**
 ```bash
 cd code
 python -m venv.venv
 source.venv/bin/activate # On Windows:.venv\\Scripts\\activate
 pip install -r requirements.txt
 ```

2. **Verify project structure**
 ```bash
 python scripts/setup_project_structure.py
 ```

## Execution Pipeline

Run the full pipeline stages in order:

```bash
# 1. Ingestion (Download real data)
python scripts/run_ingestion.py

# 2. Preprocessing (Clean, detrend, resample)
python scripts/run_preprocessing.py

# 3. Synthesis (Generate synthetic data)
python scripts/run_synthetic_grid.py

# 4. Metrics (Compute ACF, Hurst, Spectral Density)
python scripts/run_metrics_real.py
python scripts/run_metrics_synthetic.py

# 5. Hypothesis Testing (Monte Carlo trials)
python scripts/run_hypothesis_testing.py

# 6. Regression Analysis (Feature filtering & regression)
python scripts/run_regression.py

# 7. Visualization
python scripts/run_viz.py
```

## Key Outputs

- `data/processed/*.csv`: Cleaned and resampled datasets
- `data/processed/metrics.json`: Computed metrics for all series
- `data/results/error_rates.csv`: Type I error rates from Monte Carlo
- `data/results/filtered_features.json`: **Generated by T037b** - List of allowed features (excludes Max_ACF_Lag and spectral density)
- `data/results/regression_model.json`: **Generated by T037a** - Regression coefficients, VIF, N_eff
- `figures/*.png`: Visualization plots

## Troubleshooting

- **Missing data files**: Ensure all ingestion scripts run successfully first.
- **Import errors**: Verify virtual environment is activated and requirements are installed.
- **Regression failures**: Check `data/results/error_rates.csv` exists and contains valid data.
