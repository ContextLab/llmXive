## Unresolved concerns

- The plan does not include any power or sample‑size justification for detecting the expected associations. Without an a priori power analysis, it is unclear whether the available observations (especially after species exclusions) are sufficient to achieve reasonable statistical power for the LMM and RF comparisons.
- Excluding entire species when a single nutrient is missing (Task T015) can introduce selection bias, reducing the representativeness of the sample and potentially inflating effect estimates. The methodology should discuss the bias implications or provide an alternative handling strategy (e.g., partial imputation) and justify the exclusion criterion.
- The Linear Mixed‑Effects Model includes only a random intercept for species. Other plausible confounders (e.g., soil moisture, temperature, site elevation) are not modeled or controlled, which may violate the assumption that phosphorus and nitrogen are the sole drivers of root architecture. The plan should either incorporate additional covariates or acknowledge the limitation.
- The sensitivity analysis is contingent on a verified literature dataset; if unavailable the analysis is skipped and SC‑006 is set to “N/A”. This makes the claim of biological plausibility untestable. The methodology should either require a verified source or define a fallback procedure that still provides a meaningful plausibility check.
- While the final report is required to contain an associational statement, there is no explicit verification step ensuring that no causal language appears elsewhere in the report. Add a task that scans the generated PDF (or source markdown) for causal keywords and flags violations.
- FR-001 requires downloading *both* RootReader and PlantPheno root phenotype datasets. The plan only defines task T007 to download PlantPheno; there is no task that fetches or processes the RootReader dataset, leaving the requirement unimplemented and untestable.
- FR-009 mandates that the final report explicitly contain the associational statement and that the report be checked for any causal language. The plan includes the sentence in T028 but provides no separate verification task (e.g., a lint or review step) to ensure the statement is present and that no causal phrasing slips in, making the requirement untestable.
- SC-001 measures the proportion of root phenotype datasets successfully merged with soil nutrient data. The plan never defines a concrete task that computes this proportion and records it in the metrics JSON (T027 only mentions booleans). Without a dedicated calculation step, SC‑001 cannot be evaluated.
- Task T010 records amendment AM‑001 that explicitly excludes FR‑002 (ISRIC merge) and FR‑003 (KNN imputation), but subsequent tasks (T008‑T009 for ISRIC handling and T015‑T016 for KNN imputation) still implement those very requirements, creating a contradictory specification that makes the requirements untestable.
- Task T008 attempts to download ISRIC soil data despite AM‑001 stating FR‑002 is excluded; this violates the amendment and the constitution’s requirement that deviations be consistently applied and logged.
- Task T015 describes missing‑data handling for nutrients, yet AM‑001 excludes FR‑003 (imputation). The plan both excludes and implements FR‑003, leading to ambiguous behavior for missing values.
- KNN imputation (FR‑003) is performed in T016 even though the amendment AM‑001 explicitly removes FR‑003 from the pipeline; this inconsistency prevents a clear validation of the missing‑data policy.
- The final report task (T028) includes the required associational statement for FR‑009, but there is no explicit verification step or test to ensure the report does not contain any causal language elsewhere, leaving FR‑009 untestable.
- The Constitution Check table lists Principle V as “Versioning Discipline” with status PASS, but the plan does not detail how content hashes for all generated artifacts (e.g., schema files, metrics JSON, plots) are recorded in the state file, which is required by Principle V.
