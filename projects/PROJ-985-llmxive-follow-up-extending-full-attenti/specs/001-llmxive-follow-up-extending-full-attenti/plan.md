# Implementation Plan: llmXive Follow-up: Extending "Full Attention Strikes Back"

## Summary

This feature implements a research pipeline to investigate whether static linguistic features (entropy, POS, position, n-gram perplexity) can predict "RTPurbo-selected tokens" (ground truth) derived from a full-attention Llama-3-8B model. The pipeline generates a labeled dataset, trains a CPU-based static classifier (Decision Tree/Logistic Regression), derives a deterministic heuristic rule, and evaluates the heuristic's performance against full-attention and learned-sparse baselines. 

**Critical Methodological Clarification**: The primary hypothesis is **Mimicry Validation**: can static features replicate the *behavior* of the learned RTPurbo indexer? A secondary, mandatory step is **Cross-Model Validation**: do these rules generalize to a different architecture (Gemma-2)? The plan explicitly avoids circularity by computing features (perplexity) using an independent n-gram model (KenLM) rather than the ground-truth large language model.

## Complexity Tracking

| Violation | Why Needed | Simpler Alternative Rejected Because |
|-----------|------------|-------------------------------------|
| **Sampled Subset Strategy** | Generating full attention maps for long token sequences with Llama-3-8B on 7GB RAM is intractable for the full dataset. | Running on the full dataset would violate the 6h time limit and 7GB RAM constraint of the GitHub Actions Free Tier, making the core experiment non-reproducible on the target platform. |
| **Independent Perplexity (KenLM)** | Using the same Llama-3-8B model to compute 'local_perplexity' creates a circular dependency with the ground truth. | A tautological validation where the static model merely mimics the learned model's internal logic would fail to prove the existence of independent static features. |
| **Cross-Model Validation** | Testing on a single model (Llama-3-8B) only validates mimicry, not generalizability. | Without testing on a different architecture (Gemma-2), the claim that "static features capture intrinsic sparsity" cannot be supported. |
| **Paired Statistical Test** | Comparing a single static run against an average of learned runs violates statistical assumptions. | A paired t-test on document-level performance differences is required to validly assess the stability of the static heuristic against a fixed baseline. |

## Functional Requirements Alignment

- **FR-001**: System MUST download and preprocess a **sampled subset** of RULER documents (50 docs) to serve as the evaluation corpus.
- **FR-002**: System MUST run a frozen Llama-3-8B model to generate full attention maps and apply RTPurbo (deterministic) to extract ground truth.
- **FR-003**: System MUST compute static linguistic features using **independent models** (spaCy for POS, KenLM for perplexity) to avoid circularity.
- **FR-004**: System MUST train a CPU-based classifier using **5 independent random seeds** for the training split to estimate variance.
- **FR-005**: System MUST execute sparsified attention using the static heuristic and measure performance against Full and Learned baselines.
- **FR-006**: System MUST perform a **paired t-test** on document-level performance differences between Static (mean of 5 seeds) and Deterministic RTPurbo.
- **FR-007**: System MUST implement a memory-efficient data loader to process the sampled subset within 7 GB RAM.
- **FR-008**: System MUST evaluate the **Cross-Model** validity by applying derived rules to a Gemma-2-9B attention map subset.
- **FR-009**: System MUST explicitly check if the performance drop is **<1%** to satisfy Constitution Principle VI.
