# Project: Predicting the Impact of Additive Manufacturing Parameters on the Porosity of 316L Stainless Steel

**Project ID:** PROJ-363

## Overview
This project investigates the relationship between Laser Powder Bed Fusion (LPBF) process parameters
and the resulting porosity in 316L stainless steel parts using machine learning.

## Structure
This directory contains high-level project documentation. The actual implementation artifacts
(source code, data, models, results) are stored in the repository root directories:
- `code/`: Python modules for data processing, training, and analysis
- `data/`: Raw and processed datasets
- `models/`: Trained model artifacts
- `results/`: Reports, plots, and metrics
- `tests/`: Unit and contract tests
