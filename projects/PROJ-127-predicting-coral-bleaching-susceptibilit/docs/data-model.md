# Data Model: Reef-Species Unified Dataset

## Overview

This document describes the final schema of the `reef-species` unified dataset, generated by the ingestion pipeline (`code/ingest.py`) and processed by the feature engineering pipeline (`code/features.py`). This dataset serves as the primary input for model training and evaluation in the coral bleaching susceptibility prediction project.

## File Location

- **Raw/Processed File**: `data/processed/reef_species_unified.csv`
- **Filtered Features**: `data/processed/filtered_features.csv`
- **Feature List**: `data/processed/feature_list.txt`

## Schema Definition

The dataset is a tabular CSV file where each row represents a unique **Reef-Species** observation pair, containing environmental conditions, species traits, and the target label.

### Column Definitions

| Column Name | Data Type | Description | Source | Nullable |
|:--- |:--- |:--- |:--- |:--- |
| `reef_id` | string | Unique identifier for the coral reef location. | UNEP / ReefBase | No |
| `species_id` | string | Unique identifier for the coral species. | Coral Trait DB | No |
| `sst_mean` | float64 | Mean Sea Surface Temperature (°C) for the observation period. | NOAA SST | No |
| `dhw` | float64 | Degree Heating Weeks. Cumulative thermal stress metric. | NOAA DHW | No |
| `thermal_tolerance` | float64 | Species-specific thermal tolerance threshold (°C). | Coral Trait DB | No |
| `bleaching_label` | int8 | Target variable: 1 if bleaching event observed, 0 otherwise. | ReefBase | No |
| `trait_missing_flag` | int8 | Flag: 1 if species trait data was missing/unknown, 0 otherwise. | Derived | No |
| `sst_lag_1` | float64 | Lag-1 rolling mean of SST (previous time step). | Derived (`features.py`) | Yes |
| `sst_lag_7` | float64 | Lag-7 rolling mean of SST (7-day rolling window). | Derived (`features.py`) | Yes |
| `dhw_tolerance_interaction` | float64 | Interaction term: `dhw * thermal_tolerance`. | Derived (`features.py`) | No |
| `region` | string | Geographic region classification (e.g., "Western Pacific", "Eastern Pacific"). | Derived (`train.py`) | No |
| `latitude` | float64 | Latitude of the reef location. | UNEP | No |
| `longitude` | float64 | Longitude of the reef location. | UNEP | No |

### Data Quality Constraints

1. **Imputation**: Missing values in critical environmental columns (`sst_mean`, `dhw`) are imputed using the nearest valid temporal neighbor within `IMPUTATION_THRESHOLD_DAYS` (configurable, default 30 days). Rows failing this threshold are excluded.
2. **Nulls**: Critical columns (`reef_id`, `species_id`, `sst_mean`, `dhw`, `thermal_tolerance`, `bleaching_label`) must contain **no null values** after processing.
3. **Flags**: The `trait_missing_flag` column explicitly marks rows where species trait data was unavailable, allowing models to account for this uncertainty.
4. **VIF Filtering**: Features with Variance Inflation Factor (VIF) > 5 are dropped during the feature engineering phase. The final list of retained features is saved in `data/processed/feature_list.txt`.

## Derived Features

The following features are computed programmatically:

- **`sst_lag_1` / `sst_lag_7`**: Computed in `code/features.py` using `compute_lagged_features`.
- **`dhw_tolerance_interaction`**: Computed in `code/features.py` using `compute_interaction_features`.
- **`region`**: Assigned based on longitude thresholds (Western vs. Eastern Pacific) in `code/train.py` for spatial splitting.

## Relationships

- **One-to-Many**: One `reef_id` can have multiple `species_id` entries (different species at the same location).
- **One-to-Many**: One `species_id` can appear across multiple `reef_id` entries (same species at different locations).

## Usage

This dataset is loaded by `code/train.py` for spatial splitting and model training, and by `code/map.py` for risk map generation.

```python
import pandas as pd
df = pd.read_csv("data/processed/reef_species_unified.csv")
# Ensure no nulls in critical columns
assert df[['sst_mean', 'dhw', 'thermal_tolerance', 'bleaching_label']].isnull().sum().sum() == 0
```
