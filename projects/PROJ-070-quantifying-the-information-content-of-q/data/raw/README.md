# Raw Data Directory

This directory contains raw wavefunction data generated by the Exact Diagonalization (ED) and DMRG generators.

## File Format

All files are in HDF5 format with the following structure:

### Datasets
- `wavefunction_real`: Real part of complex wavefunction coefficients
- `wavefunction_imag`: Imaginary part of complex wavefunction coefficients

### Attributes
- `model_type`: Type of model ('heisenberg_1d' or 'ising_1d')
- `system_size`: Number of spins (N)
- `method`: Generation method ('ED' or 'DMRG')
- `ground_energy`: Ground state energy
- `hilbert_dim`: Dimension of Hilbert space (2^N)
- `seed`: Random seed used for generation
- `generated_at`: ISO timestamp of generation

## Naming Convention

Files follow the pattern: `{model_type}_N{N}_seed{seed}.h5`

Example: `heisenberg_1d_N10_seed42.h5`

## Generation

Generate datasets using:

```bash
python code/run_ed_generator.py --model heisenberg_1d --sizes 10,12,14,16,18,20 --output-dir data/raw --seed 42
```

## Dependencies

- HDF5 format requires `h5py` package
- Wavefunctions are complex128 precision
