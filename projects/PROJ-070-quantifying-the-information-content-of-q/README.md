# PROJ-070: Quantifying the Information Content of Quantum Entanglement

## Overview
This project investigates the relationship between bipartite entanglement entropy and algorithmic complexity in 1D many-body quantum systems. It implements pipelines for data generation, metric calculation (entropy, NCD, MPS bond dimension), and statistical correlation analysis.

## Structure
- `code/`: Source code modules (models, metrics, statistics, etc.)
- `data/`: Raw, processed, and generated data
- `tests/`: Unit and integration tests
- `docs/`: Documentation (spec, plan, research notes)
- `figures/`: Generated visualizations

## Quickstart
See `docs/quickstart.md` for installation and usage instructions.

## Key Features
- Sparse matrix operations for memory efficiency
- Support for external datasets (Zenodo/HuggingFace) and internal generation
- MPS bond dimension as a complexity surrogate
- Bootstrap resampling for confidence intervals
