# PROJ-487: The Impact of Social Media Doomscrolling

## Overview
This project investigates the relationship between aggregate negative news publication volume (GDELT) and anticipatory anxiety (Google Trends).

## Project Structure
- `data/`: Raw and processed datasets
- `code/`: Python scripts for fetching, preprocessing, and analyzing data
- `specs/`: Feature specifications and design documents
- `contracts/`: Data schema definitions

## Setup
1. Create a virtual environment:
 ```bash
 python -m venv venv
 source venv/bin/activate # On Windows: venv\Scripts\activate
 ```
2. Install dependencies:
 ```bash
 pip install -r requirements.txt
 ```
3. Run the pipeline:
 ```bash
 python code/main.py
 ```
