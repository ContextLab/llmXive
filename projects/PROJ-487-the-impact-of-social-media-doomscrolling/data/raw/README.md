# Raw Data Documentation

## Dataset: GDELT Events (Negative Sentiment)

### Description
This dataset contains aggregated event counts from the GDELT 2.0 Event Database, specifically filtering for events with negative sentiment scores. [UNRESOLVED-CLAIM: c_c6f360f0 — status=not_enough_info] It serves as the primary input for analyzing the correlation between negative news volume and anticipatory anxiety trends.

### Proxy Acknowledgment
Proxy Acknowledgment: GDELT EventCount (Negative Sentiment) is used as a proxy for 'news exposure'. This is not direct 'social media consumption' data. Social media amplification is a confounding variable.

### Data Source
- **Provider**: GDELT Project (Global Database of Events, Language, and Tone)
- **API**: GDELT 2.0 EventCount API
- **Endpoint**: `
- **Parameters**:
 - `EventCode`: Negative sentiment event codes (e.g., protests, conflicts, disasters)
 - `StartDate`: 2020-01-01
 - `EndDate`: 2023-12-31
 - `Action`: Count

### Data Format
- **File**: `gdelt_events.csv`
- **Columns**:
 - `date`: ISO 8601 date string (YYYY-MM-DD)
 - `value`: Integer count of events for the day
 - `source`: "GDELT"

### Processing Notes
- Data is aggregated daily.
- Missing days (if any) are handled during the preprocessing phase (T018) via linear interpolation, preserving zero-event days.
- This raw data has not yet been validated for stationarity or normalized.
