# Glossary

## Terms

### Prime
A visual stimulus presented before a target stimulus to influence implicit attitudes.

### Target
A social stimulus (e.g., face) that is evaluated after being primed.

### IAT (Implicit Association Test)
A psychological test that measures implicit attitudes by measuring response times.

### VAD (Valence-Arousal-Dominance)
A model for representing emotional responses. This project uses VAD to derive valence scores.

### LMM (Linear Mixed-Effects Model)
A statistical model that accounts for both fixed and random effects. Used for analyzing repeated measures data.

### VIF (Variance Inflation Factor)
A measure of multicollinearity in regression analysis.

### FDR (False Discovery Rate)
A method for correcting p-values for multiple hypothesis tests.

### PII (Personally Identifiable Information)
Information that can be used to identify an individual.

### OSF (Open Science Framework)
A platform for sharing and collaborating on research projects.

### HF (Hugging Face)
A platform for hosting datasets and models.

### Stimulus Metadata
Information about stimuli, such as valence and ambiguity scores.

### Linkage
The mapping of trial IDs to stimulus IDs.

### Associational Analysis
Analysis that identifies correlations but does not imply causality.
