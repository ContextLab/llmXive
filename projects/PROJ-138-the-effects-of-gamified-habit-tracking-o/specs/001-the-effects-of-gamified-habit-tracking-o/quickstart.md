# Quickstart: The Effects of Gamified Habit Tracking on Long-Term Behavioral Change

## Prerequisites
- Python 3.11+
- Git
- (Optional) Docker for isolation

## Installation

1. **Clone the repository**:
   ```bash
   git clone <repo-url>
   cd projects/PROJ-138-the-effects-of-gamified-habit-tracking-o
   ```

2. **Create a virtual environment**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install dependencies**:
   ```bash
   pip install -r code/requirements.txt
   ```

4. **Verify Consent Placeholder**:
   Ensure `data/consent/CONSENT_PLACEHOLDER.txt` exists. The pipeline will halt if this file is missing (FR-010).
   ```bash
   touch data/consent/CONSENT_PLACEHOLDER.txt
   ```

## Running the Pipeline

### 1. Generate Synthetic Data
Run the ingestion script to create the reproducible synthetic dataset.
```bash
python code/main.py --stage ingestion --seed 42
```
*Output*: `data/raw/user_profile.csv`, `data/raw/behavioral_logs.csv`.

### 2. Aggregate & Validate
Process daily logs into weekly bins and validate data integrity.
```bash
python code/main.py --stage aggregation
```
*Output*: `data/processed/merged_data.csv` (GENERATED artifact).
*Note*: This file is created dynamically by the pipeline. It is not pre-existing. The pipeline validates its structure (non-null values, correct columns) upon generation.

### 3. Run Statistical Analysis
Fit the mixed-effects model and survival analysis.
```bash
python code/main.py --stage modeling
```
*Output*: `data/processed/model_results.json`, `data/processed/survival_results.json`.

### 4. Generate Report
Create the final PDF/HTML report with visualizations.
```bash
python code/main.py --stage reporting
```
*Output*: `reports/final_report.html`.

## Testing
Run the test suite to verify data generation and model recovery.
```bash
pytest tests/
```
*Note*: Tests use a fixed seed to ensure deterministic results.

## Troubleshooting
- **Data Insufficiency**: If the pipeline halts with "Data Insufficiency" (< 100 users), increase the `--seed` or `--n_users` parameter in `ingestion.py`.
- **Model Convergence**: If the mixed-effects model fails to converge, check `code/data/validation.py` for high VIF (collinearity) and remove one predictor.
- **Insufficient Events**: If survival analysis halts, the dropout definition (3 weeks) may be too strict for the simulated data. Adjust `code/config.py` `DROPOUT_THRESHOLD` to 2 weeks for testing.
- **Missing merged_data.csv**: This file is generated by the `aggregation` stage. Ensure the pipeline has completed the `ingestion` and `aggregation` stages successfully before attempting to run `modeling`.
