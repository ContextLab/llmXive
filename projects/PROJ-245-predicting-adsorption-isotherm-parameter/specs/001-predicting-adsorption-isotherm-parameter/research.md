# Research: Predicting Adsorption Isotherm Parameters from Molecular Features

## Problem Statement

Can molecular descriptors (polarizability, van der Waals volume, etc.) and adsorbent properties (surface area, pore volume) predict thermodynamic adsorption isotherm parameters (Langmuir capacity, Henry's constant) with statistical significance?

## Dataset Strategy

### Data Sources & Availability

| Dataset Name | Required Variables | Verified Source URL | Status |
|--------------|-------------------|---------------------|--------|
| **MOF-177 Benchmark** | Isotherm type, Henry's constant, Langmuir capacity, Adsorbent ID, Adsorbate SMILES | `https://huggingface.co/datasets/ethanolivertroy/mof-177-benchmark` | **Verified & Primary** |
| **Synthetic Generator** | Logic test data only | `code/data/generate_synthetic_data.py` | **Logic Test Only** |

### Strategy for Data Gap

The spec initially assumed "NIST Adsorption DB" and "MOF-1000", which were not verified. The plan now uses the **MOF-177 Benchmark** (HuggingFace) as the primary, verified source for real experimental data.

**Decision**:
1.  **Scientific Run**: Use `ethanolivertroy/mof-177-benchmark`. This dataset contains real experimental isotherm data and SMILES, allowing for valid hypothesis testing.
2.  **Code Validation (US-1)**: Use a **synthetic/simulated dataset** generated by the pipeline itself to validate the logic (filtering, descriptor calculation, model training). This satisfies the "Independent Test" requirement for US-1 and US-2 logic verification without relying on external data. **Crucially, results from synthetic data are marked "Provisional" and do not contribute to the scientific claim.**
3.  **Contingency**: If MOF-177 is unavailable, the pipeline **HALTS** with a "Data Unavailable" error. No synthetic data will be used for the scientific hypothesis.

### Data Processing Plan

1.  **Filtering**: Retain only Type I isotherms (Langmuir-like). Remove entries with missing `K_H` or `Q_max`.
2.  **Descriptor Calculation**: Use RDKit to compute:
    *   `molecular_weight`
    *   `polar_surface_area`
    *   `polarizability` (estimated via molar refraction)
    *   `van_der_waals_volume`
    *   `h_bond_donors`, `h_bond_acceptors`
3.  **Normalization**: Convert all surface area units to `m²/g`.
4.  **Splitting**: Stratified split by `adsorbent_id` (80/20) to ensure no material leakage.

## Modeling Strategy

### Algorithms

1.  **Linear Regression**: Baseline for linear relationships.
2.  **Random Forest**: Handles non-linearity and interactions.
3.  **Gradient Boosting (XGBoost/LightGBM)**: High performance, handles missing values (if any).

### Validation & Metrics

*   **Cross-Validation**: 5-fold, stratified by material ID.
*   **Metrics**: R², RMSE, MAE.
*   **Null Baseline**: **Material-Only Model** (predicting mean per material ID). **Note**: "Predicting global mean" (R²=0) is a trivial reference only and is **not** the success criterion.
*   **Success Criterion**: Best model R² ≥ 0.2 improvement over **Material-Only Baseline** (SC-001).
*   **Reduced Model Criterion**: Model trained on **Top 3 Features** must achieve R² ≥ 0.2 improvement over Material-Only Baseline (SC-003).

### Statistical Rigor

*   **Multiple Comparison Correction**: Apply Benjamini-Hochberg FDR to feature importance p-values (FR-006).
*   **Cluster-Aware Permutation**: Shuffle feature values *within* material clusters to preserve correlation structure (FR-007).
    *   **Model Significance Test**: Shuffle target `y` *between* materials to generate null distribution for R².
*   **Collinearity Check**: Calculate VIF (Variance Inflation Factor) for predictors. Pre-filter features with VIF > 5 to reduce dimensionality and improve power for FDR correction.
*   **Circularity Check**: Verify that descriptors are not mathematically derived from the target (e.g., Henry's constant is not a direct function of polarizability in the source data). If a tautology is found, that feature will be flagged.
*   **Reduced Model Validation**: The Top-3 feature model (SC-003) will undergo **independent hyperparameter tuning** to ensure the reduced model is optimized for its specific feature set, avoiding suboptimal performance due to mismatched hyperparameters.

## Power Analysis

*   **Sample Size**: Target N comparable to MOF-177.
*   **Dimensionality**: ~20-50 descriptors.
*   **Power Limitation**: With N < 1000 and high dimensionality, power for FDR correction is limited.
*   **Mitigation**: Pre-filter features using VIF > 5 to reduce dimensionality before permutation testing. Report power limitations explicitly in the final report.

## Compute Feasibility

*   **Target**: GitHub Actions Free Tier (multiple CPUs, 7GB RAM).
*   **Strategy**:
    *   Use `scikit-learn` and `xgboost` (CPU-optimized).
    *   Stream data if > 7GB (unlikely for <2000 rows).
    *   Limit tree depth and number of estimators to fit memory.
    *   No GPU required for these models.
*   **Fallback**: If dataset is huge, sample first 1000 rows.

## Constitution Alignment

*   **Reproducibility**: Seeds pinned in `config.py`.
*   **Data Hygiene**: Raw data (if any) checksummed; synthetic data generated deterministically.
*   **Descriptor Integrity**: All descriptors calculated via RDKit in `code/`.
*   **Verified Accuracy**: Uses verified MOF-177 dataset. Synthetic data is excluded from scientific claims.

## Risks & Mitigations

| Risk | Impact | Mitigation |
|------|--------|------------|
| **No verified adsorption dataset** | High (Cannot validate scientific hypothesis) | Use MOF-177 (verified). If unavailable, halt with "Data Unavailable" error. |
| **Data leakage (material ID)** | High (Overfitting) | Enforce group-based split (FR-003). |
| **Multicollinearity** | Medium (Unreliable feature importance) | Cluster-aware permutation testing (FR-007) and VIF pre-filtering. |
| **Runtime > 4 hours** | Medium | Profile early; limit CV folds if needed. |
| **Suboptimal Reduced Model** | Medium (Invalid SC-003) | Explicitly re-tune hyperparameters for the 3-feature subset in Phase 2.6. |
