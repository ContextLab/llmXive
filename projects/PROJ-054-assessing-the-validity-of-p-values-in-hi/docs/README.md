# Assessing the Validity of p-Values in High-Dimensional Data

## Project Overview

This project empirically assesses the validity of p-values generated by standard hypothesis tests (t-tests, F-tests) when applied to high-dimensional data with violated assumptions. The research focuses on how correlation structures and distributional violations (heavy-tailed, skewed) affect the uniformity of p-value distributions under a true null hypothesis.

## Research Question

How do high-dimensional correlation structures and distributional violations impact the validity of p-values from standard parametric hypothesis tests, and to what extent do these violations lead to anti-conservative bias?

## Methodology Summary

### Data Generation

- Synthetic datasets with controlled correlation structures ($\rho \in \{0, 0.1, \dots, 0.9\}$)
- Systematic variation of sample-to-dimension ratios ($n/p$)
- Controlled distributional violations (t-distribution, skew-normal)
- Ground-truth null hypothesis (no mean differences)

### Analysis Framework

- **Gold Standard**: Permutation-based reference preserving correlation structure
- **KS Statistic**: Quantifies maximum deviation from expected uniform distribution
- **QQ-Plots**: Visual inspection of p-value distribution deviations
- **Bootstrap CIs**: Uncertainty quantification for KS statistics

### Sensitivity Analysis

- Sweep across correlation levels to identify thresholds of invalidity
- Examine interaction between $n$, $p$, and $\rho$
- Compare performance under different distributional violations

## Key Findings

*Note: Actual findings will be populated after running the full simulation sweep.*

Preliminary expectations based on theoretical considerations:
- P-values will deviate from uniformity as correlation increases
- Heavy-tailed distributions will amplify anti-conservative bias
- The bias will be most severe when $n \leq p$ (high-dimensional regime)
