# Quickstart: Statistical Analysis of Publicly Available Chess Game Data for Elo Rating Prediction

## Prerequisites
- Python 3.11 or newer
- `git` (to clone the repository)
- Internet access (to download the open PGN dataset)
- Optional: GitHub Actions runner for CI reproduction

## Installation

```bash
# 1️⃣ Clone the repo
git clone 
cd PROJ-283-statistical-analysis-of-publicly-availab

# 2️⃣ Create a virtual environment
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate

# 3️⃣ Install pinned dependencies
pip install -r requirements.txt
```

`requirements.txt` will be generated by the Implementer Agent and will pin exact versions of `pandas`, `numpy`, `scikit-learn`, `statsmodels`, `python-chess`, `datasets`, `matplotlib`, `seaborn`, `tqdm`, and `pytest`.

## Running the Pipeline

### 0️⃣ Verify Dataset Availability
```bash
python src/data/download.py --verify-only
```
The script checks that the verified HuggingFace dataset `official-stockfish/fishtest_pgns` contains the required columns (`white_rating`, `black_rating`, `move_times`). **If any are missing the pipeline aborts with a clear error message** (as required by Constitution Principle II). When a suitable dataset becomes available, replace the `--source` argument with the new dataset name.

### 1️⃣ Small‑Scale Test (a modest number of games)
```bash
python src/data/download.py --sample-size 100 --output data/raw/sample.parquet
python src/data/parse.py --input data/raw/sample.parquet --output data/processed/sample_games.csv
python src/validation/validate_contracts.py --input data/processed/sample_games.csv --schema contracts/game_record.schema.yaml
```
If the sample passes validation, you have a minimal, end‑to‑end run.

### 2️⃣ Full Analysis
Edit `config.yaml` if you wish to change the sample size or CV folds. Then run:

```bash
python src/main.py --config config.yaml
```

The orchestration script executes the full workflow:
1. Dataset download / streaming
2. Parsing & feature engineering (including `material_imbalance_move10`)
3. Contract validation
4. Model fitting (**Beta Regression** and Ridge regression)
5. Cross‑validation, FDR correction, sensitivity sweep
6. Diagnostic plot generation
7. Output of:
   - `data/outputs/model_summary.csv`
   - `data/outputs/plots/` (PNG files)
   - `data/outputs/reports/sensitivity.json`

### 3️⃣ Inspect Results
- **Tables**: `data/outputs/model_summary.csv` (coefficients, p‑values, R², AIC).  
- **Plots**: `data/outputs/plots/` (residuals, predicted‑vs‑actual, feature importance).  
- **Reports**: `data/outputs/reports/` (JSON with sensitivity analysis, inclusion metrics).  

### 4️⃣ Run Tests
```bash
# Contract validation tests
pytest tests/contract -v

# Unit tests (parsers, calculations)
pytest tests/unit -v

# Integration test (small end‑to‑end)
pytest tests/integration -v
```

## Troubleshooting

| Symptom | Likely Cause | Fix |
|---------|--------------|-----|
| **Dataset verification failed** | Required columns (`white_rating`, `move_times`, etc.) missing from the verified dataset. | No open substitute currently provides these fields. The pipeline will abort as required. When an appropriate dataset becomes available, update `src/data/download.py` with the new source name. |
| **MemoryError** | Attempting to load the full dataset on a runner with limited memory capacity. | Reduce `sample_size` in `config.yaml` or enable streaming mode (`--stream`). |
| **Rate‑limit exceeded** | Too many rapid requests to the HuggingFace hub. | The downloader implements exponential backoff; increase `--max-retries` if needed. |
| **Missing plot files** | Diagnostics step crashed due to empty CV scores. | Check that the pilot power analysis did not abort the run; ensure at least one CV fold completed. |
| **All p‑values = 1** | Dataset lacks variance in a predictor (e.g., all games have the same ECO family). | Verify that the sampled games are stratified by `eco_family`. |
| **Beta Regression errors** | Outcome deviation not available (ratings missing). | The pipeline will skip Beta Regression and run only Ridge on the categorical outcome; the final report will note this limitation. |
