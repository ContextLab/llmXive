# Quickstart Guide

## Prerequisites

- Python 3.10 or higher.
- pip package manager.

## Step 1: Clone and Install

```bash
git clone
cd PROJ-483-evaluating-the-robustness-of-common-stat
pip install -r requirements.txt
```

## Step 2: Verify Configuration

Ensure `code/config.yaml` contains valid settings. Default values are provided.

## Step 3: Download Data

```bash
python code/run_data_loader.py
```

This will fetch datasets from UCI/OpenML and store them in `data/raw/`.

## Step 4: Run Simulation

```bash
python code/main.py
```

This will execute the full pipeline:
- Generate null data.
- Inject dependency.
- Run statistical tests.
- Aggregate results.

## Step 5: View Results

- **Aggregated Metrics**: `results/aggregated.csv`
- **Raw P-values**: `results/simulation_raw.csv`
- **Plots**: `figures/` (generated by `visualizer.py`)

## Step 6: Visualization

```bash
python code/visualizer.py --input results/aggregated.csv --output figures/
```

Open the generated plots in a browser or image viewer.

## Troubleshooting

- **Data Download Fails**: Check your internet connection and verify the URLs in `data/manifests/datasets.yaml`.
- **Simulation Fails**: Check `results/perf_log.json` for error messages.
- **Memory Issues**: Reduce the number of replications in `config.yaml`.
