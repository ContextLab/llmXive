# llmXive: Extending "Masking Stale Observations Helps Search Agents -- Until It Doesn't"

**Project ID**: PROJ-920-llmxive-follow-up-extending-masking-stal

## Overview

This project implements a research pipeline to investigate the interaction between **Semantic Density** and **Retention Horizon** in search agents. It extends the findings of the paper "Masking Stale Observations Helps Search Agents -- Until It Doesn't" by quantifying how masking stale data affects agents with varying densities of critical evidence.

The pipeline consists of four main stages:
1. **Trajectory Generation**: Creates synthetic search trajectories with controlled semantic density and injected critical evidence.
2. **Agent Simulation**: Runs a rule-based agent with variable retention horizons to determine success rates.
3. **Statistical Analysis**: Performs logistic regression with natural splines to model the interaction effect.
4. **Visualization**: Generates a 3D surface plot (Regime Map) showing optimal retention windows.

- pip (package manager)

## Usage

### Running the Full Pipeline

The easiest way to run the entire research workflow is via the provided shell script. This script ensures data dependencies are met in the correct order.

```bash
# Run with a specific seed for reproducibility (e.g., 42)
./run_pipeline.sh --seed 42
```

**Outputs generated by the pipeline:**
- `data/raw/trajectories.json`: Synthetic trajectory data.
- `data/processed/simulation_logs.csv`: Simulation results per turn/horizon.
- `output/regression_summary.json`: Statistical model coefficients and p-values.
- `output/hypothesis_summary.md`: Human-readable hypothesis validation.
- `output/plots/regime_map.png`: 3D surface plot of success rates.

### Running Individual Stages

You can also run each stage independently for debugging or incremental analysis.

#### 1. Generate Trajectories
Creates synthetic data with controlled density levels (Low, Medium, High).
```bash
python code/generate_trajectories.py --seed 42
```

#### 2. Simulate Agent
Runs the heuristic agent simulation on the generated trajectories.
```bash
python code/simulate_agent.py --seed 42
```

#### 3. Analyze Results
Fits the logistic regression model and generates statistical summaries.
```bash
python code/analyze_results.py --seed 42
```

#### 4. Visualize
Generates the final 3D regime map plot.
```bash
python code/visualize_results.py
```

## Configuration

- **Density Terms**: Technical terms used for density calculation are loaded from `code/config/density_terms.json`.
- **Hyperparameters**: The simulation `alpha` (scaling) and `threshold` (critical density) can be adjusted via CLI arguments in `simulate_agent.py`.
