# Neural Correlates of Anticipatory Reward Processing in Vocal Learning

This project implements a pipeline for analyzing neural correlates of anticipatory reward.

## Structure
- `code/`: Source code
- `data/`: Data storage (raw, processed, figures)
- `tests/`: Test suite
- `specs/`: Specifications

## Setup
1. Create virtual environment: `python -m venv.venv`
2. Activate: `source.venv/bin/activate`
3. Install dependencies: `pip install -r projects/PROJ-517-neural-correlates-of-anticipatory-reward/requirements.txt`

## Usage
Run the pipeline:
`python code/setup_directories.py`
`python code/synthetic_generator.py`
`python code/ingestion.py`
`python code/modeling.py`
`python code/visualization.py`
`python code/reporting.py`
