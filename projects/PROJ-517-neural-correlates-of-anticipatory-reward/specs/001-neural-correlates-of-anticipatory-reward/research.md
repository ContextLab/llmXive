## Statistical Methodology

### Model Selection
*   **Family**: Generalized Linear Model (GLM).
*   **Link Function**: Log (Poisson) or Log (Negative Binomial).
*   **Selection Criteria**: **Likelihood Ratio Test (LRT)** or **AIC/BIC** comparison between Poisson and Negative Binomial models.
    *   *Correction*: Removed arbitrary D > 1.5 threshold. The model with the lower AIC or significant LRT (p < 0.05) will be selected to account for overdispersion.
*   **Predictors**: `reward_magnitude` (continuous), `cue_delay` (continuous, **mandatory covariate**).
*   **Outcome**: `spike_count` (integer).
*   **Time-Resolved Analysis**: To address 'anticipatory' dynamics, the primary analysis will use a binned approach (PSTH) where spike counts are calculated in small time windows (e.g., 50ms bins) relative to the cue/reward. A time-varying GLM or repeated measures analysis will be considered if the data supports it. The aggregate count [-500ms, 0ms] will be used as a secondary summary.

### Significance Testing
*   **Permutation Test**:
    *   **Null Hypothesis**: No relationship between reward magnitude and firing rate.
    *   **Procedure**: **Freedman-Lane (Residual Permutation)** method for GLMs with covariates.
        1. Fit full model: `y ~ reward + cue_delay`.
        2. Fit reduced model: `y ~ cue_delay`.
        3. Calculate residuals from reduced model.
        4. Shuffle residuals.
        5. Re-fit full model with shuffled residuals to generate null distribution.
    *   **Metric**: Proportion of permuted coefficients $\ge$ observed coefficient.
    *   **Block Permutation**: If data is clustered by session (multiple neurons per session), permutation will be restricted within blocks (sessions) to preserve hierarchical structure.
*   **Multiple Comparisons**: Bonferroni correction applied if analyzing multiple neurons or time windows (SC-005).
*   **Power Analysis**: Calculate Minimum Detectable Effect Size (MDES) for power=0.80, alpha=0.05 (SC-002).
*   **Collinearity Check**: Variance Inflation Factor (VIF) will be calculated for predictors. If VIF > 5, the predictor will be dropped or the limitation reported.

### Data Integrity & Validation
*   **Spike Sorting**: Validate `snr` > 3.0 and `isolation_distance` > 10.0 (standard thresholds).
    *   *Critical*: If these fields are missing, the 'Neural Correlates' claim is **REJECTED**. The pipeline will output 'Descriptive Statistics Only' with a formal limitation statement.
*   **Time Windows**: Spike count window strictly defined as [-500ms, 0ms] relative to reward.
*   **Cue-Reward Delay**: Flag trials where `cue_timestamp` to `reward_timestamp` < 500ms.

## Decision/Rationale

| Decision | Rationale |
| :--- | :--- |
| **CPU-First Execution** | The dataset size is expected to be < 2GB (streaming if larger). GLM and permutation tests are computationally efficient on CPU (scipy/statsmodels). No GPU required. |
| **Negative Binomial Fallback** | Neural spike counts often exhibit overdispersion. Poisson models may underestimate variance. The plan includes an LRT/AIC check to select the correct family. |
| **Permutation Test over Asymptotic** | Asymptotic p-values assume normality of residuals which may not hold for small trial counts (<30). Permutation tests are distribution-free and robust. |
| **Synthetic Data for CI** | Real data access may be gated or slow. Synthetic data allows rapid schema validation and integration testing without external dependencies. |
| **Covariate Control** | `cue_delay` is included as a mandatory covariate to prevent confounding. Freedman-Lane permutation ensures the null hypothesis is tested correctly in the presence of covariates. |
| **Collinearity Check** | VIF calculation will be performed to ensure `reward_magnitude` and `cue_delay` are not definitionally related. If VIF > 5, the predictor will be dropped or the limitation reported. |
| **Time-Resolved Analysis** | To address the 'anticipatory' construct, a binned analysis (PSTH) is prioritized over a single aggregate count. |

## Data Availability & Feasibility

*   **Feasibility**: The plan relies on open datasets (OpenNeuro/Zenodo). If a dataset requires registration (e.g., dbGaP), the plan will switch to a verified open substitute or explicitly state "Data Unavailable" and halt.
*   **Memory**: Streaming will be used for large datasets. Aggregates (counts, means) are calculated in chunks to stay within 7GB RAM.
*   **Disk**: Intermediate files (unified CSV) will be written to `data/processed/`. Total disk usage expected < 5GB.
*   **Production Limitation**: If a real dataset is provided that lacks `spike_sorting_metadata`, the pipeline will not produce a 'Neural Correlates' claim, adhering to the Constitution's requirement for Signal Integrity.
