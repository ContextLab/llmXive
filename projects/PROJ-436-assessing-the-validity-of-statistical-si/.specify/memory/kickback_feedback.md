## Unresolved concerns

- The plan uses a Binomial test to check if the empirical error rate deviates from 0.05. While valid for a single condition, the plan sweeps 8 missingness rates x 3 mechanisms x 3 methods = 72 conditions. The plan mentions Bonferroni correction but notes it will 'primarily report raw error rates'. Without a rigorous multiple-comparison correction strategy for the *entire* sweep, the identification of 'tipping points' (where error > 5.5%) is prone to false positives due to the sheer number of tests performed. The methodology for defining the 'tipping point' (a single threshold crossing) is statistically fragile without controlling the Family-Wise Error Rate (FWER) or False Discovery Rate (FDR) across the sweep.
- The plan assumes that 'synthetic treatment' and 'synthetic outcome' generation on proxy datasets preserves the 'distributional properties' necessary for valid MAR/MNAR simulation. This is a strong assumption. MAR mechanisms depend on the relationship between observed covariates and the missingness probability. If the proxy dataset's covariates do not have the same correlation structure with the outcome as a real RCT, the simulated MAR mechanism will not reflect real-world behavior. The plan lacks a validation step to ensure the synthetic data generation process actually mimics the statistical properties of a real RCT before running the main simulation.
