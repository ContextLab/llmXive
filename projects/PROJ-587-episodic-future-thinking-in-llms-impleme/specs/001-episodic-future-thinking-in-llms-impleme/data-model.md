# Data Model: Episodic Future Thinking

## 1. Overview

This document defines the data structures used for storing episodic memories, planning tasks, and evaluation results. All data is persisted in `data/` with checksums and follows the schema definitions in `contracts/`.

## 2. Entity Definitions

### 2.1 EpisodicMemory
Represents a single stored memory of a (state, action, outcome) tuple.

- **episode_id**: Unique identifier (UUID).
- **state_embedding**: Vector representation of the environment state (float32 array).
- **action_embedding**: Vector representation of the action taken (float32 array).
- **outcome**: Text description of the result (string).
- **timestamp**: Unix timestamp of the event (float).
- **confidence_score**: Model confidence in the retrieval match (float, 0.0-1.0).
- **source_dataset**: Identifier of the source dataset (e.g., "ALFWorld").
- **task_id**: Reference to the originating planning task.

### 2.2 PlanningTask
Represents a benchmark task from ALFWorld/TextWorld.

- **task_id**: Unique identifier (string).
- **initial_state**: Text description of the starting state (string).
- **goal_state**: Text description of the target state (string).
- **required_steps**: Expected number of steps (integer).
- **episodic_dependencies**: List of task IDs that require episodic retrieval (list of strings).
- **ground_truth_solution**: List of actions forming the correct solution (list of strings).
- **environment**: Source environment ("ALFWorld" or "TextWorld").

### 2.3 FutureScenario
Represents a generated plan combining episodic memories with current state.

- **scenario_id**: Unique identifier (UUID).
- **generated_plan**: Text description of the generated plan (string).
- **episodic_references**: List of `episode_id`s used in the plan (list of strings).
- **counterfactual_details**: List of details generated that are not supported by retrieved memories (list of strings).
- **confidence_scores**: Dictionary mapping detail IDs to confidence values (dict).
- **coherence_score**: Human/rater rating (1-5 Likert) if applicable (float).

### 2.4 EvaluationResult
Stores the outcome of a single evaluation run.

- **result_id**: Unique identifier (UUID).
- **task_id**: Reference to the planning task.
- **model_variant**: "baseline" or "episodic".
- **threshold_used**: Similarity threshold used (float).
- **success**: Boolean indicating if the plan solved the task.
- **metrics**: Dictionary of specific metrics (precision, recall, confidence).

## 3. Data Flow

1. **Ingestion**: Raw datasets (ALFWorld/TextWorld) are downloaded and parsed into `PlanningTask` objects.
2. **Trajectory Extraction**: Successful trajectories are extracted and converted into `EpisodicMemory` objects.
3. **Indexing**: `EpisodicMemory` objects are embedded and stored in the FAISS HNSW index.
4. **Generation**: `FutureScenario` objects are generated by the model during inference.
5. **Evaluation**: `EvaluationResult` objects are computed by comparing `FutureScenario` against `PlanningTask` ground truth.

## 4. Storage Format

- **Raw Data**: JSON/Parquet files in `data/raw/`.
- **Processed Data**: Parquet files in `data/processed/` (e.g., `trajectories.parquet`, `embeddings.parquet`).
- **Indices**: FAISS index files (`.index`) in `data/processed/`.
- **Results**: JSONL files in `data/results/`.
