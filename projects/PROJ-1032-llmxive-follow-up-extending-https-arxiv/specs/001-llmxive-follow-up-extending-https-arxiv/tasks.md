## Phase 3: User Story 1 - Reproducible CPU-Only Training Loop with Configurable Staleness (Priority: P1) 🎯 MVP

**Goal**: Execute an asynchronous RL training loop on CPU with configurable staleness for Phi-2 and Qwen1.5-1.8B.

**Independent Test**: The system can be tested by running a single training job with a fixed staleness value and verifying that the training log outputs a sequence of reward values and gradient norms without crashing due to OOM or CUDA errors.

### Baseline Generation (Critical Prerequisite for US1 Divergence Logic)
**⚠️ CRITICAL**: These tasks MUST be completed and executed before T013 (Async Trainer) or T020/T021 (Divergence Logic).

- [ ] T019 [US1/US2] Implement and execute synchronous baseline generation: Run `staleness=0` for each seed in the sequence, compute static mean reward/gradient of an initial sequence of steps, and save to `data/processed/baseline_manifests/{seed}.json` (FR-003, FR-004). <!-- ATOMIZE: requested -->
 *Specifics*: MUST verify seed stability (variance < 5% of mean) before saving. If unstable, **discard** and **retry** with the next seed in the pre-defined integer sequence (e.g., increment index). **Max retry limit: attempts per seed slot. **
 *Output*: `data/processed/baseline_manifests/{seed}.json` containing `mean_reward`, `mean_grad_norm`, `status`, `seed_id`.
- [X] T020 [US1/US2] Implement `src/llmxive/baseline_generator.py`: Logic to perform the synchronous run, compute the static mean reward/gradient norm, verify stability, and save the manifest. This task encapsulates the *generation* logic required by T019.
- [X] T021 [US1/US2] Implement `src/llmxive/baseline_loader.py`: Logic to load and validate the pre-computed manifest from `data/processed/baseline_manifests/{seed}.json` (generated by T020).
- [X] T022 [US1/US2] Implement stability check logic in `src/llmxive/baseline_loader.py`: Read the manifest from T020 for the current seed and verify `variance < 5% of mean ` before proceeding with async runs; discard seed if unstable (FR-004).
- [X] T022a [US1/US2] Implement the discard-and-retry loop logic: Handle unstable seeds by selecting the next seed in the sequence (incrementing integer index) and calling the generation logic in `src/llmxive/baseline_generator.py` (T020) for that specific seed. **Constraint**: Max 3 attempts per seed slot; if all fail, abort and log `ERR_SEED_UNSTABLE`.

**Checkpoint**: Baseline generation and stability logic complete.
