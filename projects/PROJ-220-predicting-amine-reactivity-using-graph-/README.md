# PROJ-220: Predicting Amine Reactivity Using Graph Neural Networks

## Project Structure

- `src/`: Source code for the pipeline (data ingestion, models, utils).
- `tests/`: Unit, contract, and integration tests.
- `data/`:
 - `raw/`: Raw data from external APIs.
 - `derived/`: Processed data and model inputs.
 - `external/`: Third-party supplementary data.
 - `interim/`: Temporary intermediate files.
- `specs/`: Project specifications and design documents.
- `figures/`: Generated plots and visualizations.
