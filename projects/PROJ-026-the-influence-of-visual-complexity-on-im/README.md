# The Influence of Visual Complexity on Implicit Bias

Automated research pipeline for analyzing the relationship between visual complexity metrics and implicit bias scores.

## Project Structure

```
.
├── code/ # Source code
│ ├── data/ # Data loading and processing
│ ├── stimuli/ # Stimulus generation and metrics
│ ├── analysis/ # Statistical analysis
│ ├── viz/ # Visualization
│ ├── tests/ # Unit tests
│ ├── config.py # Configuration
│ └── main.py # Entry point
├── data/ # Data storage
│ ├── raw/ # Raw data inputs
│ ├── processed/ # Processed data
│ └── results/ # Analysis results
├── docs/ # Documentation
├── tests/ # Root level tests
└── README.md
```

## Setup

Run the setup script to initialize directories:
```bash
python code/setup_directories.py
```
