# Implementation Plan: Predicting the Impact of Residual Stress on Fatigue Life Using Public Datasets

**Branch**: `001-predict-residual-stress-fatigue` | **Date**: 2026-10-21 | **Spec**: [spec.md](../specs/001-predict-residual-stress-fatigue/spec.md)  
**Input**: Feature specification from `/specs/001-predict-residual-stress-fatigue/spec.md`

## Summary
The pipeline will (1) verify the CI environment, (2) ingest a **repo‑bundled verification CSV** and, if available, any **open public fatigue dataset** that contains measured residual stress (none currently exists, so the synthetic dataset is used only for pipeline validation), (3) standardize units using an explicit `stress_unit` column, median‑impute missing values, compute a residual‑stress proxy **only when measured stress is missing** using a **non‑linear formula** `σ_res = k·log(heat_input+1)·sqrt(cooling_rate)` (k=0.8 for steel, k=0.6 for aluminum), (4) construct three feature sets on a **balanced subset** that guarantees identical row indices for Sets A and B, (5) train Random Forest, Gradient Boosting, and a shallow neural network with 5‑fold CV and a held‑out test set, (6) evaluate predictive gains with a Wilcoxon signed‑rank test (Bonferroni‑corrected) **without any arbitrary percentage‑improvement threshold**, (7) run cross‑material transfer tests, (8) conditionally run bootstrap mediation analysis **only if a real open dataset with ≥50 measured‑stress rows is available**; otherwise mediation is skipped and a limitation is reported, and (9) produce all required artifacts, contracts, and deterministic tests. All steps run on the GitHub Actions free‑tier CPU runner; no GPU is needed.

## Spec Deviation Flag (for kickback)
spec.md FR‑003 mandates the linear proxy `σ_res ≈ k·heat_input·cooling_rate`. Because heat input and cooling rate are already Feature Set A predictors, that linear proxy is a deterministic function of baseline features and adds no independent information (construct‑validity concern, FR‑014). This plan therefore implements a **non‑linear** proxy `σ_res = k·log(heat_input+1)·sqrt(cooling_rate)` with the same material‑specific k values. The proxy is still a deterministic function of Set A features — this is an acknowledged, unavoidable limitation of any process‑derived proxy — and its agreement with measured stress is evaluated descriptively (FR‑014). The spec should be revised to adopt the non‑linear form or to acknowledge the limitation.
