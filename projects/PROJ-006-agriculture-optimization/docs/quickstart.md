# Quickstart Guide for PROJ-006-Agriculture-Optimization

This guide explains how to set up and run the pipeline to generate analysis artifacts.

## Prerequisites

- Python 3.8+
- pip
- Git

## Installation

1. Clone the repository:
 ```bash
 git clone <repo-url>
 cd PROJ-006-agriculture-optimization
 ```

2. Create a virtual environment and activate it:
 ```bash
 python -m venv venv
 source venv/bin/activate # On Windows: venv\Scripts\activate
 ```

3. Install dependencies:
 ```bash
 pip install -r requirements.txt
 ```

## Running the Pipeline

The pipeline can be run in stages or as a full execution.

### Ingest Data
This stage downloads (or generates synthetic) data and performs spatial joins.
```bash
python src/cli/run_pipeline.py --stage ingest
```
*Note: If no real data is found in `data/raw/`, the pipeline will automatically invoke the synthetic generator.*

### Run Analysis
This stage runs the regression models on the ingested data.
```bash
python src/cli/run_pipeline.py --stage analysis
```

### Full Pipeline
Run both ingestion and analysis.
```bash
python src/cli/run_pipeline.py --stage full
```

### Force Synthetic Data
If you want to force the use of synthetic data (even if real data exists):
```bash
python src/cli/run_pipeline.py --stage full --use-synthetic
```

## Validating Artifacts

After running the pipeline, you can validate the generated artifacts.

### Validate Dataset
```bash
python src/cli/validate.py data/processed/analysis_dataset.csv --schema-type dataset
```

### Validate Regression Results
```bash
python src/cli/validate.py data/processed/regression_results.json --schema-type regression
```

## Output Artifacts

- `data/processed/analysis_dataset.csv`: The final analysis-ready dataset.
- `data/processed/regression_results.json`: Regression coefficients and diagnostics.
- `reports/final_report.pdf`: The final research report (generated by T032).

## Troubleshooting

- **Missing Data**: If the pipeline fails due to missing data, ensure you have run the ingestion stage or set up your API keys for real data access.
- **Validation Errors**: Check the logs for specific schema violations. Ensure the data matches the expected format defined in `contracts/`.
