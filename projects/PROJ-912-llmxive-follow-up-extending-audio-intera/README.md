# llmXive: Audio Interaction Model Follow-up

Automated science pipeline for extending audio interaction models via compression and robustness analysis.

## Project Structure

- `code/`: Source code for models, data loaders, and analysis.
- `data/`: Raw and processed datasets, model checkpoints, and metrics.
 - `raw/`: Original datasets.
 - `processed/`: Processed data and model artifacts.
- `tests/`: Unit and integration tests.
- `state/`: Runtime state, logs, and temporary files.

## Prerequisites

- Python 3.11+
- `pip`

## Installation

1. Clone the repository.
2. Install dependencies:
 ```bash
 cd code
 pip install -r requirements.txt
 ```
