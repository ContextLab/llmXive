# Data Model Specification

This document defines the data entities used in the `PROJ-353-investigating-the-effectiveness-of-diffe` project.
It serves as the schema for `data/raw/graphs.jsonl`, `data/processed/trajectories/*.json`, and `data/analysis_results.json`.
All schemas conform to JSON Schema Draft 7.

## 1. SyntheticGraph

Represents a single generated Watts-Strogatz graph with topology annotations.
Generated by `code/data_generation.py` (Task T019).

**Source**: `data/raw/graphs.jsonl`

### Attributes

| Attribute | Type | Description |
|:--- |:--- |:--- |
| `id` | string | Unique identifier (format: `graph_{beta}_{index}_{seed}`) |
| `beta` | number | Rewiring probability $\beta$ (0.0 to 1.0) |
| `seed` | integer | Random seed used for generation |
| `node_count` | integer | Total number of nodes (N=110) |
| `clustering_coefficient` | number | Global clustering coefficient of the graph |
| `edge_list` | list[list[int]] | Adjacency list representation of the graph |
| `labels` | list[int] | Community labels derived from the initial ring lattice |
| `is_connected` | boolean | Validation flag (must be true) |

## 2. TrainingRun

Represents the training trajectory and convergence metrics for a single model on a specific graph.
Generated by `code/train.py` (Tasks T026, T027).

**Source**: `data/processed/trajectories/training_run_{id}_{loss_type}.json`

### Attributes

| Attribute | Type | Description |
|:--- |:--- |:--- |
| `id` | string | Unique run identifier (includes graph ID and loss type) |
| `graph_id` | string | Reference to the source `SyntheticGraph.id` |
| `beta` | number | Rewiring probability $\beta$ (propagated from source graph) |
| `node_count` | integer | Node count (propagated from source graph) |
| `loss_type` | string | Either "ce" (Cross-Entropy) or "infonce" |
| `epochs_trained` | integer | Total number of epochs executed |
| `steps_to_convergence` | integer | Epoch index where accuracy $\ge$ `CONVERGENCE_THRESHOLD` (or `MAX_EPOCHS` if censored) |
| `convergence_status` | string | "converged" or "censored" |
| `final_accuracy` | number | Accuracy at the end of training |
| `trajectory` | list[object] | Per-epoch metrics: `[{loss: float, accuracy: float},...]` |
| `hyperparameters` | object | Dictionary of training hyperparameters used |

## 3. AnalysisResult

Represents the output of the statistical analysis (Tobit and Cox PH models).
Generated by `code/analyze.py` (Task T038).

**Source**: `data/analysis_results.json`

### Attributes

| Attribute | Type | Description |
|:--- |:--- |:--- |
| `tobit_p_value` | number | Raw p-value for the interaction term in Tobit model |
| `tobit_coefficient` | number | Coefficient for the interaction term |
| `cox_p_value` | number | Raw p-value for the interaction term in Cox model |
| `cox_hazard_ratio` | number | Hazard ratio for the interaction term |
| `bonferroni_factor` | integer | Number of tests performed (2) |
| `tobit_p_corrected` | number | Adjusted p-value (raw * factor) |
| `cox_p_corrected` | number | Adjusted p-value (raw * factor) |
| `is_significant` | boolean | True if `min(tobit_p_corrected, cox_p_corrected) < 0.05` |
| `summary` | string | Human-readable conclusion |
