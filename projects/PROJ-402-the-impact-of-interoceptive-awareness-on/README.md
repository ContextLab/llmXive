# llmXive: The Impact of Interoceptive Awareness on Emotional Regulation

This project implements an automated science pipeline to investigate the impact of interoceptive awareness on emotional regulation during simulated stress.

## Project Structure

- `code/`: Implementation scripts and modules
- `data/`: Raw and derived data artifacts
- `results/`: Analysis results and reports
- `contracts/`: Schema definitions and contracts
- `tests/`: Test suite

## Quick Start

1. Install dependencies: `pip install -r requirements.txt`
2. Run the audit: `python code/02_audit_metadata.py`
3. Run preprocessing: `python code/03_preprocess_hrv.py`
4. Run analysis: `python code/04_analyze_regression.py`
