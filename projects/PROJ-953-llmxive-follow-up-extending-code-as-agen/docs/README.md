# llmXive Follow‑up – Extending “Code as Agent Harness”

## Project Overview

This repository investigates the relationship between structural complexity of
code modifications generated by language‑model agents and the necessity of
dynamic re‑execution for safe verification. By extracting static metrics such
as **dependency depth**, **cyclomatic complexity**, and **semantic complexity**
we aim to predict when a lightweight static analysis is sufficient and when
full dynamic execution is required.

The pipeline consists of the following stages:

1. **Ingestion** – Stream the `swe-bench-verified` and `agentbench‑os` datasets,
 sample a representative subset, and generate a ground‑truth CSV with
 execution outcomes.
2. **Baseline Execution** – Run each sampled task in an isolated virtual
 environment to label it `Pass`, `Fail`, or `Timeout/Fail`.
3. **Feature Extraction** – Parse `code_diff` with `tree‑sitter`, build a
 dependency graph, and compute structural metrics.
4. **Model Training** – Train Logistic Regression and Random Forest models,
 sweep decision thresholds, and evaluate false‑negative rates.
5. **Reporting** – Produce a concise research summary and safety analysis.

## Quick‑Start Commands

```bash
# Install dependencies
pip install -r requirements.txt

# 0️⃣ Pilot estimation (optional)
python scripts/ingest.py --sample-size 100 --mode pilot

# 1️⃣ Ingest and generate ground truth
python scripts/ingest.py --sample-size 500 --timeout 600

# 2️⃣ Extract structural features
python scripts/extract_features.py --input data/processed/ground_truth.csv

# 3️⃣ Train models and perform sensitivity analysis
python scripts/train_model.py --input data/processed/features.csv --thresholds 0.01,0.05,0.1

# 4️⃣ Generate final report
python scripts/evaluate.py --model models/model.pkl --results data/processed/model_results.csv
```
