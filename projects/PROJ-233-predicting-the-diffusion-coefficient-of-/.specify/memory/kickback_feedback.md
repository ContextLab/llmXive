## Unresolved concerns

- FR-001 requires ingesting data 'from NIST and Journal of Materials Science sources', but the plan's Phase 0 explicitly states no verified open download exists for those sources and substitutes a real-file gate at data/raw/diffusion_measurements.csv. No plan element can satisfy FR-001's named-source ingestion as written; the spec must be amended (the plan's own Scope Correction Request agrees). Until the spec names an obtainable source, FR-001 is unbacked.
- The plan and spec are fundamentally incompatible on data: FR-001 mandates ingesting from NIST/JMS sources and the spec assumes ≥200 open-access samples, but the plan states no verified open dataset exists and the pipeline 'produces no result tables' until the spec is amended. The plan cannot satisfy FR-001, FR-009's ≥200-sample basis, or any SC measurement as written. The plan's own scope-correction request confirms this; the spec amendment must be resolved (or the plan restructured around an authorized data-entry path) before this plan is internally consistent with the spec it implements.
- The 'interaction share' metric Σ|SHAP interaction| / Σ|SHAP total| is not a proportion of explained variance (FR-010/SC-006 ask for proportion of total R²). A ratio of mean-absolute SHAP magnitudes is a different quantity, is not bounded to behave like a variance decomposition, and — critically — TreeExplainer's shap_interaction_values includes the DIAGONAL (main effects) in the interaction matrix; if summed naively the numerator double-counts main effects and the share is inflated by construction. Specify off-diagonal-only summation and either a variance-based decomposition or explicitly rename the metric as a SHAP-magnitude share, not 'proportion of R²'.
- Post-hoc 'achieved power' computed from the observed effect size (f² from the realized R² gain) is a monotone function of the observed p-value — it adds no information beyond the significance test and cannot 'validate' anything (standard critique, e.g. Hoenig & Heisey 2001). The plan should report the effect size with its CI and the minimum detectable f² at power 0.80 given n, rather than 'achieved power'.
- Hydrogen diffusion in metals is Arrhenius: log10 D is approximately linear in 1/T, and temperature typically dominates variance. Including raw `temperature` (not 1/T) as a predictor means (a) the linear baseline is handicapped against the non-linear models for a physically-known monotone relation, inflating the 'non-linear gain' (SC-001), and (b) the ≥70% interaction-share criterion (SC-006) conflates temperature main-effect variance with descriptor interactions. Add 1/T as a feature (or to the linear baseline) and report interaction share net of temperature, or justify the choice.
- The hold-out 'interaction-variance check' is computed with the SAME model whose SHAP values defined the interactions — it is an out-of-sample stability check, not an independent validation of the interaction claim. The plan mostly words this correctly ('reported as a measured outcome'), but should state explicitly that SHAP-derived shares are model-internal descriptive quantities and cannot by themselves confirm that interactions drive real-world variance; ablation ΔR² (Phase 5) is the corroborating evidence.
