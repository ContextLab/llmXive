 3. Log the switch to HAC and the resulting cluster count/metrics to `data/results/clustering_method_log.json`.
 4. **Constraint**: This task implements the Plan's 'Manifold Robustness Mitigation' strategy, which is only allowed as a fallback when the Spec's primary path (k-reduction) fails completely.
