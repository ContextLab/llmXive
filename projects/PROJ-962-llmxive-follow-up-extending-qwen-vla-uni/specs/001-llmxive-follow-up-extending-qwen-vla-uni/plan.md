# Implementation Plan: Non-Neural Approximation of VLA Priors

**Branch**: `001-non-neural-vla-approximation` | **Date**: 2026-08-02 | **Spec**: `specs/001-non-neural-vla-approximation/spec.md`
**Input**: Feature specification from `/specs/001-non-neural-vla-approximation/spec.md`

## Summary

This project implements a CPU-only pipeline to approximate Vision-Language-Action (VLA) priors using non-neural probabilistic models. The approach involves ingesting the Qwen-VLA/Hy-Embodied dataset, clustering action trajectories by kinematic features, fitting **Conditional Gaussian Mixture Models (CGMM)** to map frozen BERT text embeddings to action distributions, and evaluating the generated trajectories in a PyBullet simulation. The goal is to quantify the fidelity-complexity trade-off, measuring how much performance is lost when replacing a neural VLA backbone with classical machine learning.

> **Note on Spec Contradiction**: The source specification (spec.md) US-02 and FR-003 mandate "Decision Tree" or generic "GMM". This plan implements **Conditional GMM** to address methodology validity concerns. This constitutes a deviation from the spec's explicit model choice. A kickback is flagged to update FR-003 and US-02 to reflect the CGMM requirement.

## Complexity Tracking

| Violation | Why Needed | Simpler Alternative Rejected Because |
|-----------|------------|-------------------------------------|
| **Multi-stage Pipeline** | Essential for reproducibility and debugging. | A monolithic script would make it impossible to isolate failures in clustering vs. simulation. |
| **Streaming Data** | Dataset may exceed 7GB RAM. | Loading full dataset into memory would crash the GitHub Actions runner. |
| **Frozen BERT** | Required for consistent text representation without fine-tuning overhead. | Fine-tuning BERT would require GPU or excessive CPU time, violating the 6h constraint. |
| **Conditional GMM** | Required to model multi-modal action distributions conditioned on text. | Decision Trees produce step-functions; standard GMMs lack conditional logic. |
