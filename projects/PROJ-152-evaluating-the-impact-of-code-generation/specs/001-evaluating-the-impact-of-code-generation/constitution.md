# Constitution of the Code Security Evaluation Project

## Principle VII – Prompt‑Set Transparency

**Original Statement**
The project shall disclose, version‑control, and provide checksums for the complete set of natural‑language prompts used to drive code generation. All prompts must be publicly accessible, and any modifications to the prompt set must be recorded in the project’s constitution and approved by a designated reviewer.

---

### Amendment – Pilot Prompt Set (Approved)

To align with the resource constraints of the pilot study (Section 2.2 of the specification) and to ensure reproducibility, the prompt set is fixed to **30 prompts**:

1. **CodeXGLUE‑derived prompts (10)** – The ten most security‑relevant prompts selected from the CodeXGLUE *code‑to‑text* dataset using the relevance‑scoring pipeline defined in `code/download.py`. These prompts are stored in `data/prompts/filtered_codexglue.json` and are included in the unified manifest.

2. **Hand‑crafted prompts (20)** – Twenty manually authored prompts covering four web‑security categories [UNRESOLVED-CLAIM: c_558933a1 — status=not_enough_info], with five prompts per category [UNRESOLVED-CLAIM: c_e0979732 — status=not_enough_info]:
 - Database Access
 - HTML Rendering
 - Authentication
 - Injection

 The handcrafted prompts are defined in `data/prompts/handcrafted.json`.

The combined manifest is generated by `code/prompts.py` and written to `data/prompts/manifest.json`. A SHA‑256 checksum of the manifest is recorded in `state.yaml` to guarantee integrity.

**Amended Principle VII Text**

> *The prompt set used in any experimental run shall be explicitly enumerated in `data/prompts/manifest.json`. For this pilot study, the manifest must contain exactly 30 prompts: the top‑10 security‑relevant prompts from the CodeXGLUE dataset and 20 handcrafted prompts (5 per category: Database Access, HTML Rendering, Authentication, Injection). All prompts shall be versioned, checksum‑verified, and publicly available. Any change to this set requires a formal amendment to this constitution and reviewer approval before re‑execution of the pipeline.*
