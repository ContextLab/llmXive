# Data Model: Evaluating the Effectiveness of Differential Privacy in Federated Learning

## Overview
All artifacts follow the schemas in `contracts/` and are version‑controlled via SHA‑256 hashes recorded in the project state file. This guarantees **Data Hygiene** (Constitution Principle III) and **Single Source of Truth** (Principle IV).

### 1. Raw FEMNIST Parquet (Source)
| Field | Type | Description |
|-------|------|-------------|
| `image` | `array<int>` (length = 784) | Flattened grayscale pixel values. |
| `label` | `int` (range) | Class index (digits, lowercase, and uppercase characters). |
| `client_id` | `string` | Original LEAF client identifier (kept for provenance only). |

*Stored at*: `data/raw/femnist.parquet` (generated by `T011`).  

### 2. Client Partition Metadata (Derived)
| Field | Type | Description |
|-------|------|-------------|
| `partition_id` | `string` | `{dataset}_{alpha}_{seed}` (e.g., `femnist_0.1_42`). |
| `client_id` | `int` | Simulated client index (0‑N‑1). |
| `samples` | `list<int>` | Row indices into the raw parquet belonging to the client. |
| `label_dist` | `dict<string,int>` | Counts per label for this client. |
| `entropy` | `float` | Empirical label entropy for the client (bits). |
| `is_minority` | `bool` | `True` if the client falls in a lower entropy percentile **within its partition** (independent of α). |
| `samples_per_class` | `dict<string,int>` | Auxiliary covariate for collinearity control. |

*Stored at*: `data/partitions/partition_femnist_{seed}_{alpha}.json` (`T012`).  

### 3. Training Log (Per‑Round CSV)
| Field | Type | Description |
|-------|------|-------------|
| `run_id` | `string` | `{alpha}_{epsilon}_{seed}_{dp_flag}` (e.g., `0.1_1.0_42_DP`). |
| `dataset` | `string` | `"FEMNIST"`. |
| `alpha` | `float` | Dirichlet concentration used. |
| `epsilon` | `string|number` | Target privacy budget (`"inf"` for non‑DP baseline or numeric ε). |
| `seed` | `int` | Random seed. |
| `round` | `int` | Communication round number. |
| `global_accuracy` | `float` | Test accuracy over the entire test set. |
| `majority_accuracy` | `float` | Mean accuracy of majority clients. |
| `minority_accuracy` | `float` | Mean accuracy of minority clients. |
| `delta` | `float` | Fixed privacy δ (small constant). |
| `actual_epsilon` | `float` | Cumulative ε from Moments Accountant (≈ target). |
| `is_dp` | `bool` | `True` for DP runs, `False` for baseline. |
| `is_time_limited` | `bool` | `True` if early‑stop triggered by time budget. |
| `degradation` | `float` | `majority_accuracy_nonDP - majority_accuracy_DP` (computed post‑hoc). |

*Aggregated by*: `T018c` → `results/raw_logs.csv`.  

### 4. Filtered Datasets
- **Utility‑Collapse Filter** (`T035`): Removes rows where `global_accuracy < 1/62 ≈ 0.01613`. Output: `results/filtered_data.csv`.  
- **Time‑Limit Filter** (`T025`): Removes rows with `is_time_limited=True` for convergence metrics. Output: `results/filtered_time.csv`.  

### 5. Final Statistics & Summary
| Field | Type | Description |
|-------|------|-------------|
| `alpha` | `float` | Dirichlet parameter. |
| `epsilon` | `string|number` | Privacy budget (`"inf"` or numeric). |
| `test_name` | `string` | `"paired_t_test"` or `"lmm_minor_vs_major"` etc. |
| `statistic` | `float` | t‑value or LMM coefficient. |
| `p_value` | `float` | Raw p‑value (Bonferroni‑adjusted). |
| `significant` | `bool` | `p_value < 0.05` after correction. |
| `effect_size` | `float` | Cohen’s d (for t‑tests) or standardized LMM coefficient. |

*Stored at*: `results/final_stats.csv` (`T024a`, `T024b`).  

### 6. Summary & Validation Artifacts
- `results/summary.csv` – one row per (α, ε) summarizing mean accuracies, degradation, and convergence rounds.  
- `results/validation_report.md` – human‑readable checklist confirming checksum integrity, seed count, and any excluded runs.  
- `results/p_values_by_seed.json` – mapping seed → raw p‑values for reproducibility audits.

### Data Flow Diagram (conceptual)
1. **Download** → `data/raw/femnist.parquet` (`T011`).  
2. **Partition** → `data/partitions/...json` (`T012`).  
3. **Training** (DP & non‑DP) → `results/raw_logs.csv` (`T018c`).  
4. **Filtering** → `results/filtered_data.csv`, `results/filtered_time.csv` (`T035`, `T025`).  
5. **Statistical Tests** → `results/final_stats.csv` (`T024a`, `T024b`).  
6. **Plotting** → `figures/*.png` (`T026`).  
7. **Aggregation** → `results/summary.csv`, `validation_report.md`, `p_values_by_seed.json` (`T028`).  

All files are versioned; any change updates the hash map in `state/projects/PROJ-044‑...yaml`.
