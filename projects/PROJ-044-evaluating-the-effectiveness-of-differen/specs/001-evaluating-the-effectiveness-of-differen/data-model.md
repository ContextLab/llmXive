# Data Model: Evaluating the Effectiveness of Differential Privacy in Federated Learning

## Overview

This document defines the data structures, schemas, and storage formats used throughout the project. It ensures data hygiene (Principle III) and reproducibility (Principle I).

## Raw Data Schema

### FEMNIST Parquet (Source)

| Field | Type | Description |
|-------|------|-------------|
| `image` | `bytes` / `array` | Flattened square image pixel values (0-255). |
| `label` | `int` | Class label (-61). |
| `client_id` | `str` | Original client ID from LEAF (used for verification only). |

*Source*: Hugging Face `flwrlabs/femnist`.

## Derived Data Schema

### Client Partition (JSON/Parquet)

Generated by `code/data/partition.py`.

| Field | Type | Description |
|-------|------|-------------|
| `partition_id` | `str` | Unique ID: `{dataset}_{alpha}_{seed}`. |
| `client_id` | `int` | Simulated client index (-49). |
| `samples` | `list` | List of indices pointing to raw data. |
| `label_dist` | `dict` | Distribution of labels for this client. |
| `is_minority` | `bool` | True if partition generated with α ≤ 0.1 (pre-specified). |
| `samples_per_class` | `dict` | Count of samples per class for this client (covariate). |

### Training Results (CSV)

Generated by `code/training/fedavg.py` and `code/analysis/stats.py`.

| Field | Type | Description |
|-------|------|-------------|
| `run_id` | `str` | Unique run identifier. |
| `dataset` | `str` | "FEMNIST". |
| `alpha` | `float` | Dirichlet concentration parameter. |
| `epsilon` | `float` | Privacy budget. |
| `seed` | `int` | Random seed. |
| `round` | `int` | Training round number. |
| `global_accuracy` | `float` | Global test accuracy. |
| `majority_accuracy` | `float` | Average accuracy of non-minority clients. |
| `minority_accuracy` | `float` | Average accuracy of minority clients. |
| `delta` | `float` | Privacy parameter δ (fixed to a small, constant value). |
| `actual_epsilon` | `float` | Calculated ε from Moments Accountant. |
| `degradation` | `float` | `Accuracy_NonDP - Accuracy_DP` (calculated post-hoc). |
| `is_time_limited` | `bool` | True if training was truncated due to time limit. |

## Artifact Checksums

All raw and derived data files are checksummed (SHA-256) and recorded in `state/projects/PROJ-044-evaluating-the-effectiveness-of-differen.yaml`.

## Data Flow Diagram

1.  **Raw Download**: `code/data/download.py` → `data/raw/femnist.parquet`.
2.  **Partitioning**: `code/data/partition.py` → `data/partitions/{alpha}_{seed}/`.
3.  **Training**: `code/training/fedavg.py` → `results/raw_results.csv`.
4.  **Analysis**: `code/analysis/stats.py` → `results/final_stats.csv` + `figures/`.
