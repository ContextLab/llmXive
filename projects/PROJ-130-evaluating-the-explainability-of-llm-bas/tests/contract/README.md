# Contract Test Framework

This directory contains the contract test framework for validating data artifacts against the project's YAML schemas.

## Overview

Contract tests ensure that data generated by the pipeline (patches, correctness labels, explainability scores, statistical results) strictly conform to the schemas defined in `specs/001-evaluating-the-explainability-of-llm-bas/contracts/`.

## Files

- `conftest.py`: Pytest configuration and schema path constants.
- `test_schema_validation.py`: Core framework tests verifying schema existence and structure.
- `test_dataset_schema.py`: Validates dataset artifacts.
- `test_patch_schema.py`: Validates patch artifacts.
- `test_correctness_schema.py`: Validates correctness artifacts.
- `test_explainability_schema.py`: Validates explainability artifacts.
- `test_statistical_schema.py`: Validates statistical artifacts.
- `README.md`: This file.

## Usage

Run all contract tests:

```bash
pytest tests/contract/ -v
```

Run a specific test file:

```bash
pytest tests/contract/test_patch_schema.py -v
```

## Schema Validation Process

1. YAML schemas in `specs/.../contracts/` are loaded using `yaml.safe_load()`.
2. JSON data artifacts are loaded using `json.load()`.
3. `jsonschema.validate()` checks if the data conforms to the schema.
4. Tests pass if validation succeeds; `ValidationError` indicates a contract violation.

## Adding New Contracts

1. Define the schema in `specs/.../contracts/`.
2. Add a new test file `tests/contract/test_<name>_schema.py`.
3. Implement `test_<name>_artifact_conforms()` with valid sample data.
4. Implement negative tests (e.g., missing fields, wrong types).

## Dependencies

- `pytest`
- `jsonschema`
- `pyyaml`

Ensure these are installed in the project environment.
