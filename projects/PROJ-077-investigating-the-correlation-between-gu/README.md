# PROJ-077: Investigating the Correlation Between Gut Microbiome Diversity and Cognitive Performance

## Getting Started
## Prerequisites
- Python 3.11+
- UK Biobank access credentials

## Data Access
1. Apply for UK Biobank access at the official UK Biobank portal (https://www.ukbiobank.ac.uk/).
2. Upon approval, download the microbiome, cognitive, and dietary data associated with the project.
3. Place files in `data/raw/` with names: `microbiome.csv`, `cognitive.csv`, `dietary.csv`.

**Note**: Ensure that the downloaded files strictly adhere to the required column schemas defined in the data model documentation before running the pipeline.
