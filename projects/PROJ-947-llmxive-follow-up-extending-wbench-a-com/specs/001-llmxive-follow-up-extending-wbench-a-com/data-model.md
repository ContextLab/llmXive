# Data Model: llmXive Follow-up: Extending WBench with Sequence Complexity Analysis

## 1. Entity Definitions

### 1.1 SequenceVariant
Represents a specific version (Low/Med/High) of a WBench interaction case.
- **ID**: Unique identifier (e.g., `case_id_variant_type`).
- **Base Case ID**: Reference to the original WBench case.
- **Variant Type**: Enum {`low`, `medium`, `high`}. *This is the primary predictor (Entropy Level).*
- **Commands**: List of text commands (strings).
- **Entropy Score**: Float (0.0–1.0). *Used as manipulation check.*
- **Semantic Similarity**: Float (0.0–1.0). *Cosine similarity of intent vector vs original.*
- **Task Validity Passed**: Boolean. *Result of the Task Validity Validator (Action Chain Check).*
- **Dependency Depth**: Integer (≥1). *Derived from original un-manipulated text. Used as a covariate.*
- **Complexity Score**: Float. *In this plan, effectively the Entropy Level (categorical) for the primary analysis, not a weighted sum.*

### 1.2 InferenceResult
Represents the output of a single model run (or proxy metric calculation).
- **ID**: Unique identifier.
- **Sequence Variant ID**: Foreign key to `SequenceVariant`.
- **Model Name**: String.
- **Video Path**: Relative path to generated MP4 (or `null` if proxy used).
- **Physics Score**: Float (0.0–1.0). *Or proxy metric value.*
- **Consistency Score**: Float (0.0–1.0). *Or proxy metric value.*
- **Motion Artifact Baseline**: Float (subtracted value).
- **Status**: Enum {`success`, `failed`, `timeout`, `proxy_used`}.
- **Execution Mode**: Enum {`video`, `proxy`}. *Explicitly records the method used to derive scores.*

### 1.3 DegradationCurve
Derived entity for analysis.
- **Model Name**: String.
- **Entropy Level**: Enum {`low`, `medium`, `high`}.
- **Mean Physics Score**: Float.
- **Std Physics Score**: Float.
- **F-Statistic**: Float. *From ANOVA.*
- **P-value**: Float. *From ANOVA.*
- **Bonferroni P-value**: Float.
- **Significant**: Boolean.
- **Trend Type**: Enum {`linear`, `non-linear`, `none`}.
- **Execution Mode**: Enum {`video`, `proxy`}. *Context for the hypothesis.*

## 2. Data Flow

1. **Raw Input**: WBench Parquet (downloaded).
2. **Processed Input**: `SequenceVariant` CSV (generated by `entropy/generator.py` with semantic check and task validity validator).
3. **Intermediate Output**: `InferenceResult` CSV (generated by `inference/runner.py`).
4. **Final Output**: `DegradationCurve` CSV and statistical summary (generated by `analysis/correlation.py`).

## 3. Storage Schema

### 3.1 `data/processed/variants.csv`
Columns: `case_id`, `variant_type`, `commands_json`, `entropy_score`, `semantic_similarity`, `task_validity_passed`, `dependency_depth`, `complexity_score`.

### 3.2 `data/processed/inference_results.csv`
Columns: `result_id`, `variant_id`, `model_name`, `video_path`, `physics_score`, `consistency_score`, `status`, `execution_mode`, `timestamp`.

### 3.3 `data/processed/analysis_summary.csv`
Columns: `model_name`, `f_statistic`, `p_value`, `bonferroni_p_value`, `significant`, `trend_type`, `execution_mode`.

## 4. Constraints & Validations

- **Entropy Range**: Must be in [0.0, 1.0].
- **Semantic Similarity**: Must be > 0.85 for valid variants.
- **Task Validity**: Must be `true` for valid variants.
- **Dependency Depth**: Must be integer ≥ 1.
- **Physics Score**: Must be in [0.0, 1.0] after baseline subtraction.
- **Variance Check**: `entropy_score` variance > 0.05 required for analysis.
- **Completeness**: All `case_id` + `variant_type` combinations must have at least one `InferenceResult` (or a `failed`/`proxy_used` status).
