# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [Unreleased]

### Added
- Initial project structure and documentation
- Power analysis pipeline with synthetic data validation
- Instrument citation validation gate
- Data download and preprocessing pipeline
- ILR transformation for compositional microbiome data
- Statistical analysis with Lasso and Ridge regularization
- Benjamini-Hochberg multiple testing correction
- Interaction analysis for age-dependent effects
- Visualization generation (Manhattan plots, threshold sweeps)
- Comprehensive documentation including:
 - API reference
 - Methodology documentation
 - Contributing guide
 - Validation gate documentation
 - Quick start guide

### Changed
- Updated zero-replacement method from fixed pseudocount to Bayesian-multiplicative
- Enhanced documentation with validation gate details
- Improved error handling and logging

### Fixed
- Documentation completeness for T031 task
- Configuration file formats (ruff, black)
- Environment variable templates
