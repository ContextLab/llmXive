## Phase 4 – Core statistical association analysis (User Story 2, **US2**)  

- [ ] **T007**  Fit multivariate linear models for every taxon‑cognitive pair using **three estimators** (OLS, Lasso, Ridge) while **including all confounders** (age, sex, BMI, diet quality, physical activity, medication use). Apply Benjamini‑Hochberg correction and add `causality_claim: false`.  
  *Outputs*:  
  - `results/associations/main_effects_ols.parquet`  
  - `results/associations/main_effects_lasso.parquet`  
  - `results/associations/main_effects_ridge.parquet`  
  - Consolidated `results/associations/main_effects.parquet` (conforms to `contracts/association_result.schema.yaml`).  

- [ ] **T008**  Fit **reduced models** that omit diet‑quality and medication‑use covariates (FR‑010).  
  *Outputs*:  
  - `results/associations/main_effects_reduced.parquet`  
  - `results/sensitivity/over_control_report.json` (contains `beta_full`, `beta_reduced`, `delta`, and mean absolute delta).  

- [ ] **T023‑reduced**  Alias task that runs the same reduced‑model analysis as **T008**, satisfying the plan reference.  

- [ ] **T009**  Fit interaction models that include the term `Age_Group * Taxon` (age groups defined in `config.AGE_GROUP_CUTOFF`). Apply BH correction to interaction p‑values.  
  *Outputs*:  
  - `results/associations/interaction_effects.parquet`  
  - `results/associations/interaction_effects_bh.parquet` (schema‑compliant).  

- [ ] **T010**  Generate Manhattan‑style plots for each cognitive metric and perform a threshold‑sweep sensitivity analysis over p‑value cut‑offs {0.01, 0.05, 0.1}.  
  *Outputs*:  
  - `results/plots/manhattan_reaction_time.png`  
  - `results/plots/manhattan_numeric_memory.png`  
  - `results/plots/manhattan_reasoning.png`  
  - `results/sensitivity/threshold_sweep_report.json` (keys `"0.01"`, `"0.05"`, `"0.1"` with integer counts).  

- [ ] **T011**  Produce an interaction‑comparison report summarising overlap between significant main effects and significant age interactions.  
  *Output*: `results/sensitivity/interaction_comparison_report.json`.
