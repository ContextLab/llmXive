# Impact of Text Message Tone on Perceived Emotional Support

This repository implements the research pipeline for the study *The Impact of
Text Message Tone on Perceived Emotional Support*. The directory layout follows
the standard structure required by the project:

```
.
├── code/
├── data/
│ ├── raw/
│ ├── processed/
│ └── consent/
└── tests/
```

The `code/` package contains all pipeline scripts, `data/` holds raw and
processed datasets, and `tests/` provides the test suite. The project is
ready for execution with the provided scripts and configuration files.
