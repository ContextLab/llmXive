# Data Model: llmXive follow-up: extending "Blind-Spots-Bench"

## Overview

This document defines the data structures used throughout the pipeline: the input dataset records, the generated CoT traces, and the statistical output artifacts. All data is stored in JSON/JSONL format for interoperability, with schemas defined in `contracts/`.

## Entity Definitions

### 1. Task Record (Input)
Represents a single item from the filtered *Blind-Spots-Bench* dataset.

| Field | Type | Description | Source |
| :--- | :--- | :--- | :--- |
| `id` | string | Unique identifier for the task. | Dataset |
| `category` | string | Task category ("Abstract Reasoning" or "Object-Centric"). | Dataset |
| `prompt` | string | The full text prompt given to the model. | Dataset |
| `constraint` | string | The explicit constraint string the model must follow. | Dataset |
| `ground_truth` | string | The correct answer to the task (used for outcome). | Dataset |
| `metadata` | object | Additional fields (e.g., difficulty, source). | Dataset |

### 2. CoT Trace (Generated)
The raw output generated by the LLM for a specific task.

| Field | Type | Description | Source |
| :--- | :--- | :--- | :--- |
| `task_id` | string | Reference to the input `id`. | Inference |
| `trace_text` | string | The full generated reasoning text. | Inference |
| `generation_time` | float | Time taken to generate (seconds). | Inference |
| `status` | string | "success", "timeout", "error". | Inference |
| `error_msg` | string | Error details if status != "success". | Inference |

### 3. Parsed Trace (Derived)
The result of parsing the CoT trace for constraint mentions.

| Field | Type | Description | Source |
| :--- | :--- | :--- | :--- |
| `task_id` | string | Reference to the input `id`. | Parser |
| `first_mention_offset` | integer | Character offset of first mention (null if none). | Parser |
| `last_mention_offset` | integer | Character offset of last mention (null if none). | Parser |
| `is_semantic_match` | boolean | True if constraint found via embedding similarity. | Parser |
| `match_score` | float | Cosine similarity score (if semantic match). | Parser |

### 4. Classification Result (Derived)
The final error label for the task.

| Field | Type | Description | Source |
| :--- | :--- | :--- | :--- |
| `task_id` | string | Reference to the input `id`. | Classifier |
| `error_label` | string | "Perceptual", "Procedural", or "Correct". | Classifier |
| `reasoning` | string | Brief explanation of the classification logic. | Classifier |

### 5. Statistical Report (Output)
The final aggregated results.

| Field | Type | Description | Source |
| :--- | :--- | :--- | :--- |
| `test_type` | string | "Chi-squared" or "Fisher's Exact". | Stats |
| `p_value` | float | The calculated p-value. | Stats |
| `statistic` | float | The test statistic (Chi-sq or Odds Ratio). | Stats |
| `contingency_table` | object | Counts of errors per category. | Stats |
| `framing` | string | "Associational" (fixed value). | Stats |
| `correction_applied` | string | "Bonferroni", "None", etc. | Stats |

## Data Flow

1.  **Acquisition**: Raw Dataset -> `data/raw/` (JSONL).
2.  **Filtering**: Raw Dataset -> `data/filtered/` (JSONL, subset of categories).
3.  **Inference**: Filtered Data -> `data/traces/` (JSONL, generated traces).
4.  **Parsing**: Traces -> `data/parsed/` (JSONL, mention offsets).
5.  **Classification**: Parsed -> `data/classified/` (JSONL, error labels).
6.  **Aggregation**: Classified -> `data/reports/statistical_report.json` (Final output).

## Constraints & Validations

*   **Constraint Field**: Every record in `data/filtered/` MUST have a non-null `constraint` string.
*   **Trace Integrity**: `trace_text` MUST be preserved exactly as generated (no trimming).
*   **Determinism**: `error_label` MUST be reproducible for the same `trace_text`.
*   **Framing**: `framing` in the report MUST be "Associational".
