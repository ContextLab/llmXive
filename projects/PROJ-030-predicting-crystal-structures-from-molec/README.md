# Project: Predicting Crystal Structures from Molecular Fingerprints

**Project ID**: PROJ-030

## Overview
This project aims to predict crystal structures (space groups) from molecular fingerprints derived from organic molecules in the Crystallography Open Database (COD).

## Objectives
1. Ingest and process COD organic subset data.
2. Extract molecular fingerprints (ECFP4).
3. Train machine learning models to predict space groups.
4. Analyze feature importance to identify predictive substructures.

## Directory Structure
- `data/`: Raw and processed datasets
- `code/`: Source code for ingestion, modeling, and analysis
- `tests/`: Unit and integration tests
- `docs/`: Documentation and planning artifacts
- `logs/`: Execution logs
