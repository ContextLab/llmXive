## Unresolved concerns

- The plan proposes a 'shuffled-attention' baseline to control for stochasticity, but the core hypothesis (FR-001) relies on 'temporal recursive self-attention' attending to the confidence distribution of the *previous generation step'. A shuffled baseline destroys the temporal structure required to test the specific mechanism of 'recursive self-modeling'. The control condition does not isolate the variable of interest (temporal recursion) but rather tests a different architectural class entirely. This threatens construct validity: a failure of the recursive model vs. shuffled baseline could be due to the loss of temporal coherence rather than the failure of the recursive mechanism itself.
- The plan defines the confidence-prediction loss (`L_confidence`) as a 'proxy loss based on self-consistency of the generated path (majority vote) against the current generation'. This creates a circular dependency during training: the model is trained to predict confidence based on a metric (self-consistency) that is only calculable *after* generating multiple paths, which requires the model to already be trained. This is a tautological training loop. The plan states 'avoiding tautological ground-truth usage', but the proposed proxy is equally tautological for the training phase. The methodology cannot support the claim of learning 'confidence prediction' without an external or independent signal for correctness during the training step.
- The plan uses 'Self-Consistency' (majority vote agreement) as a proxy for 'meta-cognitive behavior' and 'error detection'. However, self-consistency is a measure of output stability, not necessarily of internal error detection or calibration. A model can be highly consistent (always outputting the same wrong answer) and have high self-consistency but zero error detection capability. The construct 'error detection' (ROC-AUC of confidence vs. correctness) is distinct from 'self-consistency'. The plan conflates these constructs, assuming that improving self-consistency implies improving error detection. This is a construct validity flaw: the chosen measurement (consistency) does not necessarily measure the intended construct (error detection) without an explicit link or separate validation.
- The plan proposes a paired t-test across 5 seeds. While 5 seeds are mentioned, the sample size (n=5) is extremely low for a paired t-test in a high-variance deep learning context. The power to detect a meaningful effect (e.g., the hypothesized 5% improvement) with n=5 is likely insufficient, especially given the noise inherent in LLM generation and the small dataset (100k tokens). The plan does not include a power analysis to justify that n=5 is sufficient to detect the expected effect size. This threatens the validity of any statistical conclusion drawn from the study.

The requirement statement is broken, making it impossible to verify if the plan element 'Custom Recursive Attention Module' fully satisfies the specific 'max recursion depth' investigation mandate. The plan mentions 'Recursion depth limited to 2' but does not explicitly address the 'systematically adjusting' aspect of the broken FR-001 text.

The plan element 'Training Regime' addresses the value, but the spec requirement text must be corrected to remove the placeholder or explicitly state the value to be testable.

While 'mean_diff' can be converted to a percentage, the plan does not explicitly state that a 'percentage difference' metric will be calculated and reported as a distinct output, creating a potential gap in the specific success criterion measurement.

- Circular Validation in Loss Function: The plan defines L_confidence as 'a proxy loss based on self-consistency of the generated path (majority vote) against the current generation'. This creates a tautological loop where the model is trained to maximize agreement with its own majority vote. Since the 'ground truth' for the confidence loss is derived from the model's own stochastic outputs (which are the very thing being optimized), the validation metric (self-consistency) is definitionally dependent on the predictor (the model's generation). This is not an empirical test of improved meta-cognition but a self-fulfilling prophecy where the model learns to be consistent with itself, regardless of factual correctness. The plan must decouple the confidence target from the model's own generation (e.g., using a teacher model or external consistency benchmark) to avoid this circularity.
- Non-Triviality of Self-Consistency Metric: The plan uses 'Self-Consistency' (majority vote agreement) as a primary outcome to validate the recursive architecture. However, the recursive module is explicitly designed to attend to confidence distributions to enforce consistency. If the architecture successfully enforces consistency, the metric will improve by definition of the architecture's design, not because the model has learned 'meta-cognition' or 'error detection'. The analysis cannot return a negative result regarding consistency if the mechanism is hard-coded to optimize for it. This conflates the mechanism's success with the emergence of a new capability.
- Statistical Power vs. Sample Size: The plan proposes 5 random seeds for statistical power. However, the training dataset is limited to 100k tokens of the arXiv subset. For a 1.1B parameter model, 100k tokens is insufficient to converge a meaningful representation, let than to establish a stable baseline for meta-cognitive behaviors. The variance introduced by the tiny dataset will likely swamp any architectural effect, rendering the paired t-test statistically invalid or meaningless. The sample size (tokens) is too small for the model capacity, making the 'empirical' claim unsound.
