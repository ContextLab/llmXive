# PROJ-558: Consciousness Bootstrapping: Self-Aware AI Through Recursive Introspection

This project implements a research pipeline for exploring recursive self-modeling as a path to emergent self-awareness in language models.

## Project Structure

- `projects/PROJ-558-consciousness-bootstrapping-self-aware-a/` - Main project directory
 - `data/raw/` - Raw dataset files
 - `data/processed/` - Processed dataset files
 - `code/` - Source code modules
 - `tests/` - Test suite
 - `artifacts/` - Model checkpoints and results
 - `artifacts/checkpoints/` - Saved model weights
 - `artifacts/results/` - Evaluation and analysis results

## Setup

1. Install dependencies:
 ```bash
 pip install -r requirements.txt
 ```

2. Create project structure:
 ```bash
 python code/create_project_structure.py
 ```

## Running Tests

```bash
pytest tests/
```
