# Statistical Report Schema

This document defines the JSON schema for the `statistical_report.json` artifact
generated by `code/analysis/stats.py` (Task T026).

## File Path
`artifacts/results/statistical_report.json`

## Schema Definition

```json
{
 "report_metadata": {
 "generated_at": "ISO-8601 timestamp",
 "model_baseline": "string (e.g., 'TinyLlama-1.1B')",
 "model_recursive": "string (e.g., 'RecursiveLlama-1.1B')",
 "num_seeds": "integer",
 "num_samples": "integer"
 },
 "self_consistency_comparison": {
 "baseline_mean": "float",
 "recursive_mean": "float",
 "percentage_difference": "float (SC-001 metric)",
 "p_value_ttest": "float",
 "cohen_d": "float",
 "confidence_interval_95": [
 "float (lower bound)",
 "float (upper bound)"
 ],
 "is_significant": "boolean",
 "bonferroni_corrected_p": "float"
 },
 "calibration_metrics": {
 "baseline": {
 "brier_score": "float",
 "ece": "float",
 "roc_auc": "float"
 },
 "recursive": {
 "brier_score": "float",
 "ece": "float",
 "roc_auc": "float"
 },
 "improvement_ece": "float (recursive - baseline)",
 "improvement_brier": "float"
 },
 "sensitivity_analysis": {
 "thresholds_tested": ["list of floats"],
 "results": [
 {
 "threshold": "float",
 "baseline_fp_rate": "float",
 "baseline_fn_rate": "float",
 "recursive_fp_rate": "float",
 "recursive_fn_rate": "float",
 "fp_rate_delta": "float",
 "fn_rate_delta": "float"
 }
 ]
 },
 "excluded_seeds": {
 "count": "integer",
 "reason": "string (e.g., 'Non-converged confidence loss')"
 }
}
```

## Field Descriptions

### `percentage_difference` (SC-001)
The percentage improvement in self-consistency scores of the recursive model
compared to the baseline. Calculated as:
`(recursive_mean - baseline_mean) / baseline_mean * 100`.

### `is_significant`
Boolean flag indicating if the p-value (after Bonferroni correction) is less
than the significance level (default $\alpha = 0.05$).

### `confidence_interval_95`
The 95% confidence interval for the difference in means between the two models.

### `excluded_seeds`
Lists any seeds that were filtered out during analysis due to non-convergence
or other validity checks defined in `filter_converged_seeds`.

## Generation Command
This report is generated by running:
```bash
python code/analysis/stats.py --input data/evaluation_results/*.json --output artifacts/results/statistical_report.json
```
