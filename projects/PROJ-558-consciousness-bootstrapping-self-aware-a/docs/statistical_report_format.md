# Statistical Report Format Specification

This document defines the JSON schema and content structure for the `statistical_report.json`
artifact generated by the User Story 3 analysis pipeline.

## File Location

`artifacts/results/statistical_report.json`

## Schema Definition

The report is a JSON object containing the following top-level keys:

```json
{
 "metadata": {
 "generated_at": "ISO-8601 timestamp",
 "recursive_model_seeds": [list of seed integers],
 "baseline_model_seeds": [list of seed integers],
 "excluded_seeds": {
 "recursive": ["reason for exclusion"],
 "baseline": ["reason for exclusion"]
 }
 },
 "self_consistency_comparison": {
 "recursive_mean": "float (mean SC score)",
 "baseline_mean": "float (mean SC score)",
 "percentage_difference": "float (in percent)",
 "paired_ttest": {
 "t_statistic": "float",
 "p_value": "float",
 "significant_at_alpha_0.05": "boolean"
 },
 "cohens_d": "float (effect size)",
 "confidence_interval": {
 "lower": "float",
 "upper": "float",
 "level": "float (e.g., 0.95)"
 }
 },
 "calibration_comparison": {
 "metric_name": "Brier Score or ECE",
 "recursive_mean": "float",
 "baseline_mean": "float",
 "paired_ttest": {
 "t_statistic": "float",
 "p_value": "float",
 "significant_at_alpha_0.05": "boolean"
 }
 },
 "sensitivity_analysis": {
 "thresholds_analyzed": ["list of float thresholds"],
 "results": [
 {
 "threshold": "float",
 "false_positive_rate": "float",
 "false_negative_rate": "float",
 "fp_rate_delta": "float",
 "fn_rate_delta": "float"
 }
 ]
 },
 "bonferroni_correction": {
 "num_tests": "integer",
 "original_alpha": "float (e.g., 0.05)",
 "corrected_alpha": "float",
 "significant_results": ["list of test names that passed corrected threshold"]
 }
}
```

## Field Descriptions

### Metadata
- **generated_at**: ISO-8601 formatted timestamp of report generation.
- **recursive_model_seeds**: List of seeds used for the recursive model runs included in the analysis.
- **baseline_model_seeds**: List of seeds used for the baseline model runs.
- **excluded_seeds**: Details on any seeds filtered out due to non-convergence (e.g., confidence loss did not stabilize).

### Self-Consistency Comparison
- **recursive_mean**: Arithmetic mean of self-consistency scores for the recursive model.
- **baseline_mean**: Arithmetic mean of self-consistency scores for the baseline model.
- **percentage_difference**: Calculated as `(recursive - baseline) / baseline * 100`.
- **paired_ttest**: Results of the paired t-test comparing the two model distributions.
- **cohens_d**: Effect size measure indicating the magnitude of the difference.
- **confidence_interval**: 95% confidence interval for the mean difference.

### Calibration Comparison
- Similar structure to Self-Consistency but for Brier Score or ECE metrics.

### Sensitivity Analysis
- **thresholds_analyzed**: The discrete set of confidence thresholds swept (e.g., 0.1, 0.2,..., 0.9).
- **results**: List of objects containing error rates at each threshold.
 - **fp_rate_delta**: Difference in FPR compared to the baseline threshold (usually 0.5).
 - **fn_rate_delta**: Difference in FNR compared to the baseline threshold.

### Bonferroni Correction
- **num_tests**: Total number of statistical tests performed.
- **corrected_alpha**: The adjusted significance threshold ($\alpha / N$).
- **significant_results**: List of metric names that remain significant after correction.

## Usage Notes

1. **Statistical Significance**: A result is considered statistically significant if `p_value < corrected_alpha`.
2. **Effect Size**: Cohen's d values > 0.8 are generally considered large effects.
3. **Excluded Seeds**: Seeds are excluded if the model failed to converge on the confidence prediction loss
 (defined as a loss variance < threshold over the last N epochs).
