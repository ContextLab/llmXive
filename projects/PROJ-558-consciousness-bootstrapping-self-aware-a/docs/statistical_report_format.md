# Statistical Report Format Specification

This document defines the schema and content of the statistical analysis report generated by the Consciousness Bootstrapping pipeline. The report is produced by `code/analysis/stats.py` and saved to `artifacts/results/statistical_report.json`.

## Overview

The statistical report aggregates results from multiple experimental seeds to determine the significance of the recursive self-attention mechanism compared to a baseline model. It includes hypothesis testing results, effect sizes, and sensitivity analysis outcomes.

## JSON Schema

The report is a JSON object with the following structure:

```json
{
 "metadata": {
 "generated_at": "ISO-8601 timestamp",
 "pipeline_version": "string",
 "seeds_analyzed": ["list of seed integers"],
 "seeds_excluded": ["list of excluded seed integers with reasons"]
 },
 "self_consistency_comparison": {
 "percentage_difference": "float",
 "p_value": "float",
 "t_statistic": "float",
 "effect_size_cohen_d": "float",
 "confidence_interval": {
 "lower": "float",
 "upper": "float"
 },
 "bonferroni_adjusted_p_value": "float",
 "significant_at_alpha_0.05": "boolean"
 },
 "error_detection_calibration": {
 "description": "Calibration curve data from error detection analysis",
 "bin_edges": ["list of float bin edges"],
 "bin_counts": ["list of int counts per bin"],
 "predicted_error_rates": ["list of float predicted rates"],
 "observed_error_rates": ["list of float observed rates"]
 },
 "sensitivity_analysis": {
 "thresholds_tested": ["list of float thresholds"],
 "results": [
 {
 "threshold": "float",
 "false_positive_rate": "float",
 "false_negative_rate": "float",
 "fp_rate_delta": "float",
 "fn_rate_delta": "float"
 }
 ]
 },
 "conclusions": {
 "primary_finding": "string describing the main result",
 "statistical_significance": "string summarizing significance",
 "practical_implications": "string describing practical impact"
 }
}
```

## Field Definitions

### Metadata
- `generated_at`: UTC timestamp when the report was generated.
- `pipeline_version`: Version identifier of the analysis pipeline.
- `seeds_analyzed`: List of random seeds that produced converged models.
- `seeds_excluded`: List of seeds excluded due to non-convergence or errors.

### Self-Consistency Comparison
- `percentage_difference`: The percentage improvement in self-consistency scores of the recursive model over the baseline.
- `p_value`: Raw p-value from the paired t-test.
- `t_statistic`: T-statistic from the paired t-test.
- `effect_size_cohen_d`: Cohen's d effect size indicating the magnitude of the difference.
- `confidence_interval`: 95% confidence interval for the mean difference.
- `bonferroni_adjusted_p_value`: P-value adjusted for multiple comparisons using Bonferroni correction.
- `significant_at_alpha_0.05`: Boolean indicating if the result is statistically significant after correction.

### Error Detection Calibration
- `bin_edges`: Boundaries of the confidence score bins (0.0 to 1.0).
- `bin_counts`: Number of predictions falling into each bin.
- `predicted_error_rates`: Average predicted error probability per bin.
- `observed_error_rates`: Actual fraction of errors observed in each bin.

### Sensitivity Analysis
- `thresholds_tested`: List of confidence thresholds used for analysis.
- `results`: Detailed metrics for each threshold including false positive/negative rates and their deltas relative to baseline.

### Conclusions
- `primary_finding`: A concise statement of the main experimental result.
- `statistical_significance`: Interpretation of the statistical tests.
- `practical_implications`: Discussion of what the results mean for the field.

## Reviewer-Resolved Metrics

The following metrics have been resolved and are included in the report:

1. **Percentage Difference in Self-Consistency**: Quantifies the improvement of the recursive model over the baseline in terms of self-consistency scores. Calculated as: `((recursive_mean - baseline_mean) / baseline_mean) * 100`.

2. **Error Detection Calibration Curve**: A binning analysis that correlates the model's predicted error probability with actual correctness. This metric addresses the "examined life" critique by providing empirical evidence of the model's ability to distinguish its own errors.

3. **Sensitivity Analysis Deltas**: Measures how the false positive and false negative rates change as the confidence threshold varies, providing insight into the robustness of the error detection mechanism.

## Generation

The report is generated by running:
```bash
python code/analysis/stats.py --output artifacts/results/statistical_report.json
```

The script requires evaluation results from `artifacts/results/` generated by `code/evaluation/run_benchmarks.py`.
