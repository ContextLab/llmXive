# Statistical Report Format Specification

## Overview

This document defines the structure and content of the statistical report generated by the Consciousness Bootstrapping pipeline. The report is produced by `code/analysis/stats.py` and saved to `artifacts/results/statistical_report.json`.

The report aggregates results from multiple experimental seeds, performing statistical comparisons between the recursive self-attention model and the baseline model across key metrics defined in the project specification.

## File Location

- **Output Path**: `artifacts/results/statistical_report.json`
- **Generated By**: `code/analysis/stats.py` (function: `generate_statistical_report`)

## Field Descriptions

### Metadata

- **generated_at**: ISO-8601 formatted timestamp of report generation.
- **config**: Snapshot of the configuration parameters used for the analysis.
- **excluded_seeds**: List of seed values that were excluded from analysis because the confidence loss did not converge (as per task T027).

### Comparisons

Each metric comparison includes:

- **recursive_mean**: Mean value of the metric across all valid seeds for the recursive model.
- **baseline_mean**: Mean value of the metric across all valid seeds for the baseline model.
- **percentage_difference**: Calculated as `((recursive_mean - baseline_mean) / baseline_mean) * 100`, reported per spec.md SC-001.
- **paired_ttest**: Results from the paired t-test comparing recursive vs baseline per seed.
 - **t_statistic**: The t-statistic from `scipy.stats.ttest_rel`.
 - **p_value**: The raw p-value.
 - **bonferroni_corrected_p**: P-value adjusted for multiple comparisons (3 metrics) using Bonferroni correction.
 - **is_significant**: Boolean indicating if `bonferroni_corrected_p < 0.05`.
- **effect_size**:
 - **cohens_d**: Cohen's d effect size calculated as `(mean_recursive - mean_baseline) / pooled_std`.
 - **confidence_interval_95**: 95% confidence interval for Cohen's d.

### Sensitivity Analysis

Results from the sweep over confidence thresholds {0.4, 0.5, 0.6} as required by FR-006.

- **thresholds_tested**: The discrete set of thresholds evaluated.
- **results**: Array of results for each threshold, containing:
 - **threshold**: The confidence threshold value.
 - **false_positive_rate**: Rate of incorrect predictions flagged as correct.
 - **false_negative_rate**: Rate of correct predictions flagged as incorrect.
 - **optimal_decision_boundary**: Boolean indicating if this threshold minimizes the sum of FPR and FNR.

### Summary

Human-readable interpretation of the statistical findings:

- **primary_finding**: A concise statement of the most important result.
- **statistical_significance_summary**: Summary of which metrics showed statistically significant differences.
- **practical_significance**: Interpretation of effect sizes in the context of the research question.
- **limitations**: Notes on constraints (e.g., CPU-only training, limited seed count, dataset size).

## Generation Process

1. **Load Evaluation Results**: Read all `evaluation_results_*.json` files from `artifacts/results/`.
2. **Filter Converged Seeds**: Exclude seeds where confidence loss did not converge (T027).
3. **Aggregate Metrics**: Group results by model type (recursive vs baseline) and metric.
4. **Compute Statistics**:
 - Calculate means and percentage differences.
 - Perform paired t-tests per metric.
 - Apply Bonferroni correction for multiple comparisons.
 - Calculate Cohen's d and confidence intervals.
5. **Sensitivity Analysis**: Sweep thresholds {0.4, 0.5, 0.6} and compute FPR/FNR.
6. **Generate Summary**: Create human-readable interpretations.
7. **Save Report**: Write to `artifacts/results/statistical_report.json`.

## Usage Example

```python
from code.analysis.stats import generate_statistical_report, save_statistical_report

# Generate the report
report = generate_statistical_report(
 results_dir="artifacts/results",
 thresholds=[0.4, 0.5, 0.6]
)

# Save to disk
save_statistical_report(report, "artifacts/results/statistical_report.json")
```

## Validation

The report must pass schema validation before being considered complete:

- All numeric fields must be finite (not NaN or Inf).
- P-values must be in the range [0, 1].
- Cohen's d confidence intervals must be ordered (lower < upper).
- Percentage differences must be calculated correctly.
- Bonferroni correction must divide alpha by the number of comparisons (3).
