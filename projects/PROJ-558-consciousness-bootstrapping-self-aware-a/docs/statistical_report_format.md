# Statistical Report Format Specification

This document defines the JSON schema for the `statistical_report.json` artifact generated by the `code/analysis/stats.py` module.

## File Location
`artifacts/results/statistical_report.json`

## Schema Definition

The report is a JSON object containing the following top-level keys:

```json
{
 "metadata": {
 "experiment_id": "string",
 "timestamp": "ISO8601 string",
 "seeds_used": ["integer"],
 "converged_seeds": ["integer"]
 },
 "self_consistency": {
 "recursive_model": {
 "mean": "float",
 "std": "float",
 "count": "integer"
 },
 "baseline_model": {
 "mean": "float",
 "std": "float",
 "count": "integer"
 },
 "percentage_difference": "float",
 "p_value": "float",
 "significant": "boolean",
 "cohen_d": "float",
 "confidence_interval_95": ["float", "float"]
 },
 "calibration": {
 "recursive_model": {
 "brier_score": "float",
 "ece": "float",
 "calibration_curve": {
 "bin_edges": ["float"],
 "bin_counts": ["integer"],
 "observed_accuracies": ["float"]
 }
 },
 "baseline_model": {
 "brier_score": "float",
 "ece": "float",
 "calibration_curve": {
 "bin_edges": ["float"],
 "bin_counts": ["integer"],
 "observed_accuracies": ["float"]
 }
 }
 },
 "sensitivity_analysis": {
 "thresholds_tested": [0.4, 0.5, 0.6],
 "results": [
 {
 "threshold": "float",
 "recursive_fp_rate": "float",
 "recursive_fn_rate": "float",
 "baseline_fp_rate": "float",
 "baseline_fn_rate": "float",
 "fp_rate_delta": "float",
 "fn_rate_delta": "float"
 }
 ]
 },
 "conclusion": {
 "summary": "string",
 "falsification_status": "string"
 }
}
```

## Field Descriptions

### Metadata
* `experiment_id`: Unique identifier for the experiment run.
* `timestamp`: ISO8601 formatted timestamp of report generation.
* `seeds_used`: List of random seeds used for the experiment.
* `converged_seeds`: List of seeds that successfully converged (i.e., did not fail the confidence loss convergence check).

### Self Consistency
* `recursive_model`: Statistics for the recursive model.
* `baseline_model`: Statistics for the baseline model.
* `percentage_difference`: The percentage difference in self-consistency scores between recursive and baseline models.
* `p_value`: The p-value from the paired t-test.
* `significant`: Boolean indicating if the difference is statistically significant (p < 0.05 after Bonferroni correction).
* `cohen_d`: Effect size (Cohen's d).
* `confidence_interval_95`: 95% confidence interval for the difference in means.

### Calibration
* `brier_score`: Brier score for the model.
* `ece`: Expected Calibration Error.
* `calibration_curve`: Details of the calibration curve.
 * `bin_edges`: Edges of the bins.
 * `bin_counts`: Number of samples in each bin.
 * `observed_accuracies`: Observed accuracy in each bin.

### Sensitivity Analysis
* `thresholds_tested`: List of confidence thresholds tested.
* `results`: List of results for each threshold.
 * `threshold`: The confidence threshold.
 * `recursive_fp_rate`: False positive rate for the recursive model.
 * `recursive_fn_rate`: False negative rate for the recursive model.
 * `baseline_fp_rate`: False positive rate for the baseline model.
 * `baseline_fn_rate`: False negative rate for the baseline model.
 * `fp_rate_delta`: Difference in FPR between recursive and baseline.
 * `fn_rate_delta`: Difference in FNR between recursive and baseline.

### Conclusion
* `summary`: A textual summary of the findings.
* `falsification_status`: Status of the falsification hypothesis (e.g., "Falsified", "Not Falsified", "Inconclusive").

## Generation

This report is generated by the `generate_statistical_report` function in `code/analysis/stats.py`. It aggregates results from multiple seeds and performs the necessary statistical tests.
