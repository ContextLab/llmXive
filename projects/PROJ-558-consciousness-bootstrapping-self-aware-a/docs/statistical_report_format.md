# Statistical Report Format

## Overview

This document defines the schema and content of the `StatisticalReport` artifact generated by the analysis pipeline (`code/analysis/stats.py`). The report aggregates results from multiple seeds to determine the statistical significance of the recursive model's performance compared to the baseline.

## Output Artifact

* **Path**: `artifacts/results/statistical_report.json`
* **Format**: JSON

## Schema Definition

The report contains the following top-level keys:

* `metadata`: Execution context (timestamp, seeds used, configuration).
* `self_consistency_comparison`: Results of the primary hypothesis test (SC-001).
* `calibration_analysis`: Results regarding error detection and calibration.
* `sensitivity_analysis`: Results from the threshold sweep.
* `excluded_seeds`: List of seeds excluded due to non-convergence.

### `self_consistency_comparison`

* `percentage_difference`: The percentage difference in self-consistency scores between recursive and baseline models.
* `t_statistic`: The t-statistic from the paired t-test.
* `p_value`: The raw p-value.
* `p_value_bonferroni`: The p-value adjusted for multiple comparisons using Bonferroni correction.
* `cohens_d`: The effect size.
* `confidence_interval`: The 95% confidence interval for the mean difference.
* `valid_seeds_count`: Number of seeds included in the analysis.

### `calibration_analysis`

* `brier_score_recursive`: Brier score for the recursive model.
* `brier_score_baseline`: Brier score for the baseline model.
* `ece_recursive`: Expected Calibration Error for the recursive model.
* `ece_baseline`: Expected Calibration Error for the baseline model.
* `roc_auc_recursive`: Area Under the ROC Curve for error detection.
* `roc_auc_baseline`: Area Under the ROC Curve for error detection.

### `sensitivity_analysis`

* `thresholds_tested`: List of discrete confidence thresholds tested (e.g., [0.5, 0.6]).
* `results`: A list of objects detailing error rates at each threshold for both models.

### `excluded_seeds`

* `seeds`: List of seed integers that were excluded from the analysis.
* `reason`: Explanation for exclusion (e.g., "Confidence loss did not converge").

## Usage

This report is the "Single Source of Truth" for the project's statistical claims. All claims regarding the efficacy of the recursive architecture must be derived from this artifact. The report is generated by `code/analysis/stats.py` after running the evaluation pipeline across multiple seeds.
