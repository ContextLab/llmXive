# Training Signal Methodology

## Overview

This document clarifies the training signal methodology used in the Consciousness Bootstrapping project, specifically addressing the correction made to the `plan.md` artifact and the operationalization of the "Internal Self-Consistency Proxy."

## Plan/Spec Correction

The original `plan.md` artifact referenced "Teacher-Student Distillation" and "Pre-computed Teacher Labels." This was identified as inconsistent with the `spec.md` Assumptions, which mandate an **Internal Self-Consistency Proxy** to avoid tautological training signals derived from external truth.

The correction (implemented in tasks T003a-T003c) replaced all occurrences of external truth references with the internal proxy methodology. The training signal is now strictly derived from the model's own generation process, ensuring the system is bootstrapping its own meta-cognitive capabilities without reliance on external labels.

## The Internal Self-Consistency Proxy

### Concept

The proxy signal is generated by the model itself during the training loop. It operates on the principle that a "correct" reasoning path is one that is stable under recursive self-evaluation.

### Implementation Details

1. **Generation**: For each training item, the model generates **N=2** distinct reasoning paths using the current model state.
 * Temperature: 0.7
 * Top-P: 0.9
 * Max Tokens: 256
2. **Majority Vote**: The correctness of the final answer is determined by a majority vote of these N=2 paths.
3. **Tie-Breaking**: In the event of a tie (1 correct, 1 incorrect), the proxy signal is deterministically set to **0 (incorrect)**. This satisfies the specification's edge case requirements and prevents ambiguous gradients.
4. **Loss Calculation**: The model's predicted confidence for the final answer is compared against this binary proxy signal. The joint loss function combines standard cross-entropy with a confidence-prediction loss term.

### Resource Constraints

* **Training (N=2)**: The use of N=2 samples is a deliberate architectural choice to meet the 120-minute CPU budget (Constitution Principle VII: Resource-Constrained Architectural Fidelity).
* **Evaluation (N=10)**: The evaluation benchmark (FR-003) strictly uses N=10 paths to ensure statistical robustness in measuring self-consistency, distinct from the training proxy.

## Philosophical Grounding

This methodology addresses the concerns raised by reviewers (e.g., Socrates, Stephen Wolfram) regarding the distinction between *simulated* introspection and *genuine* meta-cognitive adaptation. By defining "correctness" as internal stability rather than external alignment, the system attempts to model the *process* of self-examination rather than merely mimicking an external teacher. The system does not "know the good" in an absolute sense; it learns to recognize the *shape* of its own consistent reasoning.
