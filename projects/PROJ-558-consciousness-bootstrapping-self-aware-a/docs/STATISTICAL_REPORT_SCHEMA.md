# Statistical Report Schema

This document defines the JSON schema and structure for the statistical analysis
output generated by the pipeline (`artifacts/results/statistical_report.json`).

## Overview

The report aggregates results from multiple seeds, performs statistical tests
comparing the Recursive Model against the Baseline Model, and includes sensitivity
analysis results.

## JSON Schema Structure

```json
{
 "metadata": {
 "experiment_id": "string",
 "timestamp": "ISO 8601 datetime",
 "seeds_used": ["int"],
 "seeds_excluded": ["int"],
 "exclusion_reason": "string"
 },
 "comparison_metrics": {
 "self_consistency": {
 "recursive_mean": "float",
 "baseline_mean": "float",
 "percentage_difference": "float",
 "t_statistic": "float",
 "p_value": "float",
 "cohen_d": "float",
 "confidence_interval_95": ["float", "float"],
 "bonferroni_adjusted_p": "float",
 "is_significant": "boolean"
 },
 "calibration": {
 "recursive_ece_mean": "float",
 "baseline_ece_mean": "float",
 "t_statistic": "float",
 "p_value": "float",
 "is_significant": "boolean"
 },
 "error_detection": {
 "recursive_auc_mean": "float",
 "baseline_auc_mean": "float",
 "t_statistic": "float",
 "p_value": "float",
 "is_significant": "boolean"
 }
 },
 "sensitivity_analysis": {
 "thresholds_tested": [0.4, 0.5, 0.6],
 "results": [
 {
 "threshold": "float",
 "recursive_error_rate": "float",
 "baseline_error_rate": "float",
 "difference": "float"
 }
 ]
 },
 "conclusion": {
 "summary": "string",
 "supports_hypothesis": "boolean",
 "limitations": ["string"]
 }
}
```

## Field Definitions

### Metadata
- `experiment_id`: Unique identifier for the run.
- `seeds_used`: List of random seeds that converged successfully.
- `seeds_excluded`: List of seeds that failed convergence checks (non-converged confidence loss).
- `exclusion_reason`: Explanation for why seeds were excluded (e.g., "OOM", "diverged").

### Comparison Metrics
Each metric section (self_consistency, calibration, error_detection) contains:
- `recursive_mean`: Average score across seeds for the recursive model.
- `baseline_mean`: Average score across seeds for the baseline model.
- `percentage_difference`: Calculated as $((Recursive - Baseline) / Baseline) * 100$.
- `t_statistic`: Result of the paired t-test.
- `p_value`: Raw p-value from the t-test.
- `cohen_d`: Effect size.
- `confidence_interval_95`: 95% confidence interval for the difference in means.
- `bonferroni_adjusted_p`: p-value adjusted for multiple comparisons.
- `is_significant`: True if adjusted p-value < 0.05.

### Sensitivity Analysis
- `thresholds_tested`: The discrete set of confidence thresholds evaluated {0.4, 0.5, 0.6}.
- `results`: Array of results for each threshold showing error rates for both models.

### Conclusion
- `summary`: Human-readable summary of findings.
- `supports_hypothesis`: Boolean indicating if the recursive model significantly outperforms the baseline.
- `limitations`: List of caveats (e.g., "Limited to GSM8K dataset", "Small sample size of seeds").

## Generation

This report is generated by `code/analysis/stats.py::generate_statistical_report`.
It ingests evaluation results from `artifacts/results/` and outputs to
`artifacts/results/statistical_report.json`.
