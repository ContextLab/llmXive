# Statistical Report Format Documentation

This document defines the structure and interpretation of the statistical analysis artifacts produced by the Consciousness Bootstrapping pipeline (User Story 3).

## Overview

The statistical analysis phase compares the performance of the **Recursive Self-Attention Model** against a **Baseline Model** (without recursive mechanisms) across multiple random seeds. The primary goal is to determine if the recursive architecture yields statistically significant improvements in self-consistency and error detection calibration.

## Primary Artifact: `statistical_report.json`

This file is generated by `code/analysis/stats.py` and saved to `artifacts/results/statistical_report.json`.

### Schema Definition

```json
{
 "metadata": {
 "version": "1.0.0",
 "generated_at": "ISO-8601-timestamp",
 "seeds_analyzed": [int,...],
 "excluded_seeds": [int,...],
 "exclusion_reason": "string"
 },
 "self_consistency_comparison": {
 "metric": "self_consistency_score",
 "recursive_mean": float,
 "baseline_mean": float,
 "percentage_difference": float,
 "paired_ttest": {
 "statistic": float,
 "p_value": float,
 "significant_at_alpha_0.05": boolean
 },
 "effect_size": {
 "cohens_d": float,
 "interpretation": "small|medium|large|negligible"
 },
 "confidence_interval": {
 "level": 0.95,
 "lower_bound": float,
 "upper_bound": float
 }
 },
 "error_detection_calibration": {
 "description": "Aggregated results from error detection calibration across seeds.",
 "bin_edges": [float,...],
 "mean_observed_accuracy": [float,...],
 "mean_predicted_confidence": [float,...],
 "calibration_error": {
 "ece": float,
 "mce": float
 }
 },
 "sensitivity_analysis_summary": {
 "description": "Summary of threshold sensitivity from sensitivity_analysis.csv",
 "optimal_threshold": float,
 "threshold_range_tested": [float, float]
 }
}
```

### Field Definitions

- **`percentage_difference`**: The relative improvement of the recursive model over the baseline, calculated as:
 $$ \text{Percentage Difference} = \frac{\text{Recursive Mean} - \text{Baseline Mean}}{\text{Baseline Mean}} \times 100 $$
 This satisfies the requirement in **FR-005** to quantify the magnitude of the effect.

- **`significant_at_alpha_0.05`**: Boolean flag indicating if the p-value from the paired t-test is less than 0.05, after applying Bonferroni correction if multiple metrics were tested simultaneously.

- **`cohens_d`**: Cohen's d effect size, calculated as the difference in means divided by the pooled standard deviation.
 - Interpretation guidelines:
 - < 0.2: Negligible
 - 0.2 - 0.5: Small
 - 0.5 - 0.8: Medium
 - > 0.8: Large

- **`confidence_interval`**: The 95% confidence interval for the mean difference between recursive and baseline scores.

## Secondary Artifact: `sensitivity_analysis.csv`

Generated by `code/analysis/stats.py` and saved to `artifacts/results/sensitivity_analysis.csv`.

### Schema Definition

| Column | Type | Description |
|:--- |:--- |:--- |
| `threshold` | float | The confidence threshold used for classification (e.g., 0.4, 0.5, 0.6). |
| `false_positive_rate` | float | Fraction of correct answers incorrectly flagged as errors (FP / (FP + TN)). |
| `false_negative_rate` | float | Fraction of actual errors missed by the model (FN / (FN + TP)). |
| `fp_rate_delta` | float | Change in FP rate compared to the previous threshold. |
| `fn_rate_delta` | float | Change in FN rate compared to the previous threshold. |

### Usage

This file allows researchers to identify the optimal confidence threshold that balances false positives and false negatives. The `fp_rate_delta` and `fn_rate_delta` columns highlight the "tipping point" where small changes in threshold lead to large shifts in error detection performance.

## Reviewer-Resolved Metrics

The following metrics were specifically defined to address reviewer concerns regarding the "examined life" of the model (Socrates) and the "metabolic cost" of recursion (Krakauer).

1. **Self-Consistency Score**: Measures the model's ability to generate the same answer across multiple reasoning paths. High scores indicate stable internal logic.
2. **Error Detection Calibration**: Correlates the model's predicted confidence with actual correctness. A well-calibrated model knows when it does not know.
3. **Recursive Overhead (Implicit)**: While not a direct metric in this JSON, the `percentage_difference` in self-consistency serves as a proxy for the "value" added by the recursive mechanism, justifying the computational cost.

## Generation Command

To regenerate these artifacts:

```bash
python code/analysis/stats.py \
 --results-dir artifacts/results \
 --output-dir artifacts/results
```

This script expects pre-computed evaluation JSONs from `code/evaluation/run_benchmarks.py` to be present in the `results-dir`.
