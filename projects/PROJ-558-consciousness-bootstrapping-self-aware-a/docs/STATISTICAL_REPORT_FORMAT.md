# Statistical Report Format Specification

This document defines the structure and content of the `statistical_report.json` artifact generated by the analysis pipeline (`code/analysis/stats.py`). This report aggregates results from multiple experimental seeds to determine the statistical significance of the recursive self-modeling approach compared to baseline models.

## File Location
- **Output Path**: `artifacts/results/statistical_report.json`
- **Generation Script**: `code/analysis/stats.py` (function: `generate_statistical_report`)

## JSON Schema Structure

The report is a JSON object with the following top-level keys:

```json
{
 "metadata": {
 "timestamp": "ISO-8601 string",
 "project_id": "PROJ-558-consciousness-bootstrapping-self-aware-a",
 "seeds_analyzed": ["int",...],
 "seeds_excluded": ["int",...],
 "exclusion_reason": "string describing why seeds were excluded"
 },
 "metrics_comparison": {
 "self_consistency": {
 "recursive_mean": "float",
 "baseline_mean": "float",
 "percentage_difference": "float",
 "percentage_difference_description": "string"
 },
 "error_detection_calibration": {
 "recursive_brier_score": "float",
 "baseline_brier_score": "float",
 "improvement": "float"
 }
 },
 "statistical_tests": [
 {
 "test_name": "string",
 "metric": "string",
 "t_statistic": "float",
 "p_value": "float",
 "bonferroni_corrected_p": "float",
 "significant_at_0.05": "boolean",
 "effect_size_cohen_d": "float",
 "confidence_interval_95": ["float", "float"]
 }
 ],
 "sensitivity_analysis": {
 "thresholds_tested": [0.4, 0.5, 0.6],
 "results": [
 {
 "threshold": "float",
 "false_positive_rate": "float",
 "false_negative_rate": "float",
 "fp_rate_delta": "float",
 "fn_rate_delta": "float"
 }
 ]
 }
}
```

## Field Definitions

### Metadata
- **timestamp**: ISO-8601 formatted timestamp of when the report was generated.
- **seeds_analyzed**: List of integer seed values that passed convergence checks and were included in the statistical analysis.
- **seeds_excluded**: List of integer seed values that were excluded due to non-convergence (e.g., confidence loss did not stabilize).
- **exclusion_reason**: Human-readable explanation for why seeds were excluded (e.g., "Non-converged confidence loss").

### Metrics Comparison
- **self_consistency**:
 - `recursive_mean`: Average self-consistency score across all analyzed seeds for the recursive model.
 - `baseline_mean`: Average self-consistency score across all analyzed seeds for the baseline model.
 - `percentage_difference`: Calculated as `((recursive_mean - baseline_mean) / baseline_mean) * 100`.
 - `percentage_difference_description`: Text description of the magnitude of improvement (e.g., "Recursive model shows 15.3% higher self-consistency").
- **error_detection_calibration**:
 - `recursive_brier_score`: Mean Brier score for recursive model (lower is better).
 - `baseline_brier_score`: Mean Brier score for baseline model.
 - `improvement`: Calculated as `baseline_brier_score - recursive_brier_score`.

### Statistical Tests
Each entry in this array represents a paired t-test result:
- **test_name**: Name of the statistical test (e.g., "Paired T-Test: Self-Consistency").
- **metric**: The metric being tested (e.g., "self_consistency", "brier_score").
- **t_statistic**: The calculated t-statistic from the paired t-test.
- **p_value**: The raw p-value.
- **bonferroni_corrected_p**: P-value adjusted using Bonferroni correction for multiple comparisons.
- **significant_at_0.05**: Boolean indicating if the corrected p-value is < 0.05.
- **effect_size_cohen_d**: Cohen's d effect size for the difference.
- **confidence_interval_95**: 95% confidence interval for the mean difference [lower, upper].

### Sensitivity Analysis
Results from varying the confidence threshold across the discrete set {0.4, 0.5, 0.6}:
- **thresholds_tested**: The list of thresholds used.
- **results**: Array of results for each threshold:
 - `threshold`: The confidence threshold value.
 - `false_positive_rate`: Rate of incorrectly flagging correct answers as errors.
 - `false_negative_rate`: Rate of failing to flag incorrect answers.
 - `fp_rate_delta`: Difference in FP rate compared to baseline.
 - `fn_rate_delta`: Difference in FN rate compared to baseline.

## Usage Notes
- This report is designed to be machine-readable for automated analysis and human-readable for scientific review.
- The `percentage_difference` metric specifically addresses SC-001 from the specification, quantifying the improvement in self-consistency.
- All floating-point values should be rounded to 4 decimal places for consistency.
