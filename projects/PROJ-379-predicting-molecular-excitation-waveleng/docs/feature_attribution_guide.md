# Feature Attribution and Visualization Guide

## Overview

This document explains how to interpret the feature attribution results generated by the molecular excitation wavelength prediction pipeline. The pipeline uses Graph Neural Networks (GNNs) and gradient-based attribution methods to identify which atomic and substructural features contribute most to the predicted λmax (maximum absorption wavelength).

## Output Artifacts

The attribution analysis produces two primary output files located in `data/processed/`:

1. **`redundancy_masks.json`**: Generated by `code/collinearity_check.py`, this file contains binary masks indicating redundant or collinear features for each molecule.
2. **`attribution_results.json`**: Generated by `code/explain.py`, this file contains the final masked attribution weights identifying contributing substructures.

## Understanding the Data Structures

### Redundancy Masks (`redundancy_masks.json`)

```json
{
 "molecule_id": [0, 1, 0, 0, 1,...],
...
}
```

- **Key**: Unique molecule identifier (SMILES string or hash).
- **Value**: A list of integers (0 or 1) corresponding to ECFP bits or graph node indices.
 - `1`: The feature is flagged as redundant (highly collinear with other features).
 - `0`: The feature is considered independent.

These masks are generated using:
- **Pearson correlation** for ECFP bits (threshold: |r| ≥ 0.9).
- **Cosine similarity** for GNN latent subgraph vectors (threshold: > 0.9).

### Attribution Results (`attribution_results.json`)

```json
{
 "molecule_id": {
 "smiles": "CCO",
 "predicted_lambda_max": 250.5,
 "true_lambda_max": 252.0,
 "attribution_weights": [0.05, 0.00, 0.12,...],
 "masked_attribution_weights": [0.05, 0.00, 0.00,...],
 "top_contributing_atoms": [2, 0, 4],
 "top_contributing_substructures": ["hydroxyl", "methyl"]
 },
...
}
```

#### Key Fields Explained

- **`attribution_weights`**: Raw gradient-based attribution scores for each feature (atom or bit) before masking. Higher absolute values indicate stronger influence on the prediction.
- **`masked_attribution_weights`**: The attribution weights after applying the redundancy mask. Features flagged as redundant (value `1` in `redundancy_masks.json`) are set to `0` in this array.
- **`top_contributing_atoms`**: Indices of atoms with the highest masked attribution weights.
- **`top_contributing_substructures`**: Human-readable labels for the chemical substructures corresponding to the top contributing atoms.

## How to Read the Visualization

The pipeline generates visualizations (typically via `matplotlib` or `rdkit` drawing functions) that overlay attribution scores onto molecular structures.

### Color Coding

- **Red/Orange**: Positive contribution (increases predicted λmax).
- **Blue/Cyan**: Negative contribution (decreases predicted λmax).
- **Gray/White**: Neutral or masked (redundant) contribution.

### Interpreting the Mask

When viewing a molecule:
1. **Identify Red/Orange Regions**: These are the primary drivers of the predicted excitation wavelength.
2. **Check for Grayed-Out Areas**: If an atom or bond is gray, it was flagged as redundant by the collinearity check. Its contribution has been suppressed to prevent over-interpretation of correlated noise.
3. **Compare Raw vs. Masked**: If a region is bright in the raw attribution but gray in the masked view, the model's confidence in that specific feature is likely due to redundancy rather than unique chemical insight.

## Example Interpretation

Consider a molecule with a conjugated system and a hydroxyl group:

- **Raw Attribution**: Both the conjugated system and the hydroxyl group show high positive weights.
- **Collinearity Check**: The hydroxyl group's ECFP bits are highly correlated with bits from the conjugated system (r = 0.92).
- **Masked Attribution**: The hydroxyl group's weights are zeroed out.
- **Visualization**: The conjugated system appears bright red; the hydroxyl group appears gray.
- **Conclusion**: The model relies on the conjugated system for the λmax prediction. The hydroxyl group's apparent contribution in the raw model was likely an artifact of feature redundancy.

## Usage in Research

These masked attribution results are critical for:
- **Hypothesis Generation**: Identifying true chemical drivers of spectral shifts.
- **Model Trust**: Verifying that the model relies on chemically meaningful features rather than spurious correlations.
- **Sensitivity Analysis**: Understanding how robust the predictions are to feature perturbations (see `code/sensitivity.py`).

## Technical Details

- **Attribution Method**: Gradient-based attribution (integrated gradients or Saliency maps) computed via `code/explain.py`.
- **Masking Logic**: `masked_weight[i] = raw_weight[i] * (1 - mask[i])`.
- **Thresholds**:
 - Collinearity threshold: |Pearson r| ≥ 0.9.
 - GNN similarity threshold: Cosine similarity > 0.9.

## Troubleshooting

- **No Red Regions**: If the visualization shows no red regions, check if the `redundancy_masks.json` is too aggressive or if the model has low confidence.
- **All Gray**: If all features are masked, the dataset may have high feature collinearity; review the thresholds in `code/collinearity_check.py`.
- **Missing Substructure Labels**: Ensure the RDKit substructure definitions are up to date in `code/utils.py`.
