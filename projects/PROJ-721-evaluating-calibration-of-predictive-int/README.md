# PROJ-721: Evaluating Calibration of Predictive Intervals in Time Series Forecasting

## Project Structure

- `code/`: Source code for models, metrics, and pipeline orchestration.
- `data/`: Raw and processed datasets (e.g., M4 dataset).
- `results/`: Output files, logs, and generated figures.
- `tests/`: Unit, integration, and contract tests.
- `contracts/`: Schema definitions for data validation.

## Setup

1. Install dependencies: `pip install -r requirements.txt`
2. Run the pipeline: `python code/run_pipeline.py`

## Running Tests

`pytest tests/`
