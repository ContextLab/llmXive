# LLM Security Vulnerability Evaluation Project

## Project Structure
- `src/`: Source code modules
- `tests/`: Unit and integration tests
- `data/raw/`: Raw downloaded datasets
- `data/processed/`: Processed features and predictions
- `data/results/`: Analysis results and reports
- `state/`: Project state tracking
- `specs/`: Feature specifications and contracts

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Run tests: `pytest`

## Pipeline Execution
Run the main pipeline scripts in `src/data/` and `src/analysis/` directories.
