# Data Model Documentation

This document defines the core data entities, their schemas, and validation rules
for the Submarine Hydrothermal Vent Microbial Communities project.

## Overview

The project processes data from three primary sources:
1. **Environmental Logs**: pH and temperature sensor readings.
2. **Metagenomic Data**: 16S rRNA FASTQ sequences.
3. **Derived Metrics**: Alpha and beta diversity calculations.

All data flows through a unified temporal-spatial index before analysis.

## Key Entities

### 1. Sample

Represents a single observational unit combining environmental metadata and sequence data.

**Source**: Unified from `data/raw/pH_logs.csv`, `data/raw/temp_logs.csv`, and `data/raw/sequences/`.

**Schema**:
- `sample_id` (str): Unique identifier (e.g., `SITE01_20230101_1200`).
- `timestamp` (datetime): ISO8601 formatted timestamp of the observation.
- `deployment_event` (str): Identifier for the specific deployment campaign.
- `sensor_id` (str): ID of the specific sensor used.
- `coordinates` (str): "Lat,Long,Depth" string representation.
- `location` (str): Human-readable site name.
- `pH` (float): Measured pH value.
- `temperature` (float): Measured temperature in Celsius.
- `pH_sd` (float): Standard deviation of pH within the ±15 min window.
- `pH_heterogeneous` (bool): True if `pH_sd` > 0.2.
- `is_outlier` (bool): True if pH < 1.0 or pH > 10.0.
- `fastq_path` (str): Relative path to the FASTQ file.
- `qc_passed` (bool): Result of initial quality filtering.

**Validation Rules**:
- `pH` must be between 0.0 and 14.0 (soft), strictly between 1.0 and 10.0 for analysis.
- `timestamp` must be parseable.
- `coordinates` must contain exactly two commas.

### 2. OTU/ASV Table

Represents the count matrix of Operational Taxonomic Units (or Amplicon Sequence Variants).

**Source**: Generated by QIIME2 pipeline from FASTQ files.

**Schema**:
- `feature_id` (str): Unique identifier for the taxon (e.g., `ASV_001`).
- `sample_id` (str): Foreign key to `Sample`.
- `count` (int): Number of reads for this feature in this sample.
- `taxonomy` (str): Taxonomic lineage (Kingdom;Phylum;Class;...;Species).
- `relative_abundance` (float): Count / total reads in sample.

**Validation Rules**:
- `count` >= 0.
- `feature_id` must be unique per sample.

### 3. DiversityMetric

Represents calculated alpha and beta diversity indices.

**Source**: Calculated from rarefied OTU tables.

**Schema**:
- `sample_id` (str): Foreign key to `Sample`.
- `metric_type` (str): e.g., "shannon", "simpson", "observed_otus".
- `value` (float): The calculated index value.
- `rarefaction_depth` (int): The depth used for rarefaction.
- `model_type` (str): Statistical model used for downstream association (e.g., "LME", "Spearman").
- `p_value` (float): Significance value from association test.
- `estimate` (float): Regression coefficient.
- `se` (float): Standard error.

**Validation Rules**:
- `value` >= 0 for alpha diversity.
- `p_value` between 0.0 and 1.0.

## Data Flow

1. **Ingestion**: Raw CSVs and FASTQs -> `Sample` records (Unified Table).
2. **Filtering**: Outliers and heterogeneous pH samples removed.
3. **Processing**: FASTQ -> OTU Table (QIIME2).
4. **Analysis**: OTU Table -> `DiversityMetric` records.
5. **Modeling**: `Sample` + `DiversityMetric` -> Statistical Results.

## File Outputs

- `data/processed/unified_sample_table.csv`: Pre-filtered Sample data.
- `data/processed/filtered_unified_sample_table.csv`: Post-filtered Sample data.
- `data/processed/otu_table.csv`: Feature counts.
- `data/processed/diversity_transformed.csv`: Transformed diversity metrics.
- `data/processed/lme_results.csv`: Model outputs.
- `data/processed/beta_diversity_results.csv`: PERMANOVA outputs.
