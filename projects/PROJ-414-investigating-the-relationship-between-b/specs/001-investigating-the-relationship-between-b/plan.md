# Implementation Plan: Investigating the Relationship Between Brain Network Dynamics and Individual Differences in Musical Improvisation Skill

**Branch**: `001-gene-regulation` | **Date**: 2026-10-13 | **Spec**: [spec.md](../specs/001-gene-regulation/spec.md)  
**Input**: Feature specification from `/specs/001-gene-regulation/spec.md`

## Summary
The project will (1) acquire an open‑source fMRI‑derived time‑series dataset that includes improvisation vs. scripted task labels (or fall back to years‑of‑training as a proxy), (2) preprocess the data on a CPU‑only runner using **FSL/AFNI** tools via **Nipype** (motion correction, slice timing, normalization, band‑pass filtering), (3) compute sliding‑window functional connectivity and graph‑theoretic metrics (global efficiency, modularity, participation coefficient) with **Ledoit‑Wolf** regularization, (4) reduce metric dimensionality with **PCA**, (5) test associations between the principal components and **years of training** (primary skill proxy) while controlling for age, head‑motion, scanner/site, session order, and physiological noise, (6) assess significance via **5 000 permutations** followed by **FDR** correction, (7) conduct a sensitivity sweep over window/step sizes, and (8) produce NetworkX/Matplotlib visualizations. All steps are mapped to the functional (FR‑001 – FR‑008) and success‑criteria (SC‑001 – SC‑004) requirements.

Preprocessing** | Use **FSL/AFNI** via Nipype: (a) motion‑correct (MCFLIRT), (b) slice‑timing (slicetimer), (c) normalize to MNI (FLIRT), (d) band‑pass filter (0.01‑0.1 Hz) with `fslmaths`; extract Schaefer‑100 ROI signals with Nilearn. Each phase is ordered so that data is available before it is consumed, models are fitted before evaluation, and figures are generated before final reporting.

## Power Analysis (new)
Using `statsmodels.stats.power.TTestIndPower`, we estimate that with **N = 20** subjects, detecting a medium effect size (Cohen’s d = 0.5) at α = 0.05 (two‑tailed) yields power ≈ 0.46. We will report this limitation and, when possible, increase the sample size by adding more subjects from the same dataset.

## Compute Feasibility
- **Memory**: Streaming parquet loader keeps < 2 GB in memory; per‑subject matrices ≤ 200 MB.  
- **Runtime**: Estimated 3‑4 h for 25 subjects on 2‑core runner (benchmark on similar data).  
- **No GPU**: All libraries are pure CPU; no `torch.cuda` calls.
