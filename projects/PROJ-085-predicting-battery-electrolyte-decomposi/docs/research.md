# Research Methodology: Predicting Battery Electrolyte Decomposition Products

## Overview

This document outlines the research methodology, data sources, and validation strategies used in the `PROJ-085-predicting-battery-electrolyte-decomposi` project. The goal is to predict decomposition products of common battery electrolytes (EC, DMC, LiPF6) using Density Functional Theory (DFT) data and Machine Learning (ML).

## Data Sources

### Primary DFT Data
- **Source**: HuggingFace Dataset `materialsproject/mp-dft-electrolytes`
- **Content**: Pre-computed DFT structures, energies, and electronic properties for electrolyte molecules.
- **Ingestion**: Implemented in `code/data/ingestion.py`. The pipeline fetches the dataset, filters for target molecules (EC, DMC, LiPF6), and validates coverage.
- **Strict Constraint**: The ingestion pipeline raises a `DataNotFoundError` if the fetch fails or if any of the three target molecules are missing. No synthetic or mock data is used as a fallback for the primary dataset.

### External Experimental Validation Data
- **Search Methodology**: A programmatic search was conducted to find experimental onset potentials for validation.
- **Tools**: `code/data/external_search.py`
- **Sources Queried**:
 1. NOMAD API (searching for 'electrolyte', 'onset potential', 'cyclic voltammetry')
 2. PubChem (via `pubchempy`)
 3. Materials Project experimental logs
 4. Specific DOIs cited in previous literature reviews.
- **Search Outcome**: **NOT FOUND**.
 - Despite exhaustive searches across the identified repositories and specific DOI checks, no unified, programmatically accessible dataset containing experimental onset potentials for the specific target molecules (EC, DMC, LiPF6) with the required metadata was located.
 - The search logic in `code/data/external_search.py` confirmed `external_data_available = False`.
- **Current Status**: The project proceeds using **Internal Validation** (T044) against held-out DFT data, as per the contingency plan defined in T042 and T051.
- **Limitation Report**: See `docs/research.md` (Section: Limitations) and `data/validation/limitations.md` (generated by T052) for a detailed discussion of this data gap.

## Methodology

### 1. Data Ingestion and Preprocessing
- **Filtering**: Data is filtered for EC, DMC, and LiPF6 at potentials 0V, 2V, and 4V.
- **Deduplication**: Entries are deduplicated based on `molecule_id` and `potential_v`.
- **Descriptor Extraction**:
 - **Electronic**: HOMO, LUMO, Band Gap (using `pymatgen`/`RDKit`).
 - **Geometric**: Bond lengths, bond angles, dihedral angles (minimum count required by FR-003).
 - **Handling Outliers**: Metallic structures (zero/negative band gap) are flagged and excluded.

### 2. Target Calculation
- **Reaction Engine**: `code/utils/reaction_engine.py` implements a Group Contribution Method (GCM) to generate reaction stoichiometry and energy estimates for the full dataset.
- **Energy Calculation**: Decomposition energy ($E_{decomp}$) is calculated as $E_{products} - E_{reactants}$ at specified potentials ($\phi \in \{0, 2, 4\}$ V).

### 3. Model Training
- **Algorithm**: Random Forest Regressor.
- **Validation**: 5-Fold Cross-Validation with Hyperparameter Tuning (GridSearchCV).
- **Bins**: Data is split into 'Low' (0-2V) and 'High' (3-5V, mapped to 4V) potential bins.
- **Statistical Constraints**: If the 'High' bin contains insufficient samples (<30), the model runs in 'single-point analysis' mode, and statistical shift analysis is flagged as invalid (T019b, T022).

### 4. Feature Importance and Stability
- **Permutation Importance**: Calculated for each bin to identify key descriptors.
- **Shift Analysis**: Identifies descriptors entering the top 3 in the high-potential bin but absent in the low-potential bin.
- **Rank Stability**: A sensitivity analysis sweeps the decomposition energy threshold (0.45, 0.50, 0.55 eV) to verify that top-3 descriptor rankings do not shift by more than 1 position (T032).

## Limitations

1. **External Validation Data Gap**: As noted in the "External Experimental Validation Data" section, no external experimental dataset was found. Consequently, the model's predictive accuracy against real-world experimental onset potentials cannot be directly quantified. The project relies on internal validation metrics (MAE/R² against held-out DFT data).
2. **High-Potential Sample Size**: The 'High' potential bin relies on a single data point (4V). If the sample size for this bin is <10, statistical power is limited, and rankings for this bin should be interpreted with caution (T024b).
3. **Group Contribution Approximation**: The reaction energy estimates rely on a Group Contribution Method (GCM) rather than full DFT recalculations for every reaction, introducing potential approximation errors in $E_{decomp}$.
