# The Impact of Musical Training on Functional Connectivity in Adolescent Brains

This project investigates how musical training during adolescence affects resting-state functional connectivity patterns, specifically focusing on the auditory, motor, and executive control networks.

## Project Layout

The project is organized into the following top-level directories:

- `code/`: Contains all source code, including data ingestion, preprocessing, analysis modules, and the main entry point.
- `data/`: Stores all data artifacts, including raw NIfTI files, processed behavioral tables, connectivity matrices, and final results.
- `tests/`: Contains the full test suite, including unit tests, integration tests, and contract validation scripts.
- `specs/`: Contains the feature specifications, implementation plans, and research design documents.
- `results/`: Contains the final derived results and figures for the research paper.

## Requirements

- Python 3.11+
- Dependencies listed in `code/requirements.txt` (e.g., `numpy`, `pandas`, `scipy`, `nibabel`, `networkx`, `matplotlib`, `seaborn`).
