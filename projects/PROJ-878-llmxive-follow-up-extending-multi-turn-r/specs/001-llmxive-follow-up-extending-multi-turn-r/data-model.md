# Data Model: llmXive follow-up: extending "Multi-Turn Reflective Masking Elicits Reasoning in Mask Diffusion Mode"

## Overview

This document defines the data structures used for the synthetic logical puzzle dataset, the execution logs, and the analysis results. All data is stored in JSONL (line-delimited JSON) or CSV format for easy streaming and processing.

## Entities

### 1. LogicalPuzzle (Synthetic Dataset)

The core unit of the study. Generated by `graph_generator.py` with deterministic text mapping.

**File**: `data/raw/synthetic_puzzles.jsonl`

| Field | Type | Description |
|-------|------|-------------|
| `instance_id` | `string` | Unique identifier (e.g., "puzzle_001"). |
| `text` | `string` | Natural language representation of the logical puzzle (deterministically mapped from DAG). |
| `ground_truth` | `string` | The correct solution path (text or symbolic). |
| `ground_truth_path` | `array` | List of node IDs representing the valid logical path. |
| `nesting_depth` | `integer` | Max nesting depth of the dependency graph (longest path). |
| `branching_factor` | `float` | Average in-degree of non-root nodes in the graph. |
| `graph_structure` | `object` | JSON representation of the DAG (nodes, edges). |
| `target_path_id` | `string` | ID of the specific solution path selected (for perturbation validation). |
| `seed` | `integer` | Random seed used for generation (for reproducibility). |
| `is_acyclic` | `boolean` | Validation flag (should always be true). |
| `is_solvable` | `boolean` | Validation flag (should always be true). |
| `text_generation_method` | `string` | "template_based" (to verify deterministic mapping). |
| `is_orthogonal` | `boolean` | Flag indicating if the (depth, branch) pair met the orthogonality constraint (|r| < 0.2) during generation. |

### 2. ExecutionLog (Results)

Record of a single inference run. Generated by `rm_executor.py` with Independent Logical Validation.

**File**: `data/processed/execution_log.csv`

| Field | Type | Description |
|-------|------|-------------|
| `instance_id` | `string` | FK to `LogicalPuzzle.instance_id`. |
| `turns_to_converge` | `integer` | Number of turns taken to reach solution. `null` if failure (censored). |
| `convergence_status` | `string` | "success" or "failure". |
| `is_censored` | `boolean` | True if the run hit the max turn limit (50 or 1000). |
| `final_token_sequence` | `string` | The final output sequence (truncated if too long). |
| `path_coverage` | `float` | Percentage of model steps matching the DAG edges (0.0 to 1.0). |
| `limit_hit` | `boolean` | True if the run hit the max turn limit. |
| `runtime_seconds` | `float` | Wall-clock time for the run. |
| `error_message` | `string` | `null` if successful, error description if failed. |

### 3. AnalysisResult (Outputs)

Aggregated statistical results. Generated by `analyzer.py` using Survival Analysis and Segmented Regression.

**File**: `results/statistical_report.json`

| Field | Type | Description |
|-------|------|-------------|
| `cox_depth_hazard_ratio` | `float` | Hazard ratio for `nesting_depth` from Cox PH model. |
| `cox_depth_p_value` | `float` | P-value for the hazard ratio. |
| `tipping_point_depth` | `integer` | Identified depth where degradation accelerates (breakpoint). |
| `tipping_point_slope_change` | `float` | Change in slope at the tipping point. |
| `failure_rates` | `object` | Map of {threshold_turns: failure_rate}. |
| `budget_exhaustion_rate` | `float` | % of 50-turn failures that converged at 1000 turns. |
| `collinearity_vif` | `float` | Variance Inflation Factor for predictors (should be < 5). |
| `orthogonality_check` | `object` | Correlation between depth and branching in the generated dataset. |
| `spearman_correlation` | `float` | Descriptive Spearman correlation (not used for inference due to censoring). |

## Constraints & Validation

*   **Acyclicity**: `is_acyclic` must be `true` for all records in `synthetic_puzzles.jsonl`.
*   **Range**: `nesting_depth` must be in [1, 10]; `branching_factor` in [1, 5].
*   **Orthogonality**: Correlation between `nesting_depth` and `branching_factor` must be < 0.2.
*   **Turn Limit**: `turns_to_converge` must be `null` or `<= max_turns`.
*   **Uniqueness**: `instance_id` must be unique across all datasets.
*   **Censoring**: `is_censored` must be `true` if `turns_to_converge` is `null` and `limit_hit` is `true`.
*   **Path Coverage**: `path_coverage` must be >= 0.95 for a "success" status.
