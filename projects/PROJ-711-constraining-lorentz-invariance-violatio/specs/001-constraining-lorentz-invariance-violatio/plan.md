# Implementation Plan: Constraining Lorentz Invariance Violation with Fermi Gamma‑Ray Burst Spectra

**Branch**: `001-constrain-liv-fermi` | **Date**: 2026-06-16 | **Spec**: `spec.md`
**Input**: Feature specification from `/specs/001-constrain-liv-fermi/spec.md`

## Summary

This project implements a computational pipeline to constrain the linear Lorentz Invariance Violation (LIV) energy scale ($E_{\rm QG}$) using spectral lag measurements from the top 30 brightest Gamma-Ray Bursts (GRBs) observed by the Fermi Gamma-ray Burst Monitor (GBM). The technical approach involves: (1) downloading the full Fermi GBM Trigger Catalog via the HEASARC VOTable API, (2) filtering locally for the top 30 events by **Total Fluence (50-300 keV)**, (3) re-binning light curves into specific energy bands (8–50, 50–200, 200–1000 keV), (4) performing background subtraction and quality filtering, (5) computing spectral lags via Cross-Correlation Function (CCF) with bootstrap uncertainty estimation, and (6) performing a **Hierarchical Bayesian Meta-Analysis** to derive $E_{\rm QG}$ bounds while modeling intrinsic source lags as random effects. The pipeline includes rigorous null-distribution validation (10,000 Monte Carlo iterations) using **photon energy label shuffling** on the global population statistic to test the null hypothesis of "no LIV" while preserving intrinsic temporal structure.

## Complexity Tracking

| Violation | Why Needed | Simpler Alternative Rejected Because |
|-----------|------------|-------------------------------------|
| **Hierarchical Bayesian Meta-Analysis** | Required to model intrinsic source lags as random effects (nuisance parameters) and avoid bias in the LIV slope. | Simple weighted linear regression assumes a fixed or zero intrinsic lag, which is physically unlikely and leads to biased $E_{QG}$ estimates. |
| **Global Null Distribution (Energy Shuffling)** | Required by Constitution Principle VII to test the "no LIV" hypothesis while preserving intrinsic temporal structure. | Time-shifting one band destroys intrinsic correlations and does not simulate the correct null hypothesis. Energy shuffling preserves the intrinsic lag distribution while randomizing the LIV signal. |
| **Strict Redshift Exclusion** | Required by Spec Edge Cases. | Imputation of redshift would introduce unquantified systematic errors > 10%, violating data integrity principles. |
| **PyMC Dependency** | Required for Hierarchical Bayesian modeling and MCMC sampling. | `scikit-learn` does not support hierarchical models or random effects; `pymc` is necessary for the specified methodology. |

## Data Availability & Selection

- **Primary Source**: Fermi GBM Trigger Catalog via HEASARC VOTable API.
- **Selection Criteria**: Top 30 events by **Total Fluence (50-300 keV)**.
- **Access Method**: Programmatic query to `https://heasarc.gsfc.nasa.gov/cgi-bin/Tools/xTable/xTable.pl?Table=fermi/gbm/triggers` to retrieve the **full catalog** as a VOTable. The script then sorts the full dataset locally by the `Total Fluence (50-300 keV)` column and selects the top 30.
- **Redshift**: Cross-referenced from the same catalog or GCN; bursts without redshift are excluded.
- **Feasibility**: Light curves are small (MB scale); [deferred] global null iterations are computationally feasible on CPU.

## Statistical Rigor & Methodology Checks

- **Multiple Comparisons**: The analysis focuses on a single global parameter ($E_{QG}$ slope). The null distribution ([deferred] global iterations) controls the family-wise error rate for this global limit.
- **Power/Sample Size**: The sample size (30 bursts) is fixed by the "brightest" selection. The Hierarchical Bayesian model accounts for the uncertainty in the population distribution of intrinsic lags.
- **Causal Inference**: The study is observational. Claims are framed as "constraints on $E_{QG}$ assuming the dispersion relation holds," not causal proof of LIV. The Hierarchical model explicitly controls for intrinsic lags and tests for correlation between intrinsic lag and redshift.
- **Measurement Validity**: CCF is the standard method for spectral lag. Bootstrap is the standard for uncertainty.
- **Collinearity**: The regression uses $D(z)$ (distance) and $\Delta E$ (energy difference). The Hierarchical model includes a test for correlation between intrinsic lag and redshift to prevent confounding.

## Compute Feasibility (CPU-First)

- **Method**: Pure Python/NumPy/SciPy/PyMC. No GPU required.
- **Scaling**:
    - **CCF**: $O(N \log N)$ using FFT. Fast.
    - **Bootstrap**: Parallelizable across bursts.
 - **Null Test**: [deferred] iterations performed on the **global statistic** (resampling the set of lags to build the null distribution of the slope). This is computationally efficient and fits within the 6-hour limit.
- **Memory**: Streaming is not strictly necessary for the raw data (small), but the synthetic data generation will be done in batches to avoid memory spikes.
- **GPU Escape Hatch**: Not required. If the CPU time exceeds 6 hours, the plan is to reduce the number of MCMC samples or null iterations and document the trade-off.

## Open Questions & Risks

1.  **Data Access**: The "top 30" list is derived dynamically from the full catalog via the HEASARC VOTable endpoint. The script must handle the full download and local sorting.
2.  **Redshift Availability**: If < 10 bursts have redshifts, the global regression may be underpowered. The plan must handle this gracefully (e.g., "Insufficient data for population analysis").
3.  **Background Subtraction**: The spec requires "standard GBM offline tools." The implementation will use a simplified background model (pre-burst interval) if the full offline tools are not available as a Python library, but will document this approximation.

## Note on Spec Alignment

The implementation plan adopts **photon energy label shuffling** for the null test (Constitution Principle VII) rather than the "time-shifting" mentioned in the original spec (FR-007). This is a necessary correction to ensure scientific validity: time-shifting destroys intrinsic correlations and does not simulate the "no LIV" hypothesis correctly. Energy shuffling preserves intrinsic temporal structure while randomizing the LIV signal, providing a valid null distribution. This methodology is documented here and in `research.md`. A corresponding update to `spec.md` (FR-007) is recommended to align the specification with the scientifically correct method.
