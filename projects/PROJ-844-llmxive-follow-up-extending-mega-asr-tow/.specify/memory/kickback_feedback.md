## Unresolved concerns

- The plan does not specify how the regression model will be evaluated (e.g., train/validation split, cross‑validation, held‑out test set). Without an explicit evaluation protocol, the claim that the model achieves R² ≥ 0.6 cannot be verified, risking over‑fitting to the deterministic collapse rule.
- The target variable for the regression (collapse intensity) is derived from the deterministic algorithm in FR‑021. Using this derived metric as the sole prediction target may introduce circularity, because the regression could simply learn the deterministic rule rather than uncover genuine non‑linear interaction effects. The plan should clarify that the regression will be trained on the *Universal Collapse Intensity* (absolute SSS ≤ 0.5) or include an independent validation against manually annotated collapse points.
- FR-007 (associational framing) is only listed as a constraint but no concrete plan step (e.g., reporting language, documentation) is defined to ensure findings are explicitly framed as associational.
- FR-011 (human validation of the Semantic Similarity Score with AUC‑ROC ≥ 0.85) is absent; the plan does not describe a human‑annotation collection, validation procedure, or gating logic.
- FR-012 (analysis of stress‑curve shape and inflection‑point calculation) is not mapped to any phase; the plan lacks a step to compute curve shape or maximum derivative.
- FR-022 (fallback to phoneme‑level edit distance when embedding correlation fails) is not addressed in any phase or constraint.
- FR-032 (power analysis justification) is not represented; the plan does not include a step to document or verify the statistical power calculation for the chosen sample size.
- The plan states it will *download a stratified ≥ 50,000‑clip subset* of Voices‑in‑the‑Wild‑2M (FR‑001), but later the compute strategy limits the distortion‑generation step to the *first 10 k clips* on a free Kaggle GPU. This reduction violates the required sample size, making the dataset inappropriate for the stated functional requirement.
- Relying on a single free Kaggle V100 GPU (≈9 h kernel limit) to generate 54 distortion scenarios for 50 k clips (≈13.5 M utterances) is infeasible. The plan mitigates this by processing only 10 k clips, which again conflicts with FR‑001 and FR‑002’s workload and wall‑time constraints. A paid GPU cluster or a revised sampling strategy that still satisfies FR‑001 is required.
- The column definitions for `data/derived/stress_curves.parquet` in `data-model.md` (e.g., `clip_id`, `model_name`, `snr_db`, `rt60_s`, `distortion_type`, `asr_hypothesis`, `wer`, `sss`, `timestamp`) do not match the JSON schema `contracts/stress_curves.schema.yaml` (which expects fields like `curve_id`, `audio_id`, `model_id`, `vector_id`, `snr_db`, `rt60_sec`, `ss_score`, `wer`, `hypothesis`, `reference_transcript`, `timestamp`). This cross‑document inconsistency means the pipeline may produce a Parquet file that fails schema validation (FR‑034). Align the data model with the contract or update the contract to reflect the intended columns.
- The plan does not explicitly designate a Single Source of Truth (SSoT) file (e.g., `data-model.md`) as required by Constitution Principle IV. While the plan references the data model, it should state which artifact serves as the authoritative SSoT to satisfy the principle.
- The regression model (FR‑005) is trained to predict the *Universal Collapse Intensity* which is defined in FR‑036 as the first step where absolute SSS ≤ 0.5. Since SSS is the primary outcome used to define the target, the predictor variables (acoustic parameters) are being used to predict a quantity that is *by definition* a deterministic function of the same SSS curve. This creates a circular validation: the model is essentially learning the inverse of the deterministic rule that generated the target, guaranteeing high R² and making the claimed discovery of a “critical interaction vector” scientifically trivial.
- Universality assessment (FR‑051) compares critical interaction vectors derived from the regression that predicts the same absolute‑threshold collapse intensity across models. Because the target definition is identical for all models, similarity of the resulting vectors is expected a priori, rendering the universality claim circular and not an independent validation of a universal acoustic phenomenon.
- Including baseline SSS (the clean‑clip semantic similarity) as a covariate in the regression that predicts the step where SSS falls below 0.5 introduces leakage: baseline SSS directly influences the point at which the SSS curve reaches the threshold, so the model may rely on this covariate rather than learning genuine acoustic interaction effects.
