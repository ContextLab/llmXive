## Unresolved concerns

- The plan states: 'We will check for collinearity between SNR and RT60 in the synthetic generation. If they are definitionally linked, we will report the relationship descriptively.' In the proposed Cartesian product (9 SNR × 6 RT60), SNR and RT60 are *orthogonal* by design (independent variables). They are not definitionally linked. The concern about collinearity is misplaced here; the real issue is the *interaction* term (SNR × RT60) which is naturally correlated with the main effects. The plan should explicitly state that the regression model will use centering or orthogonal polynomial contrasts to handle the correlation between main effects and the interaction term, rather than checking for 'definitional linkage' which does not exist in a factorial design.
- The plan cites 'Voices-in-the-Wild-2M' and provides URLs to 'lilysmith98/audio_clips_wav' and 'Girish-Varrinkala/audio_clips'. These are generic user-uploaded Hugging Face repositories, not the canonical 'Voices-in-the-Wild-2M' dataset (which is typically associated with the CHiME or DNS challenges). The plan assumes these generic uploads contain the specific stratified metadata (speaker ID, SNR buckets) required for FR-001. If these datasets lack the necessary ground-truth transcripts or metadata fields, the stratified sampling strategy fails, and the 50k clip target cannot be met with the required properties. The plan must verify the specific schema of the cited URLs or switch to a verified, metadata-rich source like the CHiME-5 or DNS Challenge datasets which explicitly support the required acoustic parameter stratification.
- The plan lists 'hf-audio/open-asr-leaderboard/ami/test-00000-of-00015.parquet' as a source for 'ASR Transcripts' to be used for 'baseline WER calculation'. The AMI dataset is a specific meeting corpus. Using a test set from a different domain (meetings) to establish a baseline for a 'Voices-in-the-Wild' stress test introduces domain mismatch. The baseline WER should be calculated on a clean subset of the *same* source dataset (Voices-in-the-Wild) to ensure the '2x baseline' threshold in FR-021 is contextually valid. Using an external, domain-mismatched baseline invalidates the collapse detection logic.
- The plan cites 'liyongsea/ptb-sss' as a 'SSS Reference' for 'metric calibration'. The Penn Treebank (PTB) is a text corpus, not an audio dataset. It cannot be used to calibrate a Semantic Similarity Score (SSS) for *audio* ASR hypotheses against transcripts. SSS calibration requires a dataset with audio, ground truth, and human-annotated semantic integrity scores (or a validated proxy). Citing a text-only dataset for audio metric calibration is a fundamental modality mismatch that renders the FR-011 validation step impossible as described.
