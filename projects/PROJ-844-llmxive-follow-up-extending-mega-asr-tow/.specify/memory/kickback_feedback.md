## Unresolved concerns

- The sensitivity analysis (sweeping threshold 0.40-0.60) is insufficient to validate the 'universal' nature of the collapse threshold. The plan assumes the threshold is a fixed point on a curve, but if the 'collapse' is a gradual degradation (which is typical for ASR under noise), the 'threshold' is an arbitrary artifact of the chosen cutoff. The methodology does not include a test for the *shape* of the degradation curve (e.g., sigmoid vs. linear) across models. If Model A degrades linearly and Model B degrades sigmoidally, a fixed threshold will yield different 'collapse points' that do not reflect a universal interaction vector. The plan lacks a method to normalize the *rate* of degradation, which is necessary to compare 'collapse' across different architectures.
- SC-001 requires measuring R² against a 'held-out test set'. The plan describes training a regression model but does not explicitly define the data split strategy (e.g., 80/20 split, stratified by clip) required to create this held-out set. The data-model.md defines entities but lacks the 'split' entity or logic to satisfy the measurement condition of SC-001.
- The plan cites 'SBB Data (SNR variants)' as a source for 'validation of SNR handling' and 'distortion calibration'. However, the SBB dataset (marccgrau/sbbdata_snr_none) is a synthetic dataset where SNR is artificially controlled and the audio is often clean speech with added noise. Using a synthetic dataset to calibrate a pipeline designed to test *real* 'in-the-wild' distortions creates a circular validation loop. The distortion application logic (librosa/pyroomacoustics) will be tuned to match synthetic SNR levels, not the complex, non-linear SNR degradation found in real-world 'wild' audio, potentially biasing the collapse threshold detection.
- The plan states: 'Select a stratified subset (e.g., first 500 clips)'. The 'first 500' approach from a streaming dataset is not a valid stratification strategy for 'speaker diversity' or 'SNR bucket' coverage as claimed. Streaming datasets often have implicit ordering (e.g., by file ID or upload date) that does not correlate with acoustic properties. Without a pre-computed index or metadata-based sampling strategy (which is not described), this sampling method risks severe selection bias, potentially missing the specific acoustic conditions (e.g., high RT60, low SNR) necessary to observe the 'collapse' phenomenon.
- Constitution Principle VI (Non-Linear Interaction Characterization) is marked as satisfied, but the plan text only mentions 'engineered interaction terms' in the 'Complexity Tracking' table. It does not explicitly state in the 'Constitution Check' section *how* the plan validates the non-linear nature (e.g., 'by comparing the interaction term coefficient against the sum of individual coefficients'). The check is too vague to confirm compliance with the specific requirement of validating synergistic failure modes.
