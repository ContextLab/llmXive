# Data Model: llmXive follow-up: extending "AutoResearchClaw"

## Entities & Relationships

### FailureCase
Represents a single error event from ARC-Bench.
- **Attributes**:
    - `id`: Unique identifier (string).
    - `raw_error_log`: Original error string (string).
    - `task_context`: The context in which the error occurred (string).
    - `ground_truth_resolution`: The correct resolution path (string).
    - `structural_feature`: Annotated label (enum: `Syntactic`, `Logical`, `Semantic`, `Missing Context`, `Unstructured`, `None (Success)`).
    - `source_dataset`: URL of the source parquet file.
    - `gold_standard_label`: (Optional) The human-annotated label used for validation.

### DistilledRule
A heuristic derived from a failure case.
- **Attributes**:
    - `rule_id`: Unique identifier.
    - `condition_pattern`: Regex or logic pattern to match errors.
    - `action`: Prescribed pivot action.
    - `confidence`: Confidence score from distillation model.
    - `applicable_features`: List of structural features this rule applies to.

### PivotAttempt
An execution instance of a pivot attempt.
- **Attributes**:
    - `attempt_id`: Unique identifier.
    - `task_id`: Reference to the task.
    - `method`: `RuleEngine` or `Baseline`.
    - `steps_to_pivot`: Number of steps taken (int, capped at 50). **Replaces 'Time-to-Pivot'**.
    - `is_censored`: Boolean (True if steps reached cap).
    - `success`: Boolean.
    - `failure_category`: If failed, `Coverage Gap` or `Distillation Error`. **Required for FR-007**.
    - `structural_feature`: The root cause of the original failure (inherited from `FailureCase`). **Required for FR-005 stratification**.

## Data Flow

1.  **Raw Data**: `data/raw/arc_bench.parquet` (Downloaded, checksummed).
2.  **Parsed Traces**: `data/derived/parsed_traces.json` (Streamed and normalized `FailureCase` with `itertools.islice` fallback).
3.  **Labeled Data**: `data/derived/labeled_failures.json` (Annotated with `structural_feature` and `gold_standard_label`).
4.  **Rule Library**: `data/derived/rules_library.json` (Distilled `DistilledRule` set).
5.  **Results**: `data/derived/results.csv` (Aggregated `PivotAttempt` metrics).
6.  **Resource Logs**: `data/derived/resource_usage.log` (Compute time and memory usage for SC-005).

## Storage Strategy

- **Raw Data**: Read-only. Stored in `data/raw/`. Checksums recorded in `state/...yaml`.
- **Derived Data**: Read-write. Stored in `data/derived/`. Generated by scripts.
- **Processed Data**: Final analysis datasets. Stored in `data/processed/`.

## Constraints

- **Memory**: Streaming used for raw data; derived data limited to a manageable subset for analysis.
- **Format**: Parquet for raw, JSON for intermediate, CSV for final results.
- **PII**: No PII allowed; error logs scrubbed if necessary.
- **Schema Compliance**: All derived data MUST conform to the schemas in `contracts/`.
