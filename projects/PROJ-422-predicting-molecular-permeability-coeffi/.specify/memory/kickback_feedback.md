## Unresolved concerns

- The plan permits using an *approved surrogate* target when no experimental permeability column exists. However, the methodology does not specify how the surrogate’s independence from the descriptor set is verified, nor does it ensure that the surrogate truly reflects the construct of experimental permeability. This threatens construct validity (FR‑001) and violates Constitution VII’s requirement for validation independence.
- The bias‑check drops any descriptor with |r| > 0.6 with the target and then retrains the models. Removing descriptors that are strongly predictive of the target conflates confound control with feature selection and can artificially reduce model performance, undermining the validity of the comparative claim.
- The deterministic overlap metric relies on a hard‑coded lookup table mapping descriptors to SMARTS patterns. This mapping is arbitrary and not empirically justified, making the overlap p‑value a questionable measure of cross‑model agreement (SC‑003).
- The retention guard aborts if < 95 % valid molecules remain after canonicalization. While this protects data hygiene, it may lead to systematic exclusion of chemically challenging molecules, introducing a selection bias that could affect the generalizability of the results.
- FR-014 (datasets must contain a numeric `permeability` or approved surrogate column) is not listed in the FR/SC mapping; although Phase 0 searches for a target, the requirement is not explicitly tied to FR‑014.
- FR-015 (a priori power analysis with Cohen’s d = 0.3 and abort if power < 0.8) is described in the narrative but not included in the FR column of any phase; the mapping table omits FR‑015.
- FR-016 (all external data sources must be listed in the Verified Datasets block) is not present in the FR/SC mapping; no phase explicitly validates that only listed URLs are used.
- SC-006 (power analysis must report a calculated statistical power ≥ 0.8; abort otherwise) is not listed in the SC column of any phase, despite power analysis being performed.
- SC-007 (all external data sources must be drawn exclusively from the Verified Datasets block) is absent from the SC mapping; no phase explicitly enforces this constraint.
- The plan’s ‘Verified Datasets’ block lists only SMILES‑only datasets that lack any `permeability` column and also lack any approved surrogate target column (e.g., `simulated_permeability`, `logS`). FR‑001 requires acquisition of at least one public dataset containing an experimental permeability coefficient **or** a validated surrogate. Since no such dataset is cited, the pipeline will always halt at Phase 0 and cannot satisfy the core research question, making the dataset selection inappropriate for the problem.
- The plan’s bias‑check step (Phase 5) records dropped descriptors and correlation information, but the `contracts/bias_check` schema (in results.schema.yaml) expects a single `correlation_coefficient` field, not a list or arbitrary descriptor list. The plan should either aggregate to a single coefficient (e.g., max |r|) or adjust the schema to match the intended output.
- The interpretability overlap metric described in Phase 6 stores `overlap_top5`, `overlap_p_value`, and `overlap_significant`, whereas the `contracts/results.schema.yaml` for `interpretability_overlap` defines fields `overlap_top5` and `overlap_meets_threshold` (a boolean). The plan must either include the required `overlap_meets_threshold` field (derived from the p‑value) or modify the schema to accept the additional fields.
- Feature selection (bias check) drops descriptors with |r| > 0.6 *before* the data is split (Section 5.6). Using the target variable to decide which predictors to keep prior to cross‑validation introduces data leakage, inflating model performance and invalidating the statistical comparison.
- The plan allows the use of an "approved surrogate" target when experimental permeability is absent, but provides no concrete, verifiable test that the surrogate is independent of the descriptor set. Without enforcing independence, the surrogate could be derived from the same descriptors, creating a circular validation where the model is trained to predict a target that is a function of its inputs.
- The deterministic overlap metric maps each standard descriptor to a fixed SMARTS pattern and then counts overlaps between top‑5 GNN substructures and top‑5 descriptor rankings. Because the mapping is predefined and not derived from data, the metric does not provide an independent validation of interpretability; it merely measures agreement with a hand‑crafted correspondence, which may bias the result toward confirming the hypothesis.
