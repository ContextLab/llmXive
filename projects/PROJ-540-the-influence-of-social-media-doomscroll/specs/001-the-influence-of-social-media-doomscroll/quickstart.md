# Quickstart: The Influence of Social Media "Doomscrolling" on Anticipatory Anxiety

## Prerequisites
- Python 3.11+
- Internet access (to download the three verified parquet files)
- Linux/macOS environment with ≥ 2 CPU cores (CPU-only; no GPU needed)

## Installation

```bash
git clone <repo-url>
cd projects/PROJ-540-the-influence-of-social-media-doomscroll
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Running the Full Pipeline

```bash
python code/main.py
```

### What the pipeline does
1. **Ingestion** (`code/ingest.py`): downloads the three verified parquet URLs (NLP text corpora), computes SHA-256 checksums, and validates each against `contracts/dataset.schema.yaml`. **Current expected outcome**: none contains the required survey variables, so the pipeline writes `output/results/regression_results.json` with `data_status = "HALTED_NO_VALID_DATASET"` and a nested `halt_report` (real column inventories + missing-variable list) and halts per the FR-001 edge case. If a future verified dataset passes, cleaning (listwise deletion, N ≥ 30 hard stop) proceeds to `data/processed/cleaned_data.csv`.
2. **Modeling** (`code/model.py`): construct-distinctness check, OLS fit, correlation, assumption diagnostics, conditional robustness check — only when real validated data exists.
3. **Visualization** (`code/viz.py`): `output/plots/scatter_regression.png` with regression line and 95% CI.
4. **Validation** (`code/validate_sc.py`): reads the real outputs and writes `outputs/success_criteria_log.txt` with PASS/FAIL/BLOCKED-PENDING-DATA per SC-001–SC-005 plus the evidence each verdict is based on.
5. **Sign-off** (`outputs/signoff_report.json`): references the archive hash, checksums, and all produced artifacts.

## Verification Checklist
- `data/raw/` contains the three downloaded parquet files with recorded SHA-256 checksums.
- `output/results/regression_results.json` exists and is the SSoT for both outcomes: either `data_status = "HALTED_NO_VALID_DATASET"` with a nested `halt_report` (current expectation, real column inventories) or full regression results plus `output/plots/scatter_regression.png` — with **no placeholder or hard-coded values anywhere**. (There is no standalone `halt_report.json`.)
- `outputs/success_criteria_log.txt` was generated by executing `code/validate_sc.py` (not hand-written).
- `artifacts/project_artifact.zip` exists and contains `data/`, `outputs/`, and `code/`.
- `runtime` ≤ 60 seconds (SC-005).

## Troubleshooting

| Symptom | Likely Cause | Remedy |
|---------|--------------|--------|
| Halt at schema validation | No verified dataset contains the required variables (current known state). | Expected behavior per FR-001 edge case; see the nested `halt_report` in `regression_results.json`. To obtain statistical results, a verified dataset with the required schema must be added and the spec re-scoped. **Do not substitute synthetic data.** |
| N < 30 after cleaning | Excessive missingness. | Hard stop per FR-002; analysis cannot proceed. |
| VIF > 10 | Predictor collinearity/coupling. | Check `vif_scores`; coupled `baseline_anxiety` is auto-dropped with `coupling_risk`. |
| Robustness skipped | `social_media_engagement` absent or r ≤ 0.3. | Expected per FR-006; reason recorded in `flags`. |
