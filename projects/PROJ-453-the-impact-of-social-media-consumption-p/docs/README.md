# The Impact of Social Media Consumption Patterns on Cognitive Flexibility

## Overview
This project analyzes the associational relationship between social media consumption patterns (specifically switching frequency) and cognitive flexibility scores using public survey datasets.

## Disclaimer
**Associational Only**: This study reports associational estimates only; no causal claims are made.

## Project Structure
- `data/`: Raw and processed data
- `code/`: Analysis scripts
- `results/`: Model outputs and figures
- `contracts/`: Schema definitions
- `docs/`: Documentation

## Quickstart
1. Install dependencies: `pip install -r code/requirements.txt`
2. Run feasibility check: `python code/00_feasibility_check.py`
3. Run ingestion: `python code/01_ingest.py`
4. Run engineering: `python code/02_engineer.py`
5. Run model: `python code/03_model.py`
6. Run visualization: `python code/04_visualize.py`
