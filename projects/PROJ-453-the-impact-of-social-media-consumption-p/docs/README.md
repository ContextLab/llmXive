# The Impact of Social Media Consumption Patterns on Cognitive Flexibility

This project investigates the association between social media consumption patterns (specifically switching behavior) and cognitive flexibility using public survey data.

## Project Structure

- `code/`: Python scripts for data ingestion, engineering, modeling, and visualization.
- `data/`: Raw and processed datasets.
- `results/`: Model outputs, figures, and reports.
- `contracts/`: Schema definitions for data and model outputs.
- `docs/`: Documentation.

## Prerequisites

- Python 3.11+
- `pip`

## Installation

```bash
pip install -r code/requirements.txt
```

## Usage

Run the pipeline as described in `docs/quickstart.md`.
