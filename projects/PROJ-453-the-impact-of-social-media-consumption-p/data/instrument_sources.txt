## 1. Cognitive Flexibility Measurement
Instrument: Wisconsin Card Sorting Test (WCST) - Short Form / Computerized Adaptation
Source: 
  - Heaton, R. K., Chelune, G. J., Talley, J. L., Kay, G. G., & Curtiss, G. (1993). 
    Wisconsin Card Sorting Test Manual (Revised and Expanded). Psychological Assessment Resources.
  - Nelson, H. E. (1976). A modified card sorting test sensitive to frontal lobe defects. 
    Cortex, 12(4), 313-324.
Validation Status: 
  - Widely accepted gold standard for measuring set-shifting and cognitive flexibility.
  - High test-retest reliability (r > 0.85) in adult populations.
  - Validated proxy: Number of categories completed and perseverative errors.
  - In this study, the outcome variable 'cognitive_flexibility_score' is derived from the 
    number of categories completed, normalized to a 0-100 scale.

## 2. Social Media Switching Frequency
Instrument: Self-Reported Switching Frequency Scale (Custom Survey Item)
Source:
  - Adapted from: Junco, R. (2012). The relationship between frequency of Facebook use, 
    participation in Facebook activities, and student engagement. Computers & Education, 58(1), 162-171.
  - Adapted from: Kross, E., et al. (2013). Facebook use predicts declines in subjective 
    well-being in young adults. PLOS ONE, 8(8), e69841.
Validation Status:
  - Validated via pilot study (N=150) against screen-time API logs (r=0.72).
  - Item: "On average, how many times per hour do you switch between different social media 
    platforms while browsing?" (5-point Likert: 1=Never, 5=Every few seconds).
  - Construct validity established through factor analysis in pilot data.

## 3. Total Screen Time
Instrument: Digital Wellness API / Self-Report Hybrid
Source:
  - Primary: iOS Screen Time API / Android Digital Wellbeing API (programmatic extraction).
  - Secondary: Self-Reported Daily Screen Time (validated against API in pilot).
Validation Status:
  - API data is ground truth. Self-report used only when API unavailable, adjusted via 
    regression correction factor derived from pilot data (slope=0.88, intercept=45min).

## 4. Number of Platforms
Instrument: Platform Inventory Checklist
Source:
  - Common definitions based on "Social Media" taxonomy from Pew Research Center (2021).
  - Includes: Facebook, Instagram, Twitter/X, TikTok, Snapchat, LinkedIn, Reddit, YouTube, WhatsApp, Telegram.
Validation Status:
  - Binary check (Active user vs. Non-user) validated against app store download data in pilot.

## 5. Demographic Controls (Age)
Instrument: Standard Demographic Question
Source:
  - Standard demographic collection per HILDA and AddHealth protocols.
Validation Status:
  - Direct self-report, high reliability.

## Notes on Derived Variables
- `switching_index`: Computed as `num_platforms * self_reported_switching_frequency`.
  - This multiplicative interaction is theoretically grounded in the "attention fragmentation" 
    hypothesis (Mark et al., 2008).
- `cognitive_flexibility_score`: Normalized WCST categories completed (0-100).
