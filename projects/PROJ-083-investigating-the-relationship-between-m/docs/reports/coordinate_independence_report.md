## 1. Methodology

This report validates the scientific premise that topological indices (Wiener, Balaban, Zagreb) are true invariants under the defined symmetry group $G$ for Electrophilic Aromatic Substitution (EAS). As defined in `docs/reports/symmetry_group_definition.md` (Task T043), $G$ represents the group of graph automorphisms that preserve the aromatic ring structure and the electrophilic attack site.

To demonstrate **Coordinate Independence**, we perform the following steps:
1. **Sample Selection**: A random sample of 50 distinct EAS reactant molecules is drawn from `data/processed/eas_reactions.csv` (generated by Phase 5, Task T015).
2. **Symmetry Group Application**: For each molecule, we generate the set of all valid permutations $\{ \pi_1, \pi_2, \dots, \pi_k \}$ corresponding to the automorphisms in $G$.
3. **Index Calculation**: For every permutation $\pi_i$, we reconstruct the molecular graph and calculate:
 * Wiener Index ($W$)
 * Balaban Index ($J$)
 * Zagreb Index ($M_1$)
4. **Variance Analysis**: We compute the maximum absolute deviation for each index type across all permutations for a given molecule:
 $$ \Delta_{max} = \max_{i,j} | \text{Index}(\pi_i) - \text{Index}(\pi_j) | $$
5. **Failure Condition**: If $\Delta_{max} > 10^{-9}$ for any molecule, the test fails, and the specific transformation is logged.

The theoretical expectation is $\Delta_{max} = 0$ for all indices, as these are graph invariants derived from the adjacency matrix, which is invariant under simultaneous row/column permutations corresponding to automorphisms.
