## Unresolved concerns

- The ‘empirical‑spatial’ condition uses coordinates generated by Multidimensional Scaling (MDS) on the shortest‑path distance matrix of the same Barabási‑Albert graph (see FR‑011). Because these coordinates are derived from the network topology, distance‑based transmission probabilities are confounded with topological distance. This violates Principle VI (Spatial‑Topology Decoupling) and makes it impossible to attribute any observed change in epidemic threshold solely to geographic proximity. A more valid spatial embedding should be independent of the graph structure (e.g., assign random Euclidean positions or use a real‑world network with genuine coordinates).
- Phase 7 – Contract Validation is not referenced by any Functional Requirement (FR‑*) or Success Criterion (SC‑*) in the specification, constituting an over‑reach beyond what the spec mandates.
- The plan generates a synthetic Barabási‑Albert graph (≈10 k nodes) as the primary network because no real‑world scale‑free network with geographic coordinates is available. FR‑001 requires loading a *real‑world* scale‑free network; using a fully synthetic topology means the study cannot assess genuine geographic effects on an actual network, making the dataset inappropriate for the research question.
- The parameter sweep (β₀ from 0.01 to 0.5 in 0.01 steps, three λ values) combined with 50 Monte‑Carlo runs per configuration and 100 coordinate randomisations results in >7 000 SIR simulations. Even with the guard‑rail to truncate after 5 h, this workload is unlikely to finish within the 6‑hour, 2‑core, 7 GB free‑tier CI limit, violating FR‑007 and the computational boundedness principle.
- The task `sir_simulator.run(beta, lambda_, seed)` uses the parameter name `beta`, but the JSON‑Schema contract (`contracts/simulation_output.schema.yaml`) defines the field as `beta_0`. This naming mismatch could cause validation failures or confusion when mapping simulation outputs to the contract.
- The plan derives node Euclidean coordinates via Classical MDS on the all‑pairs shortest‑path distance matrix of the *same* Barabási‑Albert graph that is later used for SIR transmission. Consequently, the distance‑based transmission probability βᵢⱼ = β₀·e^{‑λ·dᵢⱼ} is a deterministic function of the underlying topology. The validation compares this ‘spatial’ model against a null that randomises those MDS‑derived coordinates. Because both the predictor (distance) and the outcome (epidemic spread) are rooted in the same topology, the analysis cannot cleanly isolate an *independent* geographic effect; it risks a circular/tautological validation where any observed difference may simply reflect the way distances were constructed from the graph itself rather than genuine external spatial structure.
