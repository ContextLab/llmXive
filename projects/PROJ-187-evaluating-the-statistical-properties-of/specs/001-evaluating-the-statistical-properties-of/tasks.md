# Tasks: Evaluating Statistical Fidelity of Synthetic Data Generation Techniques

**Inputs**: `specs/001-statistical-fidelity/spec.md`, `specs/001-statistical-fidelity/plan.md`, data model, metric‑results contract, existing code base, reviewer feedback.

The research question is: *To what extent do summary statistics, correlation structures, and distributional shapes in synthetic tabular datasets generated by CTGAN, DP‑GAN, and CopulaGAN faithfully reproduce those of the original real datasets?*  

All tasks respect the CPU‑only constraint, write only to project‑owned directories (`code/`, `data/`, `outputs/`, `specs/`), and include explicit verification steps.

## Phase 2 – Metric computation, controls, and sensitivity analysis

- [ ] T006 [US2] **Compute fidelity metrics and apply Benjamini‑Hochberg correction**  
  *Files*: `src/metrics/marginal.py`, `src/metrics/correlation.py`, `src/metrics/significance.py`  
  *Actions*  
  - **Marginal**: For each continuous column compute mean, variance, KS statistic + p‑value; for each categorical column compute χ² (or Fisher’s exact when expected < 5). Detect zero‑variance synthetic columns when the real column has variance, flag as fidelity failure, and skip KS (FR‑011).  
  - **Correlation**: Compute Pearson and Spearman matrices for real hold‑out and synthetic data; calculate absolute differences per pair. Run a permutation‑based correlation test (1 000 permutations) for each pair. Additionally compute Fisher’s z‑transformed correlation deviations (`fisher_z_deviation`).  
  - **Significance**: Aggregate all raw p‑values per dataset, apply Benjamini‑Hochberg correction (α = 0.05), store corrected p‑values, and classify a column/pair as faithful only when (i) corrected p ≥ 0.05 **and** (ii) effect‑size thresholds hold (KS ≤ 0.1 for continuous, χ² ≤ χ²₀.₉₅ for categorical).  
  - Write results to `outputs/metrics/metric_results.json`, which must conform to `contracts/metric_results.schema.yaml`.  
  *Verification*  
  - `pytest tests/contract/test_metric_schema.py` validates the JSON against the schema.  
  - `pytest tests/unit/test_faithful_rule.py` confirms dual‑criterion logic on handcrafted cases.  
  - `tests/unit/test_zero_variance.py` verifies graceful handling of FR‑011.

- [ ] T007 [US3] **Create control‑perturbation, marginal‑perturbation, and random‑noise baseline datasets**  
  *Files*: `src/analysis/controls.py` (implementation)  
  *Actions*  
  - **Correlation‑perturbation control** (FR‑021): For each column of the real hold‑out, independently permute all rows (100 % permutation, seed 42). Save as `outputs/control/corr_perturb_<dataset>.parquet` with metadata `perturbation_type: full_row_permutation`, `fraction_permuted: 1.0`, `seed: 42`. This preserves marginals exactly while destroying all dependence, providing a ground‑truth for false‑positive rates of correlation tests.  
  - **Marginal‑perturbation control** (FR‑022): For each column, randomly permute **50 %** of its rows (uniform selection, seed 42) while leaving the remaining 50 % unchanged. Save as `outputs/control/marginal_perturb_<dataset>.parquet` with metadata `perturbation_type: partial_row_permutation`, `fraction_permuted: 0.5`, `seed: 42`. This perturbs marginals but largely retains the original dependence structure, giving a ground‑truth for false‑negative rates of marginal tests.  
  - **Random‑noise baseline** (FR‑019): Sample each column independently from its empirical marginal distribution (seed 42). Save as `outputs/control/noise_baseline_<dataset>.parquet` with metadata `generation_method: independent_marginal_sampling`. Compute mean absolute Pearson/Spearman differences against the real hold‑out and store in `outputs/summary/noise_baseline_correlation.csv`.  
  *Verification*  
  - `pytest tests/unit/test_controls.py` asserts: (i) marginal‑perturbation control passes marginal KS tests but shows high correlation fidelity, (ii) correlation‑perturbation control passes all marginal tests and yields near‑zero inter‑column correlations, (iii) noise baseline exhibits |Pearson| < 0.05 and non‑significant KS p‑values, and (iv) all side‑car metadata files contain the correct seeds and fractions.

- [ ] T008 [US3] **Perform sensitivity analysis over p‑value thresholds**  
  *File*: `src/analysis/sensitivity.py`  
  *Actions*  
  - Sweep thresholds `{0.01, 0.05, 0.10}` for the faithful/unfaithful classification on the real model outputs.  
  - For each threshold, compute:  
    * False‑positive rate = proportion of correlation‑perturbation tests flagged faithful (should approximate the nominal α).  
    * False‑negative rate = proportion of marginal‑perturbation tests flagged faithful (should be low).  
    * Stability metric = number of columns whose faithful/unfaithful status changes across thresholds (SC‑004).  
  - Estimate statistical power for KS and χ² tests (using observed effect sizes) and list columns with `power_estimate < 0.8` in a `power_filtered` field.  
  - Output `outputs/analysis/sensitivity_results.json` containing per‑threshold tallies, FP/FN rates, stability metric, and power notes.  
  *Verification*  
  - `pytest tests/unit/test_sensitivity.py` validates JSON structure, correct rate calculations against the known ground‑truth labels of the control datasets, and accurate stability computation on a small subset.

- [ ] T009 [US2] **Aggregate metrics across seeds and produce summary tables**  
  *File*: `src/analysis/aggregation.py`  
  *Actions*  
  - Aggregate `metric_results.json` over the three seeds per (dataset, model, metric) to compute mean ± SD, mean effect size, and fraction of faithful columns. Write `outputs/summary/aggregated_metrics.csv` (columns: `dataset, model, metric_type, mean_statistic, std_statistic, mean_effect_size, std_effect_size, fraction_faithful`).  
  - Create `outputs/summary/sc003_baseline_comparison.csv` containing each model’s mean absolute Pearson/Spearman distortion alongside the random‑noise baseline distortion from T007.  
  - Although FR‑018 forbids overall superiority claims, include paired significance tests **only** for exploratory reporting (paired t‑test if normal, otherwise Wilcoxon) and store results in `outputs/summary/paired_tests.csv` with a clear disclaimer that no superiority claim is made.  
  *Verification*  
  - `pytest tests/unit/test_aggregation.py` checks correct mean/SD calculations on a handcrafted subset, proper test selection based on normality, and presence of baseline comparison rows.

- [ ] T010 [US2] **Generate visual artifacts for every (dataset, model, seed) triple**  
  *File*: `src/visualization/plotters.py`  
  *Outputs*  
  - For each combination, create a directory `outputs/figures/<dataset>_<model>_seed<NN>/` containing:  
    * KDE marginal PDFs side‑by‑side with empirical histograms for each continuous column.  
    * QQ‑plots comparing real vs. synthetic continuous columns.  
    * Correlation heatmaps for real, synthetic, and their difference.  
  - All figures saved as PNG (minimum 600 dpi).  
  *Verification*  
  - `pytest tests/unit/test_figures.py` asserts that each figure directory contains non‑empty PNG files for KDE, QQ, and heatmap variants after the corresponding `metric_results.json` is available.
