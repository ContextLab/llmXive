# The Impact of Visual Attention on Recall of Emotional Stimuli in Rapid Visual Sequences

**Project ID**: PROJ-484
**Branch**: main

## Overview

This project investigates the relationship between visual attention metrics (specifically fixation duration) and the recall of emotional stimuli presented in rapid visual sequences (RSVP). It implements a pipeline for data ingestion, preprocessing, mixed-effects modeling, and visualization.

## Structure

- `data/`: Raw and processed datasets
- `code/`: Python modules for the analysis pipeline
- `artifacts/`: Generated figures and logs
- `specs/`: Project specifications and contracts
- `tests/`: Unit and integration tests
