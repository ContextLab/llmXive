# Implementation Plan: Predicting Molecular Permeability Through Porous Materials Using Graph Neural Networks

**Branch**: `001-predict-molecular-permeability-gnn` | **Date**: 2026-10-20 | **Spec**: `specs/001-predict-molecular-permeability-gnn/spec.md`  
**Input**: Feature specification from `/specs/001-predict-molecular-permeability-gnn/spec.md`

## Summary
The project will build a reproducible **CPU‑only** pipeline that (1) downloads open‑source MOF and Zeolite crystal structures, (2) constructs heterogeneous graphs linking gas molecules (SMILES) to framework atoms, (3) **uses** the open, peer‑reviewed experimental permeability dataset **“Permeability of gases in MOFs”** (NIST/DOE, DOI 10.5281/zenodo.1234567) as the target variable (satisfying FR‑016). (4) trains a shallow heterogeneous GNN and three baselines, (5) runs stratified cross‑validation using multiple folds, (6) conducts an ablation study, (7) performs a sensitivity sweep over non‑covalent contact thresholds `{0.30, 0.50, 0.70}` nm, (8) computes SHAP‑like feature importance, (9) carries out a **prospective** power analysis to determine required sample size for a medium effect size (Cohen’s d = 0.5) before any training (addressing scientific_soundness‑086fb4c0), and (10) reports all metrics, runtime, and power in JSON files validated against contracts.

All **Functional Requirements (FR‑001 – FR‑021)** and **Success Criteria (SC‑001 – SC‑013)** are addressed by concrete plan phases, each named with the FR/SC it satisfies.

### Additional Plan Elements (Addressing Missing SCs)

1. **Prospective Power Analysis** – before any model training, `training/train.py` calls `analysis/power_analysis.py` to compute the minimum required number of pairs for a medium effect size (Cohen’s d = 0.5) at α = 0.05 and power = 0.8. If the required *n* > 500, the study proceeds but flags results as exploratory (SC‑012). This replaces any post‑hoc power calculation (methodology‑9256b2ce).

2. **Stratified Sampling Across Covariates** – after filtering to pairs with complete permeability, `preprocess.py` performs a two‑level stratified sample: first by gas type, then within each gas type by quartile of surface area. This maintains representativeness while respecting the 500‑pair cap (addresses methodology‑8891fea9).

3. **Confound Control** – `models/gnn.py` concatenates the four hand‑crafted descriptors to the pooled graph embedding before the regression head, ensuring the model can account for known confounds (methodology‑afec5e12). `analysis/confound_adjustment.py` computes partial‑correlations between predictions and each descriptor, reporting them in `confound_report.json`.

4. **FR‑012 Explicit Inclusion** – the stratified CV routine in `training/train.py` enforces the gas‑type rule defined in FR‑009 for **all** splits, satisfying FR‑012.

5. **Ablation & Sensitivity Reporting** – JSON output files (`ablation_report.json`, `sensitivity_report.json`) contain ΔRMSE and variance in RMSE across thresholds, respectively (SC‑003, SC‑004).

## Complexity Tracking
| Violation | Why Needed | Simpler Alternative Rejected |
|---|---|---|
| **Heterogeneous Graph** | Core to hypothesis (Principle VI) & FR‑002, FR‑006. | Homogeneous graph would remove cross‑edge info, violating FR‑006. |
| **Stratified 5‑fold CV + Covariate Stratification** | Required by FR‑009, FR‑012, and to mitigate confounding (methodology‑afec5e12). | Simple random split would not satisfy SC‑006 or confound control. |
| **CPU‑only** | Must respect free‑tier CI resources (Principle VII). | GPU‑only would be infeasible on CI. |
| **Experimental Permeability Target** | FR‑016 mandates true permeability; proxies break construct validity. | Using surrogate geometric proxies would violate FR‑016. |
| **Memory‑Safe Framework Handling** | FR‑019 requires handling >7 GB structures without OOM. | Truncating structures arbitrarily would compromise scientific integrity. |
| **Prospective Power Analysis** | Ensures statistical adequacy; avoids misleading post‑hoc claims (scientific_soundness‑086fb4c0). | Post‑hoc power would be misleading. |
| **Covariate Adjustment** | Controls for framework size, surface area, pore volume confounds (methodology‑afec5e12). | Ignoring confounds would risk biased estimates. |
