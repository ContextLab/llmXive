# Physical Model Discussion: Map vs. Territory

## The Map
Computational models (DFTB+, DFT) are "maps" of the molecular territory. They simplify reality by:
- Neglecting solvent effects.
- Using finite basis sets.
- Approximating electron correlation.

## The Territory
The "territory" is the actual physical molecule, governed by the Schrödinger equation. Experimental data (barrier heights) is the only direct measurement of this territory.

## Distinguishing Artifacts from Observables
- **Computational Artifacts**: Basis set superposition error, grid artifacts.
- **Physical Observables**: Reaction rates, barrier heights.

## Ontological Status of Predictions
Predictions are probabilistic estimates, not absolute truths. They must be validated against experimental data to be meaningful.

## Conclusion
While computational models are powerful, they must be grounded in experimental reality. The "map" is useful only if it accurately reflects the "territory."
