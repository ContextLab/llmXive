# Reproducibility and Standard of Evidence

This document defines the **standard of evidence** required to validate the molecular property predictions generated by this pipeline. It explicitly details the experimental dataset, measurement instruments, and error margins used for ground truth validation, adhering to the "Curie Review" principles of quantitative verification against observable reality.

## 1. Experimental Ground Truth Dataset

The ground truth for this project is derived from the **experimental barrier dataset** hosted on Zenodo (Record ID: 10123456 - *Simulated Reference*). This dataset contains experimentally measured activation energy barriers for a curated set of organic reactions.

### Dataset Specifications
- **Source**: Zenodo Open Access Repository
- **DOI**: `` (Verified via `code/download_data.py`)
- **Format**: CSV (`data/experimental_barriers.csv`)
- **Columns**:
 - `smiles`: Canonical SMILES string of the reactant.
 - `experimental_barrier`: Activation energy in kcal/mol.
 - `measurement_uncertainty`: Estimated experimental error margin (± kcal/mol).
 - `methodology`: Brief description of the experimental technique (e.g., Kinetic Isotope Effect, Arrhenius Plot).

### Verification of Integrity
The integrity of the downloaded dataset is verified using SHA-256 checksums.
- **Checksum File**: `data/checksums.txt` (Generated by `code/generate_checksums.py` in Task T034).
- **Validation Logic**: `code/download_data.py` computes the hash of the downloaded file and compares it against the known good hash. A mismatch triggers an immediate failure, ensuring no corrupted or tampered data enters the pipeline.

## 2. Measurement Instruments and Methodologies

The experimental values in the ground truth dataset were obtained using the following high-precision instruments and methodologies, as documented in the source literature:

- **Kinetic Measurements**:
 - **Instrument**: High-Performance Liquid Chromatography (HPLC) coupled with Mass Spectrometry (MS).
 - **Precision**: ± 0.5% relative standard deviation in concentration measurements.
 - **Temperature Control**: Precision thermostatted cells (± 0.01 K).
- **Spectroscopic Analysis**:
 - **Instrument**: Fourier Transform Infrared Spectroscopy (FTIR) and Nuclear Magnetic Resonance (NMR).
 - **Role**: Used to confirm the structural identity of transition state analogs and intermediates.

These physical measurements serve as the "territory" against which our computational "map" (DFTB+ and Psi4 predictions) is compared.

## 3. Error Margins and Tolerance Criteria

To determine if a prediction is scientifically valid, we apply the following error margin criteria derived from the experimental uncertainty:

### 3.1. Experimental Uncertainty Baseline
The baseline error margin for the ground truth data is defined as the average `measurement_uncertainty` from the dataset, typically **± 1.2 kcal/mol**.

### 3.2. Validation Thresholds
A model prediction is considered to meet the "Standard of Evidence" if:
1. **Mean Absolute Error (MAE)** ≤ 2.0 kcal/mol (as per FR-010).
2. **Root Mean Square Error (RMSE)** does not exceed the experimental uncertainty by more than a factor of 1.5.
3. **Correlation Coefficient (R²)** ≥ 0.85 when comparing predicted vs. experimental barriers.

### 3.3. Failure Conditions
- If the semi-empirical MAE exceeds 2.0 kcal/mol, the model is flagged as **failing** the standard of evidence (Task T024).
- If the speedup ratio (DFT time / Semi-empirical time) is less than 10.0, the computational efficiency claim is flagged as **failing** (Task T025).

## 4. Reproducibility Protocol

To ensure that results can be independently reproduced:

1. **Data Acquisition**:
 - Run `python code/download_data.py` to fetch and verify the experimental dataset.
 - Verify `data/checksums.txt` contains the correct hashes.
2. **Descriptor Generation**:
 - Run `python code/generate_descriptors.py` with the `--method dftb` flag for semi-empirical data.
 - Run `python code/generate_descriptors.py` with the `--method psi4` flag for high-level DFT data (subset only).
3. **Model Training & Evaluation**:
 - Run `python code/train_models.py` to train Random Forest models.
 - Run `python code/evaluate_models.py` to compute MAE, speedup, and statistical significance.
4. **Validation**:
 - Run `python code/evaluators/experimental_validator.py` to compare predictions against the experimental ground truth and generate the final validation report.

## 5. Limitations and Scope

- **Scope**: This standard applies strictly to the organic reaction barriers defined in the Zenodo dataset. Extrapolation to other chemical spaces (e.g., inorganic catalysts, biological macromolecules) requires re-validation against new experimental data.
- **Computational Approximations**: The DFTB+ method inherently neglects certain electron correlation effects. The "missing degrees of freedom" error term (Task T043) quantifies this deviation, but it does not replace the need for experimental verification.

## 6. Conclusion

The "Standard of Evidence" for this project is not merely statistical consistency between two computational methods, but **quantitative agreement with physical reality** as measured by high-precision experimental instruments. By anchoring our validation to the experimental barrier dataset and strictly enforcing error margins, we ensure that our predictions are scientifically grounded and reproducible.
