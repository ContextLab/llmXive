# Predicting Molecular Properties from Quantum Chemical Calculations

This project implements an automated pipeline to predict molecular reaction barrier heights using semi-empirical (DFTB+) and high-level (Psi4) quantum chemical calculations, followed by machine learning modeling and sensitivity analysis.

## Quick Start

See `specs/546-predicting-molecular-properties/quickstart.md` for detailed instructions on data fetching, pipeline execution, and artifact generation.

## Addressing Research Concerns

This section summarizes how the project addresses key scientific concerns raised during research review, ensuring the work maintains rigor in calculation, measurement, and physical interpretability.

### Distinction Between Calculation and Measurement (Einstein/Curie)

**Concern**: A calculation, however sophisticated, is not a measurement. Training data derived from quantum calculations inherits the approximations of the underlying theory, and predictions based on such data are inferences, not direct observations.

**Project Response**:
- **Explicit Grounding**: The pipeline distinguishes between the *experimental* barrier heights (sourced from Zenodo ID `1048765`, a curated dataset of measured values) and the *calculated* descriptors (HOMO/LUMO energies, Mayer bond orders) generated by DFTB+ and Psi4.
- **Validation Against Experiment**: The evaluation phase (T022) computes Mean Absolute Error (MAE) against the experimental ground truth, not just against other calculations. This ensures the model's predictive power is measured against real-world observations.
- **Transparency of Approximations**: The project documents the limitations of the semi-empirical (DFTB+) and DFT (B3LYP/def2-SVP) methods. The comparative analysis explicitly acknowledges that DFTB+ is an approximation, while DFT provides a higher-fidelity baseline, yet both remain calculations subject to basis set and functional limitations.
- **No Conflation**: The pipeline does not claim to "measure" properties via calculation. Instead, it uses calculation to generate *descriptors* that are correlated with measured properties, maintaining a clear chain of inference.

### Resource Constraints and Computational Efficiency (Dyson)

**Concern**: Computational resources are finite. A model that requires excessive computation is impractical. The trade-off between accuracy and speed must be quantified.

**Project Response**:
- **Resource Monitoring**: Constitution Principle VII mandates strict resource tracking. The pipeline logs `duration` and `peak_memory_mb` for every calculation to `logs/dft_execution.log` (T017a).
- **Validation**: Task T033b validates that the full pipeline execution stays within the 6-hour runtime and 7GB memory budget. [UNRESOLVED-CLAIM: c_44a7e9a4 — status=not_enough_info] Results are reported in `reports/runtime_validation.json`.
- **Hierarchical Approach**: The pipeline uses a two-tier strategy:
 1. **Semi-Empirical (DFTB+)**: Fast, scalable to the full dataset for initial descriptor generation.
 2. **High-Level (Psi4)**: Computationally expensive, applied only to a stratified subset (max 50 molecules) for baseline validation.
- **Speedup Analysis**: The `track_compute_resources.py` module quantifies the speedup of the semi-empirical approach relative to DFT, providing empirical evidence for the efficiency trade-off.

### Physical Interpretability (Feynman/Pauling)

**Concern**: A model must be interpretable. We need to understand *which* physical features drive the predictions and how robust these features are to perturbations. "There must be arrows" showing the causal pathways.

**Project Response**:
- **Feature Importance**: Task T029 extracts feature importances from the trained Random Forest models, mapping descriptors (HOMO, LUMO, Mayer bond order) to their contribution in predicting barrier heights.
- **Sensitivity Analysis**: Tasks T030b and T031c perform noise injection and threshold sweeps to test the stability of the top-ranked descriptors. The Spearman rank correlation (rho >= 0.9) serves as a quantitative measure of robustness. [UNRESOLVED-CLAIM: c_7bab2e9b — status=not_enough_info]
- **Physical Mapping**: The `evaluators/physical_interpretability.py` module explicitly maps abstract descriptors to physical quantities (e.g., orbital energies to electron stability, bond orders to bond strength), providing a "Feynman pathway" from calculation to physical insight.
- **Structural Constraints**: The `physical_validator.py` (T011c) enforces physical laws (e.g., HOMO < LUMO) on the calculated geometries, ensuring that the underlying data respects fundamental quantum mechanical principles.

### Crystalline State and Hydration (Franklin)

**Concern**: Molecular properties in the solid state are influenced by solvent interactions and crystal packing. An isolated molecule calculation may miss critical environmental effects.

**Project Response**:
- **Dataset Selection**: The Zenodo dataset (ID `1048765`) is curated for gas-phase barrier heights, where solvent effects are minimized or explicitly defined. The project scope is limited to this defined experimental context.
- **Explicit Acknowledgment**: The summary report (`reports/summary_report.md`) and documentation explicitly state that the current pipeline models isolated molecules. Future work would require incorporating solvent models (e.g., PCM, SMD) or explicit solvation shells to address crystalline/hydration effects, as suggested by Franklin's critique.
- **Confounds Analysis**: Task T011 calculates molecular properties (MW, atom count, functional groups) to identify potential confounds, ensuring that the model's predictions are not driven by trivial size effects rather than electronic structure.
