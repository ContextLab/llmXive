# Neural Narrative Networks: Brain‑Inspired Story Generation and Comprehension

This repository implements a brain‑inspired architecture (sparse autoencoder + prefrontal gating) for narrative generation and evaluates its neural similarity against fMRI data from OpenNeuro ds001495. The project also provides a quantized TinyLSTM baseline for comparison.

## Repository Structure

- `code/` – Python source code for data ingestion, model training, generation, and analysis.
- `data/` – Raw downloads (`data/raw/`), processed intermediate files (`data/processed/`), and final results (`data/results/`).
- `figures/` – Generated visualizations.
- `tests/` – Unit and integration tests.
- `contracts/` – JSON‑Schema contracts for validation.
- `specs/` – Feature specifications and planning documents.

## How to Reproduce

1. **Prerequisites**
 - Python 3.11 or newer.
 - Internet access (for downloading OpenNeuro and ROCStories datasets).
 - At least **7 GB** of RAM (the pipeline respects the `max_ram_gb` setting).

2. **Installation**
 ```bash
 # Clone the repository
 git clone <repo-url>
 cd projects/PROJ-595-neural-narrative-networks-brain-inspired

 # Create a virtual environment
 python -m venv venv
 source venv/bin/activate # Windows: venv\Scripts\activate

 # Install pinned dependencies
 pip install -r code/requirements.txt
 ```

3. **Run the Full Pipeline**
 The entry point `code.main` reproduces every step from raw data download through model training, hidden‑state generation, RSA analysis, and result summarisation.
 ```bash
 python -m code.main
 ```
 This command will:
 - Download the OpenNeuro ds001495 fMRI dataset and ROCStories corpus.
 - Extract ROI timecourses, train the sparse autoencoder, generate story representations, compute RSA matrices, run the permutation test, and create visualisations.
 - Write all intermediate and final artifacts to the `data/` and `figures/` directories.

4. **Reproducibility Manifest**
 For full provenance, see **`manifest.json`** generated by task T051. It records:
 - Exact dataset URLs and SHA‑256 checksums.
 - Software versions from `code/requirements.txt`.
 - Git commit hash of the repository.
 - Checksums of every produced file.
 This manifest enables exact replication of the computational environment and data lineage.

5. **Verification**
 After the pipeline finishes, you can verify that all expected outputs exist:
 ```bash
 ls data/processed/neural/
 ls data/results/
 ls figures/
 ```
 Additionally, run the test suite to ensure integrity:
 ```bash
 pytest -v
 ```
