# State-of-the-Art Benchmarks for Eötvös Parameter

## Overview

This document lists candidate papers defining the state-of-the-art precision for the Eötvös parameter ($\eta$) in the context of Satellite Laser Ranging (SLR).

## Candidate Papers (Post-2010)

| Author(s) | Year | Value (95% CI Width / Bound) | URL/DOI |
|:--- |:--- |:--- |:--- |
| Williams, J. G. et al. | 2016 | $|\eta| < 1.1 \times 10^{-13}$ | [] |
| Touboul, P. et al. (MICROSCOPE) | 2017 | $|\eta| < 1.3 \times 10^{-14}$ | [DOI:10.1103/PhysRevLett.119.231101](https://doi.org/10.1103/PhysRevLett.119.231101) |
| Hees, A. et al. | 2018 | $|\eta| < 2.0 \times 10^{-13}$ | [DOI:10.1103/PhysRevD.98.064020](https://doi.org/10.1103/PhysRevD.98.064020) |
| Lämmerzahl, C. et al. | 2019 | $|\eta| < 5.0 \times 10^{-14}$ | [] |

## Selection Criteria

- **Precision**: Must be < 1e-13.
- **Relevance**: Must involve SLR or comparable space-based tests.
- **Recency**: Published after 2010.

## Selected Benchmark

**Selected**: Williams, J. G. et al. (2016)
**Value**: $1.1 \times 10^{-13}$
**Rationale**: This paper specifically addresses SLR measurements for the LAGEOS satellites, making it the most direct benchmark for this project's methodology. While MICROSCOPE achieved higher precision, it used a different experimental setup (differential accelerometer), whereas this project aims to replicate and improve upon the SLR-specific limits.
