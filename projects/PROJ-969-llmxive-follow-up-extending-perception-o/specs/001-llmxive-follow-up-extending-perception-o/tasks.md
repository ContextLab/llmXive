# Tasks: Does context injection reduce the MLLM "Prejudice Gap" (reasoning deficit vs. visual limitation)?

**Inputs**: Active `spec.md`, `plan.md`, data model/contracts in `specs/001-llmxive-follow-up-extending-perception-o/`, verified open dataset `mmbench/ocean` (https://huggingface.co/datasets/mmbench/ocean).

**Compute note (CPU-only, per constitution Principle VII / FR-007 / SC-003)**: All inference runs on the free CPU-only GitHub Actions runner (≤6 h, ≤7 GB RAM): small open-source MLLMs (≤2B parameters, e.g. SmolVLM-Instruct, Qwen2-VL-2B, and the smallest CPU-runnable LLaVA/Table-2 variants) loaded with `device_map="cpu"` and CPU-permitted int8 quantisation (`optimum`/`bitsandbytes` CPU int8), batches ≤20, ≤10 sampled frames per video, fixed seeds. NO GPU execution and NO synthetic/simulated stand-in for model outputs is ever produced: every reported number comes from a real model run on real data. The pre-registered FR-022 fallback (top-15 models and/or 10-frame sampling) is the ONLY permitted reduction from the 27-model Table-2 ensemble, decided pre-inference by T005 and applied uniformly to all conditions; if even the fallback cannot fit the 6 h / 7 GB budget, that is recorded as a scope mismatch and escalated for spec amendment — never silently narrowed further and never fabricated.

## Flagged deviations from spec.md (for kickback / spec amendment)

1. **Dataset (FR-001)**: MM-OCEAN has no verified public URL; the verified open dataset `mmbench/ocean` is the primary data source for all reported results. Flagged for kickback; MM-OCEAN noted as future replication.
2. **Grounding judge (spec Assumptions "grounding validity")**: the spec mandates a blinded `gpt-4-turbo` judge; this project excludes paid APIs and uses kappa-calibrated semantic similarity instead, with an inter-rater-reliability verification (two independent manual dichotomizations, Cohen's kappa ≥ 0.8 on a 30-sample pilot) in T007 to preserve the spec's reliability criterion. Flagged for kickback.
3. **SC-004 scoping**: as written, SC-004's "citation to an injected context phrase" is unsatisfiable in the baseline and noise conditions (no context is injected). Tasks verify SC-004 per condition: the ≥95% citation+grounding threshold applies to the context condition; baseline/noise are checked for valid reasoning strings and grounding scores only. Flagged for kickback.
4. **FR-019 power target**: the spec's FR-019 contains the literal placeholder "[deferred] power", making it untestable as written. Tasks adopt the concrete target consistent with SC-010: ≥80% power to detect Cohen's d ≈ 0.5 (implemented a priori in T014, verified in T009). Flagged for spec amendment.
5. **Code layout**: the plan places code under `src/pipeline/` orchestrated by `python -m src.pipeline.run_all`; tasks build `code/src/...` modules with a single orchestrator `python -m code.src.run_all` (T013). Functional equivalence noted; layout deviation flagged.
