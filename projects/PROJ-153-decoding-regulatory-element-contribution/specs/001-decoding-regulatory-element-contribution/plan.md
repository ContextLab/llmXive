# Implementation Plan: Decoding Regulatory Element Contributions to Phenotypic Plasticity in Yeast

## Summary

This project implements a computational pipeline to identify cis-regulatory elements (CREs) driving phenotypic plasticity in *Saccharomyces cerevisiae* across heat-shock, osmotic, and oxidative stress. The approach integrates ChIP-seq data (for TF binding) and eQTL data (for expression changes) using a linear mixed-model (LMM) framework. The pipeline addresses functional requirements FR-001 through FR-017, ensuring rigorous statistical validation (LRT, permutation, FDR), data hygiene (checksums, streaming), and robustness checks (collinearity, motif validation, FDR sensitivity). The output includes ranked CRE catalogs, statistical reports, and genome browser tracks.

## Complexity Tracking

| Violation | Why Needed | Simpler Alternative Rejected Because |
|-----------|------------|-------------------------------------|
| Linear Mixed-Model (LMM) instead of simple regression | Must account for gene-specific random effects and non-independence of CRE-gene pairs. | Simple regression would inflate Type I error due to unmodeled gene-level variance. |
| Permutation testing | Required for empirical null distribution of β₁ (FR-006). | Asymptotic p-values may be unreliable for small sample sizes or complex dependencies. |
| Multi-stage filtering (FR-011, FR-012, FR-014) | Ensures data quality, reduces bias, and validates CRE-gene links. | Skipping these would risk spurious associations and violate FR-014 validation requirement. |
| FDR sensitivity sweep (FR-003) | Distinguishes biological signal from peak-calling artifacts. | Single threshold analysis would not assess robustness of results to FDR choice. |

## Data Flow & Phase Ordering

1.  **Phase 1 (Download)**: `01_download.sh` fetches data, verifies MD5 (FR-001), and aborts on missing cohort-level data (FR-011).
2.  **Phase 2 (Preprocess)**: `02_preprocess.sh` trims, aligns (MAPQ >= 30), calls peaks (MACS2), and generates `merged_peaks.bed` (FR-002, FR-004).
3.  **Phase 3 (Annotate & Filter)**: `03_annotate.py` adds context. `04_filter.py` applies FR-011, FR-012 (VIF), FR-014 (Motif/Hi-C) filters. Outputs `vif_flags.tsv`.
4.  **Phase 4 (Weight)**: `05_weights.py` calculates weights for valid CREs (FR-015).
5.  **Phase 5 (Model)**: `06_lmm.R` fits LMM with weights, performs LRT and Permutation (FR-005, FR-006).
6.  **Phase 6 (Report)**: `07_report.R` generates PDF (including Causal Limitation, GO, FDR Sweep, Selection Bias) and ranked tables (FR-010, FR-003, FR-017, FR-008).
7.  **Phase 7 (Visualize)**: `08_visualize.py` generates bigWig tracks (FR-009).
