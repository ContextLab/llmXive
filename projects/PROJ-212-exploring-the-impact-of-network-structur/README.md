# PROJ-212: Exploring the Impact of Network Structure on Synchronization in Complex Physical Systems

## Overview
This project investigates the relationship between network topology and synchronization robustness using the Kuramoto model.

## Project Structure
- `code/`: Source code modules
- `data/`: Input and processed data
- `results/`: Simulation and analysis outputs
- `tests/`: Unit and integration tests
- `config.yaml`: Configuration file

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Run main script: `python code/main.py`

## Testing
Run tests: `pytest tests/`

## Configuration
Edit `config.yaml` to adjust seeds, thresholds, and paths.
