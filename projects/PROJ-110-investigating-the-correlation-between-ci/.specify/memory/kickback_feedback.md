## Unresolved concerns

- The primary scientific goal is to test expression differences between MetS cases and controls, yet the plan admits no open dataset provides both RNA‑seq TPM and the five ATP‑III variables. It therefore resorts to an *exploratory* analysis using GTEx with a *synthetic* binary label ("control" for all). A synthetic label does not measure the MetS construct, breaking construct validity and rendering any causal inference about MetS impossible.
- If phenotype data are unavailable, the pipeline generates a synthetic binary label solely for methodological demonstration. Training differential‑expression (ANCOVA) or logistic‑regression models on a label that lacks variance (or is arbitrarily assigned) cannot answer the hypothesis and violates the requirement that the outcome be a valid MetS measurement (FR‑001/FR‑002).
- Logistic regression is fit on the synthetic label (or on a tiny subset of donors with partial phenotype data). With no true case/control variation, the model’s AUC, DeLong test, and coefficient stability are meaningless, violating the causal validity of the predictive claim (SC‑003, FR‑005, FR‑023).
- Power calculations are performed for logistic regression, DE, and correlation assuming realistic effect sizes and sample sizes. However, when the outcome variable is synthetic or missing for the majority of samples, the assumed effect sizes are undefined, making the power analysis irrelevant and misleading.
- The hierarchical mixed‑effects fallback pools biologically similar tissues when < 20 samples per group. Pooling disparate tissues may violate the assumption of a common effect across tissues and can introduce confounding if tissue‑specific expression patterns differ, reducing construct validity of the DE results.
- Correlation analyses are performed with publicly available trait proxies (BMI, HDL, etc.) that are not linked to the same donors in GTEx. Without donor‑level phenotype linkage, gene‑trait correlations are computed across mismatched samples, compromising both construct validity and confound control.
- FR-010 is required to reproduce the DE and logistic‑regression pipelines on an independent cohort and report replication metrics, but the plan explicitly skips external validation and marks it as N/A.
- FR-014 (mixed‑effects linear model with tissue random intercept for gene‑trait correlations) is absent; Phase 6 lists FR‑007, FR‑024, FR‑017, FR‑019 but does not include FR‑014.
- FR-026 mandates a primary cohort that provides both RNA‑seq expression and all ATP‑III clinical variables. The plan states that no such dataset exists and proceeds with GTEx only, violating the requirement.
- FR-030 (PMI sensitivity analysis with ≥ 95 % label concordance) is marked as ‘not applicable, logged’, so the required analysis is not performed.
- FR-031 (document and adjust for systematic PMI shifts) is also marked as ‘not applicable, logged’, leaving the requirement unmet.
- SC-006 (external validation success metrics) cannot be satisfied because the plan skips external validation entirely.
- The plan relies exclusively on the GTEx v8 TPM dataset for expression profiling, but GTEx lacks the required ATP‑III clinical variables for MetS labeling. FR‑026 (and related FR‑001/FR‑002) mandate a primary cohort that provides both RNA‑seq expression and the full set of ATP‑III measurements (e.g., METSIM muscle cohort). Using GTEx with synthetic or absent phenotype data cannot answer the core research question about correlation between circadian gene expression and MetS risk.
- Principle II (Verified Accuracy) requires a ‘Verified datasets’ block listing all external URLs. The plan states that URLs appear in such a block, but no block is present, violating the constitution.
- The plan says `cv_performance.csv` is validated against `logistic_regression.schema.yaml`, but that schema defines predictor‑level fields and does not include CV columns (fold, auc, etc.). No contract for CVPerformance is provided, creating a mismatch between the plan and the contracts.
- The primary research question—testing whether circadian gene expression differs between MetS cases and controls and improves prediction of MetS status—cannot be answered with the data available. GTEx provides expression but lacks the five ATP‑III clinical variables needed for MetS labeling, and the plan falls back to a synthetic binary label ('control' for all) that contains no case variation. Consequently, downstream analyses that require a true case/control outcome (DE, logistic regression, AUC evaluation) are fundamentally unsolvable, making the claimed success criteria (e.g., SC‑001, SC‑003) impossible to achieve.
- Generating a synthetic binary label ('control' for all) when phenotype data are missing leads to a trivial classification outcome with zero variance. Any logistic‑regression or AUC assessment on such a label is mathematically undefined or yields degenerate results, so the validation step (DeLong test vs. 0.5) is circular and provides no scientific insight.
- The plan correlates core circadian gene expression with continuous metabolic traits (BMI, glucose, etc.) that are themselves components of the ATP‑III MetS definition used later to evaluate predictive performance. If the results of these correlations are interpreted as supporting evidence for MetS association without explicitly separating the two analyses, the inference becomes circular: the same clinical variables are used both to define the outcome and to demonstrate gene‑trait relationships.
