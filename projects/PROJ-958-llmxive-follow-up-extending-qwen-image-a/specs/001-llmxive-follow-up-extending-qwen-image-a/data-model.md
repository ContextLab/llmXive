# Data Model: llmXive follow-up: extending "Qwen-Image-Agent: Bridging the Context Gap in Real-World Image Generation"

## Overview
This document defines the data structures used throughout the pipeline, from raw ingestion to final regression results. All data is stored in CSV/JSONL formats for reproducibility and easy inspection.

## Raw Data Sources

### 1. Prompts & Images (IA-Bench)
- **Source**: `data/raw/prompts_ia_bench.jsonl` (and associated image files in `data/raw/images/`)
- **Format**: JSONL / Image Files
- **Schema**:
  - `prompt_id`: Unique identifier (string)
  - `text`: The raw prompt string (string)
  - `source`: Dataset name (string: "IA-Bench")
  - `domain`: Visual domain (string: "photorealistic", "abstract", "illustration", or "unknown")
  - `image_url`: URL or local path to the ground-truth image (string)

## Derived Data

### 2. Ambiguity Scores
- **Source**: `data/derived/scoring_results.csv`
- **Generated By**: `code/scoring.py`
- **Schema**:
  - `prompt_id`: (string)
  - `text`: (string)
  - `parse_depth`: (float) - Max depth of the syntactic parse tree.
  - `clause_count`: (int) - Number of clauses detected.
  - `mtld`: (float) - Measure of Lexical Diversity.
  - `ambiguity_score`: (float) - Weighted average (0.0–1.0).
  - `routing_category`: (string) - "low", "medium", or "high".
  - `error_flag`: (boolean) - True if parsing failed (score defaulted to 0.0).

### 3. Simulation & Routing Logs
- **Source**: `data/derived/routing_logs.csv`
- **Generated By**: `code/router.py`, `code/simulation.py`
- **Schema**:
  - `prompt_id`: (string)
  - `ambiguity_score`: (float)
  - `routing_category`: (string)
  - `execution_path`: (string) - "rule_based" or "agent_simulated".
  - `simulated_tokens`: (int) - Estimated token count for the path.
  - `simulated_latency_ms`: (float) - Simulated time in milliseconds.
  - `expanded_text`: (string, optional) - The expanded prompt text (for rule-based paths).

### 4. Fidelity Deltas
- **Source**: `data/derived/fidelity_deltas.csv`
- **Generated By**: `code/fidelity.py`
- **Schema**:
  - `prompt_id`: (string)
  - `base_fidelity`: (float) - CLIP score for baseline (original prompt) against ground-truth image.
  - `hybrid_fidelity`: (float) - CLIP score for hybrid (expanded prompt) against ground-truth image.
  - `fidelity_delta`: (float) - `hybrid_fidelity - base_fidelity`.
  - `domain`: (string) - Visual domain (if available).
  - `clip_model_version`: (string) - e.g., "ViT-B/32".
  - `note`: (string, optional) - "High_Ambiguity_No_Expansion" if the prompt was routed to the agent path.

### 5. Regression Results
- **Source**: `data/derived/regression_results.json`
- **Generated By**: `code/regression.py`
- **Schema**:
  - `global_knee_point`: (float) - The identified threshold.
  - `global_slope_change`: (float) - Change in slope at the knee point.
  - `f_test_p_value`: (float) - Significance of piecewise vs. linear.
  - `permutation_p_value`: (float) - Significance of fidelity difference below threshold.
  - `domain_results`: (list of objects, optional) - Per-domain knee points and stats (only if metadata exists).
    - `domain`: (string)
    - `knee_point`: (float)
    - `r_squared`: (float)

## Data Flow Diagram
1. **Ingest**: Raw JSONL/JSON + Images → `data/raw/`
2. **Score**: `scoring.py` reads raw → writes `scoring_results.csv`
3. **Route**: `router.py` reads `scoring_results` → writes `routing_logs.csv`
4. **Expand**: `expansion.py` (called by router) generates expanded text for Low/Medium.
5. **Fidelity**: `fidelity.py` reads `routing_logs` + loads images → computes CLIP scores → writes `fidelity_deltas.csv`.
6. **Analyze**: `regression.py` reads `fidelity_deltas` (filtering out "High" if needed) → writes `regression_results.json`.

## Constraints & Validation
- **Ambiguity Score**: Must be in [0.0, 1.0].
- **Routing Category**: Must be one of {"low", "medium", "high"}.
- **Fidelity Delta**: Can be negative (if expansion degrades fidelity).
- **Missing Data**: Rows with `error_flag=True` in scoring are excluded from regression but logged.
- **Domain Metadata**: If missing, `domain_results` in regression output will be empty/null.
