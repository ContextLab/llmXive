# Quickstart: Predicting Plant Disease Severity from Publicly Available Image Data and Meteorological Records

## Prerequisites

*   Python 3.11+
*   `pip`
*   Sufficient disk space (~ GB for raw images and processed data).
*   Internet access (for downloading datasets and Open-Meteo API).

## Installation

1.  **Clone the repository** (or navigate to the project directory).
2.  **Create a virtual environment**:
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows: venv\Scripts\activate
    ```
3.  **Install dependencies**:
    ```bash
    pip install -r requirements.txt
    ```
    *(Note: `requirements.txt` will be generated by the Implementer Agent, but typically includes: `opencv-python`, `scikit-learn`, `pandas`, `numpy`, `requests`, `matplotlib`, `seaborn`, `pytest`)*.

## Data Setup

The pipeline will automatically download the PlantVillage dataset on first run.

1.  **Ensure the `data/raw/` directory exists**:
    ```bash
    mkdir -p data/raw data/interim data/processed artifacts
    ```
2.  **Verify the dataset source**:
    The script will attempt to download from the standard PlantVillage source:
    `https://huggingface.co/datasets/PlantVillage/PlantVillage/resolve/main/PlantVillage.zip`

## Running the Pipeline

The pipeline is orchestrated via `code/main.py`.

### Full Run
Executes the entire workflow: Ingestion -> Feature Extraction -> Weather Linking -> Modeling -> Visualization.
```bash
python code/main.py --mode full
```

### Dry Run (Subset)
Processes only the first 50 images to verify the pipeline logic and memory usage (US-1, Acceptance Scenario 3).
```bash
python code/main.py --mode dry-run --limit 50
```

### Specific Stage
Run only the feature extraction step:
```bash
python code/main.py --stage extract_features
```

## Output Verification

After a successful run, check the following:

1.  **Unified Dataset**:
    *   File: `data/processed/unified_analysis.csv`
    *   Verify: Contains columns `lesion_area_ratio`, `mean_temp_7d`, `residual`.
2.  **Model Results**:
    *   File: `artifacts/results.json`
    *   Verify: Contains `baseline_r2`, `augmented_r2`, `permutation_p_value`, `null_distribution_mean`.
3.  **Visualizations**:
    *   Files: `artifacts/plots/pdp_humidity_temp.png`, `artifacts/plots/sensitivity_analysis.png`.
    *   Verify: Plots exist and show trends.

## Troubleshooting

*   **API Rate Limit**: If the script hangs or errors with "429 Too Many Requests", the code implements exponential backoff. If it persists, **attempt the lightweight NOAA GHCN-Daily fallback** (pre-processed station CSV). If both fail, the specific record is **excluded** and logged.
*   **Memory Error**: If RAM usage exceeds 7 GB, reduce the batch size in `code/config.py` (e.g., `BATCH_SIZE = 100`).
*   **Missing Location**: If a large percentage of images are excluded, check the `logs/warnings.log` for "missing_location" entries. This is expected if the PlantVillage metadata is incomplete.
