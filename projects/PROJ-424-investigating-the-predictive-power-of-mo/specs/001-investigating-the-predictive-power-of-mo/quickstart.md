# Quickstart: Investigating the Predictive Power of Molecular Dynamics for Estimating Diffusion Coefficients

## Prerequisites
- Linux (Ubuntu 22.04), Python 3.11+, ~7 GB RAM, ~14 GB disk, no GPU.

## Installation

```bash
git clone <project-repo>
cd projects/PROJ-424-investigating-the-predictive-power-of-mo
python -m venv .venv && source .venv/bin/activate
pip install -r code/requirements.txt
```

## Data Preparation

Verify `data/raw/nist_refs.json` contains entries for water, ethanol, acetone at 298 K.  
The file is generated by `python data/raw/generate_nist_refs.py` (see T001).

## Run the Pipeline (end‑to‑end, FR‑009 / SC‑006)

```bash
# Single‑solvent, single‑duration, single‑seed run (the minimal case required by T004)
python code/pipeline.py --solvent water --duration 1 --seed 0
```

The command above executes:
1. Loading of the curated NIST reference data.
2. A seeded 1 ns OpenMM NPT simulation for water.
3. MSD extraction, linear regression, R² check, diffusion coefficient calculation.
4. MAE computation against the experimental reference.
5. Writing of a schema‑validated row to `data/processed/diffusion_results.csv`.

```bash
# Full batch execution (later tasks)
python main.py --full-batch
```

`results/` will contain figures and tables generated by later analysis stages.

## Verification Checklist

| Check | Where |
|-------|------|
| CSV file exists and contains one schema‑valid row | `data/processed/diffusion_results.csv` |
| No validation errors reported by the pipeline | Pipeline exit code indicating successful completion. |
| Simulation trajectory and log files written | `data/raw/simulations/` |
| MAE computed and recorded | Column `mae` in the CSV |

## Troubleshooting
- **OpenMM import fails** – ensure `openmm==8.1.1` is installed via `requirements.txt`.
- **R² < 0.95** – the run will be marked `convergence_failed`; check the log file.
- **Wall‑clock > 5.5 h** – a warning is logged per FR‑004; the pipeline still completes.
