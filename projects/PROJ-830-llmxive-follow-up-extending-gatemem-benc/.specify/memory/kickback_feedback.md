## Unresolved concerns

- The plan proposes a Linear Mixed‑Effects Model (LMM) with `score ~ method + (1|domain)` for each metric, but Access Control and Forgetting are binary outcomes. Using a linear (Gaussian) LMM on binary data violates distributional assumptions; a logistic mixed‑effects model (or appropriate link function) should be used.
- Only four domains are available (medical, office, education, household). Treating `domain` as a random intercept with such a small number of levels yields unstable variance estimates and may not satisfy the assumptions of mixed‑effects modeling.
- The power assessment is deferred and merely states “if power < 0.8, results are exploratory”. No concrete power analysis (effect size, α, sample size per domain) is provided, leaving the study at risk of being under‑powered to detect the hypothesised effects.
- Multiple‑comparison correction is applied across the three primary metrics, but each metric is compared against two baselines (Retrieval‑only and Long‑Context). This effectively entails six hypothesis tests; the correction should account for all six comparisons to control the family‑wise error rate.
- The Access Control metric is defined as “Unauthorized requests (ground‑truth `leak_target=False`) / those **allowed** by the pipeline”. This denominator (allowed requests) varies across pipelines, making the metric non‑comparable across methods and conflating the construct with the gatekeeper’s filtering behavior.
- The plan states that the Gatekeeper’s decision logic will invoke Llama‑3‑8B via a “free‑tier inference endpoint”. Llama‑3‑8B is a ~8 B‑parameter model that cannot be served on the GitHub Actions free‑tier CPU runner and typically requires a paid API or GPU resources. This makes the proposed end‑to‑end evaluation infeasible under the platform’s free‑compute constraints.
- The Verified Datasets table lists the GateMem dataset URL but does not mention the dataset’s license or any usage restrictions. The constitution (Principle III) requires that dataset licensing be documented to ensure compliance. Add a citation of the dataset’s license (e.g., Apache‑2.0, CC‑BY‑4.0) and a brief statement confirming that the license permits redistribution and commercial‑free use.
- The plan specifies using a Linear Mixed‑Effects Model (LMM) `score ~ method + (1|domain)` for each metric, including Access Control and Forgetting which are binary outcomes. LMM assumes normally distributed residuals, which is violated for binary data; a Generalized Linear Mixed‑Effects Model (e.g., logistic) should be used instead. Continuing with LMM may produce invalid inference.
