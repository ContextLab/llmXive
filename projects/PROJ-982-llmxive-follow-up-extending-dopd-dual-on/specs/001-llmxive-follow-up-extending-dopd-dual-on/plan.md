## Summary

This feature implements a discrete-state Markov Decision Process (MDP) environment to isolate and test the "privilege illusion" phenomenon in reinforcement learning. The core approach involves constructing a synthetic grid-world where a "Teacher" agent observes a privileged hidden state variable `H` while a "Student" agent only observes the projection `O`. We will implement two training regimes: (1) Uniform On-Policy Distillation (baseline) and (2) Dual On-policy Distillation (DOPD), which dynamically weights the distillation loss based on the Teacher's advantage gap. The project concludes with a statistical generalization analysis (Mann-Whitney U test) across multiple random seeds to determine if DOPD mitigates the performance drop when the privileged signal is masked during evaluation.

## Complexity Tracking

| Violation | Why Needed | Simpler Alternative Rejected Because |
|-----------|------------|-------------------------------------|
| **Custom MDP Wrapper** | Required to enable simulation of information asymmetry (hidden state H) which is the core mechanism of the "privilege illusion" hypothesis. | Standard environments cannot simulate the specific failure mode where the Student mimics a Teacher using unavailable information. |
| **50 Seeds** | Statistical power for Mann-Whitney U test to detect moderate effect sizes (per FR-005). | A small number of seeds (per some guidelines) is insufficient to rule out variance in stochastic grid-world dynamics for this specific hypothesis. |
| **Tabular Q-Learning** | Required to eliminate neural network dynamics (Constitution Principle VI). | Neural networks introduce optimization artifacts (gradient noise, local minima) that confound the isolation of the "privilege illusion" mechanism. |
