# Methods Section Update for Paper Draft

This document details the specific methodological updates required for the `docs/paper_draft.md` file, focusing on the **Rarefaction** and **Nested Cross-Validation** procedures as implemented in the project.

## 1. Rarefaction Procedure
The rarefaction step was implemented to normalize sequencing depth across all samples before downstream statistical analysis.
- **Implementation**: The `rarefy_samples` function in `code/02_preprocessing.py` performs the subsampling.
- **Depth Selection**: The rarefaction depth was set to the minimum read count observed among all retained samples after quality filtering.
- **Methodology**: Subsampling was performed *without replacement* to ensure that the total number of reads per sample is exactly equal to the minimum depth.
- **Justification**: This approach adheres to Spec FR-002, which mandates the use of Rarefaction to avoid biases introduced by uneven sequencing depths, superseding any initial plans for CSS normalization.
- **Outcome**: The output is a uniform count table where every sample has the same number of reads, enabling valid comparisons of relative abundance.

## 2. Nested Cross-Validation for Predictive Modeling
To rigorously evaluate the predictive performance of the Random Forest model while avoiding data leakage during hyperparameter tuning, a nested cross-validation scheme was employed.
- **Outer Loop (Evaluation)**: A 5-fold cross-validation split the dataset into training and hold-out test sets. The performance metric ($R^2$) was calculated on the hold-out set.
- **Inner Loop (Tuning)**: Within each training fold of the outer loop, a 3-fold cross-validation was used to perform a grid search over hyperparameters (e.g., `n_estimators`, `max_depth`).
- **Implementation**: The `nested_cv_random_forest` function in `code/04_predictive_modeling.py` orchestrates this process.
- **Significance Testing**: The resulting mean $R^2$ from the outer loop was compared against a null distribution generated by 1000 permutation tests (shuffling the target variable) to determine statistical significance (95th percentile threshold).
- **Robustness**: This method ensures that the reported performance is unbiased and generalizable, accounting for the variability in hyperparameter selection.

## 3. Integration with Correlation Analysis
The rarefied data was subsequently transformed using Centered Log-Ratio (CLR) transformation before being used in the Spearman correlation analysis (Section 2.4 of the paper draft). This two-step process (Rarefaction -> CLR) ensures that the correlation analysis is robust to compositional effects and sequencing depth variations.

## 4. Validation
All preprocessing and modeling steps include strict validation checks:
- **Null Check**: No null values are permitted in the final analysis dataset (T015/T017).
- **Memory Check**: Resource guards enforce a 7GB RAM limit (T008/T035).
- **Overlap Check**: The merge of AGP and HRS data requires at least 500 overlapping samples (T014/T018).
