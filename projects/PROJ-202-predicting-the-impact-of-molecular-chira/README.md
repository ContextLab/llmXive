# PROJ-202: Predicting the Impact of Molecular Chirality on Flavor Perception

This project implements a CPU-tractable pipeline to analyze the stereoselective binding of enantiomeric pairs to olfactory receptors and correlate these computational findings with sensory perception data.

## Structure
- `code/`: Pipeline scripts and utilities
- `data/`: Raw, processed, and interim data artifacts
- `tests/`: Unit and integration tests
- `specs/`: Feature specifications and design documents
