- Task T013 mandates a 'pre-bundled, checksummed, and pre-mapped CSV' of 50 known PCMs at `data/external/bundled_pcms_mapped.csv` as a fallback. This violates Constitution Principle I (Reproducibility) which states 'External datasets MUST be fetched from the same canonical source on every run' and Principle III (Data Hygiene) which forbids un-verified data sources. The spec/plan only authorizes fetching or curating; hard-coding a dataset in the codebase introduces non-reproducible, potentially fabricated data.
- Task T019 instructs generating a 'SHAP-derived symbolic proxy' (linear formula) if PySR fails. This violates FR-007 which requires 'explicit mathematical formulas' from symbolic regression. A linear proxy derived from a Random Forest is not a symbolic regression result and masks the failure of the core research capability. The spec/plan requires flagging the limitation, not substituting a trivial model that does not meet the 'symbolic' requirement.
- Task T023 relies on `top_n` from `config.yaml`/`validation_config.json` but SC-003 defines success as '≥ 60% accuracy on the top [deferred]'. The task does not enforce the logic that `top_n` must be derived from the literature dataset size (min of 10 or total) as required by the spec's success criteria, creating a testability gap where the success metric cannot be evaluated if `top_n` is arbitrary.
- Task T006a requires executing `target_consistency_check.py` as a blocking step but does not explicitly mandate that the execution must succeed in *writing* the artifact (`data/results/target_decision.json`) before the phase is complete. If the fetch (T005a) fails silently or the script errors, the pipeline may proceed with a missing target decision, violating the blocking prerequisite logic.
- Task T026c requires reading the 'Assumptions' section from `plan.md` verbatim. However, `plan.md` contains a 'Critical Data Strategy Update' and 'Assumptions' section, while `spec.md` also has an 'Assumptions' section.
