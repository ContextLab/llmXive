# Investigating the Relationship Between Brain Network Dynamics and Anticipatory Reward Processing

This project implements a pipeline to analyze the relationship between dynamic functional connectivity (dFC) flexibility and ventral striatum activation during reward anticipation tasks, using data from the Human Connectome Project (HCP).
