# Documentation: DFT-D3 Dispersion Transferability to Ionic Liquids

This directory contains the final documentation artifacts for project
PROJ-735, which investigates the transferability of DFT-D3 dispersion
corrections to ionic liquid systems.

## Documents

### 1. Benchmark Report (`benchmark_report.md`)
Comprehensive analysis of DFT-D3(BJ) interaction energies against CCSD(T)/CBS
references for 20 ion pairs. Includes:
- Raw and scaled energy metrics (MAE, RMSE, MSE)
- Bootstrap confidence intervals
- Scaling factor optimization and hypothesis testing
- Discussion of limitations and recommendations

### 2. Correlation Report (`correlation_report.md`)
Statistical analysis of correlations between dispersion terms and bulk
properties (density, viscosity). Includes:
- Pearson and Spearman correlation coefficients
- Bootstrap confidence intervals for all correlations
- Bonferroni-corrected p-values
- Key finding: Significant correlation between dispersion-only error and viscosity

### 3. Review Response (`review_response.md`)
Formal response to reviewer feedback from simulated Marie Curie and Linus
Pauling reviews. Addresses:
- Uncertainty quantification methods
- Experimental validation roadmap
- Many-body dispersion considerations
- Dataset limitations and future work

## Notes

- **Dataset**: Current reports are based on the 20-pair synthetic fallback
 dataset (`data/IL-Benchmark-local.zip`) required for CI/CD reproducibility.
- **Limitation**: The small dataset size (20 vs. ≥100 assumed in specifications)
 limits statistical power. Results should be interpreted with caution until
 validated on larger, real experimental datasets.
- **Future Work**: Integration of real experimental lattice energies and
 many-body dispersion corrections is planned for subsequent iterations.
