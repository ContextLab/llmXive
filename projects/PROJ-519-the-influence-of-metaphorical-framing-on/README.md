# The Influence of Metaphorical Framing on Attitudes Towards Mental Health Treatment

This project implements a research pipeline to analyze how metaphorical framing (Battle, Journey, Medical) influences attitudes towards mental health treatment.

## Structure
- `src/`: Source code for data ingestion, analysis, and visualization.
- `tests/`: Unit and integration tests.
- `data/`: Raw, processed, and derived data files.
- `config/`: Configuration files.
- `specs/`: Project specifications and contracts.

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Run tests: `pytest`
3. Execute pipeline: `python src/main.py` (once implemented)
