# PROJ-082: Investigating the Correlation Between Structural Brain Connectivity and Individual Music Preferences

An automated science pipeline for meta-analysis of brain connectivity and music preference studies.

## Overview

This project implements a robust data analysis pipeline that investigates the correlation between structural brain connectivity (white matter tracts) and individual music preferences. The pipeline supports both quantitative meta-analysis (when sufficient data exists) and narrative synthesis (when data is scarce).

## Key Features

- **Real Data First**: Prioritizes real datasets from `data/raw/studies.csv`.
- **Graceful Fallback**: Automatically switches to mock data or narrative synthesis if real data is missing or insufficient (`N < 10`).
- **Statistical Rigor**:
 - Random-Effects Meta-Analysis (DerSimonian-Laird).
 - Hartung-Knapp adjustment for low-power studies.
 - Egger's regression for publication bias.
 - Bonferroni correction for multiple comparisons.
- **Memory Safety**: Uses streaming and memory monitoring for large datasets.
- **Reproducibility**: Deterministic mock data generation with configurable seeds.

## Usage

### Running the Pipeline

The main entry point is `code/main.py`.

**Standard Run (Real Data First):**
```bash
python code/main.py
```
- Checks for `data/raw/studies.csv`.
- If found and valid (`N >= 10`): Runs quantitative meta-analysis.
- If found but `N < 10`: Runs narrative synthesis.
- If missing: Falls back to mock data (seed 43) and runs the appropriate path.

**Force Mock Data:**
```bash
python code/main.py --use-mock --config=quant
```

**Configuration Options:**
- `--config`: Select mock dataset type (`fallback`, `quant`, `bonferroni`).
- `--use-mock`: Bypass real data check and use mock data.

### Generating Specific Artifacts

- **Mock Data**: `python code/data/generate_mock_data.py --config quant`
- **Lexicon**: `python code/config/generate_lexicon.py`
- **Plots**: Automatically generated by `code/main.py` if quantitative path is taken.

## Data Policy

### Real Data First
The pipeline is designed to prioritize real empirical data. It attempts to load `data/raw/studies.csv` first.

### Fallback Behavior
- **No Fetch Failures**: The system does **not** crash if external data sources are unreachable. Instead, it falls back to local mock data.
- **Mock Data**: Generated using `numpy` with fixed seeds to ensure reproducibility.
 - **Seed 43**: Default quantitative mock (N=15).
 - **Seed 44**: Bonferroni-specific mock.
- **Narrative Path**: If `N < 10`, the pipeline skips statistical pooling and generates a narrative summary instead.

## Pipeline Execution Order

1. **Setup**: Initialize directories and config.
2. **Data Validation**: Check `data/raw/studies.csv` (T009b).
3. **Extraction**: Parse studies, convert p-values to r, extract qualitative data.
4. **Meta-Analysis**:
 - Count studies (T014a).
 - Run Random-Effects model if `N >= 10` (T014).
 - Apply Hartung-Knapp if `10 <= N < 20` (T041).
5. **Bias & Heterogeneity**: Egger's regression (T017), I² (T018).
6. **Correction**: Bonferroni adjustment (T021).
7. **Visualization**: Forest, Funnel, Correlation plots (T024-T026).
8. **Narrative**: Generate summary if quantitative path skipped (T015b-T015c).
9. **Reporting**: Generate paper draft (T032).
