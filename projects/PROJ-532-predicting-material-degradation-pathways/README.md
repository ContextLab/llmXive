# Project: Predicting Material Degradation Pathways

**Project ID**: PROJ-532
**Status**: In Progress

## Overview
This project implements an automated pipeline to predict material degradation pathways from compositional data using machine learning.

## Structure
- `code/`: Source code for ingestion, preprocessing, training, and analysis.
- `data/`: Raw and processed datasets.
- `results/`: Model artifacts, metrics, and plots.
- `specs/`: Feature specifications and data models.
- `tests/`: Unit and integration tests.

## Prerequisites
- Python 3.11+
- Dependencies listed in `code/requirements.txt`

## Execution
Run the pipeline via `python code/ingestion.py` followed by `python code/preprocessing.py` and `python code/training.py`.
