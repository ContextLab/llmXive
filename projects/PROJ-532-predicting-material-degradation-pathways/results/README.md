# Results Directory

This directory stores all output artifacts generated by the modeling and analysis pipeline.

## Structure

- `metrics/`: JSON files containing performance metrics (e.g., F1 scores, confusion matrices).
- `plots/`: Visualizations (PNG, SVG) such as SHAP summaries and threshold sensitivity plots.
- `artifacts/`: Serialized model objects (e.g., `.pkl` files) and intermediate state.

## Usage

These files are generated by the training and evaluation scripts. Do not manually edit
these files; re-run the pipeline to regenerate results if inputs or parameters change.
