# Data Directory

This directory stores all data artifacts for the Material Degradation Pipeline.

## Structure

- `raw/`: Contains raw, unmodified data downloaded from external sources (e.g., Zenodo).
- `processed/`: Contains cleaned, preprocessed, and feature-engineered data ready for modeling.

## Provenance

All files in this directory are generated by the pipeline scripts located in `code/`.
Checksums and metadata for raw data are recorded in the corresponding processing logs.

## Usage

Do not manually edit files in `raw/`. Files in `processed/` should be regenerated
by running the ingestion and preprocessing pipelines if source data changes.
