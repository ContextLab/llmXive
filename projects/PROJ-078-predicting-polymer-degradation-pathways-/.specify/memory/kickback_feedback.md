## Unresolved concerns

- The plan admits the primary datasets lack 'degradation pathway labels' and proposes training on 'synthetic label distribution' or 'small subset of manually curated examples'. Training a supervised model to predict specific chemical mechanisms (hydrolysis vs oxidation) on synthetic labels or a tiny, unverified subset invalidates the causal/associational claims in the spec. The model will learn the synthetic noise or the bias of the tiny subset, not the true structure-mechanism relationship. This approach cannot answer the research question.
- The plan relies on Integrated Gradients and permutation tests to validate 'structure-mechanism relationships'. However, if the ground truth labels (hydrolysis/oxidation) are missing or synthetic (as admitted in Dataset Strategy), the permutation test null distribution is meaningless. You cannot statistically validate that a model learned a real chemical mechanism if the target variable it was trained on does not represent that mechanism. The validation framework collapses without valid ground truth.
- The spec assumes 'degradation pathways labeled in the source datasets are considered ground truth'. The research phase explicitly refutes this assumption by stating no such verified labels exist in the available open sources. The plan proceeds with a methodology (supervised GNN) that is fundamentally dependent on this false assumption. The project cannot achieve its stated success criteria (SC-005: identifying ester bonds in top attribution for hydrolysis cases) without valid hydrolysis labels.
- The plan claims to 'validate findings using Integrated Gradients and permutation tests'. Given the data gap identified in research.md, these tests will only validate the model's ability to memorize synthetic patterns or the specific small subset used, not generalizable chemical degradation pathways. The proposed analysis does not support the conclusion that the system can predict polymer degradation pathways.
- FR-001 mandates downloading from 'NIST Chemistry WebBook and Materials Project APIs'. The plan.md (Research section) explicitly states these specific verified datasets are missing and the implementation will use 'generic SMILES datasets' as a proxy. The plan lacks a concrete task or data-model entity to satisfy the specific ingestion requirement of FR-001, creating an unbacked functional requirement.
- FR-008 requires validating the presence of 'degradation pathway' labels and flagging/excluding records if missing. The plan.md (Research section) admits the proxy datasets lack these labels entirely and proposes training on 'synthetic label distribution'. The plan does not define a mechanism to satisfy FR-008's validation logic for the actual data being used, leaving the requirement unbacked.
- SC-005 requires verifying that Integrated Gradients identifies 'ester bonds' in the top attribution scores for ≥90% of hydrolysis cases. The plan.md acknowledges the lack of ground-truth hydrolysis labels in the available data. Without a mechanism to generate or validate these specific labels, the success criterion cannot be measured, leaving SC-005 unbacked.
- SC-004 requires a power analysis warning if the dataset is <150 instances. The plan.md (Research section) notes the available proxy datasets are generic SMILES without degradation counts, and the '150' figure is an assumption. The plan does not specify how the power analysis will be triggered or measured against the actual (unknown) count of usable degradation records, leaving the measurement undefined.
- The plan proposes using 'synthetic label distribution' to train the model. This is a significant deviation from the spec's requirement to predict 'observed degradation pathways' (FR-001, FR-008). The plan should explicitly state this as a scope reduction or a 'simulation mode' to align with the spec's intent, rather than implying the original FRs are satisfied with synthetic data.
- The plan explicitly states that the 'Verified datasets' block contains NO verified source for polymer degradation records and that the available SMILES datasets (maykcaldas/smiles-transformers, HUBioDataLab/SELFormer-smiles) lack the required 'degradation pathway' labels and environmental conditions. The plan proposes to 'simulate' the pipeline with synthetic labels or a small manual subset. This is a wrong-dataset scenario: the cited resources (generic SMILES) do not contain the target variable (degradation pathway) required by FR-001 and US-1. Training a supervised model to predict hydrolysis/oxidation on data without these labels is scientifically invalid; the model cannot learn the mapping. The plan must identify a real dataset containing (SMILES + Degradation Pathway + Environment) or acknowledge the project cannot proceed as a supervised learning task.
- The plan assumes a dataset size of '~150 instances' and 'up to ~200 polymer records' based on an assumption that NIST/Materials Project contain these records. However, the research phase (research.md) confirms these specific records are NOT in the verified list. The plan proceeds with a 'fallback' of using generic SMILES data which lacks the necessary labels. This creates a fundamental mismatch: the compute plan (6 hours, 7GB RAM) is sized for a specific dataset that does not exist in the cited sources. The feasibility of the analysis is contingent on a dataset that the plan admits is missing the core target variable.
- Plan claims alignment with Principle VI (Computational Chemistry Validation) which mandates a 'χ² statistical test'. However, the Plan's 'Statistical Validation' section and the Spec (FR-006) only define a 'Permutation Test'. The χ² test is absent from the implementation plan, creating a direct violation of the Constitution's mandatory validation requirement.
- Plan claims alignment with Principle VII (Small Dataset Robustness) regarding '5-fold cross-validation (or LOOCV if n<50)'. The Spec (SC-004) and Constitution (Principle VII) state the threshold is <150 instances for triggering power analysis/warnings, but the Plan's fallback logic (LOOCV) is triggered at n<50. This creates a gap where datasets between 50-149 instances are not covered by the specific robustness strategy defined in the Constitution.
- The 'Project Structure' section lists `contracts/polymer_record.schema.yaml` and `contracts/model_output.schema.yaml`. However, the `data-model.md` and `contracts/` directory in the input also define `motif_importance.schema.yaml`. The plan omits this contract from its structure list, creating an inconsistency between the documented structure and the actual defined artifacts.
- The 'Constraints' section states 'dataset size limited by open-source availability (assumed ~150 instances)'. The Research.md explicitly confirms that verified datasets with degradation labels DO NOT exist and the plan must use 'synthetic label distribution' or 'SMILES proxies'. The Plan's assumption of ~150 *degradation records* contradicts the Research finding that such records are unavailable, risking a fundamental data gap in the implementation.
- The plan admits the ground-truth labels (degradation pathways) are missing from available open datasets and proposes training on 'synthetic label distribution' or 'small subset of manually curated examples' (research.md). Training a supervised classifier on synthetic labels to predict real-world chemical mechanisms is scientifically invalid; the model will learn the synthetic distribution, not chemical reality. This renders the core research question unanswerable with the proposed data strategy.
- The plan validates the model by checking if Integrated Gradients identifies 'ester linkages' in hydrolysis cases (SC-005, plan.md). However, the model is trained on synthetic or missing labels. If the model is trained on synthetic data, the attribution will reflect the synthetic generation rules, not chemical causality. Validating a model trained on synthetic data against a chemical prior (ester bonds) is a circular/tautological check: the model is only 'valid' if it mimics the synthetic rules that were likely derived from the same chemical priors. This does not validate predictive power on real data.
- The plan proposes using 'bond rotation' and 'atom masking' for data augmentation (research.md). In polymer chemistry, bond rotation changes conformation (3D geometry) but not connectivity (topology), which is what GNNs typically use. Atom masking removes atoms, fundamentally altering the molecule's identity and potentially its degradation pathway. Augmenting a dataset of 150 specific polymers by destroying their chemical identity (masking) or changing their conformation (rotation) to create 'new' training samples introduces noise that does not represent the true distribution of polymer degradation, invalidating the statistical generalization.
- The plan uses a permutation test on 'input motifs' to validate significance (FR-006). However, if the labels are synthetic or missing (as admitted in research.md), the null distribution generated by shuffling motifs against synthetic labels is meaningless. A permutation test validates the relationship between X and Y; if Y is synthetic, the test only validates the model's ability to fit the synthetic noise, not a real structure-mechanism relationship.
- The plan claims to use 'Integrated Gradients' to identify 'ester linkages' as a validation target. Integrated Gradients provides feature attribution for a *trained* model. If the model is trained on synthetic labels (as per the data strategy), the attribution scores are artifacts of the synthetic training process. Using these scores to claim 'scientific validity' of the structure-mechanism mapping is methodologically unsound because the ground truth for the training process was not empirical.
