# Data Model: llmXive follow-up: extending "AlayaWorld: Long-Horizon and Playable Video World Generation"

## 1. Overview

This document defines the data structures used for the symbolic state, visual state, and drift analysis. All data is stored in JSON/JSONL format for portability and checksumming.

## 2. Entity Definitions

### 2.1 Action Sequence
A discrete list of user inputs driving the simulation.
- **Fields**: `sequence_id`, `seed`, `actions` (list of strings), `timestamp_start`.

### 2.2 Symbolic State Log
The deterministic ground truth generated by the rule-based engine.
- **Fields**: `sequence_id`, `timestep`, `objects` (list of state objects), `global_state`.

### 2.3 Visual State Log
The state derived from computer vision analysis.
- **Fields**: `sequence_id`, `timestep`, `detected_objects` (list of detected states), `confidence_scores`.

### 2.4 Drift Result
The computed metric and metadata for a single sequence.
- **Fields**: `sequence_id`, `drift_score`, `is_valid`, `reason`, `resource_metrics`.

### 2.5 Ground Truth Annotation
Manually annotated frames for validation.
- **Fields**: `frame_id`, `sequence_id`, `timestep`, `objects` (ground truth), `annotator_id`.

## 3. File Manifest

| File Path | Description | Format |
|-----------|-------------|--------|
| `data/raw/action_sequences.json` | Input action sequences | JSON |
| `data/processed/symbolic_logs.json` | Symbolic state trajectories | JSON |
| `data/processed/visual_logs.json` | Visual state trajectories | JSON |
| `data/annotated/gt_subset_50.json` | Manually annotated frames (≥50) | JSON |
| `data/results/baseline_scores.json` | Drift scores (vanilla) | JSON |
| `data/results/hybrid_scores.json` | Drift scores (corrected) | JSON |
| `data/results/stats_comparison.json` | T-test results | JSON |
| `data/results/final_results.csv` | Aggregated summary | CSV |
| `data/results/experiment_log.json` | Full execution log | JSON |
| `config/params.yaml` | Configuration (e.g., error injection prob) | YAML |

## 4. Data Flow

1. **Input**: `action_sequences.json` → `symbolic_engine.py` → `symbolic_logs.json`.
2. **Input**: `action_sequences.json` + (Real/Simulated Video) → `cv_pipeline.py` → `visual_logs.json`.
3. **Validation**: `gt_subset_50.json` + `visual_logs.json` → `drift_analyzer.py` → `accuracy_check` (Pass/Fail).
4. **Analysis**: `symbolic_logs.json` + `visual_logs.json` → `drift_analyzer.py` → `baseline_scores.json` / `hybrid_scores.json`.
5. **Statistics**: `baseline_scores.json` + `hybrid_scores.json` → `stats_runner.py` → `stats_comparison.json`.
6. **Aggregation**: All results → `final_results.csv` + `experiment_log.json`.
