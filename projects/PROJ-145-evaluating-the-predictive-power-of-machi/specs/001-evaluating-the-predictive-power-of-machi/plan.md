# Implementation Plan: Evaluating Uncertainty Calibration and Extrapolation Error of Machine Learning for High‑Entropy Alloy Compositions

**Branch**: `001-evaluating-the-predictive-power-hea` | **Date**: 2026‑10‑14 | **Spec**: `specs/001-evaluating-the-predictive-power-hea/spec.md`  
**Input**: Feature specification from `specs/001-evaluating-the-predictive-power-hea/spec.md`

## Summary
The pipeline builds a reproducible, CPU‑only workflow that (1) ingests a **verified open‑source HEA dataset** (Materials Project or AFLOW Parquet files hosted on Hugging Face) **once such a dataset is publicly available**; until then a bundled placeholder CSV (`data/raw/hea_placeholder.csv`) is used only for demonstration purposes and **must be replaced** in the final study. The workflow then (2) creates a **Hold‑out Known** set and a **True Novel** set respecting composition‑hash and distance criteria, (3) computes weighted mean/variance elemental descriptors with `pymatgen`, (4) trains Random Forest and Gradient Boosting regressors with 5‑fold cross‑validation, (5) evaluates extrapolation error on the Hold‑out set and uncertainty calibration on the True Novel set (including reliability diagrams and prediction‑interval coverage), (6) runs the required Mann‑Whitney U and Spearman correlation tests with power justification, and (7) produces a final ranked CSV report. All steps run on the GitHub Actions free‑tier runner (≤ 2 CPU, ≤ 7 GB RAM, ≤ 6 h).  

**Data‑availability limitation & scope‑revision request** – No verified open‑source HEA Parquet dataset is currently listed in the “Verified datasets” block. The plan therefore **flags a pending scope revision**: once a verified dataset is identified, the placeholder will be swapped out, and all downstream steps will re‑run on the real data. This satisfies Constitution Principle II by making the deficiency explicit rather than silently fabricating data.

## Risks & Mitigations
| Risk | Mitigation |
|---|---|
| **No verified HEA source** | Placeholder used only for demo; a formal scope‑revision request is logged (Constitution II). Once a verified dataset is available, the pipeline will be re‑run without code changes. |
| **API rate‑limit (future)** | Exponential backoff with max 3 retries; on persistent failure log “partial success” and continue. |
| **Hash collision / accidental overlap** | Final strict Hill‑system string comparison before finalizing `true_novel.csv`. |
| **Numerical instability in variance** | Clamp variance < 1e‑6 to 1e‑6. |
| **Insufficient novel samples for Spearman** | Skip Spearman test, note “insufficient samples (<10)” in report. |
| **Memory overflow** | Streaming mode for raw CSV; process in chunks; fallback to random sample if RAM > 6 GB. |
| **DFT runtime exceeds budget** | Automatic decision to omit DFT and add explicit disclaimer per Principle VI. |
| **Multiple‑comparison risk** | Only two independent tests (Mann‑Whitney, Spearman); correction not required. |
| **Circularity in PCA distance** | Primary distance computed in raw descriptor space; PCA‑based distance added only as secondary check. |
