# Data Dictionary

This document defines all data artifacts generated, intermediate, and processed within the Honeybee CCD GWAS pipeline.
It specifies the purpose, schema, and lifecycle constraints for each file.

## 1. Raw Data (`data/raw/`)

| File Path | Description | Source | Constraints |
|:--- |:--- |:--- |:--- |
| `data/raw/fastq_files/` | Directory containing raw FASTQ reads (R1/R2) for all colonies. | Hugging Face `bee_genome_variants` / SRA | Immutable. Must not be modified after initial download. |
| `data/raw/ncbi_fetch_log.json` | Log of metadata fetches, including checksums and SSL verification status. | Pipeline (`code/01_download.py`) | Immutable. |

## 2. Intermediate Data (`data/interim/`)

These files are generated during the pipeline execution and may be overwritten if the pipeline is re-run.

| File Path | Description | Generated By | Schema/Format |
|:--- |:--- |:--- |:--- |
| `data/interim/synthetic.vcf` | Synthetic VCF for pipeline validation only. | `code/00_generate_synthetic_data.py` | VCF 4.2 |
| `data/interim/raw_variants.vcf` | Raw variant calls from FreeBayes before filtering. | `code/02_align_call.sh` | VCF 4.2 |
| `data/interim/bed.bed` | PLINK binary genotype matrix (0,1,2 encoded). | `code/utils/vcf_to_plink.py` | PLINK BED |
| `data/interim/bed.bim` | **ALL** high-quality SNPs after VCF conversion and basic QC. | `code/utils/vcf_to_plink.py` | PLINK BIM (6 columns: Chrom, SNP, Genetic Pos, Physical Pos, Allele1, Allele2) |
| `data/interim/bed.fam` | Sample metadata (Family ID, Individual ID, Sex, Phenotype). | `code/utils/vcf_to_plink.py` | PLINK FAM |
| `data/interim/bed_pruned.bim` | Subset of SNPs after LD pruning (r² < 0.2). Used for covariate estimation. | `code/utils/preprocess_phenotype.py` | PLINK BIM |
| `data/interim/phenotypes_cleaned.fam` | Harmonized phenotype file with encoded covariates (Geographic, Year, Varroa). | `code/02_harmonize_phenotypes.py` | PLINK FAM (Phenotype column: 0=Healthy, 1=CCD, -9=Missing) |
| `data/interim/phenotypes_harmonized.fam` | Final phenotype mapping ready for GWAS. | `code/02_harmonize_phenotypes.py` | PLINK FAM |
| `data/interim/immune_pathway_snps.txt` | **FILTERED SUBSET**: List of SNP IDs associated with immune pathways. | `code/03_filter_snps.py` | Text (one SNP ID per line) |
| `data/interim/gwas_raw.tsv` | Raw association statistics (p-values, odds ratios) for **ALL** SNPs. | `code/03_gwas.sh` | TSV (SNP, CHR, POS, P, OR, etc.) |
| `data/interim/gwas_fdr.tsv` | FDR-corrected q-values for all SNPs. | `code/utils/fdr_correction.py` | TSV (SNP, Rank, Raw P, Q-Value, Significant) |

### ⚠️ Critical Distinction: `bed.bim` vs `immune_pathway_snps.txt`

It is vital to distinguish between the **full SNP set** and the **candidate-gene subset**:

* **`data/interim/bed.bim`**: Contains **ALL** high-quality SNPs passing standard QC (MAF, missingness, HWE).
 * **Usage**: This file is the input for the primary GWAS statistical test (`code/03_gwas.sh`).
 * **Constraint**: **NEVER** use this file for filtering the GWAS test itself. The GWAS must run on the full set to satisfy the Benjamini-Hochberg FDR requirements (Spec FR-004).

* **`data/interim/immune_pathway_snps.txt`**: Contains a **filtered subset** of SNP IDs derived from `bed.bim` that map to known immune pathway genes.
 * **Usage**: This file is used **ONLY** for downstream functional annotation (`code/05_annotation.py`) and visualization of significant hits.
 * **Constraint**: **NEVER** use this file to restrict the GWAS input or to calculate p-values. Using this list for the statistical test would introduce severe bias and violate the Spec's requirement for genome-wide analysis.

## 3. Processed Data (`data/processed/`)

Final artifacts used for reporting and analysis.

| File Path | Description | Generated By | Schema/Format |
|:--- |:--- |:--- |:--- |
| `data/processed/power_analysis_report.json` | Power analysis results and sample size validation. | `code/utils/power_analysis.py` | JSON (`power_value`, `status`, `n_samples`) |
| `data/processed/gwas_results_fdr.tsv` | **Final GWAS Results**: Merged raw stats and FDR-corrected q-values. | `code/04_apply_fdr.sh` / `code/05_annotation.py` | TSV (SNP, CHR, POS, REF, ALT, Freq, P-Value, Q-Value, Significant) |
| `data/processed/me_estimate.txt` | Estimated effective number of independent tests (Me) for the honeybee genome. | `code/utils/gwas_thresholds.py` | Text (Integer) |
| `data/processed/threshold_sensitivity.json` | Sensitivity analysis of significance thresholds. | `code/utils/threshold_sensitivity.py` | JSON |
| `data/processed/lasso_auc_report.json` | LASSO cross-validation AUC metrics. | `code/04_ml_validation.py` | JSON (`auc`, `status`) |
| `data/processed/prs_scores.tsv` | Polygenic Risk Scores for each colony. | `code/04_ml_validation.py` | TSV (Sample ID, PRS) |
| `data/processed/annotation_results.tsv` | Functional annotation of significant SNPs (Gene, GO Terms). | `code/05_annotation.py` | TSV |
| `data/processed/study_design.md` | Documentation of study design and limitations. | `code/05_document_study_design.py` | Markdown |
| `data/processed/collinearity_report.json` | VIF and correlation matrix for covariates. | `code/04_ml_validation.py` | JSON |
| `data/processed/validation_metrics.json` | Aggregated validation metrics (AUC, PRS LR test). | `code/04_ml_validation.py` | JSON |
