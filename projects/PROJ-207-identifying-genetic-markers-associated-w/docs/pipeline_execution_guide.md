# Pipeline Execution Guide

This document outlines the step-by-step execution order for the Honeybee CCD GWAS pipeline.
Adherence to this sequence is critical to ensure statistical validity and data integrity.

## Critical Execution Order

The following order of operations is MANDATORY:

1. **Load ALL High-Quality SNPs**
 - **Action**: The pipeline must ingest the full set of high-quality SNPs derived from the raw VCF.
 - **Artifact**: `data/interim/bed.bim` (contains all SNPs).
 - **Constraint**: Do NOT apply any candidate-gene filtering at this stage. The statistical analysis must be performed on the complete dataset to maintain the validity of the multiple testing correction.

2. **Run GWAS on ALL SNPs**
 - **Action**: Execute PLINK logistic regression using the full SNP set and harmonized phenotypes.
 - **Script**: `code/03_gwas.py` (invoked via `code/03_gwas.sh`).
 - **Artifact**: `data/interim/gwas_raw.tsv` (contains association statistics for all SNPs).
 - **Constraint**: The input to this step must be the unfiltered `bed.bim` file.

3. **Apply FDR Correction on ALL SNPs**
 - **Action**: Apply the Benjamini-Hochberg (BH) procedure to the raw p-values from the GWAS.
 - **Script**: `code/utils/fdr_correction.py`.
 - **Artifact**: `data/interim/gwas_fdr.tsv` and `data/processed/gwas_results_fdr.tsv`.
 - **Constraint**: Correction is applied to the full set of tests. The q-values reflect the False Discovery Rate across the entire genome scan.

4. **Apply Candidate-Gene Filter (For Annotation Only)**
 - **Action**: Filter the *significant* results (q-value < 0.05) to the immune pathway gene set.
 - **Reference**: `data/interim/immune_pathway_snps.txt` (generated by `code/03_filter_snps.py` / T063).
 - **Usage**: This filtered list is used **ONLY** for downstream functional annotation and visualization.
 - **Constraint**: **NEVER** use this filtered list as input for the GWAS (Step 2) or FDR (Step 3). Doing so would invalidate the multiple testing correction and introduce selection bias.
 - **Script**: `code/05_annotation.py` (uses the filtered list to query Ensembl for significant hits).

## Execution Steps

### 1. Data Loading & Validation
```bash
python code/01_download.py
python code/utils/checksum_verify.py
```

### 2. Power Analysis (Gate)
```bash
python code/06_power_analysis.py
# Halts if power is insufficient
```

### 3. Alignment & Variant Calling
```bash
bash code/02_align_call.sh
```

### 4. Format Conversion & Preprocessing
```bash
python code/utils/vcf_to_plink.py
python code/utils/preprocess_phenotype.py
python code/02_harmonize_phenotypes.py
python code/04_filter_snps.py # Generates immune_pathway_snps.txt (Annotation List)
```

### 5. GWAS Execution (Full Set)
```bash
python code/03_gwas.py --input data/interim/bed --pheno data/interim/phenotypes_harmonized.fam
```

### 6. Multiple Testing Correction
```bash
python code/utils/fdr_correction.py
python code/08_apply_fdr.py # Merges results to data/processed/gwas_results_fdr.tsv
```

### 7. Threshold Sensitivity & ML Validation
```bash
python code/utils/threshold_sensitivity.py
python code/04_ml_validation.py
```

### 8. Functional Annotation (Filtered Set)
```bash
python code/05_annotation.py
```

## Data Artifacts Reference

| Artifact | Path | Description |
|:--- |:--- |:--- |
| Raw SNPs | `data/interim/bed.bim` | **All** high-quality SNPs (Used for GWAS) |
| Immune SNPs | `data/interim/immune_pathway_snps.txt` | Subset for **Annotation Only** |
| Raw GWAS | `data/interim/gwas_raw.tsv` | Association stats for ALL SNPs |
| Final Results | `data/processed/gwas_results_fdr.tsv` | FDR-corrected results for ALL SNPs |
