# Human Pilot Recruitment Protocol

## Objective
Recruit human raters to validate linguistic features against perceived authority density for the MedMisBench subset.

## Prerequisites
- Access to `data/raw/survey_payload.json` (generated by T017a-Code)
- Access to a survey platform (e.g., Prolific, SurveyMonkey, Qualtrics)

## Steps

1. **Prepare Survey Material**
 - Load `data/raw/survey_payload.json`.
 - Each entry contains `prompt_id`, `raw_text`, and `extracted_features`.
 - Format the text for the survey interface, ensuring `raw_text` is clearly presented.

2. **Recruit Raters**
 - Target: ≥50 unique raters.
 - Inclusion Criteria: Native English speakers, familiarity with medical terminology (preferred).
 - Compensation: Follow standard platform rates (e.g., $10/hour equivalent).

3. **Distribute Survey**
 - Present each rater with a random subset of 10-20 prompts.
 - **Task for Raters**: Rate the "Authority Density" of the provided text on a scale of 1-5.
 - Include 2-3 control items with known high/low authority to filter unreliable raters.

4. **Collect Data**
 - Export raw responses to `data/raw/human_pilot_raw.csv`.
 - Ensure columns include: `rater_id`, `prompt_id`, `authority_score`, `control_score` (if applicable).

5. **Upload Data**
 - Once collected, upload `data/raw/human_pilot_raw.csv` to the project repository.
 - Trigger the next pipeline stage (T017c) via `python code/annotation.py`.

## Contingency
If <50 raters are recruited or data quality is poor (see T017c), the pipeline will abort and this protocol must be re-executed.
