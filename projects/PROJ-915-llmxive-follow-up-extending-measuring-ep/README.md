# llmXive Project: PROJ-915-llmxive-follow-up-extending-measuring-ep

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Run setup: `python code/setup_directories.py`
3. Run pipeline: `python code/main.py`

## Directory Structure
- `code/`: Source code
- `data/raw`: Raw data
- `data/processed`: Processed data
- `data/interim`: Intermediate data
- `data/results`: Final results
- `state/`: State files
- `tests/`: Test files
- `docs/`: Documentation
