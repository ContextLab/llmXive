# Visualization Outputs

This directory contains the static image files generated by the visualization module (`code/viz.py`).

## Generated Artifacts

The following plots are generated by the pipeline:

### Histograms
- `histogram_observed_vs_null.png`: Comparison of observed discrepancies against the simulated null distribution.
- `histogram_observed_only.png`: Distribution of observed discrepancies alone.

### Q-Q Plots
- `qq_plot_observed_vs_null.png`: Quantile-Quantile plot comparing observed values to the null model quantiles.

### Heatmaps & Charts
- `heatmap_top_jurisdictions.png`: Heatmap of top 20 jurisdictions by discrepancy magnitude and percentage.
- `bar_top_10_jurisdictions.png`: Bar chart of the top 10 jurisdictions by absolute discrepancy.

## Generation Command

These plots are generated by running:

```bash
python code/viz.py --input data/processed/analysis_results.json --output-dir docs/plots
```

## Dependencies

Ensure the following packages are installed:
- `matplotlib`
- `seaborn`
- `numpy`
- `pandas`
