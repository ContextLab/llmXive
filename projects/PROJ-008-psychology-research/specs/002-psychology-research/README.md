# Specs: Mindfulness Components and Delivery Formats in ASD Social Skills

## Overview
This directory contains the feature specifications, design documents, and
implementation plans for the PROJ-008 meta-analysis project.

## Contents

- **plan.md**: Implementation plan with Constitution Principles and phases
- **spec.md**: Feature specification with user stories and acceptance criteria
- **research.md**: Research question, hypotheses, and methodology
- **data-model.md**: Entity definitions and schema contracts
- **contracts/**: Schema validation definitions (YAML)
- **docs/**: Supporting documentation (ethics, analysis plan, protocol)

## Version Control
All specifications are versioned and stored in the repository. Changes to
specifications require a corresponding update to tasks.md and implementation.

## Constitution Principles
The project adheres to six non-negotiable Constitution Principles:
1. Verified Accuracy
2. Reproducibility
3. Ethical Compliance
4. Data Integrity
5. Fail Fast
6. Clinical Trial Registry Integrity
