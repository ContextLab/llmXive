### The one non-obvious decision (flagged for review)

The grant's key is `(attempt_id,"claim",lane_revision)`, so its id CANNOT be re-derived on
a replay — by then the coordinator's revision has moved, not least because this claim's own
`ClaimAcquired` landed. So `cas_claim` locates:

- `ClaimAcquired` by derived id (its key has no variable component), and
- `ClaimGranted` by TYPE within the Attempt's history (`_granted_in`), which the table makes
  unique — `ClaimGranted` is legal only from `proposal_verified`, never re-entered.

Re-deriving the grant's id from current state would report a complete claim as half-present
and turn the ordinary lost-acknowledgement retry into a hard `LaneInconsistent`.
