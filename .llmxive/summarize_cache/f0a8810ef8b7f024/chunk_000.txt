# Project Plan: llmXive follow-up: extending "Lens: Rethinking Training Efficiency for Foundational Text-to-Image Mo"

## Overview
This project extends the research findings from "Lens: Rethinking Training Efficiency for Foundational Text-to-Image Models" by implementing a rigorous, reproducible pipeline to validate and extend the proposed metrics for training efficiency in text-to-image models.

## Research Context
The original "Lens" paper proposes new metrics for evaluating training efficiency in foundational text-to-image models. This follow-up project aims to:
1. Reproduce key findings from the original paper
2. Extend the analysis with additional statistical validation
3. Implement a robust, CPU-only pipeline for reproducibility
4. Validate the proposed metrics against human preference data

## Project Goals
- **Reproducibility**: Ensure all experiments can be reproduced on CPU-only hardware
- **Statistical Rigor**: Implement proper statistical testing and significance analysis
- **Scalability**: Handle large datasets through streaming and efficient processing
- **Validation**: Validate proposed metrics against human preference data

## User Stories

### US1: Feature Extraction Pipeline
**As a** researcher, **I want** to extract linguistic and syntactic features from image captions **so that** I can analyze the relationship between caption complexity and model performance.

**Acceptance Criteria**:
- Extract linguistic uncertainty proxy using BERT perplexity
- Calculate syntactic depth using dependency parsing
- Compute noun phrase density and token diversity
- Handle edge cases (short captions, BERT failures, timeouts)
- Validate output against schema contracts

### US2: Alignment Deviation Calculation
**As a** researcher, **I want** to calculate the alignment deviation score between CLIP scores and human ratings **so that** I can measure how well automated metrics align with human preferences.

**Acceptance Criteria**:
- Validate presence of CLIP scores and human ratings
- Normalize scores using appropriate statistical methods
- Calculate absolute deviation between normalized scores
- Handle missing ratings and zero variance cases
- Validate output against schema contracts

### US3: Predictive Modeling and Significance Testing
**As a** researcher, **I want** to train a predictive model and perform rigorous statistical significance testing **so that** I can identify which linguistic features significantly predict alignment deviation.

**Acceptance Criteria**:
- Train XGBoost model with proper cross-validation
- Perform permutation-based significance testing
- Apply Benjamini-Hochberg correction for multiple comparisons
- Conduct sensitivity analysis across seeds and thresholds
- Generate stability metrics and feature importance rankings
